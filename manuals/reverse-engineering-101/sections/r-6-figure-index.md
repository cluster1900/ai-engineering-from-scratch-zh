# 图索引

> 本手册的每一张图，按顺序，按它的说明提出的那一条主张。

每一行链到其图，主张是打开说明的那句加粗句子。图里的每一个数字都来自[我们捕获的运行](manuals/reverse-engineering-101/capture/out)，每张图的源从其节链接。颜色遵循前言的调色板：

- 蓝色是 rea、其 CLI、其 MCP 服务器，以及其领域层
- 紫色是 Ghidra provider
- 绿色是夹具文件及其字节
- 梅色是 agent 及其模型调用
- 橄榄色是脚本化与托管代码
- 靛蓝是 MCP 消息与会话
- 琥珀色是生命周期状态，例如主张状态
- 青色是持久记录，例如 Evidence 包
- 玫瑰色是失败或被拒绝的主张
- 灰色是主机、编译器与读者
