## 在 GitHub 上开始本阶段

**先修课程：** 选择一个你已完成其所列阶段的项目。
Terminal-Native Coding Agent 要求完成 Phase 11、13、14、15 和 17。

**起始项目：** [Terminal-Native Coding Agent](01-terminal-native-coding-agent/)

从 repository 根目录运行此命令：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

保留命令、退出码、最终计划状态、预算总额、trace 事件，以及
在连接真实 Model 之前你会修改的架构决策。

**下一步操作：** 从
[完整的 Phase 19 项目列表](../../README.md#phase-19)中选择符合你目标的毕业项目。项目是可选项，
而不是必须依次完成的数字序列。在开始构建前编写验收证据。

使用[跨阶段路线图](../../ROADMAP.md)补齐所有先修知识缺口。
