# Phase 1：数学基础

> 通过代码而非教科书，理解每一种 AI 算法背后的直觉。

## 在 GitHub 上开始本 Phase

**Prerequisites:** 完成 Phase 0，或确认可从 repository 根目录正常使用 Python 3.11+ 和 Git。

**第一课：**[Linear Algebra 直觉](01-linear-algebra-intuition/)

在 repository 根目录运行以下命令：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

保留命令、退出码、归一化 Vector 输出、投影残差，以及一句解释 Matrix-Vector 乘积为何属于 Neural Network 层的话。

**下一步操作：**修改一个输入 Vector，预测结果，再次运行，然后继续学习 [Vector、Matrix 与运算](02-vectors-matrices-operations/)。

浏览 [Phase 1 完整课程列表](../../README.md#phase-1)或[跨 Phase ROADMAP](../../ROADMAP.md)。
