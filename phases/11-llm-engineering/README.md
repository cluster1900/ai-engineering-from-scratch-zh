# Phase 11：LLM Engineering

> 让 LLM 在生产应用中发挥作用。

## 在 GitHub 上开始本阶段

**Prerequisites:** Phase 10 Lessons 01 到 05，或具备同等的
Tokenization、数据流水线、Pretraining 和 Scaling 知识。

**First lesson:** [Prompt Engineering](01-prompt-engineering/)

从 repository 根目录运行以下命令：

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

保留命令、退出码、生成的 Prompt metadata、测试结果，以及一项
Prompt 改动和它造成的输出差异。Demo 使用模拟的 Model 响应，
不需要 API key。

**Next action:** 解释哪个 Prompt 变量改变了行为及其原因，然后
继续学习 [Few-Shot, Chain-of-Thought and Tree-of-Thought](02-few-shot-cot/)。

浏览 [完整的 Phase 11 课程列表](../../README.md#phase-11)或
[跨 Phase ROADMAP](../../ROADMAP.md)。
