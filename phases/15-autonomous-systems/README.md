# Phase 15：自主系统

> 无需人工干预即可安全运行的 Agent。

## 在 GitHub 上开始本 Phase

**Prerequisites:** Phase 14 Lesson 01，Agent Loop。

**第一课：** [长时间运行的 Agent](01-long-horizon-agents/)

在 repository 根目录运行以下命令：

```bash
python3 phases/15-autonomous-systems/01-long-horizon-agents/code/main.py
```

保留命令、退出码、运行时长预测、复合可靠性表，以及在长时间运行前你会要求的一项运维控制措施。

**下一步：** 使用不同的单步可靠性重新计算一条轨迹，然后继续学习[自学式推理](02-star-family-reasoning/)。

浏览[完整的 Phase 15 课程列表](../../README.md#phase-15)或[跨 Phase ROADMAP](../../ROADMAP.md)。
