# Phase 10：从零构建 LLMs

> 构建、训练并理解 LLM。

## 在 GitHub 上开始此阶段

**先修课程：** Phase 5 NLP 基础。在学习 Model 构建课程之前，强烈建议先学习
Phase 7 Transformers。

**第一课：** [Tokenizers](01-tokenizers/)

在 repository 根目录运行此命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

保留命令、退出码、encode/decode 往返结果、学到的 merge 数量
以及压缩比。`tiktoken` 可用于可选对比。

**下一步操作：** 添加一个小型语料库中未出现过的单词，检查其拆分结果，
然后继续学习[从零构建 Tokenizer](02-building-a-tokenizer/)。

浏览[完整的 Phase 10 课程列表](../../README.md#phase-10)或
[跨阶段 ROADMAP](../../ROADMAP.md)。
