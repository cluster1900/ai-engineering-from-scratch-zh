## 在 GitHub 上开始本阶段

**Prerequisites:** Phase 7 Transformers 和 Phase 4 Computer Vision。

**First lesson:** [Vision Transformer Patch Token](01-vision-transformer-patch-tokens/)

在 repository 根目录运行以下命令：

```bash
python3 phases/12-multimodal-ai/01-vision-transformer-patch-tokens/code/main.py
```

记录该命令、退出代码、patch 网格和序列长度、参数数量，
以及一句解释为什么更高的分辨率会产生更多视觉 Token 的话。

**Next action:** 更改一个图像尺寸或 patch 大小，预测序列长度，
然后继续学习 [CLIP 与 Contrastive Pretraining](02-clip-contrastive-pretraining/)。
