# Phase 3：Deep Learning 核心

> 从第一性原理构建 Neural Network。在亲手构建之前，不使用任何 framework。

## 在 GitHub 上开始此 Phase

**Prerequisites:** Phase 1 Linear Algebra Intuition。建议先学习 Phase 2，
以掌握 Model Evaluation 相关术语。

**First lesson:** [Perceptron](01-the-perceptron/)

在 repository root 运行以下命令：

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

保留该命令、退出码、converged gate 结果、单个
perceptron 在 XOR 上的失败结果，以及最终的 two-layer XOR 预测。

**Next action:** 解释为什么单个 linear boundary 无法解决 XOR，然后
继续学习[Multi-Layer Network 与 Forward Pass](02-multi-layer-networks/)。

浏览[完整的 Phase 3 课程列表](../../README.md#phase-3)或
[跨 Phase ROADMAP](../../ROADMAP.md)。
