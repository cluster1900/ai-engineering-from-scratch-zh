# Phase 16：Multi-Agent 与 Swarm

> 协调、涌现与集体智能。

## 在 GitHub 上开始本阶段

**Prerequisites:** Phase 14 Agent Engineering。第一个 TypeScript 演示需要
Node.js 20+ 和 `npx`。

**第一课：** [为何使用 Multi-Agent](01-why-multi-agent/)

在 repository 根目录运行以下命令：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

保留命令、退出码、single-agent 与 multi-agent 的 Token 和 Tool 调用
总数，以及一项能够证明额外协调成本值得付出的权衡。

**下一步：** 修改任务，再次比较两种方法，然后继续学习
[FIPA-ACL 的传承与 Speech Act](02-fipa-acl-heritage/)。

浏览 [Phase 16 完整课程列表](../../README.md#phase-16)或
[跨阶段 ROADMAP](../../ROADMAP.md)。
