# Phase 4：Computer Vision

> 从 Pixel 出发，逐步理解 Image、视频与 3D。

## 在 GitHub 上开始本阶段

**Prerequisites:** Phase 1 Lesson 12（Tensor 操作）和 Phase 3 Lesson 11
（PyTorch 入门）。第一个 Demo 只需要 NumPy。

**First lesson:** [Image 基础](01-image-fundamentals/)

从 repository 根目录运行以下命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

保留命令、退出代码、HWC 和 CHW shape、normalized Channel 统计数据、
往返转换的 Pixel 差异，以及 interpolation 粗糙度。该 Demo 会生成一张
确定性的合成 Image，并且不使用网络。

**Next action:** 解释 HWC 与 CHW 之间发生变化的是哪个轴，然后继续学习
[从零实现 Convolution](02-convolutions-from-scratch/)。

浏览 [Phase 4 完整课程列表](../../README.md#phase-4)或
