# Phase 2：ML 基础

> 经典 ML 仍然是大多数生产级 AI 的支柱。

## 在 GitHub 上开始此 Phase

**Prerequisites:** Phase 1 Math Foundations 和 NumPy。使用以下命令检查路线：
`python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route ml-foundations`。

**First lesson:** [什么是 Machine Learning](01-what-is-machine-learning/)

在 repository root 运行以下命令：

```bash
python3 phases/02-ml-fundamentals/01-what-is-machine-learning/code/ml_intro.py
```

保留该命令、退出码、test accuracy、random baseline，以及一句解释所学 classifier
为何能超过该 baseline 的话。

**Next action:** 修改 class separation，预测 accuracy 将如何变化，
再次运行命令，然后继续学习[从零实现 Linear Regression](02-linear-regression/)。
