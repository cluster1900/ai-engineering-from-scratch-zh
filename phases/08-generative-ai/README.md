# 第 8 阶段：生成式 AI

> 创建图像、视频、音频、3D 内容等。

## 在 GitHub 上开始此阶段

**先修课程：**第 2 阶段 ML 基础、第 3 阶段 Deep Learning 核心，以及
第 7 阶段第 14 课——从零构建 Transformer。

**第一课：**[Generative Model 的分类体系与历史](01-generative-models-taxonomy-history/)

从仓库根目录运行以下命令：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

保留命令、退出码、密度估计、生成的样本，以及一句话，说明隐式 Generator
无法回答关于 `p(x)` 的什么问题。

**下一步：**更改随机种子，比较密度估计，然后继续学习
[Autoencoder 与 VAE](02-autoencoders-vae/)。

浏览[完整的第 8 阶段课程列表](../../README.md#phase-8)或
[跨阶段 ROADMAP](../../ROADMAP.md)。
