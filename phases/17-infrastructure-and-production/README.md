## 在 GitHub 上开始此阶段

**Prerequisites:** Phase 11 LLM Engineering 和 Phase 13 Tools and Protocols。

**First lesson:** [托管式 LLM 平台](01-managed-llm-platforms/)

从 repository 根目录运行此命令：

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

保留命令、退出码、成本与延迟对比、冗余带来的提升，以及一份简短的决策记录，说明你做出选择时所依据的工作负载假设。

**Next action:** 修改一项工作负载或 SLA 输入，解释新的选择，然后继续学习 [Inference 平台经济学](02-inference-platform-economics/)。
