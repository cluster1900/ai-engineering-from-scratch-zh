# Phase 5：NLP，从基础到高级

> 语言是通往智能的接口。掌握每一个层次。

## 在 GitHub 上开始本 Phase

**Prerequisites:** Phase 2 Lesson 14，Naive Bayes。第一课只需要
Python 3.11+。

**第一课：** [文本处理](01-text-processing/)

从 repository 根目录运行此命令：

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

保留命令、退出码、Token 列表、词干、词元，以及一个词干提取丢失含义、
但词形还原保留含义的示例。

**下一步操作：** 添加一个包含标点符号和不规则动词的句子，
检查结果，然后继续学习 [Bag of Words 和 TF-IDF](02-bag-of-words-tfidf/)。

浏览[完整的 Phase 5 课程列表](../../README.md#phase-5)或
[跨 Phase ROADMAP](../../ROADMAP.md)。
