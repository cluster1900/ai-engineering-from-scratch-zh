# Phase 0：环境设置与工具

> 为接下来的一切准备好环境。

## 在 GitHub 上开始本 Phase

**Prerequisites:** 无。开始前需要安装 Git 和 Python 3.11 或更高版本。其他工具仅在所选路线需要时安装。

**第一课：**[开发环境](01-dev-environment/)

在 repository 根目录运行可感知路线的预检：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

保留命令、repository 根目录工作路径、退出码、必需检查结果以及输出的 `Next:` 命令。可选项缺失不算失败。

**下一步操作：**修复每一项必需检查失败，重新运行，直到命令以状态码 0 退出，然后继续学习 [Git 与协作](02-git-and-collaboration/)。

浏览 [Phase 0 完整课程列表](../../README.md#phase-0)或[跨 Phase ROADMAP](../../ROADMAP.md)。
