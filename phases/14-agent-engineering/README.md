# Phase 14：Agent Engineering

> 现代 AI Engineering 的核心。从第一性原理开始构建 Agent。

## 在 GitHub 上开始本 Phase

**Prerequisites:** Phase 11 LLM Engineering 和 Phase 13 Tools and Protocols。

**First lesson:** [Agent 循环](01-the-agent-loop/)

在 repository 根目录运行以下命令：

```bash
python3 phases/14-agent-engineering/01-the-agent-loop/code/main.py
```

保留命令、退出码、思考-行动-观察轨迹、最终答案、轮次计数，
以及结束本次运行的确切停止条件。

**Next action:** 修改脚本任务或轮次预算，预测其影响，
然后继续学习 [ReWOO 与 Plan-and-Execute](02-rewoo-plan-and-execute/)。

浏览 [Phase 14 完整课程列表](../../README.md#phase-14)或
