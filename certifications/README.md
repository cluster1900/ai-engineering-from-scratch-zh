# 认证备考课程体系（Certification Curricula）

> 凭证应当证明你具备真才实干的工程交付能力，而非证明你死记硬背了一套题库。

本部分将公开的权威行业认证大纲转化为完全免费、“手写构建优先”的系统化研读路线。每条路线都将既有的 AI Engineering from Scratch 课程与针对特定认证的专题讲座、交互实验（Labs）、诊断自测及原创模拟试卷有机结合。

## 认证体系（Programs）

每份备战指南均支持在 Claude Code、Codex、ChatGPT、Cursor 或其他编码 Agent 中无缝运行：导师技能会为你挑选最优学习路线，逐课细致讲解，端到端执行动手实验，并将你的学习进度直接持久化保存在本地仓库中。

## 核心原则

- 以公开的考试大纲确定考点覆盖率与权重分配。
- 以官方技术白皮书和协议规范定义当前技术行为。
- 每节课程、每个实验与每道习题均为原创开发。
- 绝无真题泄露（Exam Dumps）、机密试题、包过承诺或应试死记技巧。
- 练习评分展示真实的知识掌握程度，而非厂商官方的折算量表分。
- 亲手构建并交付实打实的代码与工具产物，远胜于被动通读文档。
