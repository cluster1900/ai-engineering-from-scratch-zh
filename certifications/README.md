# 认证课程体系

> 认证证书应当证明你能胜任实际工作，而不是证明你背过题库。

本部分将公开认证蓝图转化为免费、以构建为先的学习
路径。每条路径都将现有的 AI Engineering from Scratch 课程
与认证专属课程、Lab、诊断测试和原创模拟
考试结合起来。

首个项目是 [Claude Certifications](claude/README.md)，覆盖
2026 年 7 月考试指南中发布的全部四项 Claude 认证。

## 规则

- 公开考试指南定义考查范围和权重。
- 官方产品文档定义当前技术行为。
- 每节课程和每道练习题都必须原创。
- 禁止使用考试 dump、机密题目、通过保证或答案模式技巧。
- 练习结果是课程原始分数，而不是官方换算分数。
- 实践产物比被动阅读更重要。
