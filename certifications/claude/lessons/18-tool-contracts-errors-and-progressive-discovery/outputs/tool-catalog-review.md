# Tool 目录审查：支持证据

## 目录边界

政策角色可以使用当前有效政策搜索和来源查找。它无法使用账户 Tool 或写入能力。每个 Tool 都有可感知租户的执行 scope。

## Tool 契约

`search_active_policy`：当支持政策决定答案时使用；不得用于账户事实或公共研究。`read_assigned_account`：当经过身份验证的案例需要账户事实时使用；不得用于政策或其他租户。

## 错误Matrix

验证错误只有在修改输入后才可重试。授权错误在访问权限或批准发生变化前不可重试。依赖项 timeout 可以重试一次，并保留所有部分结果及 trace ID。

## 渐进式发现

初始界面提供对角色获准使用的能力名称进行搜索的功能。专用定义仅在限定 scope 的发现完成后加载；受限名称不会被公开。

## 授权

发现过程绝不授予执行权限。服务会为每次调用检查 principal、tenant、当前 scope、对象所有权和绑定的批准。

## 选择 Fixture

十二个 fixture 涵盖政策问题与账户问题的区分、公共研究、不使用 Tool 的回答、验证、授权、冲突、timeout 和部分结果。
