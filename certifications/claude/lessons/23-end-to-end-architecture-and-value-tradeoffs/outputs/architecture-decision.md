# ADR：合同审查模式

## 决策

选择确定性工作流：接收、分段、版本化 retrieval、分析、独立证据审查、生成修订稿以及法律顾问审批。
负责人：法律技术架构团队。

## 候选方案评分

增强型调用速度最快，但会丧失故障隔离能力。工作流在安全性、可审计性和可预测延迟方面领先。自适应 Agent 仅在未建模的分支处理方面领先。Multi-agent 审查增加了独立性，但不增加写入权限。

## 硬性门禁

授权、租户隔离、来源 provenance 和安全性不能为了便利而折中计算。任何缺乏支持的重大结论都会阻止候选方案通过。

## 故障路径

retrieval 超时会返回部分证据且不生成修订稿。政策冲突会转交法律顾问。无效 schema 会获得一次针对性修复。Tool 中断时使用人工审查队列。回滚会恢复先前的 index 和工作流版本。

## 被拒绝的替代方案

拒绝使用单个巨型增强调用，因为职责和证据会被混在一起。
拒绝使用自适应执行 Agent，因为流程已知，且相关操作需要人工授权。

## 反转条件

如果超过 20% 的已受理案例需要安全、未建模的证据发现，并且经过 Evaluation 的 Agent 能够在不突破成本、延迟或硬性门禁的前提下提高成功率，则重新考虑该工作流。架构负责人负责批准反转。
