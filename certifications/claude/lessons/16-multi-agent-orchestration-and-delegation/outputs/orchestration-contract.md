# 编排契约：Runtime 迁移决策

## 目标与范围

比较三种迁移方案并交付一份决策简报。研究过程为只读。任何 Agent 都不得编辑
repository、联系供应商或选择最终架构。

## 任务与依赖

coordinator 使用互不重叠的主张 ID 分配来源、runtime 和风险研究任务。
所有任务都只能使用允许的只读 Tool。综合阶段必须等待每项必需结果达到 complete
或被明确标记为 partial。独立审查必须等待经过验证的综合结果。

## 结果状态

Complete 表示满足每个主张字段的要求。Partial 保留有效主张并指出缺失的来源。
Blocked 指明所需的政策、权限或外部状态。

## 预算

每位研究者的预算为五个来源、六次 Tool 调用和 12 分钟。coordinator 只能针对
一个已明确指出的缺口重新委派一次。

## 合并规则

按主张 ID 和 provenance 合并主张。重复来源会被折叠；冲突必须保持可见，
同时保留两个来源版本并指定升级负责人。

## 独立审查

reviewer 在隔离的 Context 中接收简报、主张、证据和评分标准。它返回稳定的
发现项 ID，并且不能编辑候选简报。
