|---|---|---|---|---|---|---|

将每个输入边界作为 `input_schema` 转录到验证器架构包中。它必须声明每个 property 的类型，只要求已声明的 properties，并将 `additionalProperties` 设置为 `false`。无参数 Tool 仍需使用封闭对象 schema，其中 `properties` 和 `required` 数组为空。

```json
{
  "type": "object",
  "properties": {
    "case_id": {"type": "string"}
  },
  "required": ["case_id"],
  "additionalProperties": false
}
```
