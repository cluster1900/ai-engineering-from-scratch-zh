# 管道并行和气泡分析

> 张量并行性将矩阵乘法跨等级分离――管道并行性将模型跨等级分离,每个等级一个阶段――微批次流经管道――开始和结束的空时间就是泡;最小化它是整个过程――

**Type:** Build
**Languages:** Python
**Prerequisites:** 第 19 期 Track C 课程 42-49
**Time:** ~90 分钟

## 学习目标

- 将序列模型分为N个阶段,并模拟跨N个阶级的前向管道.
- 使用GPipe 计划通过管道安排M个微批次(仅向前填充,然后向后)并计算气泡分数――
- 将泡与Megatron-LM 和 PipeDream 中使用交错 1F1B 时间表进行比较.
- 捍卫阶段分配:每个阶段的相等数量比每个阶段相等数量更重要.

## 问题

在fp16中70B参数模型只需要140GB参数――没有任何消费者GPU能够支持它―― ZeRO-3 跨级分片参数,但仍然需要每个级别为每个前向步骤收集完整的层次,每个层支付日记(N) 跳.管道并行采用不同的路线:将模型切成N个阶段,并将每个阶段放置一个阶段――第1层前向完成第0级,并将激活张量移至第1级;等级1 运行第二层交换等级2;等级1 运行第二层交换等级2;等级就是――向流向――内存线性下降,因为每个阶段只保留一个阶段;计算是顺序的,这就是泡问题――

气泡是管道开始时(等待第一个微批次到达最后阶段) 和结束时(等待最后一个微批次回流) 的空时间――对于M个微批次和N个阶段,每个阶段的气泡分数为 (N-1) /(M+N-1) ⋅当M=8、N=4时,即27%.

### 时间表

在开始任何后期操作之前,使用所有M个微批次向前填充管道;然后反向倒流.每个微批次的激活必须保持向后,因此内存随着M线性增长而保持向前需要M+N-1个周期,向后需要另一个M+N-1个周期.

### 时间表

交错:一旦微批次的前进到最后阶段,就开始其后进并让它流回.时间表每阶段交换进行一次前进和一次后退.气泡仍然是N-1,但激活内存受管道深度限制,而不是微批次数量.

### 为什么每个阶段的平等计算是重要的

如果阶段0需要50ms,阶段1需要100ms,则每个周期都在阶段1上门控. 其他阶段每周期空50ms,等待阶段1释放.

### 微批量和批量

管道运行 M 个微批次,每个微批次的大小为 B ⋅有效批量大小为 M*B ⋅管道步骤结束时的梯度是组合 M*B示例的梯度。气泡分数取决于 M;优化器看到的是 M*B ⋅调整 M 意思是将泡 ((M 值较低) 与每个微批次内存(GPipe 的激活内存值较高,M 值较高)进行交易。

## 野外生产模式

三种模式使管道平行硬化到足以运输.

**激活检查点与管道配对。**当GPipe 上运行M个微批次时,激活内存是一个微批次M倍――激活检查点在向后时间重新计算向前时间,以计算取内存;这种组合使管道能够处理长序列――

**阶段平衡是测量出来的，而不是假设的。**生产团队运行一个分析过程,测量目标硬件上的实际每层计算(FLOP 和挂钟),然后根据该测量结果进行分区――Megatron-LM`--num-layers-per-stage`标志接受一列表,以便在阶段允许不均的层次计数,以不同的每层成本.

**发送-接收调度必须避免死锁。**每个阶段都在线接收死锁之前发送的管道.标准修复是交错:偶数级阶段先发送,然后接收,奇数级阶段先接收,然后发送.

1. 实现1F1B并验证气泡分数与GPipe匹配,但内存的激活有限.

## 关键术语

|术语 |人们怎么说|它实际上意味着什么 |
|------|----------------|------------------------|
|管道| “模型沿深度平行” |每个等级一个阶段，激活逐级流动|
|泡泡| “管道空闲时间”|开始+结束时的 (N-1) 个步骤，其中某些阶段没有工作 |
|微批次| “批次切片”|前进/后退各1个；随着 M 的增大，气泡会缩小 |
| G管道| “填充然后排水” |所有 M 都在任何后退之前前进；高激活记忆|
| 1F1B | “交错时间表” |每级一前一后；有界激活记忆|
