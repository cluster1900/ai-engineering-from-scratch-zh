## 学习目标
- 将一批可变分辨率图像中的补丁打包成一个序列,并构建区块角形注意力面具.
- 针对给定任务,在 AnyRes造中做选择.
- 在不变大小的情况下,为OCR、图表和摄影计算代币预算.
- 输出四方形尺寸的三种失败模式:被挤压的文本,被剪切的内容,上浪费的标志.

## 问题
变压器需要一个序列――一个批量是一叠长度相同的序列――如果你的图像是224x224,每次都会得到196个补丁符号,不需要填充,任务完成――用224训练,用224推断,再也不用思考分辨率――

现实不配合──文档是版(8.5x11英寸,约 2:3)──图表截图是横版(16:9)──收据又高又窄(1:3)──医学影像通常是2048x2048或更大──移动设备截图是1170x2532(0.46:1)──

在2024年之前,有三种选择,以及为什么它们都会失败:

1. 压缩将扭曲文本和人脸――下采样会破坏图表标签和OCR内容――在LLaVA-1.5之前,这是标准做法――
2. 收获到固定的视角比率――你会丢掉图像的大部分内容,
3. 到最长边缘. 解决失真,但对于版图像,50%以上的代币会浪费在填充上.

2024-2025 年的答案:让变压器 吃下原生分辨率的图像补丁,并弄清楚如何将不同构成的批量 打包成一个序列,同时避免浪费计算.

## 概念
### 和补丁包

据说,这项研究的结果是:

1. 按选择的补丁尺寸计算其原生补丁格.
2. 将每张图像的补丁平坦成自己的可变长度序列.
3. 将所有图像的补丁连接成一批的长序列.
4. 构建区块横向注意力面具,让图像A的补丁只在图像A内部参加.
5. 携带每个补丁的位置信息(2D RoPE 或分数位置嵌入式)。

三张图像组成的批量:336x336(576代币)、224x224(256代币) 和448x336(768代币),将变成一个1600-代币序列,配上一个1600x1600的块角面膜──没有填充──没有浪费计算──变压器可以处理任意的面积比例──

在训练中,NaViT还引入了部分补丁下降 随时丢弃50%的补丁 在整个批量中,这既能规范,也能加速训练.

### 任何Res (LLaVA-NeXT)

给定一张高分辨率图像和一个固定编码器 (CLIP或SigLIP在336),将图像切块:

1. 从预定义集合中选择一个格式布局(1x1) 、(1x2) 、(2x1) 、(1x3) 、(3x1) 、(2x2) 等使其最适合图像的视角比例──
2. 切成整个图像,每个子都变成一个336x336的收获.
3. 同时生成一个缩影图像:整张图像大小到336x336,作为全球文本代币.
4. 将每个都送进冷336码码编码―― 连接片代币+缩影代币――

对于一张672x672 图像,使用2x2格格加缩略图:4 * 576 + 576 = 2880 个视觉代币――昂贵但有效LLM 同时看局部细节和全局上下文――

当你的编码器是结的,只支持一种分辨率时,AnyRes是首选路线. 它会让图像的图像数量爆炸.

### 子 (子)

 Qwen2-VL 引入了多模旋转位置嵌入式. 不同于 NaViT 的分位或 AnyRes 的片和小图片,每个补丁都携带一个3D 位置.

输入任意HxW图像,补丁嵌入器 生成H/14 x W/14 个代币,每个代币获得自己的 (t=0,r=row,c=col) 位置,RoPE使用正确频率旋转注意力,完成.

不同于 AnyRes,M-RoPE 在原生分辨率下是 O(H x W / P^2) 代币没有带来的乘法开销. 不同于NaViT,它仍然期望每次处理单张图像.

### 包装面具

对于一个长度为`N_total`包装序列,覆盖图像`i=0..B-1`它们的长度为`n_i`形状为`(N_total, N_total)`的面具`M`在两个索引落入同一张图像的块时为1,否则为0――你可以从累积长度列表构建它:

```
offsets = [0, n_0, n_0+n_1, ..., N_total]
M[i, j] = 1 iff there exists b where offsets[b] <= i < offsets[b+1] and offsets[b] <= j < offsets[b+1]
```

在 PyTorch 中,这可以使用.`torch.block_diag`或显式集合 一行实现── FlashAttention 的变量长度路径(`cu_seqlens`) 完全跳过面具,直接使用累积长度子在序列中 内部出席对于典型批量,比密集面具快约10x──

- 构建区块斜角注意力面具 (为了清晰起见,使用密集)
- 与包装成本和方形尺寸和任何的比较.
- 为混合批量 (图片,截图,图片) 打印代币预算表.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Patch-n'-pack | "NaViT-style packing" | 将来自不同图像的可变长度 patch sequences concatenate 到一个 batch dimension 中 |
| Block-diagonal mask | "Packing mask" | Attention mask，将每张图像的 patches 限制为只 attend 自己，而不是 pack 中的相邻图像 |
| AnyRes | "LLaVA-NeXT tiling" | 将高分辨率图像切成固定大小 tiles 的 grid，并加一个全局 thumbnail；用固定 encoder 编码每个 tile |
| NaFlex | "SigLIP 2 native-flex" | 单个 SigLIP 2 checkpoint，可在 inference 时服务 256/729/1024-Token budgets，无需重新训练 |
| M-RoPE | "Multimodal RoPE" | 3D rotary position encoding（time、row、column），无需 position tables 即可处理任意 H、W、T |
| cu_seqlens | "FlashAttention packing" | FlashAttention varlen path 使用的 cumulative-length tensor，用来替代 dense block-diagonal mask |
| min_pixels / max_pixels | "Resolution bounds" | Qwen2.5-VL 的 per-request knobs，用于限制非常小或非常大输入上的 Token count |
| Visual token budget | "How many tokens per image" | 每张图像发出的 patch Token 粗略数量；决定 LLM 的 prompt budget 和 Attention cost |
