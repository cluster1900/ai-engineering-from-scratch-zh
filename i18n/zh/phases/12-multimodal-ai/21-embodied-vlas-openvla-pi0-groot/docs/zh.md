## 问题

能根据自然语言指令做家务的机器人,自1970年代以来一直是研究目标.2020年代的答案是:视觉语言行动 (VLA) 模型.它使用与VQA相似的VLM架构,但输出不是文本,而是动作.

美国航空航天局的特色挑战:

1. 动作空间是连续的(关节角、力量),并且高维(7-DOF臂 + 3-DOF抓住器 = 30 Hz 10 低) ⋅
2. 机器人专用训练数据稀缺――开放X体有约100万轨迹;网络文本图像是5B+──
3. 控制频率很重要.30Hz控制循环意味着每个动作只有33ms.
4. 安全性. 误动会损坏硬件.

## 概念

### 行动代号化 (RT-2)

RT-2 的技巧:把每个联合目标表示为一个量化后的文本标志.将归结为 [-1, 1] 范围分散为 256 个字符串,并将每个字符串映射到一个词汇 ID──一个10DOF行动在每个控制步骤将变成10 个标志.

在混合数据上对 PaLM-X VLM进行共调:

- 网站图像与文本对
- 机器人示范,行动表示为标志.

模型看 挑起红立方(语言)→图像(视觉)→10个标记的行动序列(分辨的联合目标)。网络预训保留一般知识转移:即使 快速移动 不在训练数据中,RT-2 也能遵循 向快速移动的对象。

RT-2 论文中的推断为 3-5 Hz,限制在VLM自动降解码中.

### 开放的 7B 参考实现

开放权重的RT-2等价物品──7B拉马脊柱,DINOv2 + SigLIP双视觉编码器,基于256桶的动作代码化──

在开放X体上训练(跨22个机器人的970k轨迹) 附带LoRA细调支持,用于适应新机器人。

推理:在A100上配合量化可达4-5Hz──对慢速操作足够快,但不适合高频控制──

### 快速代码器更快的行动解码

由于大多数动作集中在bin空间的小区域内――FAST (Frequency-Domain Action Sequence Tokenizer) 通过DCT缩小行动序列,并量化其系数――

一个30步的行动轨迹 变成了约10个快速代币,而不是300个分离式代币.

### 和流量匹配的操作

物理智能的 π0(黑色等.2024年 10 月) 用流量匹配行动专家 替代离散行动代币:

- 一个小型动作变压器 读取VLM的隐藏状态,并通过纠正流 输出连续的50步动作序列――
- 动作头 使用流量匹配损失 训练;VLM预训练 保持不变。
- 推理:完整的行动序列 在约5个指标步骤中输出,实际达到50Hz 控制.

的主张:在广泛的操作任务集合中击败OpenVLA 和Octo──持续行动表述保留了密化会破坏的平滑性──

0.5 和 π0-FAST 是增量升级──π0-FAST 将将快速标记化与流量匹配结合──

### 面向人体的双重系统

面向人形机器人 (面向人形机器人)

- 系统2:大型VLM 读取场景 + 指令,并以约1Hz 产生高水平的子目标
- 系统1:小型动作头变压器,根据子目标产生低层50-100Hz联合命令.

这种分离对应卡内曼的快思考与慢思考:系统2规划,系统1执行.优势:慢速VLM规模规划不会阻碍快速控制.系统1保持小型以后降低延迟.

通过使用来自全宇宙的真实数据进行细节调整.

### 开放的X体

训练数据──RT-X(2023年10月)汇集了22个数据集,覆盖了22个机器人上的1M轨迹──Open X-Embodiment是所有人都使用的集体:

- /桥 V2 / 无线机器人 / RT-2 厨房 / 语言表──
- 每个样本:(机器人状态,摄像头视图,指令,行动序列)
- 训练卫生:统一行动空间,归一化关节范围,调整摄像头尺寸.

通过100-1000 条任务专用演示,可在OpenX-Embodiment上进行LoRA细节调整来弥合.

### 只有机器人

微调将网络VQA数据与机器人轨迹混合.比例很重要:VQA 太多,模型会忘记动作;机器人数据 太多,模型会丢失通用知识.

RT-2 的比例:约 1:1──OpenVLA:web-to-robot 约 0.5:1──π0:类似──精确比例是需要根据数据集尺寸调整的超参数──

只有机器人 训练会产生任务专用模型,遇到出发指令就会失败.

### 安全和行动限制

每个生产级VLA都配有:

- 硬关节限制不能超过规格施加扭矩)
- 速度限制 (软剪切)
- 工作空间的限制 (终端效应器 不能离开桌面)
- 为了新任务使用人体循环批准.

这些作为控制层检查 位于VLA 外部.

## 关键术语

| Term | 人们通常怎么说 | 实际含义 |
|------|-----------------|----------|
| VLA | "Vision-language-action" | 接收 image + instruction 并输出 action commands 的模型 |
| Action tokenization | "Discrete bins" | 将连续 joint targets 量化为每个 dim 256 个 bin，每个 bin 是一个 vocab ID |
| FAST tokenizer | "Frequency action tokens" | DCT + quantize，将 30-step trajectories 压缩到约 10 个 Token |
| Co-fine-tune | "Mix web + robot" | 在 robot demos 旁边同时使用 web VQA data 训练，以保留通用知识 |
| Flow-matching action head | "π0 continuous output" | 小型 transformer，通过 rectified flow 输出 50-step action sequence |
| System 1 / System 2 | "Dual-system control" | 大型 VLM 慢速规划，小型 action head 快速行动；GR00T 模式 |
| Open X-Embodiment | "RT-X dataset" | 1M-trajectory 跨机器人 dataset；training corpus |
