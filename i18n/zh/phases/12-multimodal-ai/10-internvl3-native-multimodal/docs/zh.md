# 实习VL3:原生多模式预训

> 在InternVL3之前,每个开源VLM都遵循相同的三步配方:拿一个在数亿文字代币上训练的文本LLM,接上一个视觉编码器,然后细节调整接处.这能工作,但会产生调整债务:文本LLM已经把完整的预训预算花在纯文本上,没有原生理解视觉代币.当你加入视觉时,把LLM必须重新学习如何视觉输入和自己的文本推理 关联,同时也不能忘记文本能力.

## 概念
### 亲生多模式预训

从头开始在一个原生多模体上训练.

- 只有文字的数据40% ((FineWeb、Proof-Pile-2等)
- 35%的图像和文本数据接在一起 (OBELICS、MMC4式)
- 20%的对照图像标题数据
- 5%的视频文本数据

视觉代币,文字代币以及跨模式互动,都从第一个梯度步骤开始参与同一个损失.

基础模型的训练是单阶段的. 指示调整会随后进行,但基础模型已经把视觉代币理解为一等公民.

### 视觉位置变量编码

采用M-RoPE,并采用固定的轴配置──InternVL3 引入V2PE:位置编码 会按模式类型(文字、图像、视频) 变化,并带有可学习的扩展──实践中:

- 获得1D位置 (文字指数)
- 获得2D位置
- 获得3D位置,时间,行,col)

三者共享同一个RoPE频率基础,但每个频段的隐藏dim分配是一个学习参数,而不是固定分分分.

在同等计算下,视频基准比M-RoPE高1-2分.

### 视觉分辨率路由器 (ViR)

部署优化――并非所有图像都需要全分辨率编码――一张只有一个低细节物体的照片,如果按1280px本地编码,会浪费代币――ViR是一个小分类器,会在编码之前预测回答问题所需的最低分辨率――

在生产流量中,60%的查询使用低或中等就足够了.净效果:在相同质量下产量 提升2-3倍.

### 离合视觉语言部署 (DvD)

当你服务一个大型VLM时,视觉编码器 每张图像运行一次,但LLM会为每个输出代币自归运行.

### 单阶段与多阶段质量

国际体育平台 (internVL3) 的主要基准要求:在78B参数下匹配Gemini 2.5 Pro的MMMU-Pro──在38B下匹配GPT-4o──在8B下领先的开放-8B排名榜──全部基于单阶段预训练+指令调节配方──

结合债务假设是可测的:相对于视觉基准收益,InternVL3-8B在文本基准上分数损失,比Qwen2.5-VL-7B更少.

### 国际VL3.5和国际VL-U

国际教育局 (InternVL3.5(8月 2025) 扩大了这一食谱――同样的原生预训方法,更多数据,更多参数――MMMU的改进是增量式的――

通过MMDiT头部输出图像――这里"U"代表"理解+世代",跟随转移式统一模型――课 12.13) ・同一个原生预训练的脊柱 同时支持理解和世代头――

### 培训前的本土人

培训是免费的.

- 计算――从头训练一个新VLM的成本和训练一个文本LLM 相同:数百万GPU-小时――后期适应 复用现有LLM重量,节省大部分成本――
- 信息――大规模的互联图像文本体 很稀缺――OBELICS有141万份文件;MMC4有571万份――纯文本可以达到15T代币――多模拟预训数据稀缺是硬约束――
- 基础LLM重复使用. 产生的预训练 放弃了之后换入新LLM的选项.

国际VL3的注释是:再利用损失比再利用债务更糟糕――基准支持这一主张――生产成本也阻止未来实验室低成本复制――后期VLM将继续存在,因为对大多数项目来说,它们仍然更便宜――

## 使用它
`code/main.py`是一个训练组合混合器和ViR路由器模拟器.

- 接收一个目标体组混合 ((%文字、%插曲、%标题、%视频),并计算每种方式的预期步骤──
- 在一批查询上模拟 ViR路由(分布:50%低细节,30%中度,20%高细节),并报告平均代币数量──
- 基于编码器与LLM FLOPs 报告DvD吞吐量估计――
- 预测后期与本土预训练在调节,计算,数据以及预期的结合债务症状上

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Native multimodal pretraining | "From scratch together" | Text + image + video tokens 从第 1 步开始参与 Loss，而不是之后再接上 |
| Alignment debt | "Post-hoc penalty" | 由把 vision 接到 frozen LLM 上导致的 text skills 和 answer consistency 可测量退化 |
| V2PE | "Variable visual pos encoding" | 每个 modality 的可学习 position encoding allocation；InternVL3 的 M-RoPE 后继方案 |
| ViR | "Resolution router" | 小 classifier，在 encoding 前按 query 选择所需最低 resolution，从而节省 inference tokens |
| DvD | "Decoupled deployment" | Vision encoder 在一个 GPU 上，LLM 在另一个 GPU 上，并通过 stream handoff；可让大型 VLMs 的 throughput 翻倍 |
| InternVL-U | "Unified understanding + generation" | 2026 年后续版本，为 native-pretrain backbone 加入 image-generation heads |
| Interleaved corpus | "OBELICS / MMC4" | 文本和图像按自然阅读顺序排列的 documents；native pretraining 的原材料 |
