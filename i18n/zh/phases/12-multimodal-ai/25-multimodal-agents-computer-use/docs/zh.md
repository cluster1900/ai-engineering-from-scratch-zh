## 概念
### 基因用户界面的接地

基于GUI的接地是:给定一个屏幕截图 和一条自然语言指令,输出要点击的 (x, y) 坐标(或其他操作) ⋅

查看Click(arXiv:2401.10935) 是第一个规模化开放结果:在合成+真实GUI数据上细调 一个VLM,以纯文本代码输出坐标──有效──

密集用户界面增加了1120x1120高分辨率编码.

专注于移动UI,并与iOS可访问性数据集成.

输出格式通常是JSON:

```json
{"action": "click", "x": 384, "y": 220, "element_desc": "Search button"}
```

`element_desc`帮助恢复:如果坐标在截图之间漂移,语义提示可以让系统重新地址.

### 行动方案

一个典型的行动方案有6-10种类型的行动:

- `click`其他:
- `type`字母是:
- `scroll`: (方向,数量)
- `drag`其他类型:
- `select`选择指数
- `hover`其他:
- `navigate`其他地方
- `wait`时间:
- `done`答案: (成功,解释)

执行并返回新状态.

### 截图与可访问性树

两种输入模式:

- 仅截图:完整图像,没有结构信息.
- 可靠性树:结构化DOM/iOS可访问性信息――对地面可靠多;适用于树可用的地方――
- 混合物:两者都有,用树作为原子行动的可靠基因,用屏幕截图提供语义背景.

制作代理 在可能时使用混合式.浏览器自动化.

### 长视野记忆

一个20步工作流程会产生20张截图.

- 总结发生的事情,丢弃旧的屏幕截图.
- 跳转框:保留第一张、最后一张,以及每第3张截图.
- 工具记录日志:执行操作,保留已完成内容的文本日志;不要重新查看旧的截图.

克劳德的计算机使用API 使用日志模式.

### 视觉工具的使用

图表代理 (ArXiv:2510.04514) 为图表理解引入了视觉工具的使用:作物、放大、OCR、调用外部检测──代理可以把"作物到区域 (100, 200, 300, 400) 然后调用OCR"作为工具调用 输出──工具 返回文本;VLM 继续推理──

这种模式可以泛化:集标提示,区域注释和外部检测工具都符合相同的输出工具调用,接收结构化响应方案.

- 网络场/WebShop──较早的基准;已被边界化和──

### 为什么还难

性能瓶:

1. 细粒度视觉接地――"点击小X"经常在移动分辨率下失败――
2. 后者会偏离目标.
3. 错误恢复――当一次点击 失败(错误按) 当检测 + 恢复很少出现训练数据 中──
4. 交叉页面文本──在页面或长表格之间跳转会丢失状态──

研究方向:记忆架构,明确的重新规划,多模拟验证,用于成功行动的截图匹配.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| GUI grounding | "Click coordinates" | Model 在 screenshot 上针对 instruction 的 target 输出 (x,y) |
| Action schema | "Tool definitions" | 有效 actions（click、type、scroll、drag）的 JSON description |
| Accessibility tree | "Structured DOM" | 来自 browser/iOS APIs 的 machine-readable UI hierarchy |
| Hybrid agent | "Screenshot + tree" | 同时使用 image 和 structured info；比单独使用任一者更可靠 |
| Visual tool use | "Zoom/crop/detect" | Agent 在 plan 中途调用 external vision tools（OCR、detection） |
| Summary-chain | "Memory compression" | 周期性 text summaries 替代很长的 screenshot history |
| VisualWebArena | "E2E web bench" | 2024 benchmark，用于 end-to-end web tasks |
| AgentVista | "2026 hard bench" | 12-domain realistic workflows；即使 Gemini 3 Pro 也只有约 30% |
