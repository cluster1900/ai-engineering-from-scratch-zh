# 展示和分辨散 统一模型

> 转移混合连续和离散表示──显示-o(Xie等, 2024 年 8 月)走的是另一条路:文字代币 使用因果下代币预测,图像代币 使用 MaskGIT 思路下面罩式离散传播──二者都位于一个带混合注意力面具的变压器中──结果是一个背骨、每种模式 一个代币化器、一个损失式配方(下一个代币扩展到面罩式预测) 上统一 VQA、文字到图像、涂料和混合模式生成──本课讲解 展示-o 设计:为什么面罩式离散传播是一种并行、和少数步的图像,并将其与转移式 E3 相比较.

**Type:** Learn
**Languages:** Python (stdlib, masked-discrete-diffusion sampler)
**Prerequisites:** Phase 12 · 13 (Transfusion)
**Time:** ~120 minutes

## 学习目标
- 解释掩盖的分离散布:一种先均的掩盖标志、再让变压器恢复它们的时间表──
- 从速度和质量上比较并行图像解码(Show-o, MaskGIT) 与自动降低图像解码(Chameleon,Emu3)。
- 在一个检查点中处理的三类任务:T2I、VQA、图像涂料.
- 选择一种掩盖时间表 (色,线性,缩短),并推它对样品质量的影响.

## 问题
输血的两损训有效,但动态更棘手:连续输法损失与分离的NTP损失 位于不同的数值尺度上――平衡损失权重是一个超参数搜索――架构有效,但复杂――

展示的答案是:保持两种模式都离散,但通过掩饰分离散并生成图像,而不是顺序生成. 训练目标变成一个单一的掩饰标志预测,它自然泛化为下一个标志预测.

## 概念
### 面具的离散传播 (MaskGIT)

原始 Chang et al. (2022) 的 MaskGIT技巧很优雅. 从一个完全蒙面的图像开始,每个代币都特别.`<MASK>`在每一步中,并行预测所有隐藏的代币,然后保留最高的预测,并重新隐藏其余部分──大约8-16次代后,所有代币都被填充完成──每一步揭开多少的代币的时间表 需要调整,可سین时间表 效果很好──

训练很简单:从 [0, 1] 中均采用一个掩盖比率,将其应用到图像的VQ代币上,训练变压器恢复被掩盖的部分──这是BERT对文字做的事情,只是扩展到图像生成──

### 显示器:一个变压器,混合面具

展示将MaskGIT 放进因果语言模型变压器──注意力面具如下:

- 文字代码:原因
- 图像代币:在图像区块内完全双向的(这样的掩盖代币 在预测时可以看到所有其他图像代币) 』
- 文字到图像:文字出席到之前的图像,图像出席到之前的文字.

训练在以下任务之间交换:
1. 文字序列上的标准NTP──
2. 样本:文字 →图像,使用隐藏图像代币 和隐藏代币预测损失──
3. 样本:图片 →文本,使用隐藏文本代币 ((本质上就是NTP) ⋅

统一损失 是`<MASK>`标志上的交叉透,它同时覆盖文字NTP(只有最后一个标志被化) 和图像被化-传播(随机子集被化) ⋅

### 并行采样

在每一步中,并行预测所有隐藏的代币;提交Top-K 高置信度代币;重复──

对于:
- 马里昂/Emu3(对代币自动降级):N_代币次向前传递,通常每张图像1024-4096次。
- 转移:每步一次完整转变器通过.
- 显示面的分离散射):约16步,每步一次完整的变压器通过.

在相近规模模型下,Show-o比Chameleon更快;它大致匹配输血的步数,同时每步成本更低 (分的语法逻辑与持续的MSE损失) ⋅

### 在一个检查点的任务

显示在推理时支持四类任务,由快速格式选择:

- 文字生成:标准自动退缩文字输出.
- 视频:图片,短信,
- 通过掩盖的分离散播输出图像.
- 涂料:输入带有部分隐藏的代币的图像,并填充──

能力来自面具预测 训练,几乎是免费的.

### 掩盖时间表

每一步都揭开多少代币的时间表 会塑造质量――展示

```
mask_ratio(t) = cos(pi * t / (2 * T))   # t = 0..T
```

第0 步,所有代币都被掩盖了(比率1.0) ――第T 步,没有代币被掩盖了――Cosine将权重集中在中间区间的比率中,在那里预测最有信息量――线性时间表也可用,但更快进入平原――

### 展示2

展现2 ((2025后续, arXiv 2506.15564) 扩展了展现:更大的LLM基础,更好的Tokenizer,改进的面具时间表,架构模式相同.

### 在Show-o坐的地方

在2026年分类中:

- 单纯但推理慢──
- 微散令牌 + 隐藏传播:Show-o、MaskGIT、LlamaGen、Muse──并行采样,但仍受到了令牌损失限制──
- 持续+扩散:输血、MMDiT、DiT──质量最高,训练更复杂──
- 在VLM:JanusFlow、InternVL-U──最新路线──中连续的流量相匹配.

按任务选择:当你想在一个开放模型中同时获得T2I +涂料 + VQA,并且速度合理时,选择 Show-o;当质量最重要且你能承担两损失管道时,选择转――

## 使用它
`code/main.py`模拟展示样本:

- 一个包含16个VQ代币的玩具网.
- 一个模拟变压器,它基于快速和当前的未蒙面的代币预测登录.
- 使用可西因时间表做8步并行隐藏样本.
- 打印中间状态 (面具模式演变) 和最终的代币.

运行它,观察面具如何一步一步消解.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Masked discrete diffusion | “MaskGIT-style” | 训练模型预测 masked Tokens；推理时，迭代式 unmask 置信度最高的预测 |
| Cosine schedule | “Unmask schedule” | mask ratio 随推理步数衰减；将置信度增长集中在中间区间 |
| Parallel decoding | “All tokens at once” | 每一步用一次 forward pass 预测完整的 masked Token 序列，然后提交 top-K |
| Hybrid attention | “Causal + bidirectional” | 一种 mask：对 text tokens 是 causal，在 image blocks 内是 bidirectional |
| Inpainting | “Fill-in generation” | 以部分 Tokens 被 masked 的 image 为条件，预测缺失部分；从训练目标中免费获得 |
| Commitment rate | “Top-K per step” | 每次迭代中有多少 Tokens 被声明为“完成”；控制推理与质量的 trade-off |
