# 输血:在一个变压器中结合 权力降低性文字 + 扩散图像

> 梅伦 和 Emu3 把全部筹码押在离散代币上.它们能工作,但量化瓶很明显:图像质量将在低于连续空间扩散 模型的位置进入平台期.转移.Meta,Zhou等.2024年8月) 押相反的方向:保持图像连续,完全消除VQ-VAE,并使用两个损失 训练一个变压器.文本代币使用下一个代币预测.图像补丁使用流量匹配 /扩散损失.

**Type:** Build
**Languages:** Python（stdlib，MNIST-scale 玩具双 loss trainer）
**Prerequisites:** Phase 12 · 11（Chameleon），Phase 8（Generative AI）
**Time:** ~180 minutes

## 学习目标
- 连接一个在同一脊柱上运行两个损失的变压器 (图片补丁上传输MSE)
- 解释为什么图像补丁 之间使用双向注意力,同时文本标志 使用因果注意力,是正确的面具 选择──
- 在计算,质量和代码复杂性上,与马里昂式离散图像,NTP相比
- 说出MMDiT的贡献:每块使用特定模式的权重,在残留流上进行联合注意力.

## 问题
离散图像代币与连续图像代币的争论比LLM更早──连续表示(原始像素、VAE隐藏) 保留细节──离散代币(VQ指数)适应变压器的原生词表,但会在量化步骤丢失细节──

马里昂/Emu3 选择离散路线:一个损失,一个构建,但图像保真度受到了托克尼泽的质量限制.

扩散模型选择连续路线:图像质量很强,但它与LLM分开的模型,噪音调节工程复杂,也没有与文本生成的干净集成方式.

输血问题是:能不能两者兼得?保持图像连续,仍然训练一个模型,并把两个损失合进一次梯度步──

## 概念
### 双损失架构

一个仅用于解码器的变压器处理包含以下内容的序列:

- 文本 标签: 离散,来自BPE词汇)
- 图像补丁(连续,16x16像素块,通过线性嵌入 投影到隐藏的暗,与ViT编码器的输入相同)
- `<image>`和 `</image>`标签,用于标记连续贴片 所在位置──

发行只运行一次――损失会为每个代币 选择两个头之一:

- 对文本标志:在词语逻辑头上使用标准交叉透.
- 对图像补丁:在连续补丁上使用扩散损失,预测加入到每个补丁的噪音.

变压器体的分化流程共享.

### 注意面具:因果性文本+双向图像

文本标记必须是因果的;不能让文本标记出席到未来文本,否则老师强迫会被破坏――但图像补丁表示同一个快照;它们应该在同一个图像区块内相互双向出席――

面具:

```
M[i, j] = 1 if:
  (i is text and j is text and j <= i)   # causal for text
  OR (i is image and j is image and same_image_block(i, j))   # bidirectional within image
  OR (i is text and j is image and j < i_image_end)   # text attends to previous images
  OR (i is image and j is text and j < i_image_start)   # image attends to preceding text
```

在训练和推理中实现为区块三角形面具.

### 变体:稳定扩散3 的变体

恒定扩散3(埃塞尔等.2024年 3 月) 在与转移接近的时间发布了MMDiT(多模式扩散变压器) ⋅这两个架构是同宗分支──

的关键差异:

- 每个块使用模式特定的重量――每个变压器块对文本代码和图像补丁分别有独立的Q、K、V 和 MLP权重――注意力是共同的(跨模式);其他部分是模式特定的――
- 修改流程训练――一种特定的流程匹配变体,采样方式明确,数学上比DDPM更简单――
- 规模――MMDiT 是SD3的脊柱(2B 和 8B 参数变体) ・ 输血论文扩展到7B。

两者汇聚到一个核心思想:一个变压器对文本运行NTP,对连续图像表示运行传播――

### 为什么它胜过马风格

连续扩散与离散NTP在图像生成上的质量差距是可测量的.

- 在7B参数尺寸下,FID比同样规模的马式模型好 3-5 分.
- 不需要训练的标记器:图像编码器 更简单的(线性投影到隐藏,与ViT的输入层相似) ⋅
- 图像补丁 去噪音可以并行化推理,不像自动降低图像代币.

缺点:输血是双损 模型,训练动态更难――减肥 需要调调――NTP与扩散之间的时间表不匹配可能导致某个头 占主导――

### 下游分支

通过解用于理解和生成视觉编码器来改进转化的想法:一个使用SigLIP,另一个使用VQ,同时共享变压器体──Show-o(课 12.14) 把扩散转换为分离扩散罩预测──统一生成家族在转化后迅速分叉──

2026年能够输出图像的生产级VLM,例如双子座3 Pro、GPT-5、Claude Opus 4.7的图像生成路径,几乎肯定使用了这个家族的后代.

## 使用它
`code/main.py`在一个很小的MNIST类似的问题上构建玩具转移:

- 文本标题是描述数字的短整数序列.
- 图像是4x4 字节网格.
- 一对共享权重的线性投影 充当变压器 替代;文本上使用NTP损失,噪音补丁上使用MSE损失――
- 训练循环交换使用两个损失,注意力面具是显而易见的.
- 生成在一次前进传输中产生文本标题和4x4图像.

这种变压器是玩具级的. 双损失管道,注意力面具,构建和推理循环才是真正的产品.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Two-loss training | "NTP + diffusion" | 一个 transformer 在同一个 gradient step 中，同时优化文本 Token 上的 cross-entropy 和连续图像 patch 上的 MSE |
| Flow matching | "Rectified flow" | 一种 diffusion 变体，预测从噪声到 clean data 的 velocity field；数学上比 DDPM 更简单 |
| MMDiT | "Multimodal DiT" | Stable Diffusion 3 的架构：joint attention、modality-specific MLPs 和 norms |
| Block-triangular mask | "Causal text + bidirectional image" | 一种 attention mask：跨文本是 causal 的，但在图像区域内是 bidirectional 的 |
| Continuous image representation | "No VQ" | 图像 patch 作为实值 Vector，而不是整数 codebook indices |
| Velocity prediction | "v-parameterization" | 网络输出是噪声与数据之间的 velocity field，而不是噪声本身 |
