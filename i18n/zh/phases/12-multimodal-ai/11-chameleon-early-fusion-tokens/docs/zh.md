# 马龙与早期融合代币单独的多模模型

> 到目前为止,我们见过的每个VLM都把图像和文本分开处理.视觉代币从视觉编码器,流入投影器,然后在LLM内部与文本相遇.视觉词表和文本词表从不重叠.Chameleon(Meta,2024年5月)提出了一个问题:如果它们重叠会如何?训练一个VQ-VAE,把图像转换为来自共享词表的离散代币.现在,每个多模档都是一个序列:文本代币和图像代币 交错排列,使用单个自主降低的损失.副作用是:模型可以产生混合模列输出,也就是在一次性交换文本和图像代币的过程中进行生成.阅读阅读早期的论文,并从一个中文代币的构建到一个结尾,并从一个中文代币的构建到一个结尾.

## 问题

基于适配器的VLM(LLaVA、BLIP-2、Qwen-VL) 把文本和图像当作两种不同的东西──文本代码 经历`embed(text_token)`图像经过`visual_encoder(image) → projector → ... pseudo_tokens`△模型有两条输入路径,并在中途合并.

三个后果:

1. 士只能消耗图像,不能输出图像.
2. 混合模态文档 (例如文章中段落和图像交换出现) 很别扭:要么在模型外部解析多模态输入,要么串联多次生成――
3. 分布不匹配──视觉标志 和文本标志 位于隐藏空间的不同区域,会造成微小的对齐问题──

马里昂拒绝这个前提:图像只是来自共享词表的离散代币序列.

## 概念

### 作为图像标记器

这个标记器是一个向量定量化变量自动编码器.

- 编码器:CNN + ViT,将图像映射为空间特征地图,例如32x32个dim 为 256个特征.
- 编码书:一个学习得到的 K 个向量 的词表(Chameleon 使用 8192),同样暗为 256。
- 量化:通过L2距离对每个空间特征查找最近的代码簿入口──使用整数指数 替换连续特征──
- 解码器:CNN,将量化特征转回像素.

训练:VAE重建损失+承诺损失+代码簿损失──代码簿指数 构成图像的离散字母──

对马龙来说:一张图像变成32*32 = 1024 个标志,来自大小为 8192 的词表――与文本标志(来自 LLM 的 BPE 词表,例如 32000)拼接──最终词表:40192──变形器 看到的是一个序列、一个损失──

### 共享词表

马龙的词表组合文本 标志、图像 标志 和模态 分隔符──每个标志都有单一的ID──输入 嵌入层把每个ID 映射到D-dim隐藏矢量──输出投影把隐藏的映射回语音符──软max 下选择一个标志,不管它属于什么模态──

分隔符很重要:`<image>`和 `</image>`标签包住图像 标签序列――生成时,如果模型输出 `<image>`接下来,下游软件就知道下一个1024个代币是要发送给解码器进行像素染的VQ索引.

### 混合模态生成

引号是在共享词表上的下一个标志预测. 示例提示:"绘制一只猫,描述它. "

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

模型自主选择序列:它可能先生成图像再生成文本,先生成文本再生成图像,或交错生成──相同的解码器,相同的损失──

相比之下,适配器VLM的生成仅限于文本.

### 训练稳定性:QK-标准 降落 层规则订单

早期合训练大规模不稳定.

- 在注意内,对查询和关键投影先应用LayerNorm,再做点产品──防止深层网络中的逻辑大小爆炸──多个大模型都使用它──
- 落后放置――在每次残余添加之后应用落后,而不仅仅是注意和MLP之后――当来自图像代币的渐变可能占主导地位时,需要更强的正则化――
- 剩余分支上使用前LN(标准做法),再在最后一个区块的跳转连接上额外加一个LN――稳定最后一层的渐进流――

没有这些技巧时,34B-param 马龙 训练在多个检查点 发散.

### 代币器的重建上限

在8192个代码簿输入中,每张512x512图像1024个代币的设置下,重建PSNR上限约为26-28dB.

标记器是瓶──更好的标记器(MAGVIT-v2、IBQ、SBER-MoVQGAN) 会抬高上限──Emu3(课 12.12) 只有通过更好的标记器才能达到 SDXL 质量生成──

### 马里昂vsBLIP-2 / LLaVA

马 (早 fusion,共享词表):
- 一个损失,一个解码器.
- 生成混合模态输出
- 标记器是质量上限.
- 成本高:输入路上每张生成图像都需要VQ-VAE解码器──

结后,分离塔楼:
- 视觉输入,只能输出文本.
- 复用预先训练的法学士.
- 了解任务没有标记器
- 便宜:单次前进通行.

按任务选择. 如果需要图像生成,选择马龙家族. 如果只需要理解,适配器-VLM 更简单,并且再使用更多预先训练的计算.

### 和任何GPT

宇(阿德普,2023) 是一个相关方法:完全跳过单独的视觉编码器,把原始图像补丁 像代币一样送入LLM的输入投影,不使用Tokenizer──比马龙更简单,但失去了共享语音输出出生成能力──

任何GPT(Zhan等, 2024) 把马龙 扩展到四种模态:文本、图像、语音、音乐──每种模态都使用相同的VQ-VAE技巧,共享变革器──任何一代──课 12.16 中会进一步介绍──

## 使用它

`code/main.py`构建一个玩具端到端早期融合模型:

- 一个很小的VQ-VAE式量化器,把8×8补丁映射到代码书指数(K=16) 
- 一个共享词表,由(文字标识 0..31)+(图像标识 32..47)+(分区 48,49)组成。
- 一个玩具自动降解器 (大图表),在合成标题 +图像标记序列上训练――
- 一个样本循环,给定提示后输出交换的文本 +图像标志.

代码有意让变压器极小,这样你可以从头到尾追踪信号流量.

## 关键术语

| Term | 人们的说法 | 实际含义 |
|------|------------|----------|
| Early fusion | "Unified tokens" | 图像从第一步起就被转换为离散 Token，并共享 Transformer 的词表 |
| VQ-VAE | "Image tokenizer" | CNN + ViT + codebook，将图像映射为 Transformer 可预测的整数 indices |
| Shared vocabulary | "One dictionary" | 覆盖文本 + 图像 + 模态分隔符的单一 Token ID 空间 |
| QK-Norm | "Attention stabilizer" | 在 query 和 key 做 dot product 之前对它们应用 LayerNorm，防止 norm blowup |
| Mixed-modality generation | "Text + image output" | 一次 pass 中自主生成交错文本和图像 Token 的 inference |
| Codebook size | "K entries" | VQ-VAE 可 quantize 到的离散 Vector 数量；在压缩率和 fidelity 之间权衡 |
| Tokenizer ceiling | "Reconstruction limit" | 解码 VQ Token 能达到的最佳 PSNR；限制模型的图像质量 |
