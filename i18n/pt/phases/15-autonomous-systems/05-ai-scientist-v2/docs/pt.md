2. **新颖性检查。**A avaliação de Beel et al. foi realizada neste passo, onde foi descoberto um erro de identificação: já há métodos que são frequentemente classificados como novelas.
3. **实验计划。**Agente 起草实验协议 并编写代码──
4. **执行。**O código em sandbox entra em funcionamento. O erro é o resultado de um erro de codificação.
5. **图表生成。**Modelo de linguagem visual 读取生成的图表,并重写它们以提高可读性──这是 v2 的关键技术新增点──
6. **写作。**LLM 起草论文,并与内部评审员 代。
7. **可选：投稿。**O trabalho foi enviado para um local.

### O que significa o workshop?

Um artigo do trabalho produzido por v2 passou pela revisão de pares do workshop ICLR 2025 ⋅ autor ao comitê do programa ⋅ divulgou a origem do trabalho ⋅ esta receção é um ponto de dados; não é uma declaração de que o sistema ⋅ vai fazer pesquisa ⋅ licença ⋅

重要背景:workshop 论文的门低于主要会议论文──Peer review 噪声很大;在任意一天,都会有一小部分投稿被接收──一次成功是概念的证明,而不是可靠性声明──Nature 2026 论文记录端到端循环,且它本身由人类研究人员共同签署;它不是系统写了一篇 Nature 论文──

### O que foi descoberto?

Beel et al. (arXiv:2502.14297)  efectuaram uma avaliação externa.

- **实验失败。**42% dos experimentos por erro de codificação fracassaram, por importação de erros, por desajustes de forma, por variáveis indefinidas, por ciclo de retiro, por parte, mas não por todo.
- **新颖性错误标记。**A literatura-retorno 步骤 frequentemente把既有概念标记为小说── isto é equivalente a alucinação no campo da investigação──
- **呈现质量差距。**A crítica gráfica gerou efeitos visuais de publicação, mas ocultava os pontos fracos das experiências de base.

O último descobrimento para esta fase é o mais importante. Uma produção de dados credíveis não foi feita em um sistema de estudos credíveis, mais perigoso do que um sistema claramente falhado, e não mais seguro. A avaliação deve atingir a reivindicação de nível inferior, não pode ficar no gráfico.

### Escapa de caixa de areia 风险

Sakana  seu próprio repositório README 警告:

> Como o software executa o código do LLM, não podemos garantir a segurança. Há pacotes perigosos, acesso à web não controlado e riscos de gerar processos não esperados.

É o que se passa com o código de código; o código pode fazer qualquer coisa que o processo seja permitido fazer. Se não houver uma caixa de areia de restrições rigorosas para o sistema de arquivos, rede e ações de processo, qualquer agente de pesquisa autônoma pode transmitir dados externos, consumir computação ou reescrever a si mesmo.

A história da AlphaEvolve é mais fácil, porque seu avaliador é muito próximo. A AI Scientist v2 é um ciclo de código aberto, e tem um objetivo aberto. Por isso, precisa de mais isolamento.

### V2 Na estaca de fronteira

| System | Target | Output kind | Evaluator | Known failure |
|---|---|---|---|---|
| AlphaEvolve | algorithms | code | unit + benchmark | 受 evaluator 严谨程度限制 |
| DGM | agent scaffolding | code | SWE-bench | reward hacking |
| AI Scientist v2 | research papers | text + code + figures | peer review（弱） | 实验失败、错误标记、润色掩盖弱点 |

Entre estes três, o avaliador automático do v2 foi o mais fraco, o mais amplo, o mais curto caminho para o artefato público.

## Use-o

`code/main.py`将 v2 循环模拟为一个状态机:想法 → 新性检查 → 实验 →图表 → 写作 → review → 接收或代―― cada estado tem uma probabilidade de falha configurável, essa probabilidade provém da descoberta de Beel et al.

- Há muitas ideias até chegar à fase de publicação.
- Há muitos posts que existem em que há falhas de experiências-chave.
- O orçamento de retomada é o que se deve fazer entre a qualidade e a produção.

## Entrega-o

## 关键术语

| Term | What people say | What it actually means |
|---|---|---|
| AI Scientist v1 | “Sakana 的 templated research agent” | 将实验填入固定 scaffold |
| AI Scientist v2 | “无 template 的 research agent” | 带有 VLM 图表批评的 agentic tree search |
| Agentic tree search | “分支式 research agent” | 并行扩展多个实验计划；由内部 critic 剪枝 |
| Vision-language critique | “对图表进行 VLM 润色” | Multimodal model 读取图表并重写以提高清晰度 |
| Literature retrieval | “新颖性检查” | 搜索 prior work 以确认想法新颖性，并已被记录会发生错误标记 |
| Polish masking | “漂亮论文，破损研究” | 呈现质量超过实验质量；隐藏弱点 |
| Sandbox escape | “LLM 代码逃逸” | agent 执行的代码做了 loop designer 未预期的事情 |
