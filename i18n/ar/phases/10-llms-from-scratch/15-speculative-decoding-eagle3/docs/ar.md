## 概念
### 不变量: أخذ العينات من رفض ليفياثان

جعل`p(t)`أظهرت في بعض المواعيد المسبقة،`q(t)`تعريف توزيع المؤشر `d ~ p` فى احتمال`min(1, q(d) / p(d))` إذا رفضت، فإنّها من التوزيع المتبقّى`(q - p)_+ / ||(q - p)_+||_1`في النهاية نموذج الطاعة`q` مهما `p`多差, هذا كله صحيح,越差就越常拒绝, ولكن الخروج لا يزال دقيقة

- لا .`N`التدوينات التالية، باستخدام مؤشر واحد إلى الأمام`prefix + d_1 + ... + d_N` المحققون سوف يعودون معا`q_1, q_2, ..., q_{N+1}` من اليسار إلى اليمين عبر  في الموقع `j`أول مرة رفضت فيها`residual(q_j, p_j)`采样并停止──若全部接受,则从 `q_{N+1}`مثل رمز مكافأة

### ما الذي يحدد السرعة

جعل`α`لجميع الرسومات المخططة توقعات قبول معدل.`c = cost(draft) / cost(verifier)`لتكلفة比. . .

```
E[accepted] = (1 - α^(N+1)) / (1 - α)
```

كل قبول Token توقعات الجدار الوقت هو `(N * c + 1) / E[accepted]`◊ بالمقابل`N`على الأقل تحويلها، يمكنك الحصول على أفضل نقاط.`α = 0.8, c = 0.05`: 最优 `N`حوالي 57, التسارع 3.2×...`α = 0.95, c = 0.02`: 最优 `N`حوالي 810، وتسارع تقترب من 5 ×.

أكبر 杆 هو `α` في الثابتة `N = 5`时,从 `α = 0.6`(مخطط الفانيلا)提升到 `α = 0.9`(EGLE-3) ، سوف يجعل كل مؤشر إلى الأمام توقعات قبول الوهم من 2.2 提升 إلى 4.1 ∙ استخدام نفس المؤشر، انتاج تقريبا ضعف ∙

### التقدم على مدى سنتين

**Vanilla speculative (Leviathan, 2023).**النموذج المسود هو التدريب المستقل في نفس العائلة LLM.`α ≈ 0.6`أفضل ما يمكن أن يكون هو فقط 2x الزيادة

**EAGLE-1 (Li et al., 2024).**مسودة هي تحويل صغير ، عادةً على سطح واحد إلى اثنين ، فإنه يستخدم الاختبار الدقة الأخيرة المخفية للثبتة كإدخال ويقصد مباشرة التوقعات التالية.`α`ارتفع إلى 0.7 0.8 

**EAGLE-2 (Li et al., 2024).**加入动态草案树:不是提出单条包含 `N`个标志的序列,而是提出一棵小型候选树,用一次验证器前进 (树注意) لكل مرشح打分,然后沿最高概率路径前进.`α`ارتفع إلى 0.85

**EAGLE-3 (Li et al., 2025, NeurIPS).**كما تم إجراء تغييرين. أولا، إزالة تماما الخسارة التنبؤية الميزة: EAGLE-1/2  التدريب مشروع الخروج من الحالات الخفية للمثبتة، مما يحد من المزيد من البيانات التي يمكن أن تجلبها المكاسب.

```python
def accept(q_prob, p_prob, u):
    if p_prob <= 0:
        return True
    return u < min(1.0, q_prob / p_prob)
```

### الخطوة 2: توزيع البقايا

```python
def residual(q, p):
    raw = [max(0.0, qi - pi) for qi, pi in zip(q, p)]
    s = sum(raw)
    if s == 0:
        return list(q)
    return [r / s for r in raw]
```

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Leviathan rule | “min(1, q 除以 p)” | 以概率 `min(1, q(d)/p(d))` 进行 Bernoulli accept/reject；当 rejection 时从 residual 中采样，可精确保留验证器分布 |
| Residual distribution | “(q 减 p) 的正部，归一化” | `(q - p)_+` 在零处截断并重新归一化，是 rejection 时应采样的正确分布 |
| Acceptance rate α | “draft 对的频率” | 在拒绝规则下，每个 Token 的期望 Bernoulli 成功概率；支配所有加速数学 |
| EAGLE-1 | “hidden-state draft” | 条件化于验证器 last-layer hidden state 的微型 Transformer draft（Li et al., 2024） |
| EAGLE-2 | “dynamic draft tree” | EAGLE-1 加上一棵候选 continuation 树，并在一次验证器 pass 中用 tree attention 打分 |
| EAGLE-3 | “training-time test” | 去掉 feature-prediction loss，基于直接 Token prediction 训练，并在训练时把 draft 自己的输出反馈给它 |
| Training-time test (TTT) | “exposure bias 修复” | 训练时以 autoregressive 方式运行 draft，使训练和测试输入分布匹配，是 scheduled sampling 的直接类比 |
| KV rollback | “撤销被拒绝的 draft” | rejection 后将验证器 KV cache 重置到已接受 prefix 长度的 bookkeeping |
| Bonus token | “免费的那个” | 当全部 `N` 个 draft 都被接受时，以零额外验证器成本从 `q_{N+1}` 额外采样一个 Token |
| Tree attention | “一次验证许多候选” | 使用尊重 draft tree 拓扑的 non-causal mask 的 Attention；在一次 forward pass 中为树中的每个节点计算 `q_i` |
