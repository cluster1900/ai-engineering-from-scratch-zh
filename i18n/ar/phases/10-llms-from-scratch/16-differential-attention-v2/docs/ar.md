## مفهوم الأساسي

### Softmax                                                                                                                                                                                                                                                              

对于查询 `q`و المفاتيح`K = [k_1, ..., k_N]`, الاهتمام 权重是:

```
w_i = exp(q . k_i / sqrt(d)) / sum_j exp(q . k_j / sqrt(d))
```

لا شيء`w_i`سأكونُ بدونِ`k_i`مع`q`完全无关, تسجيل `q . k_i`و هو أيضاً يدور حول التغيرات`||q||^2 / d` بعد التطبيع على التوالي الرئيسي للطاقة النفطية `O(1/N)`△无关 Token 的总贡献是 `O((N-1)/N) = O(1)`هذا ليس حجم صغير

模型想要的更像是硬顶-k:在匹配令牌上给高权重,在其他位置接近零──软max 过于平滑,无法直接做到这一点──

### التفاوت

将每个头的Q 和 K投影 拆成两份:Q = (Q_1, Q_2),K = (K_1, K_2) ――计算两个注意地图:

```
A_1 = softmax(Q_1 K_1^T / sqrt(d))
A_2 = softmax(Q_2 K_2^T / sqrt(d))
```

输出:

```
DiffAttn = (A_1 - lambda * A_2) V
```

相减会抵消两个地图 共享的任何噪声分布―― إذا كانت هناك وزن متوسط تقريبا على خريطتين على 127k 无关标志上 (على الرغم من أن هذا صحيح عند البدء في الاختيار) ، فإن هذه الأجزاء ست抵消 بعضها البعض――信号少数真正相关的标志上 (على الرغم من أن الارتفاعات في الرأس والثباتات في الخريطين تظهر بنفس الدرجة، إلا أنها ستُ抵消، بينما لن تبقى هذه الحالة بعد تدريب النموذج‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬

`lambda`كل رأس واحد يمكن تعلمه حجم، والمعايير هي`lambda = exp(lambda_q1 dot lambda_k1) - exp(lambda_q2 dot lambda_k2) + lambda_init`يمكن أن تكون ضارة`lambda_init`الاعتراف هو مثل 0.8 من الاصطلاحيات الصغيرة.

### V1 مقابل V2: فرق

V2 سوف يضاعف رأس الاستفسار 数量加倍,并保持 KV heads 不变(من التنبؤ فوق 借用参数) ――البعرض الرئيسي 保持与基线相同──相减后,额外维度将被投影回去,以匹配基线变压器的 O_W投影──三件事同时发生:

1. سرعة فك الرمز مع خط الأساس
2. FlashAttention 可原样运行(لا حاجة إلى النواة المخصصة)。
3. إشعار 时 的算术强度 提高(每次从HBM加载字节 时对应更多计算)

V2 أيضا نقل V1 باستخدام لتحقيق استقرار في عملية خفض في الفأس RMSNorm. تحت حجم 70B درجة التدريب المسبق، سوف RMSNorm جعل التدريب في المرحلة الأخيرة غير مستقرة.

## بناءها

`code/main.py`باستخدام بيثون النقيّة تمّ تحقيق الاهتمام التفاضليّ. استفسار لعبة مع إشارة معروفة بالإضافة إلى الضوضاء.

### الخطوة 1: الاهتمام القياسي softmax

ستدلب ماتريكس عمليات: قائمة القوائم ‬الخطوط المكتوبة ‬بأقصى قيمة في الصفحات المحدودة لضمان استقرار القيمة العددية‬‬

```python
def softmax(row):
    m = max(row)
    exps = [math.exp(x - m) for x in row]
    s = sum(exps)
    return [e / s for e in exps]
```

### الخطوة الثانية: تقسيم القيادة إلى نصفين

V1 风格:将头寸 减半──V2 风格:保持头寸,并将头寸 数量加倍──玩具实施 为了教学清晰使用 V1数学完全相同,只有簿记 不同──

### 步骤 3: 两个 فرع softmax + 相减

```python
A1 = [softmax([dot(q1, k) / scale for k in K1]) for q1 in Q1]
A2 = [softmax([dot(q2, k) / scale for k in K2]) for q2 in Q2]
diff_weights = [[a1 - lam * a2 for a1, a2 in zip(r1, r2)] for r1, r2 in zip(A1, A2)]
out = [[sum(w * v[j] for w, v in zip(row, V)) for j in range(d_v)] for row in diff_weights]
```

انتباه: يمكن أن تكون الناتج من الوزن سلبي. هذا ليس مشكلة.

### 步骤 4: ضجيج ضجيج

构建一个长度为 1024的合成序列──将信号标志 放在已知位置,其余位置填充噪声──计算 (أ) 标准软max Attention on signal 位置重量,以及 (ب) الاهتمام المفارقات 权重──测量两者的信号-噪音比──根据两个分支训练到多大程度产生差异,DIFF注意通常能稳定产生高出 3x-10x的信号-噪音比──

### الخطوة 5: V1 مقابل V2  参数核算

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Differential attention | “两个 softmax 相减” | 将 Q、K 拆成两半，计算两个 softmax maps，从第一个中减去第二个（由 lambda 缩放），然后乘以 V |
| Noise floor | “softmax 的非零尾部” | Softmax 放在每个无关 Token 上的 O(1/N) 权重，在 long contexts 中会累加到 O(1) |
| lambda | “相减的缩放系数” | 每个 head 的可学习标量，参数化为 `exp(lq1.lk1) - exp(lq2.lk2) + lambda_init`；可以为负 |
| DIFF V1 | “ICLR 2025 版本” | 原始 Differential Transformer；将 head dim 减半以保持参数量，需要 custom kernel，decode 更慢 |
| DIFF V2 | “2026 年 1 月修复版” | 在保持 KV heads 的同时将 Q heads 加倍；decode speed 与 baseline 持平，并兼容 FlashAttention |
| Per-head RMSNorm | “V1 稳定器” | V1 在差分之后应用的额外 norm；V2 移除了它，以避免后期训练不稳定 |
| Signal-to-noise ratio | “有多少 Attention 被浪费了” | 真实 signal 位置上的权重与无关位置平均权重之间的比率 |
| Lost in the middle | “Long-context failure mode” | 一个实证现象：长 context 中间位置文档的检索 accuracy 会下降——DIFF attention 可以缓解这一点 |
| Arithmetic intensity | “每加载一个 byte 对应多少 FLOPs” | V2 在 decode 时通过每次 KV 加载对应双倍 queries 来提高的比率；对 memory-bound decode 很重要 |
