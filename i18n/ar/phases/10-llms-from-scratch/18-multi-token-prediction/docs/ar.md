## 问题

التنبؤ بالرمز التالي هو هدف تدريب LLM القياسي. كل حالة مخفية يتم مراقبتها للتنبؤ بشيء واحد فقط: التالي للتومين التالي. هذا هو إشارة ضعيفة بشكل غير متوقع. معظم المعلومات في المسلسل تمتد إلى رمز خارج: الهيكل والتوافق والواقع والعمليات الحسابية. يجب أن يمر النموذج عبر بضع مليارات من الرموز وتجميع العديد من الرموز الواحدة للتعلم هذه المحتوى.

والمسألة التي طرحها MTP هي: إذا كان كل حالة مخفية يتم مراقبة مرة واحدة للتنبؤ بمتعدد الوهم المستقبلي؟ Gloeckle et al.(Meta, 2024) يثبت هذا الأمر.

DeepSeek-V3 ((2024 年 12 月) سوف MTP 重新设计为序列模块,在每个预测深度上保留因果链――模型从 `h_i^(0)`预测 `t+1`ثم من حالة مخفية جديدة`h_i^(1)`预测 `t+2`و`h_i^(1)`- لقد تمّ إختيارها`h_i^(0)`和 `E(t+1)`إضافة، وفقا لهذا النوع من التوصيات. كل عمق لديهم كتلة تحويل صغيرة الخاصة بهم. إضافة مشتركة و رأس الخروج المشترك  جعل العناصر التداول البديل للحفاظ على درجة متوسطة. في حجم DeepSeek-V3، وحدات MTP في 671B زيادة في الوزن على النموذج الرئيسي 参数 14B.

هذا الدراسة سوف تتخذ من صفر بناء وحدات MTP وحتى D-خسارة العمق.

## مفهوم الأساسي

### التسلسل MTP 配方

DeepSeek-V3 في الموديل الرئيسي إضافة`D`个 MTP وحدات.`k`(من بين `k = 1..D`)预测深度 `k`الـ (أوتوكين) ، وذلك في وضع محدد`i`时预测 `t_{i+k}`.

الوحدة`k`包含:

- حجر محول`T_k`, أن يكون لديك انتباهك و MLP
- ماريخ إلقاء`M_k`، سوف تكون الوضع المخفي في المستوى الأول مع إضافة رمز الحقيقة الأساسية في المستوى السفلي
- التكامل المشترك `E`(مع الموديل الرئيس نفسه)
- رأس الناتج المشترك `Out`(مع الموديل الرئيس نفسه)

التدريب، بالنسبة إلى الموقف`i`"أوّل" "في حالة مخفية"

```
h_i^(0) = main model backbone at position i
h_i^(k) = T_k( M_k * concat(RMSNorm(h_i^(k-1)), RMSNorm(E(t_{i+k}))) )   for k >= 1
```

التنبؤ المعمق 为:

```
logits_{i+k} = Out(h_i^(k-1))   for k = 1..D
```

الخسارة العميقة هي مقارنة بالحقيقة القاعدية`t_{i+k}`من الانتروبيا المتقاطعة:

```
L_k = CE(logits_{i+k}, t_{i+k})
```

فقدان المفاصل عبر عمق:

```
L_MTP = (lambda / D) * sum_{k=1..D} L_k
```

`lambda`هو عنصر الوزن الأصغر، DeepSeek-V3 في التدريب 10% قبل استخدام 0.3, بعد استخدام 0.1──`L_main + L_MTP`.

### لماذا متسلسل وليس متوازي

المُتوازيّة الأولى من المُتوازيّة المُتوازية لديها رؤوس خروجية، كلّها تُطبّق مباشرةً`h_i^(0)`كل رأس يخرج من نفس العمود الفقري في حالة مخفية`t_{i+k}`.يمكنك التدريب بشكل طبيعي لكن هذه التوقعات لا تتشروط`head_1`         `head_2`هذه الرؤوس هي أدوات التقطعات

DeepSeek-V3  تصميمات متسلسلة من `h_i^(k-1)`إضافة إلى عمليات إضافة الوسائل التالية`E(t_{i+k})` تكوين `h_i^(k)`هذا يحتفظ بالسلسلة السبيلية`t_{i+k+1}`, عمق`k+1`من الوحدة سوف نرى`t_{i+k}`处的内容──这在结构上与自归解码器 消费自输出方式相同,因此 ماودولات MTP يمكن أن تكون مباشرة كمصممين للتخفيف المضاربة استخدام──

推理时:将 `h_i^(k-1)`ووضع`t_{i+k}`输入 مودول `k+1`, حصلت على على`t_{i+k+1}`يُمكن أن يُحصل على إيجلي على مسودة، وذلك فقط باستخدام وحدات MTP جيدة للتدريب كشبكة مسودة.

### 参数核算

لـ"الخفية"`h`、词表为 `V`نموذج:

- المُصطلح الرئيسي: مليارات المُصطلحات، بالإضافة إلى واحد كبير`V * h`رأس الخروج
- رأس الخروج المشترك: رأس النموذج الرئيسي
- التوابل المشتركة:复用主模型的嵌入──没有额外参数──
- كل وحدة MTP:
  - التنبؤ`M_k`:`(2h) * h = 2h^2`.
  - حجر المحول`T_k`:attention(MHA 为 `4h^2`)加 MLP(SwiGLU 且比例为 8/3 时通常为 `8h^2`كلّ بلوك`12h^2`.

كل وحدة من مجموع العناصر الخارجية:`~14h^2`◊ بالنسبة لـ DeepSeek-V3 `h = 7168`,D = 1 الوحدة: الورق على الصفحة`~14 * 7168^2 = ~720M`参数──DeepSeek-V3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   

### التشخيص المضاربي 回报

خلال التدريب المقبل، سوف تجعل وحدات MTP التدريب يتغير ببطء حوالي 10%

1. إشارات تدريب أكثر كثافة. كل حالة مخفية ترى D+1 个监督目标.

2. 推理时免费的投机式解码草案──MTP 已被训练预测下几个代币──重复使用网络草案时,它能达到80%+的接受率──在这个水平下,N=3或N=5的规格解码可带来1.8×吞吐量──10%的训练成本将在第一次运行推理时开始回本──

## بناءها

`code/main.py`端到端构建一个MTP模块:共用嵌入、投影、变压器块、共用输出头──然后它会在一段简短的合成序列上计算每深度交叉热损失,并按组件印印参数──32 个代币的玩具词汇 让数字更容易阅读──

### 步骤1: الجدول المشترك

واحد`vocab_size x hidden`الجدول المستخدم في كل طراز من الطرازات المختلفة في كل عمق

### 步骤 2: مجموعة لكل عمق

```python
def combine(prev_hidden, next_token_embed, M_k):
    # concat along feature dim, then project down to hidden
    concat = rms_norm(prev_hidden) + rms_norm(next_token_embed)  # vector addition stand-in
    projected = matvec(M_k, concat)
    return projected
```

سوف تجري عملية DeepSeek-V3 الحقيقية خلال اثنين من RMSNorm`[2h]`, لم تستخدم واحدة`h x 2h`المصفوفة الصورة، هذه اللعبة، لتحقيق النوعية، باستخدام الجهاز المتجه

### 步骤 3: عمق k من كتلة المحول

الاهتمام الذاتي 加 MLP──在玩具中,一个单层线性注意区 和一个SwiGLU MLP 让结构可见,同时避免使用numpy──

### 步骤 4: رأس الخروج المشترك

复用主模型的输出投影──输出覆盖词汇的逻辑──

### الخطوة 5: خسارة في العمق

(ماكس)`k`处 أساسية حقيقة الـ Token 的交叉`lambda / D`缩放因子跨深度 聚合──

### الخطوة 6: الحسابات

打印总参数、共享(嵌入、头) 参数,以及 لكل وحدة 额外参数──展示 MTP 额外参数与主模型大小的比例──

## التدريب

1. 运行 `code/main.py` عرض مع إشارة اصطناعية 增强,per-depth loss 单调下降── تغيير اصطناعي,جعلها تستخدم وضع ثابت,并验证 عمق-1 和 عمق-2 فقدان مدينة收──

2. 计算一个密集 70B 模型(隐藏 8192,80 层) في D=1 MTP 模块 下的参数开销──与 DeepSeek-V3 报告的 14B 开销进行比较──解释为什么 DeepSeek 的数字更高:MTP 变压器块 继承了相同的MoE 结构,从而增加了每模块 参数──

3. في اللعبة تنفيذ D=2: إضافة وحدات MTP الثانية، استقبلية h^(1) 并预测 `t_{i+2}` التحقق من الخسارة المشتركة 和 المعايير النقد مع معادلات ورقة DeepSeek 19-21 匹配──

4. 将玩具 切换为平行MTP(Gloeckle-style): في حالة مخفية الرئيسية 之上添加 D 个输出头,每个预测不同的抵消――测量在同一个合成信号上,每个深度的损失与序列版本相比如何──对于 k > 1,sequential 版本应产生更低的深度-k损失,因为它在中间预测为条件──

5. سوف تدرب ماودول MTP جيد باستخدام مشروع على طراز EAGLE:`t_{i+k}` في تسلسل مدام، قياس هذه المخططات الوهم مقارنة مع معدل قبول نموذج الرئيس التوقعات  إذا كنت في اللعبة تصل إلى 50٪ +، فإنه يعيد وجود تجربة MTP-كما-مخطط 

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| MTP module | “额外 loss block” | 一个小型 transformer block 加 projection，用来预测主模型前方 `k` 个位置的 Token |
| Prediction depth | “哪个 offset” | 整数 `k`，使得 module `k` 基于截至位置 `i` 的 prefix 预测 `t_{i+k}` |
| Parallel MTP | “Gloeckle-style” | 位于同一个 backbone hidden state 之上的 D 个独立 heads，没有条件链 |
| Sequential MTP | “DeepSeek-V3 style” | 每个 module 都以先前 depth 的 hidden state 加下一个 Token 的 embedding 为条件；保留 causal chain |
| Shared output head | “复用主 head” | MTP modules 调用主模型的 LM head，而不是单独的 output projection |
| Shared embedding | “复用主 table” | 同一个 vocabulary embedding table 在所有地方使用；没有重复参数 |
| Projection matrix M_k | “结合 hidden + next-token” | 一个 `h x 2h` linear layer，将前一个 hidden state 和 target-token embedding 折叠为下一深度的输入 |
| Joint loss L_MTP | “平均额外 losses” | per-depth cross-entropy losses 的算术平均值，并按 `lambda` 缩放 |
| Acceptance rate at depth 1 | “MTP draft 多常正确” | D=1 MTP module 的 top-1 prediction 等于主模型 top-1 prediction 的比例；DeepSeek-V3 上超过 80% |
| Lambda weighting | “额外 loss 的重要性” | per-depth 缩放因子；DeepSeek-V3 在训练开始时为 0.3，之后为 0.1 |
