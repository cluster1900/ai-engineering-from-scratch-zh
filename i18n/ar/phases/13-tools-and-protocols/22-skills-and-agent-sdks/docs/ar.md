# مهارات العميل: قابلة للانتقال

> المهارة ليست مجرد تغيير اسم أفضل للوثائق. إنها مجموعة من البرامج التي تتضمن التعليمات والموارد والوسائل المساعدة التي يمكن تنفيذها، وفقًا لما هو واضح في عملية التشغيل.

**Type:** Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 13 · 01 (The Tool Interface), Phase 13 · 05 (Tool Schema Design)
**Time:** ~90 minutes

## 學习目标

- 明确定义 وكيل المهارات،不将其与 prompt、代码库规范文件(إرشادات مخزن)
- 研读可移植的 `SKILL.md`契约,并将其与特定运行时专专有扩展清晰解──
- 将服务发现(اكتشاف) 选择(اختيار) 激活 (激活) 资源加载 (资源加载) 工具调用 (工具使用) 和验证 (验证) 解释为独立的生命周期阶段――
- في التشغيل سيتم إدراج المهارات في قائمة المهارات، قبل تنفيذ التحقق الصارم للبرمجيات الخاصة بها.
- 针对具体工程任务,在技能、MCP工具、hook、subagenct或普通代码之间做理性的技术选择类型──

## 十分钟极速初体验

قبل قراءة المفاوضات المعمقة، يرجى الانتهاء من هذه العملية. سوف تقوم ببناء مهارة صغيرة، سوف تقوم بتثبيت حزمة برنامج المراقب الكاملة في بيئة العميل الحقيقي المضيف، وتطبيقها، وتحقق النتائج، وتفريغها.

### حقيقة مضيف تجربة

المضيف الحقيقي يحتاج إلى Node.js`npx`、بايتون 3、بيئة المضيف الذي يدعم مهاراتك المحددة، وكذلك حرية كتابة المشاريع أو المجال المستخدم الذي تختاره في الجهاز التثبيت.

```bash
node --version
npx --version
python3 --version
```

قبل التثبيت، تحدد أولاً المضيف الذي تريد استخدامه ومجال التثبيت. إذا كان هناك غياب في أي من التواليات المذكورة أعلاه، يمكنك قراءة هذا الدروس على الموقع، أو إجراء مباشرة التدريبات اليدوية التالية.

### 1. من الموقع

في أي استخدام لخزنة تعلم المشاريع:

```bash
mkdir -p agent-skills-first-run
cd agent-skills-first-run
TARGET_ROOT="$(pwd -P)"
printf 'TARGET_ROOT=%s\n' "$TARGET_ROOT"
ls -A
```

آخر أمر يجب أن لا يكون هناك أي إصدارات. إذا كان هناك إصدارات، يرجى تغيير دليل فارغ، حتى هذا المراجعة لديها حدود واضحة.

لممارسة مهاراتك الأولى

```bash
mkdir -p my-first-skill
```

 إقامة `my-first-skill/SKILL.md`, تحتوي على:

```markdown
---
name: my-first-skill
description: Turn rough meeting notes into a compact decision record when the user asks to capture a technical decision.
---

# Decision record

Extract the decision, context, alternatives, owner, and next review date.
If the notes do not contain a decision, ask one clarifying question instead
of inventing one.
```

验证该文件是否已成功创建在目标目录中:

```bash
test -f my-first-skill/SKILL.md
```

无任何输出和退出码为 0 表示文件已存在──

### 2. تنصيب كاملة

ابقوا هنا`agent-skills-first-run`حالياً:


ستعمل`SKILL_ROOT`‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬`SKILL.md`وذلك في حال تم إرسالها إلى المنطقة المختلفة.

### 3. 显然调用它

في وكيل تم تركيبه`agent-skills-first-run`كدليل عمل، باستخدام لغة الصفحة المضيفة:

| 宿主 | 显式调用方式 |
|---|---|
| Codex | 输入 `skill-contract-reviewer`，或从 `/skills` 菜单中选择，然后提交审查请求 |
| Claude Code | 输入 `/skill-contract-reviewer` 紧跟审查请求 |
| 通用可移植回退 | `Use skill-contract-reviewer to review the target package.` |

في الطلب استخدام الطباعة خارج`SKILL_ROOT`和 `TARGET_ROOT`绝对路径── تطلب من المضيف أن يفتح ويعرض أوامر بعد الحل بالكامل قبل تنفيذها ، بدلاً من الاعتماد على أوامر مضحكة من قائمة العمل الحالية:

```text
Use skill-contract-reviewer to review <TARGET_ROOT>/my-first-skill. The installed bundle root is <SKILL_ROOT>. Run python3 <SKILL_ROOT>/scripts/check_skill.py <TARGET_ROOT>/my-first-skill. Before running it, show the fully resolved argv. Return the validation report, selected primitives, and one sentence for each selection. Include the resolved script path, resolved target path, cwd, argv, and exit code as execution evidence.
```

يجب أن يظهر الأمر بعد الحل على النحو التالي، لا يترك أي عنصر غير ملء:

```bash
python3 "/absolute/install/path/skill-contract-reviewer/scripts/check_skill.py" \
  "/absolute/workspace/path/agent-skills-first-run/my-first-skill"
```

يجب أن تلبي نتائج المراجعة الناجحة في نفس الوقت الخصائص الثلاثة التالية:

1. المضيف يمكن أن يكون على اسمها`skill-contract-reviewer`.
2. المحققون نجاح دراسة البرنامج والعمل مع إصدار كتاب التحقق المضمن.
3. تحتوي الاستجابة على تقرير تحقيقي (مثالية شاملة لا أخطاء هيكلية) ، وتقدم توصيات أساسية معينة لانتخاب المكونات المستندة إلى ذلك.

 يجب أن يحدد أيضاً في شهادات التنفيذ مسار الكتاب ‬المستهدف ‬المسجلات الحالية‬cwd‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬

### 4. 探查隐式选择(اختيار ضمني)

فتح وكيل جديد، إدخال نفس المهمة ولكن**不提及**اسم المهارة:

```text
Review <TARGET_ROOT>/my-first-skill as a reusable agent package and tell me whether its package contract is valid.
```


## 问题

افترض أن فريقك لديه مجموعة موثوقة جدا من عمليات الإصدار على الإنترنت: معرفة التغييرات المشتركة المشتركة؛ فحص بيانات نقل قاعدة البيانات؛ تحديث التغييرات؛ تنفيذ أمر التزود، وإصدار المراجعة على الإنترنت؛

إذا وضعت هذه المجموعة من العمل مباشرة في عرض طويل، على الرغم من سهولة نسخ الملصقات، ولكن في النشاط المهني النشطة الثغرة تظهر: هذا المقطع  عدم وجود هوية مستقرة  عدم وجود قواعد العثور على الخدمة  عدم وجود موارد تحميل الحدود  عدم وجود هيكل حزمة يمكن اختبارها، ولا يمكن الإجابة على سلسلة من أسئلة البنية التحتية: من لديه الحق في تدوينها؟

على النقيض من ذلك، فإن الخطأ القصوى هو جعل كل التعليمات القابلة للرد في جزء من العقل كاملة إلى مهارة.`SKILL.md`، والكتابة التي نشأت تبدو ذات بنية عامة ، في الواقع مقيدة عميقة على السلوك غير المعلن لمضيف محدد

مهمة أولى في مجال هندسة البرمجيات هي**分类**قبل أن تقرر كيفية حزم المكونات، فكر أولاً في معرفة ما هو بالضبط هذا المكونات.

## 概念

### المهارات 封装过程性知识

المهارة العميلة هي واحدة`SKILL.md`للدخل المستندات المعتادة. هذا الملف المرجعي يحتوي على المادة الأمامية.

```figure
skill-package-anatomy
```

هذا**目录**الملفات المحددة هي الوحدة الأقلّة في إرسال الدعم الدولي، وليس مجرد نسخة.`SKILL.md`لكنّه قد غادر المستندات المرجعية، حتى لو كانت لغته الصحيحة تماماً، فهذا أيضاً هو البرنامج الذي لم يعد موجوداً.

### 临近概念辨析

| 构件类型 | 核心职责 | 何时加载或运行 | 不应被冒充为 |
|---|---|---|---|
| Prompt | 塑造单次模型交互 | 由应用或用户内联引入 | 包含丰富资源的带版本软件包 |
| 代码库规范（Repository instructions） | 阐明某特定代码库的固有通用准则 | 编码运行时进入该作用域时载入 | 可复用的具体任务工作流 |
| Agent Skill | 提供可复用的过程性知识 | 显式或隐式激活时载入 | 强安全隔离边界 |
| MCP Tool | 暴露类型化的远程能力 | 由模型或应用程序主动发起调用时 | 复杂详细的端到端操作步骤 |
| Hook（钩子） | 在特定事件发生时执行确定性逻辑 | 当所声明的事件发生时触发 | 具有概率性的模型自主路由 |
| Subagent（子代理） | 委托具有独立上下文和状态的任务 | 由编排器创建或调用时启动 | 静态的只读指令包 |
| Plugin（插件） | 分发更大规模的运行时功能扩展 | 宿主安装或启用它时生效 | 可移植的 skill 契约本身 |
| 习得的 Skill 库（Learned skill library） | 存储通过实践探索习得的行为沉淀 | 策略检索到先验程序或轨迹时 | 基于规范标准的 `SKILL.md` 软件包 |

发布技能 可以指导代理 如何审查发布──MCP服务 可以暴露发布注册中心──Hook 可以禁止向主分支直接推代码──Subagent 可以独立审查候选版本──各组件之所以能够有机组合,正因为它们各自坚守不同的职责边界──

### المهارات والمهارات

في مجال البحث العلمي،مهارات أحياناً تُحدد مبادئ البرامج المُتعلقة، أو مسارات التفاعل الناجحة، أو قطع استراتيجيات تستهدف بيئة محددة.

المهارات العملية في هذه السلسلة من المقررات مختلفة تماما. انها حزمة برمجيات مكتوبة يدويا أو مختارة، مع بيانات واضحة من نظام الملفات، وتسجيل المهارات والبيانات، على النموذج التقدمية الإفصاح، والآلية التنظيمية التي تديرها الوقت التشغيل، وكذلك الحقوق في استخدام الأدوات التي يسيطر عليها المضيف بشكل صارم.

| 评估维度 | Agent Skill 软件包 | 习得的 Skill 库 |
|---|---|---|
| 基本单元 | 包含 `SKILL.md` 的目录 | 程序代码、策略片段、交互轨迹或记忆记录 |
| 创建方式 | 人工编写、生成或精选策划 | 通常由 agent 在环境交互中自主探索习得 |
| 选用机制 | 依赖目录描述（Description）加运行时策略 | 基于任务状态的向量检索或策略匹配 |
| 执行方式 | 模型遵循 Markdown 指令并调用宿主工具 | 环境直接执行存储的行为逻辑或代码产物 |
| 可移植性 | 程序包契约可在所有兼容的宿主间流通 | 通常与特定环境及特定的动作空间深度绑定 |
| 评测标准 | 路由准确率、制品质量、安全及宿主兼容性 | 强化学习奖励值、任务成功率、泛化能力及库规模 |

هذه الأفكار كلها تتعلق بقدرة التعبير المكرر، ولكن لا فقط لأن نفس الاسم يخلط بينهما في تنفيذ المشاريع.

### القواعد الأساسية للنقل

المهارات العميلة 规范在前事中强制要求两个必填字段:

```yaml
---
name: release-readiness
description: Inspect a release candidate when the user asks whether a version is ready to publish.
---
```

`name`هو علامة ثابتة، يجب أن تتوافق مع قواعد الإسم، ويجب أن يتوافق تماما مع اسم الكتيب الأب.`description`و هو أيضاً المستندات التي يُعطى البشر نظرة، و هو أيضاً نموذج لإجراء المعلومات الرئيسية في طريق الإجراءات، و يجب أن يوضح هذا المهارة بوضوح.**能做什么**و كذلك**何时应当选用它**.

核心规范允许的可选字段包括:

| 字段 | 用途 | 可移植性说明 |
|---|---|---|
| `license` | 声明该程序包的开源或商用许可条款 | 核心标准规范 |
| `compatibility` | 声明环境要求（如 Python 3.10+、特定 CLI 工具等） | 核心标准规范 |
| `metadata` | 携带字符串键值的自定义扩展数据 | 核心标准规范 |
| `allowed-tools` | 建议预先批准的工具列表 | 实验性特性；不同宿主支持度不一 |

يجب أن يكون واضحاً تحديد عمليات العمل، والقرارات الرئيسية، والخطط المتعلقة بمعالجة الفشل الغريب، والمسارات المتقاربة لمستندات الموارد المشتركة.

```markdown
# Release readiness

Use this workflow for a release candidate, not for ordinary development builds.

1. Read `references/release-policy.md`.
2. Run `python3 scripts/inspect_release.py --format json`.
3. Stop if the report contains a blocking failure.
4. Produce the checklist from `assets/release-checklist.md`.
5. Ask for approval before any publish or tag action.
```

### 运行时扩展(إضافات الوقت) هو الطبقة الثانية

يسمح المضيف بالجزء في المادة الأمامية بكتابة عدة أحكام أو ملفات تعريف محددة.

| 行为特性 | 宿主扩展示例 | 属于通用核心规范？ |
|---|---|:---:|
| 对模型自主路由隐藏，但保留用户手动直接调用 | `disable-model-invocation` | 否 |
| 对用户的命令菜单隐藏，但允许模型自主路由选用 | `user-invocable` | 否 |
| 在斜杠命令菜单中展示参数使用提示 | `argument-hint` | 否 |
| 在被委托的隔离子上下文中运行该 skill | `context`, `agent` | 否 |
| 固定模型型号或思考计算等级（Reasoning Effort） | `model`, `effort` | 否 |
| 注册生命周期自动化钩子 | `hooks` | 否 |
| 在 Codex 中禁用隐式调用 | `agents/openai.yaml` 策略 | 否 |

يجب أن ينظر إلى كل قسم من المملكة الخاصة على أنه مُعدل خارجية. يجب أن يضمن أنه حتى بعد استبعاد هذه الحالات، لا يزال العمل الأساسي متاحاً بشكل قانوني. يجب أن يكتب لهم مستندات تخفيض الوصول إلى الوراء، ويتم إجراء اختبارات مستهدفة على مضيفهم في الواقع.

### المادة الأمامية هي بيانات قابلة للتنفيذ

قبل أن يتم قراءة المعلومات في المهارات، كان هناك تغيير في سلوك النظام:

- 格式错误的 `name`سوف يؤدي مباشرة إلى فشل الخدمة
- 含糊不清的 `description`سوف يؤدي إلى خطأ في طريق الخطأ
- ويمكن أن يُزيل هذا المهارة بشكل كامل من قائمة المهارات المتاحة للنموذج.
- 工具预授权配置会改变主持是否弹出用户授权确认框──
- 上下文 سيتم إعادة توجيه إعداد المفوضية إلى وكيل مستقل

يجب أن يدرس الملفات المخصصة وكود الأعمال بشكل صارم. يجب أن يدرس المادة الأمامية. يجب أن يتم إجراء تجربة تحركية للطاقة الذكية، وإدخال التحكم في الإصدار، وإدخال سلوكها من خلال الوسائل إلى نظام تقييم Eval.

### دورة حياة المهارة

```figure
skill-runtime-lifecycle
```

كل سهم في الرسم يمثل حدود مع نمط الفشل المستقل:

1. **服务发现（Discovery）：**في طريق الكتيب المُقدّم للمُقدّمة مسبقًا،
2. **静态校验（Validation）：**قبل أن يتم الكشف عن المخططات، قم بإيقاف إصلاحات الخطأ أو غير الآمنة.
3. **编目索引（Cataloging）：**فقط إلى النموذج على النحو التالي`name`مع`description`, absolut不提前全量加载──
4. **决策选择（Selection）：**من قبل النموذج أو التوجيهات الواضحة تحديد ما إذا كانت هذه المهارة مرتبطة بالمهمة الحالية.
5. **按需激活（Activation）：**ستعمل`SKILL.md`正文全量载入模型可见的上下文中──
6. **渐进披露（Disclosure）：**فقط في حالة الحاجة الحقيقية إلى إشارات أو أصول
7. **执行推进（Execution）：**في مراجعة سلطة المضيف و قواعد عزل الصناديق، استخدام أدوات المضيف من جميع الأنواع.
8. **结果核验（Verification）：**独立于模型的自述表态,客观核验最终产品质量──

混 هذه المراحل تؤدي إلى نموذج فكر خاطئ: مهارة اكتشاف غير مساوية لتحقيق النشاط ؛ مهارة نشاط غير مساوية للحصول على جميع حقوق التشغيل التي وصفتها ؛ استخدام واحد من الأدوات يتم إطلاقها غير مساوية لنتائج العمل النهائية هي صحيحة.

### المهارات والأدوات 正交互补

حل MCP هو: ما هي القدرات الخارجية التي يمكن للتطبيقات الحالية استخدامها، ما هي مخططاتها العادية؟ بينما حل المهارة هو: كيف يجب على العميل أن يعالج هذا النوع من المهام حسب الوزارة؟

```figure
skill-tool-orthogonality
```

يمكن أن يذكر في المهارات الصحيحة اسم أداة، ولكن الحقوق في تسجيل الأدوات والتنظيمات الفعلية تخص تماماً لبرنامج المضيف. إذا كانت هذه الأداة لا توجد في بيئة التشغيل، يجب أن يقدم المهارات وضوحاً أو واضحاً بشكل مباشر، ولا يمكن أن يكون خطأ في التفكير في أن المهارات المذكورة في المهارات الصحيحة ستخلق هذه الأداة دون أي فرصة.

### المهارات و المعلومات

代码库说明文件(如 `AGENTS.md`) لتصفيك**当前所处**والمهارة هي عملية تشغيل قيود تشكيل، وتصميم، وتوليد قواعد الملفات والخطوط الحمراء الأمنية.

عندما يتم تطبيقهما معاً، فإن التعليمات الفورية للمستخدم والقواعد المعتمدة للمكتبة الحالية من الكود تمتلك أولوية أعلى، وتشكل قيوداً على المهارات. على سبيل المثال، لا يمكن أن تتجاوز المهارات المستخدمة بشكل عام على المكتبة المحلية من الكود بشكل صارم.

### مهارات 之间不进行代码级 وارد

المهارة يمكن أن تكون وكيل إرشاد في اللغة الصينية لتطبيق المهارة الأخرى، ولكن هذا بالتأكيد ليس رمز على مستوى اللغة التخطيطية.`import` المهارة الثانية التي يتم استخدامها لا تزال يجب أن تكون كاملة في التجربة التي تمارسها في عملية العثور على الخدمة  الوصول إلى مراجعة المؤهلات  تنشيط الحركات  اختبار الحقوق  إدارة النظام المستقل

في كتابة على مدار المهارات، يجب أن يتم شرحها على أنها خطوات عملية قابل للملاحظة:

```markdown
After producing the candidate changelog, invoke the `release-risk-review` skill.
Pass the candidate path and require a blocking or non-blocking verdict.
If that skill is unavailable, stop and report the missing dependency.
```

هذا النوع من التعبير يجعل الاختبار المحدد للعلاقات، ويمنح المضيف فرصة لتنفيذ استراتيجيات الالتزام عند تشغيلها.

## 动手构建

`code/main.py`تطبيق معايير الاختيار والتكاملات من نوع خفيف. العملية كلها تعتمد على قاعدة المعايير في بايثون.

الاختبارات:

- `parse_frontmatter(text)`:精准分离元数据与马克down 正文
- `validate_skill_text(text, directory_name, allowed_runtime_extensions=())`: strict校验必填字段、命名约束、未声明扩展、正文存在性以及可移植长度限制──
- `ValidationIssue`مع`SkillReport`: إعادة شهادة مراجعة كاملة للمنظمات، وليس مجرد قيمة غير واضحة.
- `FrontmatterSyntaxError`: للمحاولة غير القانونية التي لا يمكن تحليلها بأمان

الاختيارات للخروج`TaskShape`مع`select_primitives(task)` يعتمد على الخصائص الفعلية للمهمة، ويحتوي على تحديدها بشكل صحيح على أداة كود عام 

## استخدمها

قبل كتابة مهارة جديدة، يرجى إكمال هذه البطاقة القرارية:

| 决策问题 | 若答案为“是” | 最匹配的基本构件 |
|---|---|---|
| 该任务是否需要在多个步骤中反复运用模型的主观判断？ | 操作流程基本固定，但具体决策千变万化 | Skill |
| 该操作是否必须在特定事件发生时 100% 强制触发？ | 哪怕遗漏一次执行也是完全不可接受的故障 | Hook 或常规业务代码 |
| 模型是否需要调用具有类型化输入的外部能力？ | 该操作本身存在于模型的思维上下文之外 | Tool 或 MCP Server |
| 该工作是否需要完全隔离的上下文、独立状态或责任归属？ | 由独立的执行单元完成工作并仅返回受限结果 | Subagent |
| 该指南是否仅适用于当前这一个特定的代码库？ | 描述的是本地开发命令、目录规范与约束边界 | 代码库说明（如 AGENTS.md） |
| 单次简短的即时交互是否就足以解决问题？ | 无需任何版本化和包生命周期的管理维护 | Prompt |

العديد من عمليات الإنتاج المعقدة تكون عادةً مجموعة من العديد من المكونات. يمكن أن يمنع هذا القرار المطور من الوقوع في منطقة خطأ في تشكيل المكونات.

## 关键术语

| 术语 | 通俗说法 | 精确工程含义 |
|---|---|---|
| Agent Skill | "保存好的 Prompt 模板" | 包含过程性操作指南与可选资源的标准化、可发现文件目录 |
| 可移植核心（Portable Core） | "所有运行时共享的通用字段" | 由 Agent Skills 官方规范所定义的基础契约标准 |
| 运行时扩展（Runtime Extension） | "额外的 Frontmatter 字段" | 平台特定的专有配置，其行为生效需要对应宿主适配器的支持 |
| 激活（Activation） | "Skill 跑起来了" | Skill 的正文指令被完整载入模型可见的上下文，后续执行可能滞后发生 |
| Skill 依赖（Skill Dependency） | "Import 另一个 Skill" | 由运行时负责调度的调用关联步骤，受到环境可用性与权限策略的严密审查 |
| Tool 契约（Tool Contract） | "函数 Schema 声明" | 为某项外部能力所定义的输入、输出、权限、副作用、错误码以及审计证据规范 |
