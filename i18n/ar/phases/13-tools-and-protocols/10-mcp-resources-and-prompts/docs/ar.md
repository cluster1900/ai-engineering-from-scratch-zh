## 2026-07-28 无状态信封

本课针对 MCP 协议版本 `2026-07-28`في هذا النظام التنظيمي، لا توجد إطلاق يد المشاركة أو جلسة بروتوكول`_meta`键中携带其协议版本和客户端功能──

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "resources/list",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      },
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
```

الخادم يجب أن يتم تنفيذه`server/discover` عودة النتائج إلى إصدار دعم خارجية  الموارد مع القدرات السريعة  تحقيق العلامة وكذلك تلميحات الاحتفاظ (كاشش)  النقاط الاحتفاظ بها  العميل يمكن استخدام منه بشكل مباشر ، ولكن اكتشاف  العميل  قادرة على الحصول على صورة سريعة مستقرة في بناء واجهة الوصول.

```json
{
  "resultType": "complete",
  "supportedVersions": ["2026-07-28"],
  "capabilities": {
    "resources": {"listChanged": true, "subscribe": true},
    "prompts": {"listChanged": true}
  },
  "ttlMs": 3600000,
  "cacheScope": "public"
}
```

常规结果会声明 `"resultType": "complete"`◊ ردّ`_meta`-أعرض`io.modelcontextprotocol/serverInfo`معلومات تنفيذية من جانب خدمة التعرف. هذه المعلومات تستخدم للتشخيص، وليس بطاقة هوية.`-32022`错误,同时带上所请求的版本以及服务支持的版本列表──

无状态契约会重塑你的设计直觉―― استفسارات القائمة لا تعتمد على واحد من المعلومات التاريخية على اتصال سابقة.

## الموارد هو ثابتة

الموارد هي من خلال محتوى URI 标识.

الخصائص التي يجب أن يكون بها أوراي جيد:

- ثابتة بما فيه الكفاية، يمكن أن يتم إضافةها إلى كتب أو إرسالها بين الطلبات المتعددة.
- 划分在服务的专有命名空间( namespace) 下。
- 独立于具体进程 ID 或连接──
- قبل زيارة مخزن التجربة
- كل مرة يُقرأ فيها يتمّ إعطاء الحقّ في التعرف على الحقّ

`notes://note-1`优于 `note-1`لأن مساحة تسميته واضحة . يمكن استخدام خادم الملفات`file://`و بعد أن تمت إصدار أورات، يجب أن يتم فحصها بشكل صارم على الحدود المخصصة.

`resources/list`返回调用方当前可见的资源──必需按照稳定键 (例如 URI)排序──确定性的顺序可以防止缓存震荡击穿(缓存错过)、快照漂移以及主机UI 在刷新时发生跳动──

```json
{
  "resultType": "complete",
  "resources": [
    {
      "uri": "notes://note-1",
      "name": "Architecture decision",
      "description": "Why the service uses a stateless boundary",
      "mimeType": "text/markdown"
    }
  ],
  "ttlMs": 300000,
  "cacheScope": "public",
  "_meta": {
    "io.modelcontextprotocol/serverInfo": {
      "name": "notes-server",
      "version": "2.0.0"
    }
  }
}
```

`resources/read`返回一个或多个内容项──未知的URI 不代表读取成功但内容为空──目前的资源 规范将无效或未知的资源URI 归类为 JSON-RPC 无效参数,错码为`-32602`.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "error": {
    "code": -32602,
    "message": "Unknown or invalid resource URI",
    "data": {
      "uri": "notes://missing"
    }
  }
}
```

هذا التمييز يسمح للعميل بتحديد الموردات بشكل واضح عدم وجود وثائق فارغة فعالة، وفي الوقت نفسه يمنع العودة غير المطلوبة إلى البحث الشامل على نطاق أوسع.

### الموارد 模板

الموردة المستخدمة لوصف URI ذات العناصر العادية. عندما يتم إعداد جميع المواد المحددة عندما تكون تكلفة المواد المحددة مرتفعة أو لا حدود لها، يجب استخدام الموديل.`notes://projects/{project}/decisions/{decision}`أخبر العميل كيف يُبني عنوانًا فعالًا ، دون الحاجة إلى إدراج كل القرارات مرة واحدة.

المخطط لا يعني تخفيف تجربة التحليل والتحديد والتحديد والتحديد والتحديد والتحديد والتحديد والحد من الطول والخطوط، وذلك باستخدام العناصر القوية من نوع الاختيارات لتكوين استفسارات الاحتفاظ.

### 内容并非可信指令

المورد 文本可能包含即时注入、密钥、误导性命令或恶意格式的标记──主机 应保留来源追踪(来源),并将资源 内容一律视为数据──服务器 应限制内容大小、返回准确的MIME 类型、脱敏调用方无权访问的字段,并避免返回无关记录──

## المستخدم السريع

تُمكن المضيف أن يُصَوِّرها على إرشادات مُسلّطة (slash commands) أو (menu单项) أو (工作流按──) ، والاتفاق نفسه لا يحدد نوعًا محددًا من أشكال إظهار UI المحددة.

على نفس الطلبات`prompts/list`إنتاج يجب أن يكون محدد. كل طلب يحتاج إلى اسم ثابت وصف مفيد، وكذلك قادرة على جعل المضيف في الاستخدام.`prompts/get`قبل جمع بيانات المواد المفروضة

```json
{
  "resultType": "complete",
  "prompts": [
    {
      "name": "review_note",
      "title": "Review a note",
      "description": "Review one note for a named concern",
      "arguments": [
        {
          "name": "uri",
          "description": "The note resource URI",
          "required": true
        }
      ]
    }
  ],
  "ttlMs": 600000,
  "cacheScope": "public"
}
```

`prompts/get`سوف يتم تحليل العناصر إلى مجموعة من المعلومات. لن يبدل نظام المضيف التعليمات. المضيف يمتلك القرار على كيفية دخول المعلومات العائدة إلى النموذج على ما يلي، والحفاظ دائما على استراتيجية الثقة الخاصة به ذات الأولوية العالية.

في الخادم 边界处严格校验提示 参数。 URI المشار إليه في الإرشاد يجب أن يمر مع إدارة القراءة المباشرة نفسها.

## 缓存提示是正确性 جزء

`ttlMs`إعلام العميل النتيجة يمكن استخدامها لفترة طويلة`cacheScope`وصف من يمكن أن يشارك هذه القيمة الحفظية

| 范围 | 含义 | 典型用途 |
|---|---|---|
| `public` | 在鉴权许可的前提下可在多用户间复用 | 公共 prompt 目录 |
| `private` | 绑定到请求发起用户或凭证上下文 | 用户名下的私有笔记内容 |

تُختار النظام التلفزيوني العام على مدار 5 دقائق، بينما يمكن أن يُعدّ النتائج الخاصة على مدار 1 دقيقة.

المفوضية 规范中 `cacheScope`                                                    `public`和 `private` لاستعادة نتائج تتضمن أسرار حساسة أو تغيرات أكثر شيوعاً`cacheScope: "private"`配合 `ttlMs: 0`بعد ذلك، تم تطبيق قواعد لا تخزين أكثر صرامة في استراتيجية تخزين المضيف.`no-store`本身并不是 MCP 规范中 `cacheScope`取值──

缓存提示永远不能取代鉴权.缓存键必须包含所有影响可见性的请求维度,包括租户(租户) 、用户、权限范围(范围) 、语言区域(本地) 以及分页游标标(صفحة cursor) ⋅ إذا لم يتمكن المشاركة في缓存 من إظهار هذه ال维度 بأمان، يرجى استخدام `private`配合 0 TTL، وتطبيق مستضيف 层 no-store 策略──

## 订阅 استخدام المستخدمين الإجابة

现代的订阅模式取代原始的`resources/subscribe`RPC و النسخة القديمة على أساس HTTP GET من نقطة الحدث.

العميل على شكل JSON-RPC الطلبات`subscriptions/listen`في درجة التوصيل HTTP المباشر، هذا هو POST الطلب، والتي تتمثل في الحفاظ على حالة مفتوحة على HTTP ك SSE(Server-Sent Events)`notifications`المستخدم هو قائمة بيضاء. الخادم لا يمكن أن يقدم نوع الإخطار غير المطلوب.

```json
{
  "jsonrpc": "2.0",
  "id": 17,
  "method": "subscriptions/listen",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {},
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      }
    },
    "notifications": {
      "resourcesListChanged": true,
      "promptsListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

طلب الهوية 即为订阅 هوية ((تسجيل الهوية) 』 قبل إرسال أي شيء مطلوب من الحدث، الخادم سوف إرسال `notifications/subscriptions/acknowledged`الإخطار. من بين هذه الظروف المضادة يحتوي فقط على الخادم.

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/subscriptions/acknowledged",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "notifications": {
      "resourcesListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

كل حدث على هذا التدفق يحتوي على نفس البيانات:

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/resources/updated",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "uri": "notes://note-1"
  }
}
```

إشعار عن الموارد  قد حدث تغييرات  العميل في الحالي من حقوق التعرف`resources/read`重新读取该资源── العميل لا ينبغي أن يفترض أن يكون المعلومات في الحدث نفسه تحتوي على آخر الملفات المحتوى──

العديد من المشتركين يمكن مشاركتهم نفس المقطع الاستديو 通道──تعرف الاشتراك 让客户端 能够对其进行多路解复用(demultiplex)──在HTTP 上,关闭响应流即可取消订阅──平稳关闭流的服务器会返回一个与最初请求关联的最终`resultType: "complete"`响应‬

切勿将订阅流当作协议会话(بروتوكول جلسة) استخدام。 بعد ذلك عملية القراءة لا تزال كاملة طلب مستقل، قادرة على الطريق إلى أي صحة الخادم 实例。
