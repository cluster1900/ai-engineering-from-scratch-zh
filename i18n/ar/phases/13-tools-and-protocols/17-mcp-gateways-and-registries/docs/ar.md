# 无状态 MCP 网关与 سجل 准入

> يجب أن يجعل كل طريق واضحاً. 2026-07-28 规范 تمنحها طريقة، اسم، نسخة، قدرة، هوية، كاشوفية وملاحقة الحدود، دون الحاجة إلى الاعتماد على أي من مراحل الإرسال.

**Type:** Learn
**Languages:** Python
**Prerequisites:** Phase 13 · 15 (security), Phase 13 · 16 (authorization)
**Time:** ~75 minutes

## 學习目标

- بعد أن تم جمع العديد من خادمات MCP في نقطة واحدة 2026-07-28 ، و لا تعتمد على المحادثة المباشرة
- قبل تطبيق استراتيجية أو تحول، التحقق الأول لكل طلب من البيانات والمسارات.
- حسب استقرار الاسم فضاء 确定性排序 描述器 锁定  RBAC 和私有缓存进行工具 合并──
- سجل شهادة اكتشاف الخدمة، ولكن لا يزال هناك حاجة لإجراء استراتيجية دخول الإنترنت.
- صحيح طريق من درجة الطلب`subscriptions/listen`、MRTR 重试以及 المهام 扩展调用──
- سوف يترك اليد والجلسة  دعم مع طريق الترميز الحديثة لإجراء فصل الفيزيائي.

## 问题

إنّ توصيل مشترك واحد مباشرة إلى خادم واحد بسيط جداً، ولكن مع توسيع حجمها، فإنّ الحالة الإنتاجية المعقدة تتطلب إجابة موحدة للمسألة التالية:

- هل تسمح بالدخول إلى أي خادم؟
- أي موضوع يستطيع رؤية أو استخدام أداة معينة؟
- كيفية التعامل مع الإصدارات الأخيرة؟
- كيفية مراجعة التغيرات التالية للمصفوف؟
- أين يجب تنفيذ الحد من السرعة والتحقيق؟
- هل يمكن لأي مثال من المجموعة أن يعالج طلب المجيء التالي؟

网关(Gateway)充当客户端与各后端MCP服务器 之间中介――它对外暴露统一的MCP端点,施加横切的安全策略,并负责转发经批准请求――

旧版网关设计往往将一个客户端会议多路复用多后端会议 中,并对 `Mcp-Session-Id`进行重写── هذا ينطوي على النسخة القديمة兼容设计──2026-07-28 核心协议中已没有任何协议会议的概念──

## 概念

### 现代网关请求路径

针对每一个入站请求:

1. من انتقال الطبقة التعرف الحق في الاعتراف طلب موضوع ((أساسي)
2. 验证 `MCP-Protocol-Version`.`Mcp-Method`.`Mcp-Name`و`params._meta`.
3. على الموضوعات ‬الموارد المستهدفة‬الوسائل والحجج‬التي تمنحها الهيئة‬
4.  تطبيق وصف  استراتيجية  سجل  إدخال  محدودة التيارات و استراتيجية الاتفاقية البيانات 
5. بناء آخر آخر تم اختياره كاملة جديدة
6. نتائج العودة بعد الاختبار، والعودة إلى العملاء نتائج معالجة الجانب التابع للشبكة.
7. -أحداث المراجعة السجلية، و لا طباعة مفاتيح المفتاح

لا تحتاج العملية بأية جلسة اتفاقية مخفية. لا يزال حالة درجة التطبيق يمكن أن تستمر بشكل جيد في قاعدة البيانات.

### 单一 POST 端点

现代 Streamable HTTP سوف تنشر كل JSON-RPC 报文均均通过 HTTP POST 发送:

```text
POST /mcp
Authorization: Bearer <gateway-token>
MCP-Protocol-Version: 2026-07-28
Mcp-Method: tools/call
Mcp-Name: notes.search
Accept: application/json, text/event-stream
```

对于该 POST请求,网关可以返回 JSON响应,或者返回仅限于该请求作用域的 SSE流――现代请求针对 GET 和 DELETE 均返回 HTTP 405 Method Not Allowed――`Mcp-Session-Id`مع`Last-Event-ID`لا يوجد أي سلطة أو قدرة على التواصل أو الإعادة

يجب أن تكون قيمة HTTP Header و JSON-RPC Body متطابقة تماما. في نهاية البحث، عندما تجد عدم الاتفاق، عود مرة أخرى على الفور.`-32020`错误进行拒绝──这样负载均衡器、网关与限流器便无需完整解析                                                                                                                                                                                                                                                   

                                                                                                                                                                                                                                                              `-32020` إذا كان الرأس مع الجسم واحد ولكن الإصدار غير مدعوم، عود إلى HTTP 400 مع الخطأ `-32022`و`data`精确为 `{"supported":["2026-07-28"],"requested":"<actual>"}` طريقة غير معروفة للعودة إلى HTTP 404 مع الخطأ`-32601`.

`ProtocolError`يمكن أن تحملها`data`, سيتم ترتيبها إلى JSON-RPC  خطأ في المواد .`id`، لذلك لن تتلقى أبدا JSON-RPC نجاح أو خطأ في الاستجابة.

### في كل طبقة تنفيذ الخدمة

网关面向客户端实现 `server/discover` في الوقت نفسه، فإن شبكة التواصل ستقوم أيضاً بتحديد إمكانات إصدارات الإتفاقات والإمكانيات التي تدعمها الخدمات في كل نهاية أخرى.

网关返回的发现结果示例:

```json
{
  "resultType": "complete",
  "supportedVersions": ["2026-07-28"],
  "capabilities": {
    "tools": {"listChanged": true}
  },
  "ttlMs": 30000,
  "cacheScope": "private",
  "_meta": {
    "io.modelcontextprotocol/serverInfo": {
      "name": "enterprise-gateway",
      "version": "2.0.0"
    }
  }
}
```

فقط إعلانات خارجية أن شبكة الإنترنت نفسها قادرة على الدعم الكامل للطرف الخارجي.

`serverInfo`純ّة بيانات عرض وتحليل تقرير، لا تعتبرها سجلًا أو دليلًا على صحة الناشر.

### 逐请求的客户端 قدرات

كل طلب يُرسل إلى آخر محتاج إلى إحضار آخر`_meta`信封:

```json
{
  "io.modelcontextprotocol/protocolVersion": "2026-07-28",
  "io.modelcontextprotocol/clientCapabilities": {},
  "io.modelcontextprotocol/clientInfo": {
    "name": "enterprise-gateway",
    "version": "1.0.0"
  }
}
```

لا تنظر إلى قدرات العملاء الخارجيين بشكل عميق. في النهاية، فإن الشبكة نفسها هي فقط المستخدم.

### 确定性的命名空间隔离

وضع كل أدوات آخر تحت مساحة الإسم العامة المحددة:

```text
notes.search
notes.create
issues.list
issues.open
```

维护 from public名称到后端实例及原始工具 名称的映射表──绝不能按发现先后顺序随意处理重名碰撞──公共名称构成审批与审审计契约的一部分,变更公共名称属于 Breaking Migration──

### 锁定已批准的描述符 (مصدرات الموصف المعتمدة)

في مرحلة الانتقال، يتم إجراء تصنيف كامل للمصفوفة والمعالجة والحساب، والحفاظ عليه تحت اسم عام محدد تماما.

عندما تتغير الاختبار:

- سوف تتوقف`tools/list`-منتصف المنتصف
- 坚决拒绝直接调用──
- 触发安全审计事件──
- في الحديث لا يزال هناك حاجة إلى إعادة التقييم الإجتماعي أو الإجتماعي

网关 هو نقطة تحكم مركزية قوية ، ولكنها لا تجعل وصفًا أولًا يظهر في الفضاء آمنًا.

- المراقبين، وقتاً ومرة

### 凭据中介机制(الوساطة الاعتمادية)

网关 يقوم بتصديق الهوية للمستخدم الخارجي،并独立向后端各服务 进行身份认证──后端的认证凭证绝不能泄露给前端客户端──

保持以下映射绑定关系显式清晰:

```text
outer principal -> gateway role and policy
backend issuer + resource -> backend registration and token
```

لا يمكن أبداً نقل رمز التوصيل الخارجي إلى النقطة الخلفية. لا يمكن أبداً إعادة استخدام رمز آخر إلى المصدِّقين أو الموارد الأخرى. إذا كان هناك أداة تحتاج إلى تمثيل عملية تنفيذ المستخدم النهائي، يجب أن يتمّ تمثيل تبادل الوتوكات المصمّمة خصيصاً أو دعوى تمثيل النظام التوصيل لهذا الصندوق، فلا تستخدم بطاقة حساب خدمة مشتركة لتحميل المستخدم.

### غير متعلقة الحد من سرعة الجلسة

 حسب المواطن المعتمد، المصدر، الموارد، الأداة العامة، الاسم، درجة التكلفة، ومدى التنفيذ في نافذة الزمن.

قبل تنفيذ منطق الأعمال المرتفعة، أولاً تنفيذ تأكيد القانونية منخفضة التكلفة.

### 长生命周期的变更通知

لإشعار بتغييرات القائمة والموارد، رسلة `subscriptions/listen`并接收 SSE 响应──通知过器使用平字段:`toolsListChanged`.`promptsListChanged`.`resourcesListChanged`و`resourceSubscriptions`:

```json
{
  "jsonrpc": "2.0",
  "id": "listen-tools",
  "method": "subscriptions/listen",
  "params": {
    "notifications": {
      "toolsListChanged": true
    },
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
```

أول الأحداث تستخدم للتأكيد على دعمها الملاحظة الجمعية.

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/subscriptions/acknowledged",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": "listen-tools"
    },
    "notifications": {
      "toolsListChanged": true
    }
  }
}
```

网关 بعد ذلك فقط تحويلات من نوع التغييرات التي تم تأكيدها.`params._meta`في المنتصف`io.modelcontextprotocol/subscriptionId`لا يوجد جهاز إعادة إعادة إرسال أو إعادة إرسال تلقائي. بعد إعادة الاتصال، يجب على المستخدم إعادة فتح المشتريات وتحديث بيانات القائمة التي تعتمد عليها.

现代路径彻底取代了 `resources/subscribe`.`resources/unsubscribe`وبالإضافة إلى هذه الميزات القديمة فقط باعتبارها طرق النسخة القديمة التي تحت السيطرة على الإصدارات غير المطلوبة.

### 穿透网关的 MRTR 交互

عندما تعود`resultType: input_required`عندما، فقط على شرط دعم بيانات العملاء الخارجيين لطلب الدخول المطلوب، يمكن للشبكة أن تحويل النتيجة إلى النطاق السفلي. إلا إذا كان الشبكة قد انتهت و إعادة إنتاج عملية التواصل، وإلا يجب أن يتم نقلها بشكل فردي.`requestState`.

客户端 استخدام كامل جديد JSON-RPC ID مع `inputResponses`重试原始公共工具──网关 重试请求重新鉴定权,校验相同公共路径,然后构建全新的后端请求向下转发──网关绝不能假定前轮已经获得无限批准──

### المهام التوسع 路由

المهام هي إضافة رسمية،`io.modelcontextprotocol/tasks` هي بالتأكيد ليست بديلاً من جلسة بروتوكول الأساسية‬

 العميل في كل طلب من العميل.`tools/call`، وكل ما يخصه هو أن يعود إلى النتائج العادية`resultType: task` المهام نتيجة مباشرة`taskId`.`status`الوقت`ttlMs`و الاختيارات`pollIntervalMs` قبل إرسال هذا النتيجة، يجب أن تكون حالة المهمة قابلة للتمسك وتتمكن من القراءة

网关针对这个不透明的任务 标识符记录已认证主体与后端路由──随后 `tasks/get`.`tasks/update`و`tasks/cancel`调用均使用 `params.taskId` كمـ`Mcp-Name`، مما يوفر المفاتيح الطبيعية للجميع من الوسطى.`tasks/get`عودة مع وجود حالة المهمة الحالية`resultType: complete`، وخلال النهاية في النهاية نتيجة النهائية أو خطأ الاتفاق`tasks/update`发送带键名 的`inputResponses`لتوفير المهام المطلوبة غير مقصودة، وإعادة إلى الفضاء الكاملة`tasks/cancel`إعلان التعاون مع إغلاق الغرض، عودة إلى الفضاء كاملة  تأكيد الإجابة، ولكن لا يضمن أن المهمة اللاحقة ستوقف على الفور

لا تنفيذ جديد `tasks/list`أو`tasks/result`方法, they belong to the old version of experimental models.  تحتاج إلى إدخال المهام من خلال `tasks/get`暴露完整的内嵌请求;客户端通过 `tasks/update`‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬

## 关键术语

| 术语 | 含义 |
|------|------|
| MCP 网关 | 位于客户端与后端 MCP server 之间的安全策略与路由中心 |
| 准入记录（Admission record） | 允许特定后端接入网关的完整安全证据与审批策略决策 |
| 完全限定 tool 名称 | 稳定的对外公共路由名称，如 `notes.search` |
| Descriptor 锁定（Pin） | 在服务发现和请求分发期间严格比对校验的已批准哈希 digest |
| 私有缓存作用域（Private cache） | 缓存结果严格受限于单一授权主体与上下文，禁止跨用户共享 |
| 请求级作用域 SSE | 直接挂载在单次 POST 请求上的流式响应，连接关闭即取消请求 |
| `subscriptions/listen` | 客户端通过 POST 打开的 SSE 长连接，用于监听特定的列表变更通知 |
| 任务路由（Task route） | 将不透明的 taskId 映射到具体后端的应用层状态映射 |
| Legacy 适配器 | 带有明确版本门禁的隔离层，用于兼容旧版握手与 session 机制 |
