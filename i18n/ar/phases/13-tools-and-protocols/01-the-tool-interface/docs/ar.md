## 概念
### الخطوة الأولى: وصف

المضيف استخدام ثلاثة أدوات

- **Name.**إشارة ثابتة يمكن قراءتها بواسطة آلة`get_weather`، وليس شيء الطقس
- **Description.**段自然语言简介── عندما يسأل المستخدم عن الحالة الجوية الحالية في مدينة معينة
- **Input schema.**一个描述工具参数的JSON Schema对象(مشروع 2020-12)。

模型会接收这个列表──提供商现代将使用供应商特定的模板将这些声明序列化到系统提示,因此作为调用方,你只需要处理结构化形式──

### الخطوة الثانية: تقرر

给定用户消息和可用工具,模型会选择三种行为之一──

1. **直接用文本回答**لا تقوم بإجراء مكالمة أداة
2. **调用一个或多个 tools。**输出结构化 call objects──在 `parallel_tool_calls: true`(OpenAI 和 Gemini 默认启用,Anthropic 需要选择), يمكن أن ينطلق العديد من المكالمات في جولة واحدة
3. **拒绝。**النتائج المهيكلة في الوضع الصارم يمكن أن تولد نوعية`refusal`حظر، وليس دعوة.

أداة واحدة تصل إلى الحمل المفيد هناك ثلاثة أجزاء ثابتة:`id`أداة`name`، و JSON `arguments`وجود الهاتف، من أجل جعل المضيف قادر على إصدار النتائج اللاحقة مع مكالمة معينة، عندما تتصل مكالمات متوازية، هذا أمر مهم جدا.

### الخطوة الثالثة: تنفيذ

المضيف المكالمة المقبلة، وفقاً لتعليمات مخطط التحقق من الحجج،并运行 εκτελεστής. الحجج غير الفعالة يعني أن النموذج توهم 已某段或使用错类型

إن المفرد هو مجرد كود عادي. في Python,TypeScript,shell command,database query,الذي ينتج نتيجة، عادةً تكون سلسلة، ولكن يمكن أن تكون أي قيمة JSON أو كتلة محتوى مهيكلة في MCP يمكن أن تكون نص، صورة أو مرجع للموارد.

### الخطوة الرابعة: مراقبة

المضيف سوف أداة النتيجة  إضافة إلى المحادثة 中( ك带有匹配 `id``tool`الموديل الآن في السياق تمتلك أداة خروج، يمكن أن تولد الإجابة النهائية، أو طلب المزيد من المكالمات.

### ثقة انفصلت

أدوات هناك نوعان مهمان جداً للسلامة

- **Pure.**لا يوجد آثار جانبية`get_weather`.`search_docs`.`get_current_time`يمكن أن تجري بشكل آمن التكهنات
- **Consequential.**سيتغير الحكومة                                                                                                                                                                                                                                                             `send_email`.`delete_file`.`execute_trade`يجب أن أضيف البوابة

يظهر قاعدة اثنين، في دور واحد، أن يكون هناك اثنين من الثلاثة: المدخلات غير الموثوق بها، البيانات الحساسة، والعمل التالي، واجهة الأداة، هو تمكينك من تنفيذ هذه القاعدة من خلال رفض المكالمات، وتطلب من المستخدم تأكيد أو تعزيز المجال.

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Tool | “模型可以调用的东西” | name + JSON-Schema-typed input + executor function 组成的三元组 |
| Function calling | “Native tool use” | Provider-level API 支持，用于输出结构化 tool calls，而不是 prose |
| Tool call | “模型发出的行动请求” | 模型输出的一个 JSON payload，包含 `id`、`name`、`arguments` |
| Tool result | “tool 返回的内容” | executor 的输出，被包装在带有匹配 id 的 `tool` role message 中 |
| Parallel tool calls | “一次多个 calls” | 一个 model turn 中的多个 call objects，彼此独立，并可通过 id 排序 |
| Strict mode | “Guaranteed JSON” | Constrained decoding，强制模型输出通过已声明 schema 的验证 |
| Pure tool | “Read-only tool” | 无 side effects；可以安全地重新运行 |
| Consequential tool | “Action tool” | 会改变 external state；需要 gate、audit 或用户确认 |
| Four-step loop | “The tool-call cycle” | describe → decide → execute → observe |
| Host | “Agent runtime” | 持有 tool registry、调用模型并运行 executor 的程序 |
