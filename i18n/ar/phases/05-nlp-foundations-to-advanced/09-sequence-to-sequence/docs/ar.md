## 概念
**Encoder.**读取 source sentence 的 RNN──它的最终隐藏状态是 **context Vector** لجميع المدخلات المثبتة                                                                                                                                                                                                                                                         

**Decoder.**另用文本向量初始化 RNN──在每一步,它以前一次生成的令子 作为输入,并产生目标词汇上的分布──通过样本或 argmax 选择下一个令子──再把它回去──重复,直到产生`<EOS>`الـ "توكين" أو يصل إلى أقصى طول

**Training:**في كل خطوة من مراحل التشريح  حساب الخسارة المتقاطعة للاندروبي،并沿序列 求和──通过两个网络做标准 backprop عبر الوقت──

**Teacher forcing.**خلال التدريب، المُعزل في خطوة`t`                                                  `t-1`علامة *أرض-حقيقة* بدلا من المفكّر نفسه قبل مرة واحدة من التنبؤات. هذا سوف يثبت التدريب. بدونها، في مرحلة الخطأ المبكر، فإن النموذج لن يتعلم أبدا.**exposure bias**.

**The bottleneck.**كودر تعلمت عن كل شيء عن المصدر، يجب أن يتم إخراجها إلى السياقات المتجهة.

### 步骤 1: مرموز

```python
import torch
import torch.nn as nn


class Encoder(nn.Module):
    def __init__(self, src_vocab_size, embed_dim, hidden_dim):
        super().__init__()
        self.embed = nn.Embedding(src_vocab_size, embed_dim, padding_idx=0)
        self.gru = nn.GRU(embed_dim, hidden_dim, batch_first=True)

    def forward(self, src):
        e = self.embed(src)
        outputs, hidden = self.gru(e)
        return outputs, hidden
```

### 步骤 2: جهاز تشكيل

```python
class Decoder(nn.Module):
    def __init__(self, tgt_vocab_size, embed_dim, hidden_dim):
        super().__init__()
        self.embed = nn.Embedding(tgt_vocab_size, embed_dim, padding_idx=0)
        self.gru = nn.GRU(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, tgt_vocab_size)

    def forward(self, token, hidden):
        e = self.embed(token)
        out, hidden = self.gru(e, hidden)
        logits = self.fc(out)
        return logits, hidden
```

المفكّر 每次调用步骤──输入:一批单个 Token 和当前隐藏状态──输出:下一个 Token 的词汇库存,以及更新后的隐藏状态──

### 步骤 3: حلقة تدريب مع إجبار المعلم

```python
def train_batch(encoder, decoder, src, tgt, bos_id, optimizer, teacher_forcing_ratio=0.9):
    optimizer.zero_grad()
    _, hidden = encoder(src)
    batch_size, tgt_len = tgt.shape
    input_token = torch.full((batch_size, 1), bos_id, dtype=torch.long)
    loss = 0.0
    loss_fn = nn.CrossEntropyLoss(ignore_index=0)

    for t in range(tgt_len):
        logits, hidden = decoder(input_token, hidden)
        step_loss = loss_fn(logits.squeeze(1), tgt[:, t])
        loss += step_loss
        use_teacher = torch.rand(1).item() < teacher_forcing_ratio
        if use_teacher:
            input_token = tgt[:, t].unsqueeze(1)
        else:
            input_token = logits.argmax(dim=-1)

    loss.backward()
    optimizer.step()
    return loss.item() / tgt_len
```

اثنين من المفاتيح التي تستحق الاسم`ignore_index=0`سأقفز فوق إشعار التعبئة`teacher_forcing_ratio`يبدأ كل خطوة باستخدام الوهم الحقيقي بدلا من احتمالات توقعات النموذج.

### 步骤 4: حلقة الاستنتاج (طموح)

```python
@torch.no_grad()
def greedy_decode(encoder, decoder, src, bos_id, eos_id, max_len=50):
    _, hidden = encoder(src)
    batch_size = src.shape[0]
    input_token = torch.full((batch_size, 1), bos_id, dtype=torch.long)
    output_ids = []
    for _ in range(max_len):
        logits, hidden = decoder(input_token, hidden)
        next_token = logits.argmax(dim=-1)
        output_ids.append(next_token)
        input_token = next_token
        if (next_token == eos_id).all():
            break
    return torch.cat(output_ids, dim=1)
```

التشفير الفاسد في كل خطوة اختيار احتمال أعلى رمز.**Beam search**سأحتفظ بالعلبة`k`个部分序列,最后选择得分最高的完整序列──梁宽 3-5 是标准设置──

```markdown
---
name: seq2seq-design
description: 为给定任务设计 sequence-to-sequence pipeline。
phase: 5
lesson: 09
---

给定任务（translation、summarization、paraphrase、question rewrite），输出：

1. 架构。默认使用 pretrained transformer encoder-decoder（BART、T5、mBART、NLLB）。RNN-based seq2seq 只适用于特定约束。
2. Starting checkpoint。命名它（`facebook/bart-base`、`google/flan-t5-base`、`facebook/nllb-200-distilled-600M`）。让 checkpoint 匹配任务和语言覆盖范围。
3. Decoding strategy。Greedy 用于 deterministic output，beam search（width 4-5）用于质量，带 temperature 的 sampling 用于多样性。用一句话说明理由。
4. 发布前要验证的一个 failure mode。Exposure bias 会表现为较长输出上的 generation drift；抽样 20 个位于 90th-percentile length 的输出并目检。

对于少于一百万 parallel examples 的情况，拒绝推荐从头训练 seq2seq。将任何面向用户内容却使用 greedy decoding 的 pipeline 标记为 fragile（greedy 会重复并陷入循环）。
```

## التدريب
1. **Easy.**实现 toys copy task──在 target等到源的输入输出对 上训练GRU seq2seq──测量长度 5、10、20 的精度──复现瓶──
2. **Medium.**添加束宽 3 的束搜索解码──在小型平行体上对比贪测量 BLEU──记录束搜索 胜出的地方(通常是最后几个代币) 以及它没有差异的地方──
3. **Hard.**في مجموعة بيانات 10K زوج المقاطع فوق الميقات`facebook/bart-base` مقارنة النموذج المنسق بشكل جيد من خروج شعاع 4 مع النموذج الأساسي في المدخلات المحتفظة 上的输出── تقرير BLEU,并挑选 10 个素质例子──

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Encoder | Input RNN | 读取 source。产生 per-step hidden states 和最终 context Vector。 |
| Decoder | Output RNN | 从 context Vector 初始化。一次生成一个 target Token。 |
| Context vector | 摘要 | 最终 encoder hidden state。固定大小。Attention 要解决的 bottleneck。 |
| Teacher forcing | 使用真实 Token | 训练时喂入 ground-truth previous Token。稳定学习。 |
| Exposure bias | Train/test gap | 在真实 Token 上训练的模型，从未练习过从自身错误中恢复。 |
| Beam search | 更好的 decoding | 每一步保留 top-k partial sequences，而不是 greedy 地直接承诺。 |
