## 问题

الدروس 09 من خلال فشل واحد قابلة للتقرير في نهاية المطاف. إنما يتم تدريب مرموز GRU المترجم على المهام، والحدد الدقيق لمدة 5 ساعات هو 89٪، والحدد الدقيق إلى 80٪ تقريباً. السبب هو بناء، وليس خطأ التدريب: مرموز 提取到每一点 信息都必须塞进一个固定大小的隐藏状态,而 مرموز مرة أخرى لا ترى أي شيء آخر.

Bahdanau、Cho 和 Bengio في عام 2014 نشرت كتابة ثالثة. لا تحملي الحالة النهائية للكودر، بل احتفظي بكل حالة الكودر. في كل خطوة للكودر، الحساب المتوسط للدول الكودرة، والتي تعني الـ الديكودر الآن بحاجة إلى رؤية موقع الكودر.`i`多少? هذا المزيد من المعدل هو السياق، ويتغير في كل خطوة من المقرر.

هذا هو الفكرة الكاملة. تغييرات  توسعتها. الاهتمام الذاتي وضعها في تسلسل واحد. الاهتمام متعدد الرؤوس وذهب إلى تنفيذها. ولكن النسخة 2014 قد كسرت الزجاجة.

## 概念

![Bahdanau attention: decoder queries all encoder states](../assets/attention.svg)

في كل خطوة مُشفّر`t`:

1. استخدام سابقة إصدارات المشفير مخفية `s_{t-1}` كمـ**query**.
2. سوف يضعها مع كل مرموز مخفي`h_1, ..., h_T`打分── كل مرموز 位置一个 skalar──
3. على النتائج، قم بتحقيق التركيز`α_{t,1}, ..., α_{t,T}`، وكل هذه هي 1
4. متجه السياق`c_t = Σ α_{t,i} * h_i`◊ إعدادات الدول 
5. المُفكّر 接收 `c_t`إضافة إلى إشارة خروجية سابقة، توليد إشارة أخرى

加权平均才是重点. عندما يقوم المُعَطِّلُونَ بالترجمة إلى "أنا" 时, فإنه سَيَجْعَلُ "أنا" فوق المُعَطِّلِينَ الحالة 权重大,其他位置权重小. عندما يَحتاجُ "ليس" 时, فإنه سَيَجْعَلُ "مر" 权重大.

## أشكال ((أسهل عضة شخص مكان)

هذا هو أول مرة يتم فيها إلقاء الضرورة على كل شخص

| Thing | Shape | Notes |
|-------|-------|-------|
| Encoder hidden states `H` | `(T_enc, d_h)` | 如果是 BiLSTM，`d_h = 2 * d_hidden` |
| Decoder hidden state `s_{t-1}` | `(d_s,)` | 一个 vector |
| Attention score `e_{t,i}` | scalar | 每个 encoder 位置一个 |
| Attention weight `α_{t,i}` | scalar | 对所有 `i` 做 softmax 之后 |
| Context vector `c_t` | `(d_h,)` | 与一个 encoder state 的 shape 相同 |

**Bahdanau（additive）score。** `e_{t,i} = v_α^T * tanh(W_a * s_{t-1} + U_a * h_i)`.

- `s_{t-1}`شكل هو`(d_s,)`،`h_i`شكل هو`(d_h,)`.
- `W_a`شكل هو`(d_attn, d_s)`.`U_a`شكل هو`(d_attn, d_h)`.
- فهي في شكل متراكم داخلي`(d_attn,)`.
- `v_α`شكل هو`(d_attn,)` مع`v_α`صنع المنتج الداخلي 会缩成一个规模――**这就是 `v_α` 的作用。**انها ليست سحر. انها تحويل متجه الاهتمام-التخفيف الى توقعات النتائج المتعددة.

**Luong（multiplicative）score。**ثلاثة تغيرات:

- `dot`: `e_{t,i} = s_t^T * h_i` طلب`d_s == d_h`△硬性约束── إذا كان رمزك هو ثنائي الاتجاه، نقفز
- `general`: `e_{t,i} = s_t^T * W * h_i`، من بينهم`W`شكل هو`(d_s, d_h)` تحويل الحزمة من الدرجة والمرحلة
- `concat`: 本质上是Bahdanau 形式──很少使用,因为前两个更便宜──

**一个值得点名的 Bahdanau / Luong gotcha。**Bahdanau استخدام `s_{t-1}`(生成当前 كلمة *之前* 的解码状态) ――Long 使用 `s_t`(توليد* بعد* حالة) ―― إدمجها معاً سوف يسبب تحديداً صعباً جداً من التدفقات الخطأ الصغيرة── اختيار ورقة، ثم الالتزام بها~~

## بناءها

### 步骤 1: إضافية ((Bahdanau) الاهتمام

```python
import numpy as np


def additive_attention(decoder_state, encoder_states, W_a, U_a, v_a):
    projected_dec = W_a @ decoder_state
    projected_enc = encoder_states @ U_a.T
    combined = np.tanh(projected_enc + projected_dec)
    scores = combined @ v_a
    weights = softmax(scores)
    context = weights @ encoder_states
    return context, weights


def softmax(x):
    x = x - np.max(x)
    e = np.exp(x)
    return e / e.sum()
```

حسبما أوضحت في السجل، فحص شكلك`encoder_states`شكل هو`(T_enc, d_h)`.`projected_enc`شكل هو`(T_enc, d_attn)`.`projected_dec`شكل هو`(d_attn,)`, لم يُبث`combined`شكل هو`(T_enc, d_attn)`.`scores`شكل هو`(T_enc,)`.`weights`شكل هو`(T_enc,)`.`context`شكل هو`(d_h,)`يمكن أن تنشر

### الخطوة 2: لوونغ نقطة و عام

```python
def dot_attention(decoder_state, encoder_states):
    scores = encoder_states @ decoder_state
    weights = softmax(scores)
    return weights @ encoder_states, weights


def general_attention(decoder_state, encoder_states, W):
    projected = W.T @ decoder_state
    scores = encoder_states @ projected
    weights = softmax(scores)
    return weights @ encoder_states, weights
```

كل واحد من هذه الأوراق ثلاث خطات. وهذا هو سبب وجود ورقة لونج.

### الخطوة الرابعة: لماذا هذه هي جسر من المحولات

把上的语言翻译成 ق/ك/ف:

- **Query**= حالة المُفكّر `s_{t-1}`
- **Key**= حالة المُشفّر ((نا نَناْ来打分的对象)
- **Value**= دولة مُرمّدة ((ما زاد السُلطة والشيء)

في الاهتمام الكلاسيكي، المفاتيح والقيم هي نفس الشيء. الاهتمام الذاتي سوف يفرقها: يمكنك جعل استفسار تسلسل  نفسه،并为 K 和 V باستخدام مختلف التنبؤات المتعلمة. الاهتمام متعدد الرأس باستخدام مختلف التنبؤات المتعلمة ويقوم بالعمل بها.

الرياضة هي نفسها. الأشكال هي نفسها. من اهتمام Bahdanau إلى توجه نقطة منتج مقياسية.

### الاهتمام الكلاسيكي 什么时候仍然重要

- تعليميات الرأس الواحد الطبقة الواحدة
- المحولات 放不下的 على جهاز تسلسل 任务。
- أي ورقة من 2014-2017 . لا تعرف ما هو قائمة بهادناو ، ستقرأها

### الاهتمام - الوزن - مثل التفسير

أوزان الاهتمام تبدو يمكن تفسيرها. إنها أوزان عبر الموقع وراء واحد. يمكنك رسمها.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Attention | 看东西 | 对 value sequence 做加权平均，weights 由 query-key similarity 计算。 |
| Query, Key, Value | QKV | 三个 projections：Q 发问，K 是要匹配的内容，V 是要返回的内容。 |
| Additive attention | Bahdanau | Feed-forward score: `v^T tanh(W q + U k)`。 |
| Multiplicative attention | Luong dot / general | Score 是 `q^T k` 或 `q^T W k`。更便宜，在大多数任务上 accuracy 相同。 |
| Alignment matrix | 好看的图 | Attention weights 作为 `(T_dec, T_enc)` 网格。读取它可以看到 model attend 到了什么。 |
