## 问题

客户发来一张完美的产品照片,但背景有分散注意的标牌. 您想抹去标牌,并让所有其他部分保持像素级一致. 您不能从头运行文本到图像,因为结果将有不同的颜色,不同的光照,不同的产品角度. 您想只重建被蒙面的区域,并且希望重建的内容尊重周围下文.

هذا هو التلوين.

- **Inpainting.**في الاختلافات، الحفاظ على الصور الخارجية.
- **Outpainting.**في الغالب، يتم إعادة إنتاجها خارج الصورة أو تمتد إلى خارج اللوحة، والاحتفاظ بها داخلها.
- **Image editing.**إعادة إنتاج كامل الصورة، ولكن الحفاظ على معنى أو هيكل المخطط الأصلي.

2026 سنة كل خط أنابيب التنشر 都带有涂料模式──Flux.1-Fill、Stable Diffusion Inpaint、SDXL-Inpaint、DALL-E 3 Edit──它们基于同一个原理──

def sample_data(rng):
    cluster = rng.choice([0, 1])
    center = [-1.0] * 5 if cluster == 0 else [1.0] * 5
    return [c + rng.gauss(0, 0.2) for c in center], cluster

### الخطوة 3: استخدام القناع الوعي العكس

```python
def inpaint_step(x_t, mask, clean_image, alpha_bars, t, rng):
    # replace unmasked dims with a freshly noised version of the clean source
    a_bar = alpha_bars[t]
    for i in range(len(x_t)):
        if not mask[i]:
            x_t[i] = math.sqrt(a_bar) * clean_image[i] + math.sqrt(1 - a_bar) * rng.gauss(0, 1)
    # ...then run the normal reverse step on x_t
```

هذا هو طريقة بسيطة، و هو فعال على البيانات 1D للعبة.

## 关键术语

| Term | 人们的说法 | 实际含义 |
|------|------------|----------|
| Inpainting | “填洞” | 在 mask 内重新生成；保留外部像素。 |
| Outpainting | “扩展画布” | 在画布外重新生成；保留内部。 |
| 9-channel U-Net | “正确的 inpainting model” | 输入为 `noisy \| encoded-source \| mask` 的 U-Net。 |
| SDEdit | “带 noise level 的 img2img” | 加噪到时间 `t`，用新 prompt denoise。 |
| InstructPix2Pix | “纯文本编辑” | 在 (image, instruction, output) 三元组上 fine-tuned 的 diffusion。 |
| RePaint | “无需重新训练” | 在 reverse 过程中周期性 re-noise，以减少 seams。 |
| SAM | “Segment Anything” | 通过点击或框生成 mask；与 inpaint 配合使用。 |
| Flux-Kontext | “带上下文编辑” | 接收 reference image + instruction 进行编辑的 Flux 变体。 |
