## المشكلة

أنت تريد واحدة للاستخدام`p_data(x)`عينة. غان سوف تلعب لعبة منخفضة في التوزيع بشكل متكرر. VAEs سوف تلعب من المعدل القاسية.`log p(x)`الحدود السفلية ((لذا لديك احتمالات) ، وكذلك (ج) نموذجات من نوعية SOTA المتناسبة

سوهل-ديكسشتاين وآخرون (2015) أعطى النتائج النظرية: تحديد سلسلة ماركوف للضوضاء الغوسية تدريجياً`q(x_t | x_{t-1})`,并训练一个逆链 `p_θ(x_{t-1} | x_t)`إلى التنمر. هو، جين، آبيل (2020) عرض الخسارة يمكن تبسيطها إلى صف واحد  预测 noise  并整理数学.2020 عام هو لا يزال فضولية.2021 عام تولدت state-of-the-art عينات.2022 عام أصبح مستقر الانتشار.2026 عام هو الجودة الأساسية.

## المفهوم

![DDPM: forward noise, reverse denoise](../assets/ddpm.svg)

**Forward process `q`.**في`T`个小步骤中加入 غاوسيان الضوضاء.

```
q(x_t | x_0) = N( sqrt(α̅_t) · x_0,  (1 - α̅_t) · I )
```

من بينهم`α̅_t = ∏_{s=1..t} (1 - β_s)`, على التكافؤ`β_t`جدول أعمالك`β_t`في T=1000 خطوة من 1e-4 إلى 0.02  التغيرات السريعة،`x_T`سأقترب`N(0, I)`.

**Reverse process `p_θ`.**تعلم شبكة عصبية`ε_θ(x_t, t)`,预测被加入的噪音──给定 `x_t`,按下式 تعبير:

```
x_{t-1} = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - α̅_t)) · ε_θ(x_t, t) )  +  σ_t · z
```

من بينهم`σ_t`أَوْ هو`sqrt(β_t)`هذا التعبير سيء جداً، لكنه مجرد رقم`q(x_{t-1} | x_t, x_0)`في حالة طلب الحل`x_{t-1}`,并用 ضجيج التنبؤ التقدير 替换 `x_0`.

**Training loss.**

```
L_simple = E_{x_0, t, ε} [ || ε - ε_θ( sqrt(α̅_t) · x_0 + sqrt(1 - α̅_t) · ε,  t ) ||² ]
```

من البيانات في العينة`x_0`, إختار واحداً`t`, العينة`ε ~ N(0, I)`، عبر الشكل المغلق`x_t`,并对噪音做回归──一个损失,没有最小x,没有KL,没有重组技巧──

**Sampling.**من`x_T ~ N(0, I)`بدأت`t = T`إلى`1`代 خطوة عكسية‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬

## لماذا يعمل

ثلاثى直觉:

1. **Denoising is easy; generating is hard.**في`t=T`البيانات هي ضوضاء نقية .الشبكة يجب أن تحل مشكلة بسيطة`t=0`،الشبكة تحتاج فقط إلى تنظيف بضع بكسلات`t`، مشكلة صعبة ، ولكن الشبكة سوف تحصل على العديد من التدرج من نفس مجموعة من الوزن من كل مستوى الضوضاء.

2. **Score matching in disguise.**(Vincent(2011) دليل,预测 ضجيج等价格估计 `∇_x log q(x_t | x_0)`,也就是 *score*──العكس SDE استخدام هذا النقطة 沿 كثافة تراجع 上行  一次被引导的随机走,走向高概率地区──

3. **The ELBO reduces to simple MSE.**الحدود السفلى المتغيرة الكاملة في كل خطوة زمنية مدينة واحدة KL المفهوم. استخدام DDPM المعلمات، هذه المفهومات KL سوف تسهيل لتقديم معدل محدد من التنبؤات الضوضاء MSE؛ كيف يذهب بعيدا عن المعاملات (((ادعى لها سائل الخسارة) ، الجودة عكس ذلك * تحسين* 已

## بناءها

`code/main.py`实现 a 1-D DDPM──Data هو مزيج من وضعين──net هو نوع صغير من MLP، استقبالي `(x_t, t)`ليس输出 المتوقع الضجيج. تدريب هو خط الخسارة.

### الخطوة الأولى: الجدول الزمني المسبق (الشكل المغلق)

```python
betas = [1e-4 + (0.02 - 1e-4) * t / (T - 1) for t in range(T)]
alphas = [1 - b for b in betas]
alpha_bars = []
cum = 1.0
for a in alphas:
    cum *= a
    alpha_bars.append(cum)
```

### الخطوة الثانية: العينة`x_t`في إطلاق واحد

```python
def forward_sample(x0, t, alpha_bars, rng):
    a_bar = alpha_bars[t]
    eps = rng.gauss(0, 1)
    x_t = math.sqrt(a_bar) * x0 + math.sqrt(1 - a_bar) * eps
    return x_t, eps
```

### الخطوة الثالثة: خطوة تدريبية واحدة

```python
def train_step(x0, model, alpha_bars, rng):
    t = rng.randrange(T)
    x_t, eps = forward_sample(x0, t, alpha_bars, rng)
    eps_hat = model_forward(model, x_t, t)
    loss = (eps - eps_hat) ** 2
    return loss, gradient_step(model, ...)
```

### الخطوة الرابعة: أخذ العينات العكسية

```python
def sample(model, alpha_bars, T, rng):
    x = rng.gauss(0, 1)
    for t in range(T - 1, -1, -1):
        eps_hat = model_forward(model, x, t)
        beta_t = 1 - alphas[t]
        x = (x - beta_t / math.sqrt(1 - alpha_bars[t]) * eps_hat) / math.sqrt(alphas[t])
        if t > 0:
            x += math.sqrt(beta_t) * rng.gauss(0, 1)
    return x
```

## الفخاخ

- **Schedule matters a lot.**خطية`β`هو DDPM الافتراضي، ولكن جدول التخطيطات ((نيكل و دريوال، 2021) في نفس الحساب
- **Timestep embedding is fragile.**ضعها خامة`t`作为浮游 传入对玩具 1-D 可行,但对图像会失败;始终使用正确嵌入──
- **V-prediction vs ε-prediction.**على النظام الضيق جداً أو جداً كبيرة`ε`很差──V-تنبؤ`v = α·ε - σ·x`) أكثر استقرارًا ؛ SDXL、SD3 وFlux 都使用它──
- **Classifier-free guidance.**الإستفسار 时,同时计算 مشروط 和 غير مشروط `ε`ثم`ε_cfg = (1 + w) · ε_cond - w · ε_uncond`، من بينهم`w ≈ 3-7`الدروس الثامنة والثامنة
- **1000 steps is a lot.**إنتاج باستخدام DDIM ((20-50 خطوة)、DPM-Solver ((10-20 خطوة) أو التقطير ((1-4 خطوة)。 انظر الدروس 12。

## الشروط الرئيسية

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| Forward process | “Adding noise” | 固定 Markov chain `q(x_t \| x_{t-1})`，用于摧毁 data。 |
| Reverse process | “Denoising” | Learned chain `p_θ(x_{t-1} \| x_t)`，用于重构 data。 |
| β schedule | “The noise ladder” | Per-step variance；linear、cosine 或 sigmoid。 |
| α̅ | “Alpha bar” | Cumulative product `∏(1 - β)`；给出从 `x_0` 得到 `x_t` 的 closed-form。 |
| Simple loss | “MSE on noise” | `\|\|ε - ε_θ(x_t, t)\|\|²`；所有 variational derivations 都 collapse 到这里。 |
| ε-prediction | “Predict noise” | 输出是被加入的 noise；standard DDPM。 |
| V-prediction | “Predict velocity” | 输出是 `α·ε - σ·x`；在整个 t 上有更好的 conditioning。 |
| DDPM | “The paper” | Ho et al. 2020；linear β、1000 steps、U-Net。 |
| DDIM | “Deterministic sampler” | Non-Markov sampler，20-50 steps，同一个 training objective。 |
| Classifier-free guidance | “CFG” | 混合 conditional 和 unconditional noise predictions 来放大 conditioning。 |

## ملاحظة الإنتاج: استنتاج التوزيع هو مشكلة الحد الأدنى
