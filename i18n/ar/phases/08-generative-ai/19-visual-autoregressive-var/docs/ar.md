## 概念

### VQ-VAE Tokenizer متعدد النطاقات

VAR  بحاجة إلى واحد **multi-scale discrete Tokenizer** بالنسبة لـ الصورة x، فإنه يخلق سلسلة من تحسينات القرار تدريجياً:

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

استخدام كل واحد من أشكال الكود نفسها، والتي تقدر بنفس القدر 4096-16384 .

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

هذا واحد**residual VQ**变体──尺度 k 捕获尺度 1..k-1 遗漏的内容──decoder 接收所有尺度嵌入的和并生成图像──

التكنولوجيا المتعددة النطاقات VQ Tokenizer فقط تدريب مرة واحدة، مثل VQGAN) ، ثم 结── كل العمل المولود يتم من قبلها Autoregressive 模型完成──

### التنبؤات القادمة

生成模型 هو محول، فإنه يرى جميع الوسائط السابقة من الوسائط، وموقع الوسائط القادمة من الوسائط.

هيكل تسلسل المدخل:
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

وضعية إضافة مع الوقت编码尺度索引和尺度内的空间位置──注意 在尺度顺序上是因果的:尺度 k、位置 (i, j) 的标志可以注意到尺度 1..k 的所有标志,也可以注意到尺度 k 本身在所使用的内尺度 序列中更早出现的标志(VAR باستخدام الاهتمام المثبت للموقف, لا وجود سببية داخل المقياس, أي في واحد من الوسائل جميع المواقع并行预测) 

訓練 Loss: في كل مقياس k, given all previousmeasure's Token,预测 Token z_k。对离散 VQ codes 使用交叉 Entropy Loss──结构与GPT相似,只是在这里序列变成了尺度结构化的序列──

### 生成

推理时:
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

عندما K = 10 个尺度时,生成需要10次 Transformer forward pass. كل مرسلة تمتثل في إنتاج حجم كامل، بدلا من التعود على نفسها في الحجم. بالنسبة ل 256x256 图像, هذا حوالي 10 مرات مرسلة, بينما DiT هو 28-50 مرة.

### لماذا النتائج التالية

ثلاثة ميزات هيكلية:
1. **从粗到细符合自然图像统计规律。**قواعد ذات صلة بالقياسات التي يتم عرضها في مجتمع البيانات والشعوبات: هيكل التردد المتدني مستقر ويمكن التنبؤ به؛ التفاصيل المتدنية المتدنية تتألف من محتوى متدني المتدني.
2. **尺度内并行生成。**مختلفة عن GPT 风格 Token AR، VAR قدم واحد توليد مقياس معين من جميع Token。
3. **没有生成顺序偏置。**يمكن للرمز من الحجم k أن يرى الحجم الكامل k-1؛ لا يوجد أي تعويض من الجانب الأيسر أو فوق، لن يضطر الرمز المبكر إلى التزام قبل أن يستخدم في الفترة الأخيرة.

### علاقة مع التوزيع

VAR و Diffusion مشاركة في نفس القصة المضغوطة: كل منهما ينفصل مشكلة التوليد إلى سلسلة من الأسئلة الأسهل.

- التوزيع: تدريجياً تضمين الضجيج، تعلم إلغاء الخطوة.
- VAR: تدريجياً زيادة درجة القرار، تعلم التنبؤ بعد ذلك

它们是穿越相同问题的不同轴线──都产生可处理的条件分布──经验上,VAR 推理更快(pass 更少,尺度内全并行),并且在类条件的ImageNet 上匹配或胜过DiT──文本条件的VAR(VARclip、HART) 是一个活跃研究方向──

## التدريب

1. **尺度数量消融。**استخدام 4、6、8、10 个尺度训练 VAR──衡重建质量与Autoregressive pass 数量关系──更多尺度 = 更细残值 = 更好质量,但通过更多──

2. **Codebook size。**訓練 كودكوب حجم 为 512、4096、16384 的 Tokenizer── أكبر كودكوب 带来更好的重建,但预测更难──找到拐点──

3. **尺度内并行检查。**على تدريب جيد VAR، قياس واضحة نمط الاهتمام.

4. **VAR vs DiT scaling。**على نفس المهام الصفوية-شروطية ImageNet، في التدريب في VAR و DiT تحت ميزانية المكافآت المتكافئة، مثل 33M 、130M 、458M)  رسم FID مقابل الحساب.

5. **Text conditioning。**扩展 VAR,让它通过 adaLN 接收文本嵌入(CLIP pooled) كإدخال إضافي للتعويضات──这是HART 配方──它能让文本一致的样本上的FID 改善多少?

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|----------------------|
| VAR | "Visual AutoRegressive" | 通过在 VQ Token 网格金字塔上进行 next-scale prediction 来生成图像 |
| Next-scale prediction | "Predict coarser, then finer" | 模型以不断增加的分辨率尺度预测 Token，并以所有之前尺度为条件 |
| Multi-scale VQ tokenizer | "Residual VQ" | 生成 K 个分辨率递增 Token 网格的 VQ-VAE，decoder 会对所有尺度求和 |
| Scale k | "Pyramid level k" | K 个分辨率层级之一，从 k=1 的 1x1 到 k=K 的 (H/p)x(W/p) |
| Parallel-within-scale | "One forward per scale" | 尺度 k 的所有 Token 在一次 Transformer pass 中预测，而不是自回归预测 |
| Causal-across-scales | "Scale-ordered attention" | 尺度 k 的 Token 可以 Attention 到尺度 1..k 的全部内容，但不能 Attention 到尺度 k+1..K |
| Residual VQ | "Additive tokenization" | 每个尺度的 Token 编码较低尺度留下的 residual；decoder 对所有尺度 Embedding 求和 |
| VAR scaling law | "Image GPT scaling" | FID 随 compute 遵循可预测的 power law，类似语言模型的 perplexity |
| HART | "Hybrid VAR + text" | Text-conditional VAR 变体，将 MaskGIT-style iterative decoding 与 VAR 的尺度结构结合 |
| Scale position embedding | "(scale, row, col) triple" | Positional encoding 同时携带尺度索引和尺度内空间坐标 |
