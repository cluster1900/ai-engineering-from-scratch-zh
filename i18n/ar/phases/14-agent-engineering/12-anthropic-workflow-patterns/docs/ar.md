# الأنثروبيكا أساليب سير العمل:简单优于复杂

> شلونتز وجانغ (Anthropic,2024 年 12 月) تميز بين عمليات العمل (预定义路径) ووكلاء (动态工具使用) 五种工作流模式 覆盖大多数情况──从直接 API calls 开始──只有当步无法预测时,才添加代理──

**类型：**学习 + 构建
**语言：**Python (stdlib)
**先修要求：**المرحلة 14 · 01 (حلقة العملاء)
**时间：**حوالي 60 دقيقة

## 學习目标

- يقولون أنشروبيك الخمسة أنماط سير العمل: السلسلة السريعة، التوجيه، التوازي، الموسيقي-العمال، المقيّم-التحسين.
- تفسير الفرق بين العميل وتدفق العمل، فضلا عن تكاليف المشاريع الخاصة بهم
- 识别何时选择工作流而不是代理(反之亦然)
- استخدام القانون المُقدّم للمخططات لتحقيق جميع الأنماط الخمسة

## 问题

团队 دائماً ما يفترض استخدام وظيفة واحدة لتسوية المشاكل في إدخال إطار عمل متعدد الأجهزة. 成本 هو حقيقة وجود: الإطار سوف يزيد من المستويات، تغطية الإطارات، خفاء تدفق التحكم، ومغرضة التعقيد المبكر.

### 五种模式

1. **Prompt chaining。**إنتاج المكالمة 1 كإدخال المكالمة 2.. تطبق على حالة التفكك المفروضات ذات التفكك الخطوي الواضح..

2. **Routing。**تصنيف LLM  اختيار لتدخل استخدام LLM أو أداة.

3. **Parallelization。**并发运行 N 个 LLM دعوات,聚合结果──两种形态:sectioning(不同 chunks) و التصويت(相同提示,运行 N 次,多数/合成)

4. **Orchestrator-workers。**الموسيقي LLM 动态决定运行哪些工人(同样是 LLM),并综合它们的输出──类似于代理循环,但 orchestrator 不会无限循环──

5. **Evaluator-optimizer。**واحد LLM  طرح جواب، آخر LLM  تقييمها. 代 حتى المقيّم 通過.

### تدفقات العمل 胜过代理的地方

- **可预测任务。**إذا كنت تستطيع أن تُحدد الخطوات، فمن الأفضل أن تُحددها
- **受成本约束的任务。**تدفقات العمل لديها عدد محدد من الخطوات ؛ العملاء قد يكونوا غير قادرين على التحكم في التكثر.
- **受合规约束的任务。**المراجعون يرغبون في قراءة الرسم البياني بدلاً من اقتراحها من المسارات

### وكلاء 胜过工作流的地方

- **开放式研究。**عندما يتوقف الخطوة التالية على المحتويات التي ستعود إليها الخطوة السابقة
- **可变长度任务。**需要数分钟到数小时、步骤数未知工作──
- **新领域。**عندما كنت لا تعرف كيفية عمل العمل الصحيحة

## بناءها

`code/main.py`على`ScriptedLLM`تم تحقيق جميع أنماط سير العمل الخمسة:

- `prompt_chain(input, steps)` 顺序执行。
- `route(input, classifier, handlers)` التصنيف + الإرسال
- `parallel_vote(prompt, n, aggregator)` 运行 N 次并聚聚合──
- `orchestrator_workers(task, workers)`الموسيقي اختيار العمال
- `evaluator_optimizer(task, proposer, evaluator, max_iter)` 循环 حتى تمر

运行:

```
python3 code/main.py
```

كل نمط يطبق آثارهم. عدد مجموع خطوط الكود لكل نمط هو حوالي 10-15 صفوف. تكلفة الإطار عادة ما يتم قياسها بألف صفوف.

## 关键术语

| 术语 | 人们常说什么 | 它实际意味着什么 |
|------|----------------|------------------------|
| Workflow | "预定义 flow" | Engineer 拥有的 LLM 和 tool calls graph |
| Agent | "Autonomous AI" | Model 拥有的 graph；动态 tool direction |
| Augmented LLM | "带 tools 的 LLM" | LLM + search + tools + memory；原子单元 |
| Prompt chaining | "顺序 calls" | call N 的输出是 call N+1 的输入 |
| Routing | "Classifier dispatch" | 选择由哪条 chain/model 处理输入 |
| Parallelization | "Fan out" | N 个并发 calls；通过 sectioning 或 voting 聚合 |
| Orchestrator-workers | "Dispatcher agent" | Orchestrator LLM 动态选择 specialist LLMs |
| Evaluator-optimizer | "Proposer + judge" | 迭代直到 evaluator 通过；Self-Refine 的泛化 |
