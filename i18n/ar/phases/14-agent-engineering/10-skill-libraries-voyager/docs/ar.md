## 问题

كل جلسة تمت من عميل قادر على إعادة بناء كل شيء، سوف يرتكب ثلاثة أنواع من الأخطاء:

1. **浪费 Token。**كل مهمة ستعود إلى نفس التفكير
2. **丢失进展。**الجلسة A 中学到的修正不会迁移到 الجلسة B。
3. **无法处理长程组合。**المهام المعقدة تتطلب مستوى قدرة؛ لم يتمكن من إعمالها بسرعة واحدة.

الجواب في Voyager هو: تعتبر كل قدرة قابلة للاستعادة كجزء من الحجز في المكتبة، يمكن من خلال بحث التشابه، يمكن مزجها مع مجموعة مهارات أخرى، ويمكن من خلال تنفيذ التحسين المستمر.

## 概念

### ثلاثة أجزاء

فويجر (arXiv:2305.16291) 围绕以下内容组织代理:

1. **Automatic curriculum。**من قبل مقترح محرك فضول سوف يعتمد على العميل حاليا المهارات والحالة البيئية اختيار المهمة التالية.
2. **Skill library。**كل مهارة تمتلك كود يمكن تنفيذها. بعد نجاح المهمة سيتم إضافة مهارة جديدة.
3. **Iterative prompting mechanism。**عندما تفشل، سيتم قبول العميل لتنفيذ الخطأ، والبيئة ضدّها، والإصدار الذاتي، ثم تحسين هذه المهارة.

Minecraft 评估(Wang et al., 2024):相比 القاعدة، المواد المميزة أكثر 3.3 倍، أدوات الحجر 快 8.5 倍، أدوات الحديد 快 6.4 倍، المخطط عبر المسافة 2.3 倍.

### 动作空间 = 代码

输出原始命令──Voyager 输出 جاوا سكرفت 函数──一个技能是:

```
async function craftIronPickaxe(bot) {
  await mineIron(bot, 3);
  await mineStick(bot, 2);
  await placeCraftingTable(bot);
  await craft(bot, 'iron_pickaxe');
}
```

بواسطة المهارات المكونة والتي تم تصميمها حسب التوصيف ووضعها كخزن مفتاح كعملية يتم استكشافها بدلاً من كإرشاد.

هذا هو 2026 كلود وكيل SDK مهارة: a段具名、可检查的代码,再加上代理 按需加载说明.

### مهارات

ـ "تصنع حفرة الماس" ـ "وكيل:

1. لوصف المهمة  إجراء إدماجها

### 代改进

دورة "فوايجر":

1. عميل 编写一个技能──
2. المهارات في البيئة
3. 返回三种信号之一:`success`.`error`(بضبط آثار)`self-verification failure`.
4. وكيل استخدام هذا الإشارة كمهارة إعادة الكتابة
5. حلقة حتى نجاح أو تحقيق أكبر عدد من الجولات

هذا هو التكرير الذاتي (درس 05) يستخدم في إنتاج الكود، ومستخدم في التحقق من البيئة.

### المناهج الدراسية والبحث

وحدة المنهج الدراسي لـ Voyager سوف تتفق مع العميل 已拥有、还没有做什么, تقديم طرح مثلبناء ملجأ بالقرب من البحيرة 的任务──مقترح استخدام البيئة حالة + مخزون المهارات 选择略高于当前能力的任务,也就是探索最佳区间──

بالنسبة للعميل الإنتاج، سيتحول هذا إلى عامل: ما الذي يفتقر إليه: قاعدة مهارات ومجال، ما هي مهارات لم نكن قد غطاها؟

### هذا النمط يسهل الخروج من هناك

- **Skill library rot。**نفس المهارة تم استخدامها مع وصف مختلف قليلا إضافة 10 مرات.
- **Composed-skill drift。**مهارة الأب تعتمد على مهارة أبها التي تم تحسينها لاحقاً. مهارة إعطاء مهارة إصدار إصدار.
- **Retrieval quality。**مع نمو قاعدة المهارات إلى عدة مئات أو أكثر، على أساس وصف المهارات استرداد المتجهات 会退化── استخدام مرشح علامات التجديد 和硬约束补充(`category=tooling`)。

## 关键术语

| Term | 人们怎么说 | 实际含义 |
|------|----------------|------------------------|
| Skill | “可复用能力” | 带有 description 的命名代码块，可通过相似度检索 |
| Skill library | “agent 的 how-to 记忆” | Skill 的持久化存储，可搜索、可组合 |
| Curriculum | “任务 proposer” | 由当前能力缺口驱动的自底向上目标生成器 |
| Composition | “Skill DAG” | Skill 调用 Skill；执行时进行拓扑排序 |
| Iterative refinement | “自我修正循环” | Env 反馈 + 错误 + 自验证，会折回到下一个版本中 |
| Action-space-as-code | “程序化动作” | 输出函数，而不是原始命令，用于时间跨度更长的行为 |
| Dedup on write | “Skill collapse” | 近重复 description 会合并为一个 canonical Skill |
