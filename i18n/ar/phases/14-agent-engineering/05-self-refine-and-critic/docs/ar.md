## 概念

### التطهير الذاتي ((Madaan et al., NeurIPS 2023)

ماجستير في العلوم، ثلاثة أدوار:

```
generate(task)            -> output_0
feedback(task, output_0)  -> critique_0
refine(task, output_0, critique_0, history) -> output_1
feedback(task, output_1)  -> critique_1
refine(task, output_1, critique_1, history) -> output_2
...
stop when feedback says "no issues" or budget exhausted.
```

关键细节:`refine`سوف نرى التاريخ الكامل، أي كل النتائج والانتقادات السابقة، لذلك لن تكرر الخطأ.

النتيجة الأساسية: في 7 مهمات (الرياضيات والرموز والإختصار والحوار) ، يصل متوسط الارتفاع إلى +20، بما في ذلك GPT-4── لا حاجة للتدريب‬ لا حاجة إلى أدوات خارجية‬ نموذج واحد‬‬

### النقد ((Gou et al., arXiv:2305.11738, v4 فبراير 2024)

ضعف التطهير الذاتي: رد الفعل 步骤 هو LLM 给自己打分── بالنسبة للمزاعم الفعلية، هذا ليس موثوقاً(الوهم 往往在生成它的模型看来很有说服力)──Critic Usage`verify(task, output, tools)`بدل `feedback(task, output)`، من بينهم`tools`بما في ذلك:

- باستخدام محرك البحث للمزاعم الفعلية
- باستخدام مترجم رمز من أجل صحة الرمز
- باستخدام حساب الرياضيات
- المحققون المحددين في مجال اختبارات الوحدة

المحقق سوف ينتج النقد المهيكلي على أساس النتائج الأداة.

النتيجة الأساسية: النقدية في مهمة الواقعية أفضل من التكرير الذاتي، لأن النقد لديه أساسها.

- تحسين: حسب النقد 修订输出。

- **Rubber-stamp loops。**نفس النموذج باستخدام نفس النموذج السريع صنع الجيل والنقد، سوف تتلقى يبدو جيدا بالنسبة لي── استخدام مختلف النماذج على بنية، أو باستخدام نموذج أصغر 、أكثر تكلفة صنع النقد──

## 关键术语

| Term | 人们怎么说 | 它实际是什么意思 |
|------|----------------|------------------------|
| Self-Refine | “会修复自己的 LLM” | 在一个 model 中执行 Generate -> feedback -> refine loop，并带 history |
| CRITIC | “Tool-grounded verification” | 用外部 verifier（search、code、calc、tests）替换 feedback |
| Evaluator-Optimizer | “Anthropic workflow pattern” | 两个角色：evaluator 打分，optimizer 修订，并循环到收敛 |
| Output guardrail | “Post-hoc check” | OpenAI Agents SDK validator，在 agent 生成输出后运行 |
| Verify step | “Critique phase” | 承重决策点：grounded 还是 self-rated |
| Refine history | “Model 已经尝试过的内容” | 先前 outputs + critiques 被前置到 refine prompt；去掉后质量会崩塌 |
| Rubber-stamp loop | “Self-agreement failure” | 相同 prompt 的 critique 返回 “looks good”；用结构上不同的 prompts 修复 |
| Stop condition | “Convergence test” | Verifier 通过，或没有 feedback 且达到 iteration cap；绝不能只有单一条件 |
