# أوتوجين v0.4: نموذج الممثل و إطار العميل

> أوتوجين v0.4 ((ميكروسوفت ريسर्च,2025 سنة 1 月) حول نموذج الممثل 重新设计了代理管弦化── التبادل غير المزامن من الرسائل٬ عوامل القائمة على الأحداث٬ عزل الخطأ٬ الطبيعة并发── هذا الإطار الآن في وضع الصيانة ، بينما Microsoft Agent Framework(2025 سنة 10 月 المشاهدة العامة) أصبح خلفا لها──

**类型：**学习 + 构建
**语言：**Python (stdlib)
**先修：**المرحلة 14 · 01 (حلقة العملاء) ، المرحلة 14 · 12 (أنماط تدفق العمل)
**时间：**حوالي 75 دقيقة

## 學习目标

- 描述演员模型:agent 作为演员,message 是唯一的IPC,每个演员 独立隔离故障──
- تقول أن ثلاثة مستويات API من AutoGen v0.4:Core、AgentChat、Extensions، وفقًا للاستخدامات الخاصة بها
-  شرح لماذا سوف تسليم الرسالة مع التعامل 解会带来 عزل الخطأ 和自然并发──
- في Python لتحقيق وقت تشغيل محرك stdlib ،并将一个双代理代码- مراجعة تدفق 移植到其上.

## 问题

فمعظم الإطار العميل هو معاصر: عميل واحد  توليد المحتوى، عميل واحد  استهلاك المحتوى، تعمل في كومة مكالمة واحدة وسطها.

الإجابة على AutoGen v0.4 هي: نموذج الممثل. كل عميل هو ممثل لديه صندوق إرسال خاص. الرسالة هي الطريقة الوحيدة للتواصل.

### AutoGen v0.4 中的三个API层

1. **Core.**إطار ممثلين من المستوى السفلي`AgentRuntime`.`Agent`.`Message`.`Topic`◊ تبادل رسائل غير متزامن، محرك على الحدث
2. **AgentChat.**面向任务的高层API(بدل v0.2 من ConversableAgent)`AssistantAgent`.`UserProxyAgent`.`RoundRobinGroupChat`.`SelectorGroupChat`.
3. **Extensions.**集成:OpenAI、Anthropic、Azure、tools、memory‬

### لماذا هذا مهم؟

في v0.2 模型中,同步调用 `agent_a.chat(agent_b)`سأعيق العميل حتى يعود العميل`send(agent_b, msg)`سأضع الرسالة في صندوق البريد الخاص بالعميل ثم سأعود إليها على الفور

- **Fault isolation.**العميل ب 崩 لن يؤدي إلى العميل أ 崩, الوقت التشغيلي 会 القبض على عامل ب وسط الفشل,并决定 كيفية التعامل مع ((لوج ‬التقاعد ‬الحروف الميتة) ‬
- **自然并发。**الكثير من الرسائل يمكن أن تكون في نفس الوقت. الممثل لم يصل لمعالجة صندوق البريد الخاص به.
- **面向分布式。**سواء كان الممثل في العملية أو في المضيف الآخر، صندوق البريد + النقل هم نفس الاختبار.

### 拓

- **RoundRobinGroupChat.**وكيل فى حركة تحركية ثابتة
- **SelectorGroupChat.**وكيل المنتخب 根据对话背景 选择下一位。
- **Magentic-One.**يستخدم في تصفح الويب، تنفيذ الرمز، معالجة الملفات، فريق مرجعية متعددة الوكلاء.

## بناءها

`code/main.py`实现 a stdlib ممثل وقت تشغيل:

- `Message`: مع`sender`.`recipient`.`topic`.`body`نوعية الحمل المفيد
- `Actor`: مع`receive(message, runtime)`من الاختصار
- `Runtime`:带有共享 queue、delivery、 fault isolation ‬ حلقة الأحداث
- إثنان من الممثلين:`ReviewerAgent`رمز المراجعة`ChecklistAgent`قائمة التحقق، تتبادل الرسائل حتى يتم التوصل إلى توافق.

运行:

```
python3 code/main.py
```

تراقب جلسات عرض تقديم الرسالة لا يجعل أحد الممثلين الآخرين ينهار الفشل المثالي، وكذلك عملية استلامهم إلى الحكم المشترك.

## 关键术语

| 术语 | 人们怎么说 | 它实际意味着什么 |
|------|----------------|------------------------|
| Actor | "Agent" | 私有 state + inbox + handler；没有共享 memory |
| Message | "Event" | 类型化 payload；actor 交互的唯一方式 |
| Inbox | "Mailbox" | 每个 actor 的 pending message queue |
| Runtime | "Agent host" | 路由 message 并隔离失败的 event loop |
| Topic | "Channel" | actor 之间命名的 publish-subscribe route |
| Fault isolation | "Let it crash" | 一个 actor 失败不会让其他 actor 崩溃 |
| RoundRobinGroupChat | "固定轮转 team" | Agent 按顺序轮流行动 |
| SelectorGroupChat | "按 context 路由的 team" | Selector 选择下一位 |
| Magentic-One | "参考 team" | 用于 web + code + files 的 multi-agent squad |
