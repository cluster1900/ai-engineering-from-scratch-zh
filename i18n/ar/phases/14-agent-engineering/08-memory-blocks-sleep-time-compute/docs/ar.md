# حظر الذاكرة مع حساب وقت النوم (Letta)

> تمت إضافة النموذج إلى فكرة اثنين في التطورات لعام 2024 لتصبح Letta. في عام 2026، يمكن أن يتم تحرير نماذج مباشرة من كتلة الذاكرة المفصلة الوظيفية، وكذلك وكيل وقت النوم في الذاكرة المتكاملة في الوكيل الأساسي 空时异步步的记忆.

**Type:** Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 14 · 07 (MemGPT)
**Time:** ~75 minutes

## 學习目标
- يقولون عن Letta استخدامات ثلاث طبقات من الذكريات ((العمود الأساسي والتذكر والملفات) وكذلك كل طبقة من الدور.
- 解释 ذاكرة-block pattern:بلوك البشر٬بلوك الشخص، فضلا عن كتلة محددة من قبل المستخدم ككائنات من نوع الأول٬
- وصف ما هو حساب وقت النوم ، لماذا يقع خارج المسار الحرج ، ولماذا يمكن أن تعمل على الوكيل الأساسي أكثر قوة نموذج.
- تطبيق دورة من العملاء الثنائيين المكتوبين، والذي يقدم العميل الأساسي الرد، وكيل وقت النوم في دورات التكامل بين الكتل.

## 问题
تم حل تدفق التحكم في الذاكرة الافتراضية. ثم ظهرت ثلاثة مشاكل إنتاج:

1. **Latency.**كل عملية ذاكرة تقع في مسار حرج فوق. إذا كان الوكيل يجب أن يقوم بقطع أو إجمالي أو تعديل في انتظار المستخدم، سيتزايد تأخر الذيل بشكل كبير.
2. **Memory rot.**写入会不断累积――被矛盾推翻的事实会留下――检索会被陈旧内容淹没――
3. **Structure loss.**平的档案库 无法表达Human block 总是在提示中;Persona block 总是在提示中;Task block 按会议 交换。

Letta (letta.com) هي إصدار إعادة كتابة عام 2026.

## 概念
### ثلاثة مستويات

| Tier | Scope | Where it lives | Written by |
|------|-------|----------------|------------|
| Core | 始终可见 | 在 main prompt 内 | Agent tool call + sleep-time rewrites |
| Recall | 对话历史 | 可检索 | 自动轮次日志 |
| Archival | 任意事实 | Vector + KV + graph | Agent tool call + sleep-time ingest |

- **Persona block**مفهوم الذات للعميل

Letta سوف تعيد تعديلها إلى أي كتب محددة من قبل المستخدم: للاستخدام في الغايات الحالية `Task`كتلة، للاستخدام في قاعدة الفعل`Project`الحجر، للاستخدام الصلب`Safety`كلّ بلاكَةَ مدينةَ`id`.`label`.`value`.`limit`(خطاب على الحد)`description`(جعلي الموديل يعرف كيف يُعدّها)

الكتل قابلة للعبور على سطح الأداة 编辑:

- `block_append(label, text)`
- `block_replace(label, old, new)`
- `block_read(label)`
- `block_summarize(label)`  ضغط قريبا من الحد

### حساب وقت النوم

2025 年 Letta 的新增项: 在后台运行第二个代理,位于关键路径外──睡眠时间代理 处理对话转录和代码库文本,将 `learned_context`写入 مشترکة الكتل،并整合或作废档案记录──

الخصائص التي تحصل عليها:

- **No latency cost.**ردود الأساسية 不等待 ذاكرة عمليات
- **Stronger model allowed.**وكيل وقت النوم يمكن أن يكون أكثر تكلفة ‧ أكثر بطء النموذج، لأنه لا يتعرض لخمول ‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬
- **Natural consolidation window.**عندما لا ينتظر المستخدم، إجراء إعادة التأثيرات

هذا الشكل يطابق طريقة عمل البشر: أنت تكتمل المهمة، النوم، الذكريات الطويلة الأجل في الليل沉下来.

### ليتا V1 مع التفكير الأصلي

(Letta V1)`letta_v1_agent`، 2026) ترك استخدام `send_message`/ ضربات القلب و في خط`Thought:`الردود API (OpenAI) 和带延伸思维的消息 API (Anthropic) 会在单独的频道上发出推理,并跨轮次传递(在生产中跨供应商加密) ‧循环控制 仍是 ReAct──思维痕迹是结构性的,而不是以提示形式的──

### هذا النمط سهل الخروج من المكان

- **Block bloat.**لا حدود`block_append`会很快触及限度──在会导致超出 cap 的写入前接入区块总结器──
- **Silent drift.**وكيل وقت النوم 重写了块,而主要 وكيل 从未注意到──为块加版本,并在踪中显示差异──
- **Poisoned consolidation.**وكيل وقت النوم سوف يستخدم المهاجمين المحتوى المباشر في النواة.

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Memory block | “可编辑的 prompt section” | Core memory 中 typed、persistent、LLM-editable 的 segment |
| Human block | “用户记忆” | 关于用户的事实，固定在 core 中 |
| Persona block | “Agent 身份” | Self-concept、语气、约束，固定在 core 中 |
| Sleep-time compute | “异步记忆工作” | 第二个 agent 在 critical path 之外执行整合 |
| Core / Recall / Archival | “层级” | 三层记忆拆分：始终可见 / 对话 / external |
| Block limit | “上限” | 每个 block 的字符限制；迫使进行 summarization |
| Native reasoning | “Thinking channel” | Provider-level reasoning output，而不是 prompt-level `Thought:` |
| Learned context | “Sleep output” | Sleep-time agent 写入 shared blocks 的事实 |
