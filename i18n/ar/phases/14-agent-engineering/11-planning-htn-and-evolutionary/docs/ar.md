## 概念

### شبكات المهام الهرمية

HTN 包含:

- **Tasks** مركب  منتظرة تدمير) و بدائية 可直接执行)
- **Methods** تقسيم المهام المركبة إلى مهام فرعية، مع وجود شروط مسبقة
- **Operators** 带有前条件和效果的原始行动──
- **State**مجموعة من الحقائق

التخطيط: إعطاء مهمة هدف ووضع أولي، إيجاد عملية تفكيك، مما يجعلها شرطاً مسبقاً 按顺序满足的原始运算者──

HTN قبل LLM ظهرت، وما زالت طريقة مرجعية لإثبات الخطط الصحيحة.

### (جوبالاكريشانان وزملاءه، 2025)

سيتم تشغيل استفسارات الشات (arXiv:2505.11814) رمزية على الشات و LLM:

1. 尝试使用现有方法 分解当前复合任务──
2. إذا لم يكن هناك طريقة                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         `s`كيف ستفصلين`task`؟
3. سوف تستجيب لـ LLM 转换成候选次任务──
4. 根据操作方案做验证; رفض التفكك غير الفعال.
5. المُسَلَمَة

المخططات المُنتجة لكل خطة يمكن أن تثبت الصوت، لأن اقتراحات الـ LLM فقط كتحللات مرشحة  دخول، لن تحرر أبداً خطة مباشرة ‧ الطبقة الرمزية ‧ المسؤولة عن الصوابية ‧ الـ LLM ‬ توسيع المكتبة

تعلم الأساليب عبر الإنترنت ((OpenReview `gwYEDY9j2x`(متابعة 2025) انضم إلى طالب واحد، من خلال التراجع 泛化 LLM 生成的分解  أقصى حد ممكن للحد من 75% من استفسارات LLM 频率──

### ألفا إيفولف (نوفيكوف وزملاءه، 2025)

ألفا إيفولف (arXiv:2506.13131, ديب ميند، يونيو 2025) هي نوع آخر من الأشياء: بواسطة مجموعة جيميني 2.0 فلاش / برو 编排的进化代码搜索──

حلقة:

1. من برنامج البذور + المقيّم البرمجي 开始(عودة درجة اللياقة البدنية)。
2. مجموعة الـ LLM  طرحت الطفرات
3. سوف تتمكن من تقديم الطفرات إلى المقيّم
4. حافظ على أفضل ما لديك، استمر في التحول

نتائج المنشورة:

- 56 سنة来首次改进 ستراسن 4x4 مضاعفة المصفوفة المعقدة ((48 مرة مضاعفات واسكالرية) 👇
- 通過 بروج تخطيط الهورستي  استعادة 0.7% من حساب جوجل ‬
- في الحدود من العمل الحد الأقصى إنجاز 32٪ من FlashAttention سرعة.

硬性约束: وظيفة اللياقة البدنية 必须可由机器检查──对散文答案做进化搜索 不会收──

### ماذا تستخدم

| 问题类别 | 使用 | 原因 |
|---------------|-----|-----|
| 带硬约束的 Scheduling | HTN + ChatHTN | 可证明的 soundness |
| Compiler optimization | AlphaEvolve | 机器可检查的 fitness |
| Multi-step task execution | ReAct / ReWOO | LLM in the loop，没有 formal guarantees |
| 带 tests 的 Code improvement | AlphaEvolve | Tests 就是 evaluator |
| Policy-bound automation | HTN | Preconditions 编码 policy |

### هذا النموذج يسهل الخروج

- **没有 operators 的 HTN。**没有前条件/效果方案, soundness 主张就会崩塌──ChatHTN 的LLM يوحي بالتفكك要求方案 能拒绝无效运动──

## استخدمها

- **HTN planners** `pyhop`.`SHOP3`أو لتنفيذ سياسات محددة في مجال القانون
- **ChatHTN** رمز البحث؛ هذا النموذج ((رمزية + LLM fallback) يمكن أن يتم تنفيذها إلى أي خطط HTN
- **AlphaEvolve** ورقة DeepMind؛ هذا النموذج ((جميع + تقييم)可复现──OpenEvolve 和类似开源叉 正在出现──
- **Agent frameworks** حاليا لا يوجد HTN أو AlphaEvolve من الدرجة الأولى.

## التدريب

1. استخدام التراجع  توسيع خطط HTN: عندما يكون أحد المشغلين في حالة بعد ذلك في الوقت الزمني  فشل, 回滚并尝试下一个方法──
2. 给 ChatHTN 添加 LLM-النهج التخزين:当 LLM 在状态模式 `P`中分解 المهمة `T`时,存储结果──下一次调用时先重新检查方法库──
3. سوف تغير تقييم البحث التطوري إلى مجموعة اختبارات حقيقية.
4. 阅读AlphaEvolve's evaluator design notes──为你关心的域名 设计一个评价器(تحسين استفسار SQL、تحقيقات التجارب-تجميع تقليل、تشرين YAML)。
5. 组合使用: باستخدام HTN سوف يتم تقسيم المهام المركبة إلى مهام فرعية ، ثم في كل مهام فرعية من عاملات بدائية فوق استخدام البحث التطوري.

## 关键术语

| 术语 | 人们的说法 | 实际含义 |
|------|----------------|------------------------|
| HTN | “Hierarchical planner” | 带有 operators、preconditions、effects 的 task decomposition |
| Method | “Decomposition rule” | 将 compound task 拆分为 subtasks 的方式 |
| Operator | “Primitive action” | 带有 precondition 和 effect 的具体步骤 |
| ChatHTN | “LLM + HTN” | 当没有 method 匹配时，symbolic planner 询问 LLM |
| AlphaEvolve | “Evolutionary code search” | Ensemble LLMs mutate code；deterministic evaluator 负责选择 |
| Fitness function | “Evaluator” | 针对 outputs 的 deterministic、机器可检查 score |
| Online method learning | “Cached LLM decomposition” | 存储并泛化 LLM plans，以降低 query cost |
