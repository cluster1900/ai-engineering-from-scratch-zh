## 概念
### خمسة بدائيات

1. **Agent.**ماجستير في إدارة الأعمال + تعليمات + أدوات + إعطاءات
2. **Handoff.**تمنح وكيل آخر`transfer_to_<agent_name>`أداة
3. **Guardrail.**لإنفاق ((فقط الوكيل الأول) ‬المخرج ((فقط الوكيل الأخير) أو دعوة الأداة ((كل أداة) للتحقق من الصحة‬
4. **Session.**跨 turns ‬ التاريخ المحاور الذاتية‬
5. **Tracing.**أجيال الماجستير في مجال الجامعة ‬المكالمات الأداة ‬المساعدات ‬الوقوفات

### التسليم كأدوات

模型会在它的工具列表中看 `transfer_to_billing_agent`❖ تدفعها إلى وقت التشغيل

1. 复制 محادثة سياق ((( أو من خلال `nest_handoff_history`(بيتا ستنهار)

3. مع عميل الهدف  تابع الهرب

هذا هو نمط المشرف في تطور المنتجات (درس 13 / درس 28)

### الحراسة

ثلاثة أنواع:

- **Input guardrails.**في أول وكيل دخول 上运行. في أي مكالمة LLM قبل رفض عدم الامان أو طلبات خارج نطاق النطاق.
- **Output guardrails.**في أخر عمل من العملاء، تمكننا من التقاط تسريبات المعلومات الشخصية، انتهاكات السياسة، ردود فعل خاطئة.
- **Tool guardrails.**按功能-工具 运行──تحقق من الحجج、الافضالات للتفتيش、تنفيذ المراجعة‬

وضع:

- **Parallel**(默认) ――التربية LLM مع الدرجة الرئيسية LLM 同时运行。更低尾延迟。如果触发,主要LLM的工作会被丢弃(浪费代币)。
- **Blocking**(`run_in_parallel=False`(‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬

### هذا النمط سهل الخروج من المكان

- **Handoff drift.**العميل (أ) يُعطى العميل (ب) ، العميل (ب) يُعطى العميل (أ) يَدَهُ
- **Guardrail bypass.**الحراسة الأدوات فقط في أدوات الوظيفة 上触发;内置 أدوات ((قراء الملفات  جلب الويب) تحتاج إلى سياسة منفصلة‬
- **Over-tracing.**المجموعات من المجموعات تحتوي على محتوى حساس.

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Agent | "LLM + instructions" | SDK 中的 Agent type；拥有 tools 和 handoffs |
| Handoff | "Transfer" | 模型调用以 delegate 给另一个 agent 的 tool |
| Guardrail | "Policy check" | 对 input / output / tool invocation 的 validation |
| Tripwire | "Guardrail trip" | guardrail 拒绝时抛出的 exception |
| Session | "History store" | runs 之间持久化的 conversation memory |
| Tracing | "Spans" | 覆盖 LLM + tool + handoff + guardrail 的内置 observability |
| Blocking guardrail | "Sequential check" | Guardrail 先运行；trip 时不浪费 Token |
| Parallel guardrail | "Concurrent check" | Guardrail 同时运行；latency 更低，trip 时浪费 Token |
