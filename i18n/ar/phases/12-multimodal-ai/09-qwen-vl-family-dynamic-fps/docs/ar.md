## 概念
### كوان-فيل (أغسطس 2023)

第一代:OpenCLIP ViT-bigG/14 作为 encoder(2.5B params)、LLama-compatible Q-Former(1 خطوة مع 256 استفسار)、Qwen-7B base──贡献:

- 448x448 分辨率 ((( حينها افتتح VLM من SOTA)
- التأريخ: استخدام带显式坐标 رمز 输出的 صور نص جوز 训练──"قطة في <box>(112, 204), (280, 344)</box>"──
- من البداية على إجراء تدريبات اللغة الصينية + الإنجليزية متعددة اللغات.

في ذلك الوقت، كان هناك الكثير من المشاركين في هذا المجال.

### Qwen2-VL (سبتمبر 2024)  M-RoPE 与原生分辨率

Qwen2-VL باستخدام المُرمّح ViT الأصليّ ذو القرار الثابت + Q-Former stack

- تُصدر 960 个视觉 Token──无需大小化、无需裁、无需图像──
- M-RoPE (متعدد الحركات المتعددة) ―― كل رمز  تحمل 3D 位置 (t, h, w), بدلا من 1D── بالنسبة للصورة t=0; بالنسبة للشاشة t = frame_index──RoPE  حسب كل محور 频率旋转查询/مفتاح متجه── بدون جدول إدراج موضعي──
- مُرُبّك MLP──去掉 Q-Former؛ في رموز اللصقة المدمجة 上 استخدام MLP 2-طبقة──
- 带动态FPS的视频──默认以1-2 FPS 采样视频,但模型接受任意数──

结果:Qwen2-VL-7B 在多个多多模特基准上追平 GPT-4o,并在 DocVQA 上超过它(94.5 مقابل 88.4) ―― التغييرات في الهيكل هي خطوة حاسمة──

### Qwen2.5-VL(2025 年 2 月)  FPS ديناميكي + الوقت المطلق

التحول الكبير في Qwen2.5VL هو فيديو.

- 绝对时间 Token──不使用位置索引(frame 0, 1, 2...),而使用实际时间──"في 0:04 ، قفز القط". 模型会看到与框架代币 交错的 交错的`<time>0.04</time>`الارقام
- FPS الديناميكي── slow speed مواد على شكل 1 FPS 采样,动作场景 على 4+ FPS 采样──由用户或训练器选择;M-RoPE 会适配──
- فيات 中的窗口注意力──                                                                                                                                                                                                                                                          
- 显式 JSON 输出格式──使用工具-call 数据训练:"{\"工具\": \"点击\", \"符串\": [380, 220]}"──开箱即代理-ready──
- مقياس MRoPE-v2 : الموقع سيكون مع أكبر إدخال : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : : 

基准:Qwen2.5-VL-72B 在多数视频基准上超过GPT-4o,在文档上追平 Gemini 2.0,并为GUI گراونغ 设定开放模型 SOTA(ScreenSpot: 84% دقة مقابل GPT-4o 的 38%) 👇

### Qwen3-VL (نوفمبر 2025)

Qwen3-VL هو مرة واحدة زيادة في حجم التحسين، والتركيز هو التكامل بدلا من إعادة الاختراع: أكبر LLM العمود الفقري ((Qwen3-72B) 、 توسيع تدريب البيانات、 تحسين OCR، وكذلك من خلال قوان3 التفكير  الحصول على التفكير أقوى.

هذا النتائج: بحلول عام 2025، تمت إرساء بنية Qwen-VL على نحو مستقر.

### M-RoPE رياضياً

经典 RoPE 使用成对坐标,按位置 `m`旋转维度为 `d``q`:

```
q_rot[2i]   = q[2i]   * cos(m * theta_i) - q[2i+1] * sin(m * theta_i)
q_rot[2i+1] = q[2i]   * sin(m * theta_i) + q[2i+1] * cos(m * theta_i)
theta_i     = 10000^(-2i/d)
```

M-RoPE سوف تختفي dim 切分为三条带――假设 `d = 96` تقسيم 32 ضيق 给 temporal、32 给 height、32 给 width── كل شريط 按自己的轴位置旋转──位于 (t=5, h=10, w=20)`R_t(5)`.`R_h(10)`.`R_w(20)`.

رموز النص استخدام `t = text_index, h = 0, w = 0`(أو نوع من التأثيرات) ، لتحقيق الموافقة.`t = frame_time, h = row, w = col` استخدام الصور`t = 0`.

الميزة: إعداد موقع يُمكن معالجة النص والصور والفيديو، لا حاجة إلى إرسال رمز أو إعداد موقع مختلف.

### ديناميكي-FPS 采样逻辑

给定一个时长为 `T`秒的视频和目标 الوسائط  الميزانية `B`:

1. 计算你能承担最大 FPS:`fps_max = B / (T * tokens_per_frame)`.
2. من`{1, 2, 4, 8}`中选择满足 `fps <= fps_max`هدف FPS:
3. إذا تحرك قوة ((حركة التدفق البصري أو طلب المستخدم المحدد) ، تختار FPS أعلى
4. 按选定FPS 均采样; بين 插入 `<time>t</time>`الارقام

Qwen2.5VL 会隐式训练这种逻辑;推理时用户通过 `fps`参数控制── 60 ثانية تسلسل حركة، باستخدام 4 FPS、 لكل 81 رمزا 计算، يساوي 19440 رمزا، في سياق 32k 中可管理──

### إنتاج العامل المهيكلي

وكيل Qwen2.5 - VL  تدريب واضحة وجهة نحو الهيكل أداة دعوة:

```
{
  "tool": "mouse_click",
  "coords": [1024, 512],
  "button": "left",
  "modifier": null

```

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| M-RoPE | "Multimodal RoPE" | hidden dim 中带 temporal、height 和 width bands 的 3D rotary position embedding |
| Dynamic FPS | "Smart sampling" | 根据运动、时长和 Token 预算为每个视频选择的帧采样率 |
| Absolute time token | "Timestamp token" | 在序列中交错插入的 `<time>t</time>`，让模型看到实际秒数而不是帧索引 |
| Window attention | "Local attention" | 为提速而限制在小窗口内的 spatial self-attention；周期性加入 global attention |
| Structured agent output | "JSON mode" | 通过训练数据监督教 VLM 输出可解析 JSON，其中包含 coords 和 tool names |
| min_pixels / max_pixels | "Resolution bounds" | Qwen2.5-VL 的每请求控制项，用来约束总像素数，从而约束 Token 数 |
| Grounding | "Point-at-it" | 将 bounding-box 坐标作为文本 Token 输出；自 Qwen-VL v1 起使用 |
