### ثلاث فئة

输入 `x`و العلامات`y`يمكن أن يكتب التوزيع المشترك في شكلين:

```math
P(x, y) = P(x) \cdot P(y \mid x) = P(y) \cdot P(x \mid y)
```

كل نوع من التغييرات تغير مختلف العوامل:

| 漂移 | 变化部分 | 保持不变的部分 | 支付示例 | 能观察到的监控器 |
|---|---|---|---|---|
| 协变量漂移 | `P(x)` | `P(y \| x)` | 高购物金额的应用用户变多 | 输入监控 |
| 先验漂移 | `P(y)` | `P(x \| y)` | 攻击期间欺诈率翻倍，但欺诈特征不变 | 预测与结果监控 |
| 概念漂移 | `P(y \| x)` | 输入可以不变 | 相同购物金额对应不同欺诈风险 | 只有结果监控 |

غاما وغيرهم`P(y | x)`تغيرات تسمى حقيقة المفهومات التحول، لن تغير`P(y | x)``P(x)`تُطلق على التغيرات التحولات الافتراضية. وتحركاتها المختلفة تُقسم إلى ارتفاعات، زيادة، تقدم، ومعايير.

协变量漂移不一定有害──如果模型学好 `P(y | x)`لا يزال بإمكان التنبؤ بالتحقيق لكل نوع من المدخلات، ولكن عندما يكون التدفق يتحرك نحو النموذج التدريبي نادرًا أو قريبًا من حدود القرار، لا يزال من الممكن أن ينخفض معدل التحقيق.

### كولموجوروف-سميرنوف 统计量

双样本 KS 统计量 `D`هو أكبر فجوة عمودية بين وظائف التوزيع المكتملة:

```math
D = \max_x \left\lvert F_{\text{reference}}(x) - F_{\text{current}}(x) \right\rvert
```

样本完全相同时 `D`为 0,完全不重叠时为 1──它无需分箱──p 值由科尔摩戈罗夫 分布结合有效样本量 `n * m / (n + m)`حصلت على.

في الوقت الحالي، فإن حجم العينات كبير، حتى لو كان هناك فارق غير واقعي، سوف يجعل قيمة الـp تقترب من الصفر. في كل نافذة، عند مليون حدث، يمكن أن يكون هناك انحراف كبير في الـ0.02 من الـstandard difference.`D`في الواقع، لا يوجد سوى`D`و كل قيمة تلبي شروط قيمةها

### 类别 خصائص الاختبار

بالنسبة لخصائص فئة الدفع، وبالتالي، قم بتكوين خطين:

```math
\begin{aligned}
\text{expected}[r][c] &= \text{row\_total}[r] \cdot \text{column\_total}[c] / \text{grand\_total} \\
\text{chi2} &= \sum_{\text{cells}} (\text{observed} - \text{expected})^2 / \text{expected}
\end{aligned}
```

لـ`k`个类别,检验自由度为 `k - 1` فقط في النوافذ الحالية التي تظهر من نوعها تساهم في أكبر عدد من المواد، لذلك يمكن للاختبار أن يستجيب للقيمة الجديدة.`chi2 / grand_total`. الجذر المربع

### 重新训练的触发条件

هناك ثلاثة أساليب لتحقيق التدريبات المعتادة:

- **定期。**كل أسبوع أو كل شهر تعليميات جديدة. بسيطة، ولكن بدون تغيير.
- **漂移。**الخصائص المهمة الوصول إلى الموقع يستمر أكثر من القدر المرة
- **性能。**结果指标低于参考值减减耐性范围时重训――

漂移类型决定重新训练能解决什么:

| 漂移 | 有用的行动 |
|---|---|
| 协变量漂移，但准确率稳定 | 通常无需处理，继续观察结果指标。 |
| 协变量漂移进入数据稀少区域 | 用覆盖这些区域的近期数据重训 |
| 先验漂移 | 重新校准分数，或调整决策阈值 |
| 概念漂移 | 先收集新标签。用旧标签重训只会再次学到旧概念。 |

```python
def quantile_edges(reference: list[float], bins: int = 10) -> list[float]:
    ordered = sorted(reference)
    n = len(ordered)
    edges = [ordered[min(n - 1, (n * i) // bins)] for i in range(1, bins)]
    return sorted(set(edges))


def psi_from_fractions(expected: list[float], actual: list[float], eps: float = 1e-4) -> float:
    total = 0.0
    for e, a in zip(expected, actual):
        e, a = max(e, eps), max(a, eps)
        total += (a - e) * math.log(a / e)
    return total
```

### 第2 步:KS 统计量及其 p 值

مع مرور الوقت على نموذجين من الترتيبات. على كل قيمة مختلفة، أولا على كل ثواني من هذه القيمة عبر المجموعتين من النموذج، ومقارنة المجموعة المجموعة.

```python
def ks_statistic(sample_a: list[float], sample_b: list[float]) -> float:
    a, b = sorted(sample_a), sorted(sample_b)
    n, m = len(a), len(b)
    i = j = 0
    d = 0.0
    while i < n and j < m:
        x = min(a[i], b[j])
        while i < n and a[i] <= x:
            i += 1
        while j < m and b[j] <= x:
            j += 1
        d = max(d, abs(i / n - j / m))
    return d
```

p 值 استخدام كولموجوروف 分布的级数 `2 * sum((-1)^(k-1) * exp(-2 k^2 lambda^2))`، من بينهم`lambda = sqrt(n * m / (n + m)) * D`.

### 第3 步: فحص الكار

`chi2_sf`通过正则化上不完全马函数计算卡方生存函数,小参数使用级数,大参数使用连分式──`chi_square_test`构建两行表、计算统计量,并返回 p 值和Cramér's V──

```python
def chi_square_test(reference_counts: dict[str, int], current_counts: dict[str, int]) -> ChiSquareResult:
    categories = [c for c in sorted(set(reference_counts) | set(current_counts))
                  if reference_counts.get(c, 0) + current_counts.get(c, 0) > 0]
    rows = [[reference_counts.get(c, 0) for c in categories], [current_counts.get(c, 0) for c in categories]]
    row_totals = [sum(r) for r in rows]
    grand = sum(row_totals)
    if len(categories) < 2 or 0 in row_totals:
        return ChiSquareResult(0.0, 0, 1.0, 0.0)
    statistic = 0.0
    for col, _ in enumerate(categories):
        col_total = rows[0][col] + rows[1][col]
        for r in range(2):
            expected = row_totals[r] * col_total / grand
            statistic += (rows[r][col] - expected) ** 2 / expected
    dof = len(categories) - 1
    return ChiSquareResult(statistic, dof, chi2_sf(statistic, dof), math.sqrt(statistic / grand))
```

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|----------------------|
| 数据漂移 | “数据变了” | 相较参考窗口，输入、预测或标签分布发生变化 |
| 协变量漂移 | “出现新类型用户” | `P(x)` 变化，而 `P(y \| x)` 不变 |
| 先验漂移 | “正样本更多了” | `P(y)` 变化，而 `P(x \| y)` 不变，也称标签偏移 |
| 概念漂移 | “游戏规则变了” | `P(y \| x)` 变化，相同输入对应不同正确答案 |
| 参考窗口 | “基准数据” | 与每个当前窗口比较的固定样本，通常是训练数据 |
| PSI | “稳定性分数” | 对各箱的“当前占比减参考占比”乘两者比值的对数求和，具有对称性 |
| KS 统计量 | “KS 检验” | 两个经验累积分布函数之间的最大差距 |
| Cramér's V | “类别效应量” | 将卡方统计量缩放到 0 到 1 范围的量 |
| 标签延迟 | “真实答案晚些到” | 从预测到真实结果到达之间的时间 |
| 告警疲劳 | “通知太多” | 大多数告警都是误报，导致人们忽略告警 |
