## 概念
### 经典 BFT 给你什么

التسامح العملي للخطأ البيزنطيني (كاسترو و ليسكوف، OSDI 1999) 可容忍 `f < n/3`العقد البيزنطية. يوجد ثلاثة مراحل.`n >= 3f + 1`个诚意或恶意节点之间 على اتفاقية لمصلحة قيمة واحدة

هذه الضمانات قوية جداً، لكن هناك فرضيات مثل هذه:

1. **Independent faults。**البيزنطيون 不会协作──
2. **Honest nodes 确实诚实。**النتائج الصادقة ليست مشكلة، البروتوكول فقط يتوافق مع عدم توافقها.
3. **问题存在 ground-truth answer。**على الحقيقة الخاطئة التوصل إلى توافق

وكلاء الـ LLM  违反了这三点──两个运行相同的基础模型的代理会共享错误──一个诚实的 LLM 仍然会幻觉──对于模糊问题,真理是代理决定的内容,没有外部 Oracle──

### ثلاث أنواع الهجمات الخاصة بالشركة

**Byzantine lie。**وكيل 输出故意错误的答案... إذا`f < n/3`, كلاسيكي BFT 能處理它──

**Sycophantic conformity。**وكيل في قراءة الردود قبل التصويت، وموافقة مع آخر المتحدث. هذا ليس من النوايا السيئة، ولكن سيكون مرتبطا مع صوت أكبر صوت.

**Correlated-error monoculture。**ثلاثة عملاء يتشاركون نموذجًا أساسيًا. وهم يسهلون.

### ردود الفعل في السنوات 2025-2026

**CP-WBFT**(arXiv:2511.10400)  ثقة-بثبت وزنه BFT。 كل ناخب عطاء جوابه إضافة مسح ثقة(توقعات الذات، أو نموذج تحديد التنظيم الخاص)。 وزن التصويت 随着信心 缩放──报告称在完整图上 BFT改善为 +85.71%──缓解 目标:精神性合规性(符合代理 往往对其主动给定的位置信心 较低)。

**DecentLLMs**(arXiv:2507.14928)  无领袖── عملاء العمال وملء تقدم المقترحات، عملاء المقيّمين للقترحات 打分,最终答案是得分位置的几何中介──当`f < n/2`时具备强性──调解 目标:بيزنطينية الكذبة 和 الأخطاء المتصلة(الوسط الجغرافي ضد المتفاصيل قوية،并拉向密集集集群,而不是 المتوسط المتحيز على النموذج)。

**WBFT**(arXiv:2505.05103)  الوزن BFT مع هيكل Hierarchical Clustering。 الوزن التصويت بواسطة جودة الاستجابة 加上从历史学习到的信任分分配──将代理 聚类为核心和边缘;Core agents 必须先达成共识,Edge agents 跟随──Mitification 目标: scalability(Core consensus 小而快) 以及部分应对单文化(Core 可按多样性 选择)。

### 实证: هل يمكن لوكلاء الذكاء الاصطناعي أن يتفقوا؟

هذه الورقة قياس العديد من النماذج الحدودية إتفاقيات المقاييس أجهزة الـLLM على قيمة رقمية واحدة تفق عليها

- حتى لو لم يكن هناك خصوم، وكلاء LLM في العديد من المعايير، ومعدلات عدم الوفاق على الأسئلة المتوسطة تزيد عن 30٪.
- 单个采用欺骗性人物的代理 可将混合代理共识 拉离诚实基线 40+百分点――
- معدلات الخلافات مع تنوع النموذج 相关; مجموعات متفرقة مقارنة مع مجموعات متفرقة 分歧更多(好处:غير مرتبطة الأخطاء) ، ولكن الانحراف أيضا更慢(坏处: الوقت للتوافق 更长)。

### التخلص من البروتوكول الأساسي

واحد وجهة إلى وكلاء LLM من أدنى جولة BFT:

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

التجميع الاسمية 步骤是 LLM-specific 关键变化──两个答案 الدراسة تقرير 4.2% 和 4.2% التحسن 属于同一集群──简单的字符串等式检查 会漏掉这一点──在生产中,使用便宜的嵌入模型或显然的加нони化──

## 关键术语
| Term | 人们常说 | 实际含义 |
|------|----------------|------------------------|
| BFT | “Byzantine fault tolerance” | Castro-Liskov 1999 protocol，用于在 `f < n/3` arbitrary faults 下达成 consensus。 |
| Byzantine | “任何坏行为” | 一个可以撒谎、丢弃 messages、静默失败的节点，除了安全 crash 外什么都可能做。 |
| Confidence probe | “你有多确定？” | 附加到 vote 上的自报或 calibrator-predicted probability。 |
| Semantic clustering | “同一答案，不同表述” | 在 counting votes 之前对等价 answers 分组。 |
| Geometric median | “Robust center” | 最小化到 sample points 距离之和的点。与 mean 不同，它对 outliers robust。 |
| Monoculture | “相同 model，相同 failures” | agents 共享 training data 或 base model 时产生的 correlated errors。 |
| Sycophantic conformity | “同意最大声的声音” | agent 的 vote 偏向最先/最大声发言的人。 |
| Core/Edge | “Hierarchical BFT” | WBFT 拆分：小规模 Core 先 consensus，Edge nodes 跟随。限制 latency。 |
