# الموازات / الساحة / المعماريات المتصلة

> مع المشرف مقابل: لا يوجد قرار مركزي. العاملين 读取共享事件bus,异步领取工作,并写回结果. 长图 明确支持面向去中心化、动态环境的"السحابة الهندسية"‬ المصفوفة (arXiv:2511.21686) 将控制流和数据流 都表示通过分布式排队传递的串行信息,以消除管弦乐器 瓶‬. 权衡很明确: باستخدام التحديد والتحديدية 改变可扩展性.

**Type:** Learn + Build
**Languages:** Python (stdlib, `threading`, `queue`)
**前置要求：**المرحلة 16 · 05 (نموذج المشرف) ، المرحلة 16 · 04 (نموذج أولي)
**Time:** ~75 minutes

## 问题
يمكن أن يمتد المشرف إلى عدد قليل من العمال.

المعماريات السحرية عكس تحول هذا التصميم. ليس من قبل المخطط المركزي، ولكن العمال من صف مشترك في الحصول على العمل.

## 概念
### الشكل

```
                ┌──── shared queue ────┐
                │                      │
       ┌────────┼────────┐  ◄──────┬───┘
       ▼        ▼        ▼         │
     Worker  Worker  Worker   Worker
      A       B       C        D
       │        │        │         │
       └────────┴────────┴─────────┘
                 │
                 ▼
            results pool
```

没有管弦乐员──每一个工 反复执行:拉取一个任务,处理,写入结果(并可选地排列后续)──

### عندما يتناسب السحابة

- **许多独立 tasks。**"تجميع" "التصنيف" "التوظيفات لا تعتمد على بعضها البعض"
- **可变时长的工作。**إذا كانت بعض المهام تتطلب 100 دقيقة، بينما تتطلب الأخرى 10 دقائق، سوف توازن الحمل تلقائيًا   العمال السريعون 会拉取后续 وظائف.
- **Throughput 优先于 determinism。**أنت مهتم بالوقت الكامل للإنتهاء وليس بالطلب الصارم

### عندما ينفذ الجماعة

- **有序 workflows。**إذا كانت الخطوة الثالثة تحتاج إلى خروج الخطوة الثانية، قد يسمح السلالة الخطوة الثالثة في الخطوة الثانية
- **Global-plan tasks。**أسئلة بحثية معقدة受益于规划者──بحثي تجمع عن واقع مستقل، وليس تقرير متواصل──
- **Debugging。**لا يوجد سجل مركزي ويعمل 异步时,复现 bug 成本很高──

### المصفوفة (arXiv:2511.21686)

المصفوفة هي ورقة عام 2025 ، سوف تتحرك إلى النتيجة الطبيعية: تدفق التحكم وتدفق البيانات كلها في صفوف منتشرة فوق الرسائل المتسلسلة.

贡献: نموذج برمجة، حيث تنسيق وكلاء متعددين هو  هذا الوكيل 订阅哪个消息主题?، بدلا من  المشرف 下一步选择哪个 وكيل؟

### معمارة المجموعة من LangGraph

LangGraph 2025 doc 明确将"ماركية السلالة" 描述为多 وكيل أنماط 之一:وكلاء هي العقدة، ولكن الحواف 形成带周期的导向图,并且任何节点都可以从池中被激活──Worker 根据条件从可用工作中选择,而不是由监督任务指派──

### وضع الفشل: الجوع والبقع الحارة

إذا كان كل العمال يحصلون على أسرع مهمة ممكنة، المهام طويلة الأمد حتى تبقى لهم فقط عندما سوف يتم الحصول على.

التخفيف:
- 带显式老龄化的优先排队 随着等待时间 提高优先排队)
- تخصص العمال: بعض العمال فقط يتلقى مهام "طويلة"
- الضغط الخلفي: الحد من دخول المهام السريعة في الصف

### الرابط التوجيهي القائم على المحتوى

## 交付 it
قائمة التحقق:

- **带 aging 的 Priority queue。**منع الجوع في المهام الطويلة‬
- **Worker idempotency。**إذا كان العامل في منتصف المديرين ينهار، ومهام واحد قد يتم التقاطها عدة مرات.
- **Durable queue。**生产环境使用 Kafka、Redis Streams أو صف مدعوم من قاعدة البيانات‬`queue.Queue`فقط في الـ"إمـنـجـوريـة"
- **每个 task 的 observability。**كل مهمة لديها هوية تتبع كل عامل لديه سجل بداية / نهاية
- **Back-pressure。**إذا كان التوالي يزداد بسرعة أكثر من أن العمال يستنزفون سرعته، فإننا سنبطئ الإنتاج.

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Swarm architecture | "Decentralized agents" | Workers 从 shared queue 中拉取；没有 central orchestrator。 |
| Event bus | "Agents subscribe to topics" | 按 type 或 content 将 tasks 路由给 workers 的 message broker。 |
| Starvation | "Task never runs" | 因为 higher-priority work 持续到达，low-priority task 永远不会被选中。 |
| Hot-spotting | "One worker drowns" | 一个 worker 获得大多数 tasks 的 load imbalance。 |
| Back-pressure | "Slow down the producer" | 当 queue 填满时，向 upstream 发出停止生产信号的 mechanism。 |
| Idempotent worker | "Safe to re-run" | 一个 task 被处理两次会产生相同 result。因为 workers 可能在 mid-run 崩溃，所以这是必需的。 |
| Durable queue | "Survives crashes" | 由 disk 或 replicated storage 支持的 queue；worker 崩溃时 tasks 不会丢失。 |
| Matrix framework | "Full message-passing swarm" | Data 和 control flow 都是在 distributed queues 上的 serialized messages。 |
