## 概念

### 两个原语

**Routine。**定义代理 角色和可用工具的系统提示──可以把它看作一组有作用域的指令:你是分类代理;如果用户询问退款,就交给退款代理──

**Handoff。**يمكن استخدام الوكيل أداة، فإنه يعود إلى كائن الوكيل الجديد.

```
def transfer_to_refunds():
    return refund_agent  # Swarm sees Agent return → switch active agent

triage_agent = Agent(
    name="triage",
    instructions="Route the user to the right specialist.",
    functions=[transfer_to_refunds, transfer_to_sales, transfer_to_support],
)
```

نظام وكيل التجديد على الفور 让它根据用户消息选择正确的交付──LLM的工具调用──负责路由──

### لماذا ينتشر بسرعة

- **API 小。**فقط تحتاج لتعلم المفاهيم
- **使用模型已经会做的事。**لقد وصل الوصول إلى أدوات الإنتاج في جميع المقدمين.
- **没有状态机负担。**أنت لا تحتاج إلى شرح الرسم البياني، دعوات العميل تصفها سوف تسلم إلى من.

### 无状态取舍

السلالة بين الجاريات واضحة أنها غير موجودة. الإطار في إطار الجاريات تحتفظ بتاريخ الرسالة، ولكن لن تستمر بأي شيء.

في الإنتاج البيئية، (OpenAI Agents SDK,2025 年 3 月) ، هذا هو واحد من التغييرات الرئيسية:SDK 添加内置 جلسة إدارة、حراسات 和 تتبع، في حين الحفاظ على التسليم 原语。

### الساحل/الرفاق 适合的场景

- **Triage patterns。**وكيل سيقوم بتوصيل المستخدم إلى المتخصص
- **基于技能的 handoffs。**إذا كانت المهمة تحتاج إلى رمز، اتصل بالمدفوع؛ وإذا كانت تحتاج إلى البحث، اتصل بالباحث.
- **短而有边界的对话。**دعم العملاء ‬استعراضات استبيانية إلى التذاكر‬ عمليات عمل بسيطة‬

### ساحة العنف

- **带共享 memory 的长 sessions。**سوف يضع الجهاز المتحادث في حالة محادثة وإعادة تعيين العميل الجديد على الفور مع التاريخ.
- **并行执行。**التسلل هو مرة واحدة وكيل فعال سوف يتغير.
- **Audit 和 replay。**无状态 runs 很难精确重播; إعطاء اللعبة 选择不是确定性的。

قائمة التحقق:

- **Handoff logging。**كل مرة يتم تسليمها، يكتب في حدث تتبع، يحتوي على من وكيل إلى وكيل، صورة مفصلة

## 关键术语

| Term | 人们的说法 | 它实际意味着什么 |
|------|----------------|------------------------|
| Routine | “Agent prompt” | System prompt + tool list。定义角色和可用 handoffs。 |
| Handoff | “转交给另一个 Agent” | active agent 可以调用的一个 tool，它返回新的 Agent。runtime 会切换 active agent。 |
| Stateless | “runs 之间没有 memory” | Swarm 不持久化任何东西；memory 是调用方的责任。 |
| Active agent | “现在谁在说话” | 当前掌握对话的 Agent。Handoff 会改变它。 |
| Context transfer | “handoff 时移动什么” | incoming agent 能看到哪些 history 的策略：full、last N 或 summarized。 |
| Handoff loop | “Agents 来回 ping-pong” | 两个 Agents 不断 hand back 给对方的失败模式。 |
| OpenAI Agents SDK | “生产级 Swarm” | 2025 年 3 月的后继者；在 handoff 原语之上添加 sessions、guardrails、tracing。 |
| Handoff filter | “转移时的 gate” | SDK feature，用于在 handoff 边界检查和修改上下文。 |
