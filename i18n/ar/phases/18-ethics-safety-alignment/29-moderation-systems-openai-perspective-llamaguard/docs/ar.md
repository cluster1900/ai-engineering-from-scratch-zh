### حرس اللاما 3/4

已在课 16 覆盖──14 个 MLCommons خطورة فئات 组织方式不同于OpenAI 13 个响应方案布鲁尔语)──支持 8 语言 (v3)──Llama Guard 4 (2025 年 4 月) 原生支持 多模,12B──

تتميز تصنيفات OpenAI وLlama Guard على حد سواء ولكن هناك اختلافات. ستصبح OpenAI "غير مشروعة" كفئة واسعة. ستصبح Llama Guard "جرائم عنيفة" و "جرائم غير عنيفة"

### API المطلوب (جوجل جيغسو)

浪潮(قبل عام 2020) من نظام درجة السمومة. فئات: السموم، السموم الشديد، الحوادث، الاحترافية، التهديد، الهوية_الاعتداء.

يستخدم على نطاق واسع كخط أساس للبحوث المتعلقة بالمحتوى، لأن هذه الـ API 稳定、有文档، ولديها بيانات تصحيحات متعددة السنوات.

### النمط ثلاثي الطبقات

1. **Input moderation.**في الجيل 前对用户提示 分类──如果 علامة،则拒绝──延迟:一次分类器调用──
2. **Output moderation.**في التسليم 前对模型输出 分类──如果标有,则替换为拒绝──延迟:代 后一次分类器调用──
3. **Custom moderation.**القواعد المحددة للسلطات ((مجلس الإدارة والمسؤولين والسياسة التجارية)

هذا التسلسل حسب التصميم: تدخيل الاعتدال 必须在一代前完成,output moderation 在一代 后运行.

### أساليب الفشل

- **Input only.**捕捉不到输出幻觉 (درس 12-14 من هجمات تشفير المعلومات سوف تتجاوز تصنيفات المدخلات)
- **Output only.**سمح بأي مدخل إلى النموذج؛ زيادة التكلفة؛ إلى المهاجم  إعلان التفكير الداخلي‬
- **Custom only.**لا يمكن أن تغطي كل الفئات، والإعمال الضعيفة جدا.

طبقات هي المعتمدة الممارسة.

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| OpenAI Moderation | "omni-moderation-latest" | 基于 GPT-4o 的 13-category (text) classifier，带部分 Multimodal support |
| Perspective API | "Google Jigsaw toxicity" | Pre-LLM-era toxicity scoring baseline |
| Llama Guard | "MLCommons 14-category" | Meta 的 hazard classifier（v3：8B text，8 langs；v4：12B Multimodal） |
| Input moderation | "pre-generation filter" | model call 前作用于 user prompt 的 classifier |
| Output moderation | "post-generation filter" | delivery 前作用于 model output 的 classifier |
| Custom moderation | "domain rules" | Deployment-specific rules（regex、allowlist、policy） |
| Layered moderation | "all three layers" | 标准生产部署模式 |
