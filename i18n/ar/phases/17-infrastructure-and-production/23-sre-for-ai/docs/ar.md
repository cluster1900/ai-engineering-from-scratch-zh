## 问题
في الصباح الثالثة، حصل مهندس يعمل على المكالمة على إشعار: عدد الأخطاء في التحقق 很高──هم يبحثون في Datadog、Loki、三 runbooks、 نشر السجلات──30 دقيقة بعد ذلك، أدركوا أن السبب الجذري هو ارتفاع الجهاز التخزينية KV 导致 vLLM OOM──هم يعيدون تشغيل القنبلة؛ خطأ اختفى──

بحلول عام 2026، يمكن أن يتم تلقائيّة هذه النوع من التحقيقات قبل 20 دقيقة.

تعديل مستقل تماما هو مشكلة أخرى. استئناف القنبلة:安全. استجمام GPU: إذا سياسة 允许则安全.

## 概念
### معمارة متعددة الوكلاء

```
          Incident
             │
             ▼
        Supervisor
        /    |    \
       ▼     ▼     ▼
  Log agent  Metric agent  Runbook agent
       │     │     │
       └─────┴─────┘
             │
             ▼
        Hypothesis + evidence
             │
             ▼
        Human approval
             │
             ▼
        Action (narrow set)
```

المراقب سوف يقوم بتقسيم الحادث إلى أسئلة فرعية.

### نطاق التعويضات الآلية

**Safe (narrow)**: إعادة تشغيل القنبلة ‬ إعادة نشر محدد‬ في مجموعة الحدود داخل المقياس المعتمدة‬ إعادة تشغيل العلامة المميزة المعتمدة‬

**Not safe (broad)**:更改服务拓ולוגיה,修改资源限制,部署代码,更改IAM,修改数据库,

أيّ شخص يُبيعه ويُنسى ذلك، فكل شخص يتعهد بالانتهاك.

### 对抗性评估 ((نيو بيرد هوكي)

兩模型 تحليل مستقل لنفس الحادث. إذا تم التوصل إلى اتفاق مع السبب الجذري، فإن الاعتقاد أعلى. إذا لم يتم التوصل إلى اتفاق، فإن فرضيتين مرئيتين تتصاعد إلى الإنسان.

### الذاكرة التشغيلية

团队人员流动是传统 SRE的隐形杀手 部落知识 会流失──AI SRE 将 runbooks + post-mortems 存入向量 DB;agents 会在每新事件中检索──当新工程师加入时,AI 拥有完整历史──

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| AI SRE | “agent for on-call” | LLM-backed incident investigation + coordination |
| Supervisor agent | “the orchestrator” | 将 incidents 拆分为 sub-queries 的顶层 agent |
| Specialized agent | “domain agent” | 拥有 tool access（日志、指标、runbooks）的 sub-agent |
| Auto-remediation | “AI fixes it” | 狭窄的预先批准 action；不是宽泛的 re-architecture |
| Operational memory | “vector runbooks” | vector DB 中用于 RAG 的 post-mortems + runbooks |
| Adversarial eval | “two-model check” | 独立分析；agreement = confidence |
| NeuBird Hawkeye | “the adversarial one” | 具备 adversarial-eval + memory pattern 的产品 |
| Bits AI | “Datadog's SRE agent” | Datadog 托管的 AI SRE |
| Pre-incident prediction | “early detection” | outage prediction 的 10-15 分钟 lead time |
