# إضفاء الطرف  محرك Apple Neural Engine، Qualcomm Hexagon، WebGPU/WebLLM، Jetson

> الحافة الأساسية 约束是 ذاكرة النطاق النطاق، وليس الحساب. DRAM المحمول 位于 50-90 GB/s; Datacenter HBM3 超过 2-3 TB/s الفجوة 30-50x.

**类型：**تعلم
**语言：**Python(stdlib، لعبة تعريف حدة عرض النطاق المحدود 模拟器)
**前置要求：**المرحلة 17 · 04(إعداد الخدمات الداخلية)
**时间：**~ 60 دقيقة

## 學习目标

- تفسير لماذا استنتاج الـ LLM المحمول هو مقيد على عرض النطاق التذاكر ، بينما الحوسبة هي العامل الثاني.
- 列举四个边缘目标(Apple ANE、Qualcomm Hexagon、WebGPU/WebLLM、NVIDIA Jetson),并将每个目标匹配到一个使用案例──
- وتحدث عن فجوة تغطية WebGPU عام 2026 ((فايرفوكس أندرويد 正在追赶) وكذلك حالة وصول Safari iOS 26
- لجميع الأهداف  اختيار شكل كمية ANE باستخدام Core ML INT4 + FP16, هيكساجون باستخدام QNN INT8/INT4, متصفح باستخدام WebGPU Q4, جيتسون ثور باستخدام NVFP4)。

## 问题

واحد من العملاء يريد مشغل دردشة على الجهاز: الصوت أولاً、الخاصة حسب الافتراض、توقف عن الاتصال 可用。 في MacBook Pro M3 Max 上، لاما 3.1 8B Q4 以 ~55 tok/s 运行可接受。 في iPhone 16 Pro، نفس النموذج 以 3 tok/s 运行不可接受。 في متن Snapdragon 8 Gen 3 وسط المحركات الأندرويد 上،是 7 tok/s。 عبر Chrome Android v121+ 上的 WebGPU 在浏览器中运行时,取决于设备,是 4-8 tok/s。

الفرق في التوصيل ليس محمولا  مشكلة. انها فجوة عرض النطاق النطاق  ضربة على شكل كمية، مرة أخرى ضربة على NPU 是否能从用户空间 访问.

### محرك عصبي أبل ((M4 / A18)

- أعلى 38 متروك للذاكرة الموحدة ((CPU و ANE 共享同一个池) 没有副本的费用──
-  من خلال الجوهر ML + `.mlmodel`编译模型访问,或通过 PyTorch 经由 مادة أداء Shaders(MPS)访问。
- Llama.cpp Backend المعدني استخدام MPS، ليس مباشرة استخدام ANE؛
- أفضل طريقة ممارسة تطبيقات iOS لعام 2026: استخدام ثقيلات INT4 + تنشيطات FP16 من ML الأساسي.

### كوالكوم هيكساجون ((سنيب دراجون إكس النخبة / 8 جنرال 4)

- أعلى 45 TOPS──集成在SoC,与CPU和GPU起,但具有独立内存域──
- QNN(Qualcomm Neural Network)SDK و AI Hub 提供 من PyTorch/ONNX تحويلات
- قوالب الدردشة ʾLlama 3.2、Phi-3 都作为AI Hub 上等级的文物发布──

### إنتل / أم دي NPUs ((بحيرة القمر، رايزن AI 300)

- 40-50 TOPS──البرمجيات متأخرة عن شركة آبل/كوالكوم؛ OpenVINO في تحسين، ولكن لا تزال في مكان خاص.
- 最适合Windows ARM مساعد الطيار التطبيقات؛ في AMD / Intel المكتبيات 上用于本地-اول 场景.

### ويب جي بي يو + ويب إل ام

- 通過 WebGPU محاسبة الصفحات في المتصفحات النماذج للعمل؛无需安装。
- في M3 Max 上,Llama 3.1 8B Q4                                                                                                                                                                                                                                                         
- ويبلإم لديها 17.6k نجوم غيت هوب OpenAI متوافقة مع JS APIApache 2.0
- تغطية 2026: كروم أندرويد v121+、سافاري iOS 26 GA،فايرفوكس أندرويد 仍在追赶──总体约为 ~70-75% تغطية الهاتف المحمول──

### عائلة (جيتسون)

- أورين نانو سوپر ((8 جيجا غاب):可容纳 لاما 3.2 3 بي、في-3,并具有不错的 tok/s。
- AGX Orin: من خلال vLLM 以 ~ 40 توك / س 运行 gpt-oss-20b。
- Thor / T4000(JetPack 7.1): أداء لل AGX Orin 2x، دعم EAGLE-3 و NVFP4。
- TensorRT Edge-LLM(2026) دعم إيغل-3 التشفير المضاربة ∆ وزرات NVFP4 ∆ قطع prefillمواقع البيانات التحسينات 已移植到边

### كل هدف من الكمية 选择

| Target | Format | Notes |
|--------|--------|-------|
| Apple ANE | INT4 weights + FP16 activations | Core ML conversion path |
| Qualcomm Hexagon | QNN INT8 / INT4 | AI Hub converters |
| WebGPU / WebLLM | Q4 MLC（q4f16_1） | 使用 `mlc_llm convert_weight` + 编译后的 `.wasm`；不支持 GGUF |
| Jetson Orin Nano | Q4 GGUF 或 TRT-LLM INT4 | Memory-bound |
| Jetson AGX / Thor | NVFP4 + FP8 KV | Edge-LLM path |

### الحافة 上的长文本陷

إطار 128K من Llama 3.1 هو مركز البيانات 功能. على الهواتف المحمولة من 8 جيجا إيه بي رامي. على أجهزة 4 جيجا طراز + 32 جيجا إيه بي كيف كاش + إيه بي كاف = OOM.

### الصوت هو تطبيق قاتل

وكلاء الصوت على التأخير  حساسة ((أول رمز < 500 ms) ―― الاستنتاج المحلي 会 تماما القضاء على تأخر الشبكة── مع الخطاب إلى النص(تغيرات التهوس توربو 可在边上运行) بعد الالتحاق، الاستنتاج الحدوي 就成为 خلية صوتية عالية الجودة الإنتاج──

- WebLLM M3 Max:Llama 3.1 8B Q4 上 ~41 توك/س

- الفجوة في عرض النطاق بين مركز البيانات و نصف إلى خمسين مرة
- تغطية الهاتف المحمول من WebGPU: ~ 70-75%

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| ANE | "Apple neural engine" | M-series 和 A-series 中的 on-device NPU；unified memory |
| Hexagon | "Qualcomm NPU" | Snapdragon NPU；用于访问的 QNN SDK |
| WebGPU | "browser GPU" | W3C-standardized browser GPU API；Chrome/Safari 2026 |
| WebLLM | "browser LLM runtime" | MLC-LLM project；Apache 2.0；OpenAI-compatible JS |
| Jetson | "NVIDIA edge" | Orin Nano / AGX / Thor / T4000 family |
| TRT Edge-LLM | "edge TensorRT" | TensorRT-LLM 的 2026 edge port；EAGLE-3 + NVFP4 |
| Unified memory | "shared pool" | CPU 和 NPU 看到同一块 RAM；没有 copy overhead |
| Bandwidth-bound | "memory limited" | Decode 受读取 weights 的 bytes/sec 限制 |
| Core ML | "Apple conversion" | 用于 ANE-native models 的 Apple framework |
| QNN | "Qualcomm stack" | Qualcomm Neural Network SDK |
