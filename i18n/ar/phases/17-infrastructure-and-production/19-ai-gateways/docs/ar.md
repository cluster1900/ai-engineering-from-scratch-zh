## 概念
### ستة ميزات أساسية

1. **Provider routing** وضع OpenAI ‬Anthropic‬Gemini‬self-hosted 等 على خلفية API‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬‬
2. **Fallback** 遇到429、5xx أو فشل الجودة 时,在别处重试──
3. **Retries** تعريضات الاحتجاجات، هناك محاولات界
4. **Rate limits** 按租客 钥匙 模型
5. **Secret references** 运行时从库 拉取凭证(绝不放在app中)
6. **Observability** سمات OTel + GenAI(مرحلة 17 · 13) + وصف التكلفة。
7. **Guardrails** تحرير المعلومات الشخصية  اكتشاف الإفراجات السرية  مرشحات المواضيع المسموح بها

### LiteLLM  MIT OSS، بيثون

- أكثر من 100 مزود ‧توافق مع OpenAI‬ إعداد الجهاز التوجيهي ‧الظهور‬اللاحظة الأساسية‬
- في مؤشر Kong 中约2000 RPS 时崩; 8 GB من أثر الذاكرة, في الحمل المستمر أسفل ظهور فشل في التقييمات.
- 最适合: تطبيق Python ٬<500 RPS ٬dev/staging gateways٬ تجربة التوجيه٬
- تكلفة: OSS = $ 0، هناك مستوى مجاني من السحابة

### المفتاح  وضع طائرة التحكم

- 截至 2026 年 3 月为Apache 2.0 OSS──Gardrails、PII ترميم、بصير jailbreak、مسار مراجعة──
- كل طلب من التخميس فوق تكلفة 20-40 ms
- مستوى الإنتاج هو 49 دولار / شهر، يحتوي على الاحتفاظ + SLA
- 最适合: تحتاج إلى حواجز محمولة + قابلية للملاحظة من الصناعات المنظمة.

### كونغ إيه إيه بيتواي

- 基于 Kong Gateway 构建(成熟的API gateway 产品,lua+OpenResty)
- كانغ) لديه مقياس) في 12 مركبة محركية (على:比 بورتكي 快 228٪ ،比 ليتللم 快 859٪
- السعر: 100 دولار/نموذج/شهر، ومرحلة إضافية
- 最适合:已在使用康;>1000 ريبس;愿意购买许可.

### الثلج الثنائي (ماكسيم AI)

- إعادة المحاولات تلقائيّة، دعم إعادة التشغيل القابل للتشغيل.
- افتحوا الإعلان 429 时 fallback إلى الأنثروبية هي وصفة طائفية
- المشارك الجديد: التجاري

### مدخل Cloudflare AI / مدخل Vercel AI

- إدارة 零-ops。 إعادة التجربة الأساسية 和 قابلية للملاحظة‬
- 最适合:运行在Cloudflare/Vercel 上的Edge-serving JavaScript apps──
- في الحواجز و حدود السعر 方面不如 Kong/Portkey

### المضيفة الذاتية مقابل المدارة

إقامة البيانات هي العامل القائم على القرار. الرعاية الصحية و التمويل المشترك في الاستضافة الذاتية.

### ميزانية التأخير

- التكلفة العليا النموذجية 5-15 ms
- مفتاح المفتاح: فوق الرأس 20-40 ميس
- كونج: فوق الرأس 3-8 ميس
- Cloudflare/Vercel: Overhead 为 1-3 ms

تأخير البوابة سوف يزيد مباشرة من TTFT.

### المادة التعريفية المحددة

简单的代币桶 可支到中度尺度──多 المستأجر 需要滑窗 + انفجار الإذن + لكل مستأجر التسطح──LiteLLM 内置代币桶;Kong 内置滑窗;Portkey 内置层次──

### البوابة + قابلية للملاحظة + توجيه

المرحلة 17 · 13(الملاحظة) + 16 ((مثل التوجيه) + 19 ((بوابات) في الإنتاج تنتمي إلى نفس الطبقة.

### أرقام يجب أن تتذكر

- ليتللم: حوالي 2000 ريبس 崩,8 جيجابايت ذاكرة
- كليف البورط: 20-40 ms فوق الصفحة؛ منذ 2026 سنة 3 月起 Apache 2.0
- كونغ:比 بورتكي 快 228٪ ،比 ليتيللم 快 859٪
- أسعار كونغ: 100 دولار/نموذج/شهر، ومرحلة إضافية
- Cloudflare/Vercel:edge 上 1-3 ms فوق الصفحة

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Gateway | “API broker” | 位于 apps 和 providers 之间的 process |
| LiteLLM | “the MIT one” | Python OSS，100+ providers，2K RPS 时崩溃 |
| Portkey | “guardrails gateway” | Control plane + observability，Apache 2.0 |
| Kong AI Gateway | “the scale one” | 基于 Kong Gateway 构建，benchmark leader |
| Bifrost | “Maxim's gateway” | Retries + Anthropic fallback recipe |
| Cloudflare AI Gateway | “edge managed” | Edge-deployed managed gateway，zero-ops |
| PII redaction | “data scrub” | 发送到 model 前进行 Regex + NER mask |
| Jailbreak detection | “prompt injection guard” | 对 user input 的 Classifier |
| Audit trail | “regulated log” | 每次 LLM call 的 immutable record |
| Token-bucket | “simple rate limit” | 基于 refill 的 rate limiter |
| Sliding-window | “precise rate limit” | Time-windowed rate limiter；fairness 更好 |
