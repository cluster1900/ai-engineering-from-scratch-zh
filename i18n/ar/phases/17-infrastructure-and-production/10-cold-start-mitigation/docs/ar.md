## 概念
### الطبقة 1  预置节点镜像(قذيفة الزجاجات)

على AWS، ستقوم بنية بوتلروكيت ذات حجم مزدوج بتفريق النظام التنفيذي مع البيانات.`EC2NodeClass`中引用快照 ID──新节 启动时重量 已经在本地 NVMe 上,步骤 2 和步骤 3 部分会消失──它与卡宾特原生配合──典型节省:大型模型 每次冷启动 节省 2-4 分钟──

GCP 上的等价方案:带有预烤容器层的自定义VM图像──Azure 上:采用相同模式的管理磁盘快照──

### الطبقة 2  نموذج التدفق (Run:ai Model Streamer)

ليس انتظار كامل تحميل الملفات 完再回答第一个请求,而是逐层将重量流到GPU ذاكرة,并在第一个变压器块 常驻后立即开始处理──NVIDIA Run:ai Model Streamer 在 vLLM 2026 中原生提供──支持 S3、GCS 和本地 NVMe──通过将 I/O 和计算设置重叠,大型模型重量载时间大约减半──

### الطبقة 3  صور لقطات ذاكرة GPU (Modal)

في أول مرة تحميل 后对 GPU状态(وزن CUDA الرسوم البيانية KV cache region)做检查点。后续重启 直接消化到HBM,比重新初始化快 10x。这最接近在2秒内启动 一个热的 GPU──Trade-off:快照 绑定 per-GPU-topology,所以如果 Karpenter 将你迁移到不同 SKU,你需要重新检查点──

### الطبقة 4  حمامات دافئة (مئات العمال = 1)

الحد من الحد من الحد الأدنى: الحفاظ على نسخة واحدة دائما جاهزة.$0.85-$1.50 لتجنب بداية باردة في الثلاثينات) ، على الطرازات الكبيرة 则更友好(每小时支付 $4 لتجنب بداية باردة في 5 دقائق) ・ حرارة المسبح 变得必需 SLA حد: عادة هو 70B + النموذج 上 TTFT P99 < 60s。

### الطبقة 5  التحميل المتعدد المستويات (LLM بدون خادم)

سوف تخزين ServerlessLLM 视为一个层次:NVMe(快但大)、DRAM(中等但可分层)、HBM(小但即时) ・・・ الوزن 预先加载到DRAM;按需加载到HBM。 ورق 报告,相比 ساذج القرص إلى HBM, latency of cold loads 降低 10-200x。 تبني الإنتاج 仍处早期,但已经存在与vLLM 的整合──

### الطبقة 6  الهجرة الحية (نمط مكافأة)

عندما يكون هناك عقدة لاستخدامها) ، النمط التقليدي هو البدء الباردة ثاني نسخة و نهج طلب قطار. الهجرة الحية سوف يدخل الوهم.

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Cold start | “the big pause” | Fresh replica 上从 request 到 first token 的时间 |
| Warm pool | “always-on minimum” | `min_workers >= 1`，保持至少一个 replica ready |
| Pre-seeded image | “baked AMI” | Container weights 已预先常驻的 node image |
| Bottlerocket | “AWS node OS” | 支持 dual-volume snapshot 的 AWS container-optimized OS |
| Model streamer | “streaming load” | 将 weights I/O 与 compute setup 重叠 |
| GPU snapshot | “checkpoint to HBM” | 序列化 post-load GPU state；restart 时 deserialize |
| Tiered loading | “NVMe + DRAM + HBM” | Storage tiers 的 hierarchy；按需 load |
| Live migration | “move tokens” | 传输 input（KB），在 destination 上 recompute KV |
| `min_workers` | “warm replicas” | Serverless minimum keep-alive count |
| Scale-to-zero | “full serverless” | Idle 时无 cost；接受完整 cold-start tax |
