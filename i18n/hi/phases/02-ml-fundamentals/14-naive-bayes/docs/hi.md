## 问题
आपको सामग्री को वर्गीकृत करने की आवश्यकता है। आप ईमेल को स्पैम या गैर-स्पैम में विभाजित करते हैं। आप ग्राहक टिप्पणी को सकारात्मक या नकारात्मक में विभाजित करते हैं। आप हजारों विशेषताओं को अलग-अलग श्रेणियों में विभाजित करते हैं।

अधिकांश वर्गीकरणकर्ता यहाँ सभी में खाएंगे। लॉजिस्टिक प्रतिगमन को पर्याप्त नमूने की आवश्यकता होती है, ताकि हजारों वजन का अनुमान लगाया जा सके। निर्णय के पेड़ एक बार केवल एक शब्द के अनुसार विभाजित होते हैं, और गंभीर रूप से ओवरफिट होते हैं।

बेयज़ ने इस स्थिति को संभाल लिया। यह एक गणितीय गलत धारणा बनाती है, प्रत्येक विशेषता अन्य सभी विशेषताओं के साथ स्वतंत्र है, लेकिन लेखन वर्गीकरण में अभी भी उन अधिक बुद्धिमान मॉडल से अधिक है, खासकर प्रशिक्षण के दौरान। यह केवल एक बार डेटा के माध्यम से पूरा किया जा सकता है। यह लाखों विशेषताओं तक विस्तार कर सकता है। यह संभावना अनुमान उत्पन्न करता है। हालांकि स्वतंत्रता परिकल्पना के कारण, ये संभावनाएं आमतौर पर सही नहीं होती हैं) ।

यह समझना कि एक गलत परिकल्पना अच्छी भविष्यवाणी क्यों कर सकती है, आपको मशीन लर्निंग के एक मूल तथ्य से अवगत कराएगाः सबसे अच्छा मॉडल सबसे सही मॉडल नहीं है, बल्कि आपके डेटा के लिए सबसे अच्छा पूर्वाग्रह-वियरिएंस ट्रेडऑफ मॉडल है।

## 概念
### बेयज़ का प्रमेय (快速回顾)

बेयज़ का प्रमेय 会反转条件概率:

```
P(class | features) = P(features | class) * P(class) / P(features)
```

हम चाहते हैं`P(class | features)`, यानि किसी विशिष्ट दस्तावेज़ में शब्द के बाद, यह दस्तावेज़ किसी श्रेणी की संभावना से संबंधित है।
- `P(features | class)`: इस श्रेणी के दस्तावेजों में इन शब्दों की संभावना को देखने के लिए
- `P(class)`:类别前几率(总体上垃圾有多常见?)
- `P(features)`सभी श्रेणियों के लिए साक्ष्य समान हैं, इसलिए तुलनात्मक श्रेणियों को अनदेखा किया जा सकता है

`P(class | features)`सर्वोच्च श्रेणी जीत

### साफ़-साफ़ आजादी का अनुमान

精确计算 `P(features | class)`️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️️

एक साफ़ धारणा यह है कि प्रत्येक विशेषता की स्थिति स्वतंत्र है।

```
P(w1, w2, ..., wn | class) = P(w1 | class) * P(w2 | class) * ... * P(wn | class)
```

आप एक असंभव संयुक्त वितरण का अनुमान नहीं लगाते, बल्कि एक साधारण विशेषण-व्यक्तिगत वितरण का अनुमान लगाते हैं। प्रत्येक वितरण को केवल एक गणना की आवश्यकता होती है।

यह परिकल्पना स्पष्ट रूप से गलत है। किसी भी दस्तावेज़ में "मशीन" और "लर्निंग" स्वतंत्र नहीं हैं। लेकिन वर्गीकरणकर्ता को सही संभावना अनुमान की आवश्यकता नहीं है। इसे सही क्रमबद्धता की आवश्यकता है, यानी कि किस श्रेणी की उच्चतम संभावना है।

### यह आज भी क्यों काम करता है

तीन कारणः

1. **排序优先于校准。**वर्गीकरण केवल शीर्ष श्रेणी में सही होने की आवश्यकता है। यहां तक कि P(स्पैम) = 0.99999, जबकि वास्तविक संभावना 0.7 है।

2. **高 bias，低 variance。**स्वतंत्रता परिकल्पना एक मजबूत पूर्ववर्ती है। यह एक मजबूत बाध्यकारी मॉडल है, जिससे ओवरफिटिंग को रोकना संभव है। प्रशिक्षण डेटा सीमित होने पर, एक मामूली त्रुटिपूर्ण लेकिन स्थिर मॉडल, एक सैद्धांतिक रूप से सही लेकिन बहुत अस्थिर मॉडल पर विजय प्राप्त करेगा।

3. **特征冗余会相互抵消。**相关特征提供冗余证据―― वर्गीकरणकर्ता 会重复计算这些证据,但它也会为正确类别重复计算提供. यदि "यंत्र" और "शिक्षा" 总是出现, वे सभी "तकनीकी" श्रेणी के लिए साक्ष्य प्रदान करेंगे।

第四个实践原因:Naive Bayes 极快――训练只是单次遍历数据并统计频率――预测是一次矩阵乘法――你可以几秒钟内完成训练――这种速度意味着你可以更快代、尝试更多特征集,并运行比慢速模型更多实验――

### गणित कदम से कदम

让我们跟踪一个具体例――假设我们有两个类别: स्पैम和非-स्पैम――我们的词汇有三个词:"免费""",资金"",会议"","

प्रशिक्षण डेटा:
- स्पैम 邮件 उल्लेख "मुक्त" 80 बार"",धन" 60 बार"",मीटिंग" 10 बार( कुल 150 个词)
- गैर-स्पैम 邮件 उल्लेख "मुक्त" 5 次、"धन" 10 次、"बैठक" 100 次( कुल 115 个词)
- 40% का मेल स्पैम है, 60% गैर-स्पैम है

प्रयोग लैप्लेस चिकनाई ((alpha=1):

```
P(free | spam)    = (80 + 1) / (150 + 3) = 81/153 = 0.529
P(money | spam)   = (60 + 1) / (150 + 3) = 61/153 = 0.399
P(meeting | spam) = (10 + 1) / (150 + 3) = 11/153 = 0.072

P(free | not-spam)    = (5 + 1) / (115 + 3) = 6/118 = 0.051
P(money | not-spam)   = (10 + 1) / (115 + 3) = 11/118 = 0.093
P(meeting | not-spam) = (100 + 1) / (115 + 3) = 101/118 = 0.856
```

नया संदेश समाहित है: "मुक्त" ((2 次) 、"धन" ((1 次) 、"बैठक" ((0 次) ✿

```
log P(spam | email) = log(0.4) + 2*log(0.529) + 1*log(0.399) + 0*log(0.072)
                    = -0.916 + 2*(-0.637) + (-0.919) + 0
                    = -3.109

log P(not-spam | email) = log(0.6) + 2*log(0.051) + 1*log(0.093) + 0*log(0.856)
                        = -0.511 + 2*(-2.976) + (-2.375) + 0
                        = -8.838
```

स्पैम 以很大优势胜出──"मुक्त" 出現两次是支持垃圾邮件的强烈证据──注意, "बैठक" 未出现时,对两个日志的贡献都是零(0 *日志(P))在多维数 NB中,缺失词没有影响──显然建模词缺失是伯努利 NB──

### तीन प्रकार

बेयज़ के तीन प्रकार होते हैं।`P(feature | class)`

#### बहुपद साफ़ बेय

प्रत्येक विशेषता को गणना के रूप में बनाना।

```
P(word_i | class) = (count of word_i in class + alpha) / (total words in class + alpha * vocab_size)
```

`alpha`                                                                                                                                                                                                                                                              

#### गौसीयन साफ़ बेय

प्रत्येक विशेषता को व्यवस्थित रूप से वितरित करना।

```
P(x_i | class) = (1 / sqrt(2 * pi * var)) * exp(-(x_i - mean)^2 / (2 * var))
```

प्रत्येक वर्ग में प्रत्येक विशेषता के लिए अपना औसत मूल्य और अंतर होता है।

#### बर्नौली साफ़ बेयज़

प्रत्येक विशेषता को दो-मूल्य परिवर्तकों के रूप में विकसित करना (उत्पन्न या अनुपस्थित) ◊ सबसे उपयुक्त लघुवचन या दो-मूल्य विशेषता वेक्टर ◊

```
P(word_i | class) = (docs in class containing word_i + alpha) / (total docs in class + 2 * alpha)
```

बहुपद के विपरीत, बर्नौली स्पष्ट रूप से किसी शब्द की कमी को दंडित करेगा। यदि "मुक्त" आमतौर पर स्पैम में दिखाई देता है, लेकिन इस मेल में नहीं है, बर्नौली इसे स्पैम के खिलाफ सबूत के रूप में मानेंगे।

### प्रत्येक संस्करण का उपयोग कब करें

| Variant | Feature Type | Best For | Example |
|---------|-------------|----------|---------|
| Multinomial | 计数或频率 | 文本 classification、bag-of-words | Email spam、topic classification |
| Gaussian | 连续值 | 具有近似正态特征的表格数据 | Iris classification、传感器数据 |
| Bernoulli | 二值（0/1） | 短文本、二值特征 Vector | SMS spam、presence/absence features |

### लैप्लेस स्लीडिंग

यदि परीक्षण डेटा में एक शब्द दिखाई देता है, लेकिन यह प्रशिक्षण डेटा के एक विशिष्ट श्रेणी में कभी नहीं दिखाई देता है, तो क्या होगा?

没有滑滑:`P(word | class) = 0/N = 0`एक शून्य गुणा में पूरे गुणा के बाद, होगा `P(class | features) = 0`, चाहे अन्य सबूतों में से कोई भी हो, एक ही शब्द पूरे भविष्यवाणी को नष्ट कर देगा, चाहे कोई भी अन्य सबूत हो, इसे समर्थन करेगा।

एक छोटे से अंक के साथ प्रत्येक विशेषता अंक को देगा`alpha`(आमतौर पर 1 के लिए):

```
P(word_i | class) = (count(word_i, class) + alpha) / (total_words_in_class + alpha * vocab_size)
```

जब अल्फा=1 时, प्रत्येक शब्द में कम से कम एक बहुत छोटा सा संभावना है। परीक्षण मेल में "डिस्कॉम्बलेट" दिखाई देता है।

अधिक उच्च अल्फा का अर्थ है अधिक मजबूत चिकनाई (उत्तम वितरण) ⋅ कम अल्फा का अर्थ है मॉडल अधिक विश्वसनीय डेटा── अल्फा को सुधार के लिए हाइपरपरमैटर की आवश्यकता है──

अल्फा का प्रभावः

| Alpha | Effect | When to use |
|-------|--------|-------------|
| 0.001 | 几乎没有 smoothing，信任数据 | 非常大的训练集，预计不会有未见特征 |
| 0.1 | 轻度 smoothing | 大型训练集 |
| 1.0 | 标准 Laplace smoothing | 默认起点 |
| 10.0 | 重度 smoothing，会压平分布 | 非常小的训练集，预计有许多未见特征 |

### लॉग-स्पेस गणना

सौ संभावनाओं को गुणा करना (प्रत्येक वस्तु 1) से कम होने से फ्लोटिंग पॉइंट का निचला प्रवाह होता है। भले ही वास्तविक मूल्य एक बहुत ही छोटी संख्या हो, फ्लोटिंग पॉइंट्स में गुणांक शून्य भी बन जाता है।

 समाधान: log space में काम करना  न कि संभावनाओं को गुणा करना, बल्कि उनकी संख्याओं को गुणा करना

```
log P(class | x1, x2, ..., xn) = log P(class) + sum_i log P(xi | class)
```

यह भविष्यवाणी को डॉट उत्पाद में बदल देगाः

```
log_scores = X @ log_feature_probs.T + log_class_priors
prediction = argmax(log_scores)
```

मैट्रिक्स गुणन― यही है साफ़ बेयज़  अनुमान इतनी तेजी से कारण यह एकल स्तरीय रैखिक मॉडल के साथ एक ही प्रकार का परिगणना है

### साफ़ बेयज़ बनाम लॉजिस्टिक रिग्रेशन

दोनों ही ग्रंथों के लिए प्रयोग किए जाने वाले रैखिक वर्गीकरण हैं।

| Aspect | Naive Bayes | Logistic Regression |
|--------|------------|-------------------|
| Type | Generative（建模 P(X\|Y)） | Discriminative（建模 P(Y\|X)） |
| Training | 统计频率 | 优化 Loss Function |
| Small data | 更好（强 prior 有帮助） | 更差（不足以估计权重） |
| Large data | 更差（错误假设会拖累） | 更好（更灵活的边界） |
| Features | 假设独立 | 能处理相关性 |
| Speed | 单次遍历，非常快 | 迭代优化 |
| Calibration | 概率较差 | 概率更好 |

 अनुभव विधि: से Naive Bayes 开始── यदि आपके पास पर्याप्त डेटा है, और NB 进入平台期,就切换到物流回归──

### बहुपदNB

शून्य से प्राप्त करनाः

1. **fit(X, y)**: प्रत्येक वर्ग के लिए,统计 प्रत्येक विशेषता के लिए आवृत्ति――加入 लैप्लेस चिकनाई――计算 लॉग संभावनाएँ―― भंडारण वर्ग पूर्ववर्ती(类别频率的 log)。

2. **predict_log_proba(X)**: प्रत्येक नमूना के लिए, गणना सभी वर्गों के लॉग P(वर्ग) + लॉग P(विशेषता_i ➡ वर्ग)  यह एक मैट्रिक्स गुणा है: X @ log_probs.T + log_priors

3. **predict(X)**: लौटा लॉग संभावना सर्वोच्चतम के वर्गों

```python
class MultinomialNB:
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        classes = np.unique(y)
        n_classes = len(classes)
        n_features = X.shape[1]

        self.classes_ = classes
        self.class_log_prior_ = np.zeros(n_classes)
        self.feature_log_prob_ = np.zeros((n_classes, n_features))

        for i, c in enumerate(classes):
            X_c = X[y == c]
            self.class_log_prior_[i] = np.log(X_c.shape[0] / X.shape[0])
            counts = X_c.sum(axis=0) + self.alpha
            self.feature_log_prob_[i] = np.log(counts / counts.sum())

        return self
```

关键洞察:拟合后,预测只是矩阵乘法加上偏见―― यही है साफ़ बेयज़ 如此之快的原因――

### गौशियनNB

 निरंतरता के लिए, हम प्रत्येक श्रेणी के लिए प्रत्येक विशेषता के औसत और औसत अंतर का अनुमान लगाते हैंः

```python
class GaussianNB:
    def __init__(self):
        pass

    def fit(self, X, y):
        classes = np.unique(y)
        self.classes_ = classes
        self.means_ = np.zeros((len(classes), X.shape[1]))
        self.vars_ = np.zeros((len(classes), X.shape[1]))
        self.priors_ = np.zeros(len(classes))

        for i, c in enumerate(classes):
            X_c = X[y == c]
            self.means_[i] = X_c.mean(axis=0)
            self.vars_[i] = X_c.var(axis=0) + 1e-9
            self.priors_[i] = X_c.shape[0] / X.shape[0]

        return self
```

预测会对每一个特征使用高西语PDF,并跨特征相乘(在日志空间中相加)

### भविष्यवाणी गति

Naive Bayes 预测 एक मैट्रिक्स गुणा है── n 个样本、d 个特征、k 个类别 के लिएः
- बहुपदNB: एक बार मैट्रिक्स गुणा (n x d) @ (d x k) = O(n * d * k)
- GaussianNB:n * k बार Gaussian PDF 求值,每次覆盖 d 个特征 = O(n * d * k)

 प्रत्येक आयाम पर दोनों ही रैखिक हैं इसे KNN के साथ गणना करने की आवश्यकता है सभी प्रशिक्षण बिंदुओं की दूरी तक) या RBF कर्नेल के SVM के साथ सभी समर्थन वेक्टरों के लिए कर्नेल मूल्यांकन करने की आवश्यकता है तुलना में,NB में पूर्वानुमान में कुछ संख्यात्मक स्तरों

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Naive Bayes | “简单的概率 classifier” | 一个使用 Bayes' theorem，并假设给定类别后特征 conditionally independent 的 classifier |
| Conditional independence | “特征彼此不影响” | P(A, B \| C) = P(A \| C) * P(B \| C)——一旦知道 C，知道 B 不会告诉你关于 A 的任何新信息 |
| Laplace smoothing | “Add-one smoothing” | 给每个特征添加一个小计数，防止零概率主导预测 |
| Prior | “看到数据之前你相信什么” | P(class)——观察任何特征之前，每个类别的概率 |
| Likelihood | “数据拟合得有多好” | P(features \| class)——如果类别已知，观察到这些特征的概率 |
| Posterior | “看到数据之后你相信什么” | P(class \| features)——观察到特征后，类别的更新概率 |
| Generative model | “建模数据如何生成” | 学习 P(X \| Y) 和 P(Y)，然后使用 Bayes' theorem 得到 P(Y \| X) 的模型 |
| Discriminative model | “建模 decision boundary” | 不建模 X 如何生成，而是直接学习 P(Y \| X) 的模型 |
| Log probability | “避免 underflow” | 使用 log P 而不是 P，防止许多小数相乘后在浮点数中变成零 |
