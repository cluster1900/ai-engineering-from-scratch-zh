### तीन प्रकार के प्रस्थान

输入 `x`和标签 `y`इसका संयुक्त वितरण दो प्रकार में लिखा जा सकता हैः

```math
P(x, y) = P(x) \cdot P(y \mid x) = P(y) \cdot P(x \mid y)
```

प्रत्येक वर्ग में विभिन्न कारक बदलते हैंः

| 漂移 | 变化部分 | 保持不变的部分 | 支付示例 | 能观察到的监控器 |
|---|---|---|---|---|
| 协变量漂移 | `P(x)` | `P(y \| x)` | 高购物金额的应用用户变多 | 输入监控 |
| 先验漂移 | `P(y)` | `P(x \| y)` | 攻击期间欺诈率翻倍，但欺诈特征不变 | 预测与结果监控 |
| 概念漂移 | `P(y \| x)` | 输入可以不变 | 相同购物金额对应不同欺诈风险 | 只有结果监控 |

गामा 等人将 `P(y | x)`                                                                                                                                                                                                                                                              `P(y | x)``P(x)`变化 को虚拟漂移 कहा जाता है। उनका समग्र वर्णन भी समय के अनुसार मॉडल में विभाजित होगा।

协变量漂移不一定有害──如果模型学好了 `P(y | x)`, प्रत्येक इनपुट के लिए सही भविष्यवाणी की जा सकती है। लेकिन जब प्रवाहित अभ्यास के लिए प्रवाहित होता है, तो यह कम होता है या निर्णय सीमा के निकट होता है, सटीकता दर में गिरावट आ सकती है।

### 群体稳定性指数

PSI क्रेडिट रेटिंग से उत्पन्न होता है। संदर्भ मूल्य को 10 बॉक्स में विभाजित किया जाता है, आमतौर पर संदर्भ 10 अंकों के आधार पर, ताकि प्रत्येक बॉक्स में संदर्भ नमूने का 10% हो।

```math
\text{PSI} = \sum_{\text{bins}} (\text{current\_share} - \text{reference\_share}) \cdot \ln\left(\frac{\text{current\_share}}{\text{reference\_share}}\right)
```

 किसी बॉक्स में शून्य के लिए अनुपात होगा, जिससे संख्या अनंत होगी, इसलिए प्रत्येक अनुपात को 0.0001 तक काटा जाएगा।

實踐中常用固定区间解释 PSI: 0.1 से कम स्थिर, 0.1 से 0.25 तक मध्यम विचलन, 0.25 से अधिक महत्वपूर्ण विचलन। ये अनुभव संबंधी प्रथाएं हैं, सांख्यिकीय जांच नहीं हैं।

### कोलमोगोरोव-स्मिर्नोव 统计量

### 类别 विशेषता का कार्ड चाचणी

 भुगतान मार्गों जैसे श्रेणीगत विशेषताओं के लिए, दो पंक्तियों का निर्माण करें संदर्भ  वर्तमान)  प्रत्येक श्रेणी के एक पंक्ति के तालिका प्रत्येक इकाई के लिए अपेक्षित गणनाएँ क्रम कुल और पंक्तियों की कुल संख्या द्वारा निर्धारित की जाती हैंः

```math
\begin{aligned}
\text{expected}[r][c] &= \text{row\_total}[r] \cdot \text{column\_total}[c] / \text{grand\_total} \\
\text{chi2} &= \sum_{\text{cells}} (\text{observed} - \text{expected})^2 / \text{expected}
\end{aligned}
```

 के लिए `k`个类别,检验自由度为 `k - 1` केवल वर्तमान विंडो में उत्पन्न वर्गों में से अधिक योगदान देता है, इसलिए परीक्षण नए मूल्य का जवाब दे सकता है Cramér का V है प्रभाव मात्रा दो पंक्तियों के लिए, यह बराबर है `chi2 / grand_total`की वर्गमूल

1. **多重检验校正。**बोनफ़ेर्रोनी 校正将 `alpha`परीक्षा संख्या के अलावा प्रदर्शन पूरे होगा`alpha`设为0.01, दो परीक्षणों को वितरित किया गया, इसलिए प्रत्येक परीक्षण 0.005 का उपयोग करता है।
2. **要求足够的效应量。** केवल पीएसआई `D`या क्रैमर के वी भी अधिक मूल्य के लिए केवल सूचना पुलिस
3. **要求持续性。**连续 `k`个窗户出现漂移才告警──演示使用 `k = 2`
4. **区分警告与告警。** सूचना उपकरण में प्रवेश, सूचना पुलिस सूचना कर्मचारी

प्रदर्शन प्रदर्शन नियम 2 का प्रभाव: एक स्वच्छ खिड़की के कार्बोन का p मान 0.0009 है, जो कि एकल परीक्षण से कम है `alpha` लेकिन इसकी क्रैमर V  0.1 से कम है, इसलिए रणनीति केवल चेतावनी रिकॉर्ड, नहीं जारी चेतावनी

### 重新 प्रशिक्षण की触发条件

常见的重训触发方式有三种:

- **定期。**हर हफ्ते या हर महीने पुनः प्रशिक्षण सरल, लेकिन परिवर्तन के समय भी पुनः प्रशिक्षण, परिवर्तन के समय प्रतीक्षा करना होगा।
- **漂移。** महत्वपूर्ण विशेषताओं के आयात व स्थानांतरण का समय  मूल्य से अधिक है।
- **性能。**结果指标低于参考值减减宽度范围重训时.

漂移类型决定重新训练能解决什么:

| 漂移 | 有用的行动 |
|---|---|
| 协变量漂移，但准确率稳定 | 通常无需处理，继续观察结果指标。 |
| 协变量漂移进入数据稀少区域 | 用覆盖这些区域的近期数据重训 |
| 先验漂移 | 重新校准分数，或调整决策阈值 |
| 概念漂移 | 先收集新标签。用旧标签重训只会再次学到旧概念。 |

पुनः प्रशिक्षण के बाद, नवीनतम लेबल किए गए डेटा पर परीक्षण नए मॉडल── सिस्टम डिजाइन पाठ्यक्रम के छाया और किंकडार्क चरणों को अपनाने के साथ प्रकाशित किया जाएगा, फिर संदर्भ विंडो को नए प्रशिक्षण डेटा के लिए पुनः स्थापित किया जाएगा──

### पहला चरण:分位数分箱 तथा PSI

箱边界 से संदर्भ十分位数`bisect_right`找到每个值所属的盒──

```python
def quantile_edges(reference: list[float], bins: int = 10) -> list[float]:
    ordered = sorted(reference)
    n = len(ordered)
    edges = [ordered[min(n - 1, (n * i) // bins)] for i in range(1, bins)]
    return sorted(set(edges))


def psi_from_fractions(expected: list[float], actual: list[float], eps: float = 1e-4) -> float:
    total = 0.0
    for e, a in zip(expected, actual):
        e, a = max(e, eps), max(a, eps)
        total += (a - e) * math.log(a / e)
    return total
```

### 第2 步:KS 统计量及其p 值

एक ही समय में दो क्रमबद्ध नमूनों को पार करें। प्रत्येक भिन्न मान के लिए, पहले दो समूहों के नमूनों के बीच उस मूल्य के पार सभी दोहरावों को फिर से तुलना करें, संचयी अनुपात को पुनः तुलना करें।

```python
def ks_statistic(sample_a: list[float], sample_b: list[float]) -> float:
    a, b = sorted(sample_a), sorted(sample_b)
    n, m = len(a), len(b)
    i = j = 0
    d = 0.0
    while i < n and j < m:
        x = min(a[i], b[j])
        while i < n and a[i] <= x:
            i += 1
        while j < m and b[j] <= x:
            j += 1
        d = max(d, abs(i / n - j / m))
    return d
```

p मूल्य उपयोग कोलमोगोरोव 分布的级数 `2 * sum((-1)^(k-1) * exp(-2 k^2 lambda^2))`, उनमें से `lambda = sqrt(n * m / (n + m)) * D`

### 第3 步:कार्थापरीक्षण

`chi2_sf`通过正则化上不完全马函数计算卡方生存函数,小参数使用级数,大参数使用连分式──`chi_square_test`构建两行表、计算统计量,并返回p 值和克拉梅尔的V──

```python
def chi_square_test(reference_counts: dict[str, int], current_counts: dict[str, int]) -> ChiSquareResult:
    categories = [c for c in sorted(set(reference_counts) | set(current_counts))
                  if reference_counts.get(c, 0) + current_counts.get(c, 0) > 0]
    rows = [[reference_counts.get(c, 0) for c in categories], [current_counts.get(c, 0) for c in categories]]
    row_totals = [sum(r) for r in rows]
    grand = sum(row_totals)
    if len(categories) < 2 or 0 in row_totals:
        return ChiSquareResult(0.0, 0, 1.0, 0.0)
    statistic = 0.0
    for col, _ in enumerate(categories):
        col_total = rows[0][col] + rows[1][col]
        for r in range(2):
            expected = row_totals[r] * col_total / grand
            statistic += (rows[r][col] - expected) ** 2 / expected
    dof = len(categories) - 1
    return ChiSquareResult(statistic, dof, chi2_sf(statistic, dof), math.sqrt(statistic / grand))
```

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|----------------------|
| 数据漂移 | “数据变了” | 相较参考窗口，输入、预测或标签分布发生变化 |
| 协变量漂移 | “出现新类型用户” | `P(x)` 变化，而 `P(y \| x)` 不变 |
| 先验漂移 | “正样本更多了” | `P(y)` 变化，而 `P(x \| y)` 不变，也称标签偏移 |
| 概念漂移 | “游戏规则变了” | `P(y \| x)` 变化，相同输入对应不同正确答案 |
| 参考窗口 | “基准数据” | 与每个当前窗口比较的固定样本，通常是训练数据 |
| PSI | “稳定性分数” | 对各箱的“当前占比减参考占比”乘两者比值的对数求和，具有对称性 |
| KS 统计量 | “KS 检验” | 两个经验累积分布函数之间的最大差距 |
| Cramér's V | “类别效应量” | 将卡方统计量缩放到 0 到 1 范围的量 |
| 标签延迟 | “真实答案晚些到” | 从预测到真实结果到达之间的时间 |
| 告警疲劳 | “通知太多” | 大多数告警都是误报，导致人们忽略告警 |
