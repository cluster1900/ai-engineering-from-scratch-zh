## 概念

### ग्राफ

एक ग्राफ निम्नलिखित भाग से परिभाषित हैः

- **State type.**एक टाइप किया गया dict (या Pydantic मॉडल), प्रत्येक नोड शहर पढ़ेंगे और इसे संशोधित करेंगे।
- **Nodes.**纯函数 `(state) -> state_update` अद्यतन 会在返回后合并进状态
- **Edges.**नोड्स के बीच संदिग्ध या प्रत्यक्ष संक्रमण
- **Entry and exit.** `START`和 `END`प्रहरी नोड्स 标记边界──

उदाहरण: एक समाहित `classify``refund``bug``sales``done`नोड्स का एजेंट, अर्थात् एक ग्राफ 形式 का रूटिंग वर्कफ़्लो

### टिकाऊ निष्पादन

प्रत्येक नोड  लौटने के बाद, रनटाइम 会序列化状态,并将其写入检查点(SQLite、Postgres、Redis、自定义) ⋅ यदि第 N 步失败, रनटाइम हो सकता है`resume(session_id)`,并带着精确状态 从第 N+1 步继续──

LangGraph 文档 स्पष्ट रूप से उत्पादन उपयोगकर्ताओं के लिए इस बिंदु के महत्व पर जोर देता हैः Klarna、Uber、J.P. Morgan── केंद्रीय主张不只是图形; बल्कि ग्राफ आकार के साथ-साथ चेकपोइंटिंग 让恢复成本变低──

### स्ट्रीमिंग

प्रत्येक नोड आंशिक आउटपुट प्रदान कर सकते हैं। ग्राफ को कॉलर स्ट्रीम के प्रति नोड-डेल्टा घटनाओं के लिए, UI को ग्राफ में अपडेट करने में सक्षम बनाता है।

### 三种 टॉपलॉजीज

1. **Supervisor.**केंद्रीय रूटर LLM को विशेषज्ञ उप-सम्बन्धी को वितरित किया गया है।`langgraph-supervisor`मध्य `create_supervisor()`(लंगचैन 团队 में 2026 में सीधे उपकरण कॉल के माध्यम से सुझाव दिया गया है ताकि बेहतर संदर्भ नियंत्रण प्राप्त हो सके)
2. **Swarm / peer-to-peer.**एजेंट  साझा उपकरण सतह  सीधे हाथ से दूर  कोई केंद्रीय राउटर 
3. **Hierarchical.**पर्यवेक्षक 管理 उप पर्यवेक्षक,以 नेस्टेड सबग्राफ 实现──

### इस तरह की एक विधि आसानी से गलत है

- **Checkpoints too small.**केवल चेकपॉइंट वार्तालाप बदल जाता है 会让工具状态 和 स्मृति लिखता है 无法恢复──पूर्ण स्थिति 必须可序列化──
- **Non-deterministic nodes.**पुनः आरंभ करें 假设节点输入会产生相同的状态更新──随机种子、壁钟、外部API都必须被捕获──
- **Over-use of conditional edges.**प्रत्येक किनारा एक सशर्त ग्राफ है, एक अमूर्त स्थिति है।

##  इसे निर्माण

`code/main.py`实现 एक stdlib स्टेटस ग्राफः

- `State`: एक टाइप किया गया डिक्ट, समाहित `messages``step``route``output``human_approval`
- `Node`: प्राप्ति स्थिति 并返回 अद्यतन dict के कॉल करने योग्य──
- `StateGraph`:nodes + edges + conditional edges + run + resume。
- `SQLiteCheckpointer`(मेमोरी में नकली): प्रत्येक नोड में 后序列化 स्थिति में;`load(session_id)`恢复──
- एक एक डेमो ग्राफः वर्गीकृत -> शाखा(वापसी / बग / बिक्री) -> मानव गेट -> भेजें。

```
python3 code/main.py
```

## 关键术语

| Term | 人们常说 | 实际含义 |
|------|----------------|------------------------|
| State graph | “Agent 即状态机” | Typed state + nodes + edges + reducers |
| Checkpointer | “Persistence backend” | 在每个 node 后序列化 state；支持 resume |
| Reducer | “State merger” | 将当前 state 与 node update 组合起来的函数 |
| Conditional edge | “Branch” | 由 state 函数选择的 edge |
| Subgraph | “Nested graph” | 作为另一个 graph 中 node 使用的 graph |
| Durable execution | “从失败处 resume” | 使用精确 state 从最后一个成功 node 重启 |
| Supervisor | “Router LLM” | 面向 specialist subagents 的 central dispatcher |
| Swarm | “P2P agents” | Agents 通过 shared tools hand off；没有 central router |
