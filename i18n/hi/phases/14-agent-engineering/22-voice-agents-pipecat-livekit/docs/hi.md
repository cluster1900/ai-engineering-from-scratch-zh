## 概念
### पिपेकेट (pipecat-ai/pipecat)

- पायथन फ्रेम के पाइपलाइन फ्रेमवर्क पर आधारित है 
- `Frame`→ `FrameProcessor`श्रृंखला
- दो प्रवाह दिशाएँ:
  - **DOWNSTREAM** स्रोत → sink(ऑडियो में, TTS बाहर)
  - **UPSTREAM** प्रतिक्रिया 和 नियंत्रण(रद्द, मीट्रिक, बारज-इन)
- `PipelineTask`通过 घटनाओं(`on_pipeline_started``on_pipeline_finished``on_idle_timeout`) तथा मेट्रिक्स/ट्रैकिंग/आरटीवीआई के पर्यवेक्षकों के लिए जीवन चक्र प्रबंधन 

典型 पाइपलाइन:

```
VAD (Silero) → STT → LLM (context alternates user/assistant) → TTS → transport
```

परिवहनःदैनिक、लाइवकिट、छोटे वेबआरटीसीTransport、फास्टएपी वेबसॉकेट、वाट्सएप。

पिपेकेट प्रवाह  संरचित वार्तालापों को बढ़ाएं(राज्य मशीनें)。 पिपेकेट क्लाउड ‒ प्रबंधित रनटाइम。

### लाइवकिट एजेंट (livekit/agents)

-  WebRTC के माध्यम से AI मॉडल  कनेक्ट करने के लिए उपयोगकर्ता 
- 核心概念:`Agent``AgentSession``entrypoint``AgentServer`
- दो आवाज एजेंट वर्गः
  - **MultimodalAgent**  OpenAI रियल टाइम या इसी तरह के कार्यक्रम के माध्यम से सीधे ऑडियो प्रसंस्करण
  - **VoicePipelineAgent** STT → LLM → TTS कैस्केड; पाठ स्तर पर नियंत्रण प्रदान करना
-  ट्रांसफार्मर मॉडल के माध्यम से  सेमैटिक टर्न डिटेक्शन को प्राप्त करना
- मूल जीवन एमसीपी 集成──
- 通过SIP 支持电话──
- लाइवकिट इन्फरेंस के माध्यम से  50+ मॉडल प्रदान करें, बिना एपीआई कुंजी की आवश्यकता; प्लगइन्स के माध्यम से 200+ अधिक मॉडल भी कनेक्ट हो सकते हैं

Vapi( अनुकूलन के बाद उच्च तकनीक लगभग ~450600ms) और Retell(180 बार परीक्षण करें

### यह तरीका आसानी से गलत जगह पर है

- **没有 barge-in handling。**उपयोगकर्ताःबैकअप;एजेंट 继续说话──
- **忽略 STT confidence。**低信心抄录被当成事实送入 LLM──应基于信心做门,或请求确认──
- **TTS mid-sentence cutoff。**जब पाइपलाइन एक वाक्य के बीच में समाप्त हो जाता है, TTS को यह जानने की आवश्यकता होती है, अन्यथा ऑडियो काटना होगा।
- **忽略 latency budget。**प्रत्येक घटक में 50200ms का अतिरिक्त समय होता है।

### 2026 में सामान्य विलंबता

- VAD:2060ms
- STT आंशिक:100250ms
- LLM 首个 टोकन:150400ms
- टीटीएस पहला ऑडियो:100200ms
- परिवहन आरटीटी:3080ms

端到端 450600ms 属于高级体验──8001200ms 很常见──任何> 1500ms का अनुभव都会感觉已经坏了──

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Frame | "Event" | pipeline 中有类型的数据单元（audio、transcript、text、control） |
| Processor | "Pipeline stage" | 带有 process(frame) 的 handler |
| DOWNSTREAM | "Forward flow" | 从 source 到 sink：audio in，speech out |
| UPSTREAM | "Feedback flow" | Control：cancel、metrics、barge-in |
| VAD | "Voice activity detection" | 检测用户何时正在说话 |
| Semantic turn detection | "Smart end-of-turn" | 基于 model 判断用户已经说完 |
| MultimodalAgent | "Direct audio agent" | Audio in，audio out；中间没有 text |
| VoicePipelineAgent | "Cascade agent" | STT + LLM + TTS；text-level control |
