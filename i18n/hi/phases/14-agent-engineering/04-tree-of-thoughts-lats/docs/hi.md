विचार श्रृंखला है एक लाइनर चाल। यदि पहला कदम गलत है, तो बाद का प्रत्येक कदम गलत परित्याग पर आधारित होगा। 24 के खेल में, चार अंकों के साथ + − × ÷  प्राप्त करें 24) में, GPT-4 CoT की सटीकता दर 4% है।

तर्क आवश्यकता यह है कि कई उम्मीदवारों का प्रस्ताव किया जाए, उन्हें मूल्यांकन किया जाए, उम्मीदवारों का चयन किया जाए, और एक गतिरोध में उभरने की क्षमता 时回溯 करे।

## 概念

### विचारों का वृक्ष (याओ एट अल., न्यूरआईपीएस 2023)

प्रत्येक नोड एक连贯的中间步骤 है (एक विचार)  प्रत्येक नोड का विस्तार किया जा सकता है के लिए 个孩子的思考──LLM प्रत्येक नोड के लिए स्कोरिंग प्रॉम्प्ट का उपयोग करें  आत्म-मूल्यांकन करें── खोज 探索 इस पेड़, हो सकता है BFS、DFS अथवा बीम──

```
                     (root: "find 24 from 4 6 4 1")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- Score: HIGH
              /   \              |                  |
          ...    ...          ...                finish
```

आत्म-मूल्यांकन एक महत्वपूर्ण भाग है।`sure / likely / impossible`वर्गीकरण`1..10`संख्यात्मक स्कोर, साथ ही उम्मीदवारों के बीच मतदान।

### LATS (Zhou et al., ICML 2024)

LATS में MCTS नीचे एकजुट हुआ ToT,React और Reflection,LLM तीन भूमिकाएं निभाता हैः

- **Policy**: प्रस्ताव候选 अगली कार्रवाई (ReAct-style)
- **Value function**:为 आंशिक पटरि 打分(ToT शैली स्व-ईव)
- **Self-reflector**:失败时写下自然语言反思 (प्रकाशना शैली)

पर्यावरण प्रतिक्रिया (observation) मूल्य फ़ंक्शन में शामिल होगी, इसलिए खोज 会由真实工具 परिणाम 提供信息,而不仅仅是模型意见──论文发布时的结果: GPT-4 का उपयोग HumanEval pass@1 为 92.7%(SOTA), GPT-3.5 का उपयोग WebShop औसत 75.9 ((ग्रैडिएंट आधारित बारीक-ट्यूनिंग के करीब)

### एमसीटीएस, न्यूनतम रूप

प्रत्येक पुनरावृत्ति में चार चरण होते हैंः

1. **Select** उपयोग UCT(वृक्षों के लिए बाध्य ऊपरी आत्मविश्वास) जड़ से 走到叶子──
2. **Expand**  नीति के माध्यम से 生成 K 个孩子──
3. **Simulate** उपयोग नीति से बच्चे के रोलआउट तक,并用 मूल्य फ़ंक्शन (या पर्यावरण पुरस्कार)
4. **Backpropagate** 沿路径向上更新訪問数 和 मूल्य अनुमान──

UCT सूत्रः`Q(s, a) + c * sqrt(ln N(s) / N(s, a))` पहला कार्य शोषण है; दूसरा कार्य अन्वेषण है`c`

### 成本现实

खोज 会让 टोकन 爆裂── 24 का खेल 上的 ToT उपयोग का टोकन है CoT का 1001000 倍──LATS 类似── यह मुफ़्त नहीं है; खोज 留给应:

- 单条轨迹 被证明不足的任务(24 का खेल 复杂 कोड) 
- दीवार घड़ी 不如正確ता  महत्वपूर्ण कार्य──
- वहाँ सुविधाजनक और विश्वसनीय मूल्य समारोह का कार्य ((कोड का इकाई परीक्षण、गणित का स्पष्ट लक्ष्य) 👇

यदि आपके कार्य में एक सही उत्तर और एक आकलनकर्ता है, तो कोई शोर है, खोजें अधिक खराब हो जाती हैं, क्योंकि यह गलत उत्तरों को ढूंढती हैं।

## 关键术语

| Term | 人们的说法 | 实际含义 |
|------|----------------|------------------------|
| Tree of Thoughts | “Branching CoT” | Yao et al. — 带有 self-evaluation 的 thought node 树 |
| LATS | “MCTS for LLMs” | Zhou et al. — 在 MCTS 下统一 ToT + ReAct + Reflexion |
| UCT | “Upper confidence bound” | 在 exploitation (Q) 和 exploration (ln N / n) 之间平衡的 select formula |
| Value function | “这个 state 有多好” | Prompted LLM score 或 environment reward；反馈给 backprop |
| Policy | “Action proposer” | ReAct-style generator；发出候选 next thought/action |
| Rollout | “Simulated trajectory” | 使用 policy 从 node 走到 leaf，并用 value 打分 |
| Backpropagate | “更新 ancestors” | 将 leaf 的 reward 沿路径向上推，更新 visit count 和 Q |
| Search cost | “Token explosion” | Game of 24 上是 CoT 的 100-1000 倍；采用前先做 budget |
