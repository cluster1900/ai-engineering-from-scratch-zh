## 概念
### तीन घटक

```
Actor         : generates a trajectory (ReAct-style loop)
Evaluator     : scores the trajectory — binary, heuristic, or self-eval
Self-Reflector: writes a natural-language reflection on the failure
```

एक डेटा संरचना को पुनः जोड़ेंः

```
Episodic memory: list of prior reflections, prepended to the next trial's prompt
```

एक बार परीक्षण होगा अभिनेता। मूल्यांकनकर्ता इसके लिए打分── यदि स्कोर कम है, तो स्व-प्रतिबिंबक एक प्रतिबिंब उत्पन्न करेगा।

### तीन प्रकार के मूल्यांकनकर्ता

1. **Scalar** बाहरी बाइनरी सिग्नल―ALFWorld सफलता या असफलता―HumanEval परीक्षण 通过或失败―最简单,信号 最强―
2. **Heuristic** 预定义的失败签名── यदि एजेंट 连续两次产生相同的行动,就标记为卡住── यदि पटरि 超过50 कदम,就标记为不有效──
3. **Self-evaluated** LLM अपने स्वयं के पटरियों पर 打分──当没有基础真理 时需要它──信号较弱;适合工具基础验证 搭配使用(05 पाठ  CRITIC) 

2026 के लिए एक आदर्श अभ्यास है मिश्रित उपयोगः स्केलर के साथ उपलब्ध समय, स्व-उपयोग के साथ अनुपयोगी समय, सुरक्षा रेल के रूप में हेरिस्टिक्स

### यह सामान्यीकरण क्यों है

प्रतिबिंब एक नया एल्गोरिथ्म है, न कि एक नामित मॉडल। लगभग प्रत्येक उत्पादन में स्व-चिकित्सा एजेंट कुछ प्रकार के वेरिएंट पर काम करता हैः

- लेटा का नींद समय गणना (Lection 08): एक स्वतंत्र एजेंट रिफ्लेक्स अतीत की बातचीत,并写入 स्मृति ब्लॉक──
- क्लाउड कोड की `CLAUDE.md`/ save memory 模式:将 चिंतन 捕获为学习,并预pendi到未来的会议
- कार्यप्रवाह के लिए`/learn-rule`आदेश:将 सुधार 捕获为显式规则──
- LangGraph के प्रतिबिंब नोड्सः एक नोड आउटपुट 打分 के लिए, और जरूरत समय मार्ग से परिष्कृत करने के लिए

ये सभी एक ही विचार से आते हैंः प्राकृतिक भाषा एक पर्याप्त रूप से समृद्ध माध्यम है, जो मैं असफलता से क्या सीखा है, उसे दौड़ के बीच ले जा सकता है।

### 什么时候有效,什么时候无效

प्रतिबिंब 适用于:

- वहाँ स्पष्ट विफलता संकेत है परीक्षण विफलता उपकरण त्रुटि गलत उत्तर)
- कार्य वर्ग 可复现(एक ही प्रकार की समस्या फिर से दिखाई देगी)。
- प्रतिबिंबित करने के लिए पर्याप्त कार्य बजट है।

प्रतिबिंबित करना:

- एजेंट पहली बार कोशिश कर चुका है सफल
- 失败来自外部因素(नेटवर्क डाउन 工具 टूट गया) 反思 नेटवर्क डाउन 对未来运行 没有帮助──
- प्रतिबिंब 变成迷信  एक बार कभी-कभी फ्लैग रन 储存一段叙事

2026 साल के फंदेः स्मृति रोट──आदर्शनास संचित; इनमें से कुछ पहले से ही बीत चुके हैं या गलत हैं; एपिसोडिक बफर के साथ 变大, फिर से चलें 会变慢──缓解方法:定期紧缩(पाठ 06)、 प्रतिबिंबों पर 设置 TTL, या उपयोग करने के लिए एक अलग नींद समय सफाई एजेंट(Letta)。

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Reflexion | “Self-correction” | Shinn et al. 2023 — Actor、Evaluator、Self-Reflector 加 episodic memory |
| Verbal reinforcement | “Learning without gradients” | prepend 到下一次 trial prompt 的自然语言 reflection |
| Episodic memory | “Per-task reflections” | 针对一个 task class 的 prior reflections bounded buffer |
| Scalar evaluator | “Binary success signal” | 来自 ground truth 的 pass/fail 或 numeric score |
| Heuristic evaluator | “Pattern-based detector” | 预定义 failure signatures（例如 stuck-loop、too-many-steps） |
| Self-evaluator | “LLM-as-judge on own trace” | 没有 ground truth 时使用的 lower-signal fallback — 与 tool-grounded verification 搭配 |
| Memory rot | “Stale reflections” | Episodic buffer 被过时 entries 填满；用 compaction/TTL 修复 |
| Sleep-time reflection | “Async self-reflection” | 在 hot path 之外运行 Self-Reflector，使 primary agent 保持快速 |
