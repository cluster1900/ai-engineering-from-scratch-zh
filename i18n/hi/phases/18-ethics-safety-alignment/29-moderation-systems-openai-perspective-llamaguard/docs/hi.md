### लामा गार्ड 3/4

已在课 16 覆盖──14 个 MLCommons जोखिम श्रेणियाँ(组织方式不同于OpenAI के 13 个响应方案布鲁尔语)──支持 8 भाषाएँ (v3)──Llama Guard 4 (2025 年 4 月) 原生支持多模,12B──

ओपनएआई और लामा गार्ड के वर्गीकरण में एक-दूसरे पर भारी मतभेद हैं। ओपनएआई एक व्यापक श्रेणी के रूप में "गैरकानूनी" होगा। लामा गार्ड "हिंसा अपराध" और "गैरहिंसा अपराध" को विभाजित करेगा।

### परिप्रेक्ष्य एपीआई (Google Jigsaw)

浪潮(pre-2020) की विषमता स्कोरिंग प्रणाली में से एक है।

इसका व्यापक रूप से उपयोग सामग्री-मध्यमता अनुसंधान आधार के रूप में किया जाता है, क्योंकि इस एपीआई में 稳定、有文档, और कई वर्षों के माप डेटा है।

### तीन परत पैटर्न

1. **Input moderation.**在世代 前对用户提示 分类──如果标记,则拒绝──延迟:一次分类器调用──
2. **Output moderation.**                                                                                                                                                                                                                                                              
3. **Custom moderation.**डोमेन-विशिष्ट नियम (रेजेक्स,अलोवलिस्ट,बिजनेस पॉलिसी)

यह तीन स्तर के अनुसार डिजाइन है अनुक्रमिकः इनपुट मॉडरेशन 必须在代前完成, आउटपुट मॉडरेशन 在代后运行.

### विफलता मोड

- **Input only.**捕捉不到输出幻觉 (अभ्यास 12-14 कोडिंग हमले इनपुट वर्गीकरणों को छोड़ देंगे)
- **Output only.** किसी भी प्रविष्टि को मॉडल तक पहुंचने की अनुमति दें; लागत बढ़ाएं; हमलावर को आंतरिक तर्क प्रकट करें
- **Custom only.**无法稳健覆盖各类类别;

लेयर किया गया है।

## इसका उपयोग करें
`code/main.py`构建一个三层级调节器:输入调节器(关键字 +类别分数) 、输出调节器(对输出使用相同的分类器) 、定制调节器(域名规则) 。你可以将输入 跑过它,并观察哪一层捕捉到了什么──

## 交付 यह
本课产 出 `outputs/skill-moderation-stack.md` एक तैनाती को निर्धारित करने के लिए, यह मॉडरेशन स्टैक कॉन्फ़िगरेशन की सिफारिश करेगाः इनपुट उपयोग करें कौन सा वर्गीकरण, आउटपुट उपयोग करें कौन सा वर्गीकरण, उपयोग करें कौन से कस्टम नियम, साथ ही किनारे मामलों का उपयोग करें क्या निर्णय 

## अभ्यास
1. 运行 `code/main.py`将良性、边界和有害输入 跑过全部三层──报告每种情况哪一层触发──

2. 扩展 Harness,加入针对特定类别的Perspective-API-style toxicity scoring── इसकी सीमा व्यवहार को श्रेणी स्कोर से तुलना करें──

3. 阅读OpenAI मॉडरेशन एपीआई डॉक्स 和 लामा गार्ड 3 श्रेणी सूची──将每个 OpenAI श्रेणी 映射到最接近的 लामा गार्ड श्रेणियाँ──找出三个无法干净映射的类别──

4. कोड-सहायक तैनाती के लिए (जैसे कि GitHub Copilot) मॉडरेशन स्टैक डिजाइन करें।

5. Azure Content Moderator 2027 में रिटायर हो जाएगा।

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| OpenAI Moderation | "omni-moderation-latest" | 基于 GPT-4o 的 13-category (text) classifier，带部分 Multimodal support |
| Perspective API | "Google Jigsaw toxicity" | Pre-LLM-era toxicity scoring baseline |
| Llama Guard | "MLCommons 14-category" | Meta 的 hazard classifier（v3：8B text，8 langs；v4：12B Multimodal） |
| Input moderation | "pre-generation filter" | model call 前作用于 user prompt 的 classifier |
| Output moderation | "post-generation filter" | delivery 前作用于 model output 的 classifier |
| Custom moderation | "domain rules" | Deployment-specific rules（regex、allowlist、policy） |
| Layered moderation | "all three layers" | 标准生产部署模式 |
