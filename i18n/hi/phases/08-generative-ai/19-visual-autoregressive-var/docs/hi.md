## 问题

Autoregressive 生成之所以主导语言建模,是因为它能预测地扩展:更多计算、更多参数、更低困惑、更好的输出──2024 साल से पहले, छवियों का उत्पादन मुख्य रूप से दो प्रकार के AR 尝试 हैंः पिक्सेलआरएनएन/पिक्सेलसीएनएन (逐像素) और डेल-ई 1 / पार्ट / म्यूज़गेन (DALL-E 1 / Parti / MuseGAN) में VQ-VAE कोड 上逐 टोकन) 

两者都受难于生成顺序问题──像素和代币 排列在2D 网格中,但AR 模型必须使用1D रास्टर क्रम 访问它们──早期角落像素不知道图像最终将变成什么──生成质量的扩展性与文本上的GPT不同,也从未在匹配计算量时达到扩散 模型质量──

VAR 通过改变生成对象来解决生成顺序问题──VAR 不在空间中个别预测图像图像图像,而是以不断提高的分辨率预测整张图像──步骤 1:预测一个1×1 टोकन(整体图像摘要)──步骤 2:预测一个2×2 टोकन 网格(更粗的特征)──步骤 3:预测一个4×4 网格──步骤 K:预测最终的 (H/8) x(W/8) 网格──

प्रत्येक माप सभी पूर्व मापों पर ध्यान केंद्रित करता है, और अपने मापों में भाग जाता है।

## 概念

### VQ-VAE बहु-मात्रा टोकनाइज़र

VAR  जरूरत एक **multi-scale discrete Tokenizer**. छवि x के लिए, यह एक श्रृंखला उत्पन्न करेगा जो धीरे-धीरे रिज़ॉल्यूशन में सुधार करेगी।

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

प्रत्येक z_k एक ही कोडबुक का उपयोग करते हैं। प्रत्येक पैमाने पर टोकनाइज़ेशन एक दूसरे से स्वतंत्र नहीं है, बल्कि प्रत्येक पैमाने के अवशिष्ट की मांग और पुनः निर्माण करने में सक्षम होने के लिए प्रशिक्षित किया जाता हैः

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

यह एक है**residual VQ**变体──尺度 k 捕获尺度 1..k-1 遗漏的内容──Decoder 接收所有尺度嵌入的和并生成图像──

बहु-मात्रा VQ Tokenizer केवल एक बार प्रशिक्षण (VQGAN के समान) के बाद, सभी उत्पन्न कार्य पूर्ण होते हैं।

### अगली स्केल भविष्यवाणी

生成模型 एक ट्रांसफार्मर है, यह सभी पहले के पैमाने के टोकन को देखता है, और अगले पैमाने के टोकन का पूर्वानुमान करता है.

इनपुट अनुक्रम संरचनाः
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

स्थिति सम्मिलन 同时编码尺度索引和尺度内的空间位置──注意 在尺度顺序上是因果的:尺度 k、位置 (i, j) के टोकन Attention 可以 Attention 到尺度 1..k के सभी टोकन,也可以 Attention 到尺度 k 本身在所用内尺度 序列中更早出现的 टोकन(VAR उपयोग स्थिर स्थिति ध्यान, कोई आंतरिक पैमाने कारणता, यानी एक पैमाने के भीतर सभी स्थानों并行预测) 

训练损失:在每个尺度 k,给定所有之前尺度的代币,预测代币 z_k――对离散 VQ代码使用交叉 Entropy Loss──结构与GPT相似,只是在这里序列变成了尺度结构化的序列──

### 生成

推理时:
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

जब K = 10 个尺度时,生成需要10次 变压器前进通过──每次通过都并行生成整个尺度,而不是在尺度内逐个代币自归──对于 256x256 图像,这大约是10次通过,而DiT是28-50次──

### Next-Scale क्यों Next-Token से ज्यादा जीत

तीन संरचनात्मक लाभः
1. **从粗到细符合自然图像统计规律。**मानवाधिकारों के अनुसार, निम्न-अवधि संरचना स्थिर और पूर्वानुमान योग्य है; निम्न-अवधि सामग्री के लिए उच्च-अवधि विवरण की शर्त है।
2. **尺度内并行生成。**GPT के प्रकार के टोकन AR से अलग, VAR एक चरण में किसी माप का उत्पादन करता है।
3. **没有生成顺序偏置。**尺度 k के टोकन  पूरे आयाम k-1 को देख सकते हैं;  बाईं ओर  या  ऊपर  की कोई विकृति नहीं है, जो शुरुआती टोकन को देर से उपयोग में आने से पहले प्रतिबद्धता करने के लिए मजबूर नहीं करेगा

### स्केलिंग कानून

टियां और अन्य  सबूत VAR में ImageNet पर FID  शक्ति-कानून स्केलिंग वक्र का पालन करते हैं, जैसे GPT की उलझन एक प्रकार है ∙∙ पैरामीटर या गणना मात्रा दोगुनी, त्रुटि को कम करने के लिए आधे से अधिक होगा ∙ यह पहली तरह से स्पष्ट रूप से प्रदर्शित होता है ∙ भाषा मॉडल की तरह इस तरह के स्केलिंग व्यवहार की छवि उत्पन्न मॉडल ∙ परिणाम VAR पैमाने    अनुमान मात्रा द्वारा गणना अनुमान, न कि प्रत्येक संरचना के अनुभव अनुमान पर निर्भर करता है ∙

### विसारण के साथ संबंध

VAR तथा Diffusion साझा एक ही डेटा संपीड़न कथा: दोनों ही उत्पन्न समस्या को एक श्रृंखला में विभाजित करते हैं आसान से अधिक सहायक समस्याएं

- प्रसारः धीरे-धीरे शोर में शामिल होना, सीखने को हटाना कदम
- VAR: धीरे-धीरे बढ़ते हुए, संकल्प, सीखने भविष्यवाणी अगले पैमाने

它们是穿越相同问题的不同轴线──两者都产生可处理的条件分布──经验上,VAR 推理更快(pass 更少,尺度内全并行),并且在类条件 ImageNet 上匹配或胜过 DiT──文字条件 VAR(VARclip、HART) एक सक्रिय अनुसंधान दिशा──

## अभ्यास

1. **尺度数量消融。**4.6 ̊8 ̊10 ̊ स्केल ट्रेनिंग VAR ̊ माप पुनः निर्माण गुणवत्ता और Autoregressive पास संख्यात्मक संबंध ̊ अधिक स्केल = अधिक细残留 = बेहतर अच्छी गुणवत्ता, लेकिन पास ̊更多 ̊

2. **Codebook size。** प्रशिक्षण कोडबुक आकार 为 512、4096、16384 के टोकनराइज़र── बड़ा कोडबुक 带来更好的重建,但预测更难──找到拐点──

3. **尺度内并行检查。**प्रशिक्षण के लिए अच्छी VAR, स्पष्ट माप ध्यान पैटर्न── में माप के अंदर, मॉडल क्या ध्यान करने के लिए क्रॉस-स्केल स्थिति पर ध्यान नहीं देने के लिए अंतर-स्केल?

4. **VAR vs DiT scaling。**एक ही ImageNet वर्ग-सशर्त कार्य के लिए, VAR और DiT को अनुकूलित करने के लिए बजट में प्रशिक्षण दें, उदाहरण के लिए 33M、130M、458M)  FID बनाम कम्प्यूटिंग को चित्रित करें VAR  प्रत्येक आकार पर DiT का नेतृत्व करना चाहिए, छोटे पैमाने पर पुनः प्राप्ति के परिणामों

5. **Text conditioning。**扩展 VAR,让它通过 adaLN 接收文字嵌入(CLIP pooled) अतिरिक्त कंडीशनिंग इनपुट के रूप में──这是HART 配方──它能让文本一致的样本上的FID 改善多少?

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|----------------------|
| VAR | "Visual AutoRegressive" | 通过在 VQ Token 网格金字塔上进行 next-scale prediction 来生成图像 |
| Next-scale prediction | "Predict coarser, then finer" | 模型以不断增加的分辨率尺度预测 Token，并以所有之前尺度为条件 |
| Multi-scale VQ tokenizer | "Residual VQ" | 生成 K 个分辨率递增 Token 网格的 VQ-VAE，decoder 会对所有尺度求和 |
| Scale k | "Pyramid level k" | K 个分辨率层级之一，从 k=1 的 1x1 到 k=K 的 (H/p)x(W/p) |
| Parallel-within-scale | "One forward per scale" | 尺度 k 的所有 Token 在一次 Transformer pass 中预测，而不是自回归预测 |
| Causal-across-scales | "Scale-ordered attention" | 尺度 k 的 Token 可以 Attention 到尺度 1..k 的全部内容，但不能 Attention 到尺度 k+1..K |
| Residual VQ | "Additive tokenization" | 每个尺度的 Token 编码较低尺度留下的 residual；decoder 对所有尺度 Embedding 求和 |
| VAR scaling law | "Image GPT scaling" | FID 随 compute 遵循可预测的 power law，类似语言模型的 perplexity |
| HART | "Hybrid VAR + text" | Text-conditional VAR 变体，将 MaskGIT-style iterative decoding 与 VAR 的尺度结构结合 |
| Scale position embedding | "(scale, row, col) triple" | Positional encoding 同时携带尺度索引和尺度内空间坐标 |
