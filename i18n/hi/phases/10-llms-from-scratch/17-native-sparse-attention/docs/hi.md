## 问题

序列长度为 N 时,Full attention 的时间成本是 `O(N^2)`, प्रत्येक स्तर केवी कैश है `O(N)`▽ 64k टोकन में, गणना और मेमोरी बैंडविड्थ 数字都非常灾难──NSA 论文中的理论估计测量值显示:在 64k 下,Atention 占总解码 延迟的 70-80%──后续所有指标,包括TTFT、 टोकन/秒、每百万 टोकन 成本,都被注意 成本主导──

स्पायर ध्यान स्पष्ट रूप से स्पष्ट है। इस प्रकार, फिक्स्ड-पैटर्न स्पायरशिप (फिक्स्ड-पैटर्न स्लाइडिंग विंडो, स्ट्रेड, ब्लॉक-लोकल) सूचना को छोड़ देता है और लंबी दूरी की याद करने के लिए असफल होता है।

Native Sparse Attention(युआन और अन्य, डीपसेक + पीकेयू + यूडब्ल्यू, एसीएल 2025 सर्वश्रेष्ठ पेपर, arXiv:2502.11089) दो और兼具: मॉडल में पूर्व-प्रशिक्षण 期间学习 के स्परसिटी पैटर्न, साथ ही एक कर्नेल-अनुसूचित 算法 को लागू करने के लिए, जिससे यह निष्कर्ष में 时真正交付计算节省.

## 概念

### तीन शाखाएँ

प्रत्येक प्रश्न के लिए, एनएसए केवी कैश के लिए तीन अलग-अलग दृश्यों का संचालन करेगा।

1. **Compressed branch.**टोकन 被分组为大小为 `l`                                                                                                                                                                                                                                                              

2. **Selected branch.**उपयोग संपीड़ित शाखा के ध्यान अंक, पहचान बाहर वर्तमान क्वेरी के साथ नवीनतम संबंधित शीर्ष-के ब्लॉक──读取这些块中细粒度(未压缩) टोकन, फिर क्वेरी 会出席到所有这些 टोकन──可以把压缩-branch Attention 看作选择的路由信号──

3. **Sliding-window branch.**प्रश्न उपस्थित होगा तक नवीनतम `W`个 टोकन (आमतौर पर 512 के लिए) स्थानीय संदर्भ में उपयोग किया जाता है।

तीन分支的输出通过学习每位置门组合:

```
out = g_cmp * out_cmp + g_sel * out_sel + g_win * out_win
```

`g_cmp, g_sel, g_win`                                                                                                                                                                                                                                                              

### यह क्यों है नॉटिवेली प्रशिक्षित

चयन 步骤(top-k blocks) is离散的──离散操作会破坏渐进流──此前的稀疏注意工作要么跳过选择的后扩散(限制训练),要么使用持续放松,而这些方法在推断中无法给出真正稀疏性──

एनएसए ने इस बिंदु को पार कियाः संपीड़ित शाखा ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान ध्यान शीर्ष के संचालन केवल संपीड़ित शाखा के बीच उच्चतम ध्यान स्कोर का पुनः उपयोग करना है ध्यान स्कोर, ताकि चयन करने के लिए आवश्यक है जो कुछ बारीकियों को लोड करें ब्लॉक`top_k`操作在前向计算图上是无运, यह केवल नियंत्रण कौन से ब्लॉक होगा内存中载

यही कारण है कि एनएसए को पूर्व-प्रशिक्षण के लिए उपयोग करने में सक्षम है। मॉडल एक साथ सीखेंगे कि तीन शाखाओं से सूचना कैसे प्राप्त की जाए, एक दुर्लभ पैटर्न उत्पन्न करें और निष्कर्ष निकालें कि वास्तविक प्रतिबद्धता को तेजी से वितरित करें।

### हार्डवेयर-अनुसूचित कर्नेल

एनएसए का कर्नेल आधुनिक जीपीयू मेमोरी पदानुक्रम के लिए है 设计的──कर्नेल 按GQA समूह 加载查询(बाहरी लूप), प्रत्येक समूह के लिए 获取应对稀少的KV ब्लॉक्स(inner loop), और SRAM 上运行注意──由于 प्रत्येक क्वेरी समूह 看到相同的选定的块──选择是每题组,而不是每题头),KV 加载会在组内摊销──算术强度维持在较高水平──

论文报告称,Triton kernels 在 64k decode 上比 FlashAttention 快 9x,并且速度率 会随序列长度增长──前进和后后核均已提供──

### 计算预算

`N`क्रम लम्बाई के लिए,`l`संपीड़न ब्लॉक आकार के लिए,`k`शीर्ष-के चयन संख्या के लिए,`w`स्लाइडिंग खिड़की के लिए,`b`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             `l`)。

- संपीड़ित शाखा: प्रत्येक प्रश्न है `O(N/l)`个 कुंजी, इसलिए कुल计 `O(N * N / l)`
- चयनित शाखाः प्रत्येक क्वेरी`O(k * b)`个 कुंजी, इसलिए कुल计 `O(N * k * b)`
- स्लाइडिंग शाखा: प्रत्येक प्रश्न है`O(w)`个 कुंजी, इसलिए कुल计 `O(N * w)`

总计:`O(N * (N/l + k*b + w))`

`N = 64k, l = 64, k = 16, b = 64, w = 512`: प्रत्येक क्वेरी की लागत के लिए `1000 + 1024 + 512 = 2536 keys`✿ पूर्ण ध्यान ✿`64000 keys` गणना घटकर 25 गुना हो गयी

`N = 128k, l = 64, k = 16, b = 64, w = 512`: प्रत्येक क्वेरी की लागत के लिए `2000 + 1024 + 512 = 3536 keys`✿ पूर्ण ध्यान ✿`128000 keys` 36x  कम करना  लाभ क्रमशः लंबाई में वृद्धि के साथ होता है, यही इसका मूल अर्थ है

### 如何比较

| Method | Differentiable | Real inference speedup | Long-range recall |
|--------|---------------|----------------------|-------------------|
| Sliding window only | yes | yes | fails |

| KV pruning (H2O, StreamingLLM) | N/A (inference-time) | yes | partial |

##  इसे निर्माण

`code/main.py`एक संक्षिप्त संश्लेषण क्रम पर तीन शाखाओं को प्राप्त करना, और प्रदर्शित करनाः

- संपीड़न MLP(के लिए सिखाने के लिए स्पष्ट, एक सरल औसत पूल आधार रेखा का उपयोग करें; वास्तविक NSA उपयोग सीखा MLP)
- संपीड़ित शाखा स्कोर द्वारा 驱动的顶级k ब्लॉक चयन
- हाल ही में `w`个 टोकन 上的 स्लाइडिंग-विंडो ध्यान
- बंद संयोजन
- गणना प्रिंट के प्रति पूर्ण ध्यान दें।

### 步骤 1: टोकन को ब्लॉक में संपीड़ित करना

```python
def compress(K, l):
    n = len(K)
    n_blocks = (n + l - 1) // l
    out = []
    for b in range(n_blocks):
        start, end = b * l, min((b + 1) * l, n)
        block = K[start:end]
        summary = [sum(row[d] for row in block) / len(block) for d in range(len(K[0]))]
        out.append(summary)
    return out
```

### 步骤 2: संपीड़ित शाखा ध्यान

运行 query 针对压缩键的软max Attention──压缩-शाखा स्कोर 同时作为顶级k चयन的信号──

### 步骤 3: शीर्ष-के ब्लॉक चयन

 चुनें सर्वाधिक स्कोर `k`个压缩块的索引──加载这些块中原始未压缩代币,并在其上运行注意──

### 步骤 4: स्लाइडिंग-विंडो ध्यान

取最后 `w`个 टोकन,并针对它们运行标准注意──

### 步骤 5: गेट + संयोजन

प्रश्न 上的小型 MLP 产生三个 गेट वजन──最终输出是三个分支输出的权重总量──

### 步骤 6: गणना गणना

印每分支、 प्रत्येक क्वेरी में भाग लेने की कुंजी संख्या तथा总数──与 `N`(पूर्ण ध्यान) तुलना करें।`l = 32, k = 4, w = 128`, एनएसए हर पूछताछ देखें`32 + 128 + 128 = 288`个 कुंजी, जबकि पूरा ध्यान है 1024, घटा 3.5x.

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Compressed branch | “粗粒度视图” | 在 block-averaged keys 上做 Attention，以每个 query `O(N/l)` 个 keys 提供 global context |
| Selected branch | “Top-k blocks” | 在 compressed-branch scores 最高的 `k` 个 blocks 上做细粒度 Attention |
| Sliding window | “Local context” | 在最后 `W` 个 Token 上做 Attention，以捕获短程模式 |
| Native trainability | “打开 sparsity 进行 pre-train” | sparsity pattern 在 pre-training 期间学习，而不是在 inference 时外挂 |
| Compression block size l | “粗粒度视图的 group size” | 多少个 Token 被合并成一个 summary；通常为 32-64 |
| Top-k | “要保留的 blocks” | 读取其未压缩 Token 的 compressed blocks 数量；通常为 16 |
| Sliding window W | “Local attention radius” | 通常为 512；更短会损害 local coherence，更长会浪费计算 |
| Branch gate | “如何混合三个分支” | per-position MLP 输出，对三个分支的贡献加权 |
| Hardware alignment | “Kernel-friendly sparsity” | 选择 sparse pattern，使实际 GPU kernel 能达到理论 speedup |
| DSA | “NSA 的后继者” | Deepseek Sparse Attention，DeepSeek 系谱中继 NSA 之后的架构 |
