इस वर्ग में शून्य से निर्माण एकल एमटीपी मॉड्यूल तथा डी-गहन हानि से गणित बहुत ही स्वच्छ है।

## 核心概念

### क्रमबद्ध एमटीपी 配配方

डीपसीक-वी 3 मुख्य मॉडल के ऊपर जोड़ा गया`D`个 एमटीपी मॉड्यूल── प्रत्येक मॉड्यूल `k`(इनमें से `k = 1..D`)预测 गहराई `k`के टोकन, यानि में दिया गया है जब तक स्थिति `i`时预测 `t_{i+k}`

मॉड्यूल `k`包含:

- एक ट्रांसफार्मर ब्लॉक `T_k`, अपना ध्यान रखना और MLP
- एक प्रक्षेपण मैट्रिक्स `M_k`, पहले एक गहराई के छिपे हुए राज्य के साथ नीचे की गहराई के मूल सत्य टोकन के एम्बेडिंग 结合起来──
- साझा एम्बेडिंग `E`(与主模型相同)
- साझा आउटपुट हेड `Out`(与主模型相同)

 प्रशिक्षण समय, के लिए स्थिति के लिए `i`का पूर्वावचन, गहराई से छिपा हुआ राज्य 为:

```
h_i^(0) = main model backbone at position i
h_i^(k) = T_k( M_k * concat(RMSNorm(h_i^(k-1)), RMSNorm(E(t_{i+k}))) )   for k >= 1
```

गहन भविष्यवाणी 为:

```
logits_{i+k} = Out(h_i^(k-1))   for k = 1..D
```

गहनता का नुकसान मूल सत्य के प्रति है`t_{i+k}`का क्रॉस-एंट्रोपीः

```
L_k = CE(logits_{i+k}, t_{i+k})
```

跨 गहराई का जोड़ खोना:

```
L_MTP = (lambda / D) * sum_{k=1..D} L_k
```

`lambda`यह एक छोटा वजन कारक है, डीपसेक-वी3 प्रशिक्षण से पहले 10% उपयोग 0.3, उसके बाद उपयोग 0.1── कुल प्रशिक्षण हानि के लिए `L_main + L_MTP`

### क्यों क्रमबद्ध है, समानांतर नहीं

Gloeckle मूल समानांतर MTP के साथ D  आउटपुट हेड, प्रत्येक सीधे लागू करने के लिए `h_i^(0)` प्रत्येक सिर एक ही रीढ़ की हड्डी से छिपे हुए राज्य 预测 `t_{i+k}`️ आप सामान्य रूप से अभ्यास कर सकते हैं, लेकिन ये पूर्वानुमान एक दूसरे के लिए शर्त नहीं हैं️ आप उपयोग नहीं कर सकते `head_1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             `head_2`, इन सिरों को एक साथ चला जाता है.

DeepSeek-V3 का अनुक्रमिक  डिजाइन से `h_i^(k-1)`अतिरिक्त वास्तविक अगले टोकन एम्बेडिंग `E(t_{i+k})`निर्माण `h_i^(k)` यह कारण श्रृंखला को बरकरार रखा गया है: पूर्वानुमान के लिए `t_{i+k+1}`, गहराई `k+1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             `t_{i+k}`处的内容── यह संरचना पर आत्म-घटनीय डिकोडर के समान है, इसलिए एमटीपी मॉड्यूल सीधे अनुमानित-डिकोडिंग ड्राफ्टर के रूप में उपयोग किए जा सकते हैं──

推理时:将 `h_i^(k-1)`और तैयार किया गया `t_{i+k}`输入 मॉड्यूल `k+1`, प्राप्त करने के लिए`t_{i+k+1}`यह ईएजीएलई शैली का मसौदा है, केवल एक अच्छी तरह से प्रशिक्षित एमटीपी मॉड्यूल का उपयोग करना है।

### 参数核算

对于隐藏为 `h`、शब्द表为 `V`का मॉडलः

- मुख्य मॉडल: अरबों से अधिक, एक बड़ा आकार के लिए`V * h`के आउटपुट सिर
- साझा आउटपुट सिरः पुनः उपयोग मुख्य मॉडल के सिर── कोई अतिरिक्त तत्व नहीं──
- साझा एम्बेडिंगः पुनः उपयोग मुख्य मॉडल के एम्बेडिंग── कोई अतिरिक्त तत्व नहीं──
- प्रत्येक एमटीपी मॉड्यूल:
  - प्रक्षेपण `M_k`:`(2h) * h = 2h^2`
  - ट्रांसफार्मर ब्लॉक `T_k`ध्यान दें`4h^2`)加 MLP(SwiGLU 且比例为8/3 时通常为`8h^2`)― प्रत्येक ब्लॉक `12h^2`

प्रत्येक मॉड्यूल का कुल अतिरिक्त घटकः`~14h^2`  DeepSeek-V3 के लिए `h = 7168`,D = 1 मॉड्यूल: कागज पर है `~14 * 7168^2 = ~720M`参数――DeepSeek-V3  रिपोर्ट 14B है, मुख्य रूप से एमटीपी मॉड्यूल के बीच विशेषज्ञ परतों से भिन्नता भी एमओई को अपनाया गया है―

##  इसे निर्माण

`code/main.py`端到端构建一个MTP模块:shared embedding、projection、transformer block、shared output head── उसके बाद यह संश्लेषणात्मक अनुक्रम में संश्लेषित होता है, जो एक संक्षिप्त संश्लेषण अनुक्रम में होता है, जिसमें प्रति गहन क्रॉस-एंट्रोपी हानि का गणना होता है,并按组件印参数──32 个 टोकन के खिलौने शब्दावली 让数字更易读──

### 步骤 1:साझा एम्बेडिंग टेबल

एक `vocab_size x hidden`प्रत्येक गहराई पर प्रत्येक MTP मॉड्यूल 共同使用── नहीं एक ही टेन्सर, बल्कि दूसरा副本

### 步骤 2: प्रति गहराई संयोजन

```python
def combine(prev_hidden, next_token_embed, M_k):
    # concat along feature dim, then project down to hidden
    concat = rms_norm(prev_hidden) + rms_norm(next_token_embed)  # vector addition stand-in
    projected = matvec(M_k, concat)
    return projected
```

वास्तविक डीपसेक-वी3 में RMSNorm के वेक्टर संक्षिप्त के दो चरणों का अनुभव होगा।`[2h]`, एक के साथ नहीं किया गया था ।`h x 2h`मैट्रिक्स 投影── यह खिलौना 为了 stdlib 简洁, वेक्टर加法来代替──

### 步骤 3: गहनता के ट्रांसफार्मर ब्लॉक

स्व-विचार 加 MLP──在玩具中, एक एकल स्तरीय रैखिक ध्यान ब्लॉक 和 एक SwiGLU MLP 让结构可见,同时避免使用 numpy──

### 步骤 4: साझा आउटपुट सिर

复用主模型的输出投影──输出覆盖词汇的逻辑──

### 步骤 5: प्रति गहराई हानि

softmax(logits) तुलना में ऑफसेट `k`处 मूल-सत्य टोकन के क्रॉस-एंट्रोपी── उपयोग `lambda / D`缩放因子跨深度 聚合──

### 步骤 6: घटक गणना

打印总参数、共享(嵌入、头)参数, तथा प्रति मॉड्यूल 额外参数── प्रदर्शन MTP 额外参数与主模型大小的比例──

## 关键术语

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| MTP module | “额外 loss block” | 一个小型 transformer block 加 projection，用来预测主模型前方 `k` 个位置的 Token |
| Prediction depth | “哪个 offset” | 整数 `k`，使得 module `k` 基于截至位置 `i` 的 prefix 预测 `t_{i+k}` |
| Parallel MTP | “Gloeckle-style” | 位于同一个 backbone hidden state 之上的 D 个独立 heads，没有条件链 |
| Sequential MTP | “DeepSeek-V3 style” | 每个 module 都以先前 depth 的 hidden state 加下一个 Token 的 embedding 为条件；保留 causal chain |
| Shared output head | “复用主 head” | MTP modules 调用主模型的 LM head，而不是单独的 output projection |
| Shared embedding | “复用主 table” | 同一个 vocabulary embedding table 在所有地方使用；没有重复参数 |
| Projection matrix M_k | “结合 hidden + next-token” | 一个 `h x 2h` linear layer，将前一个 hidden state 和 target-token embedding 折叠为下一深度的输入 |
| Joint loss L_MTP | “平均额外 losses” | per-depth cross-entropy losses 的算术平均值，并按 `lambda` 缩放 |
| Acceptance rate at depth 1 | “MTP draft 多常正确” | D=1 MTP module 的 top-1 prediction 等于主模型 top-1 prediction 的比例；DeepSeek-V3 上超过 80% |
| Lambda weighting | “额外 loss 的重要性” | per-depth 缩放因子；DeepSeek-V3 在训练开始时为 0.3，之后为 0.1 |
