# समूह चैट और स्पीकर चयन

> ऑटोजेन ग्रुपचैट और एजी2 ग्रुपचैट में N 个代理之间共享一场对话; एक चयनकर्ता 函数(LLM、round-robin या custom) 选择下一个发言人── यह उभरते मल्टी-एजेंट वार्तालाप का प्रोटोटाइप हैः एजेंटों को खुद को स्थिर स्थिति ग्राफ में नहीं पता है, वे केवल साझाकरण池 पर प्रतिक्रिया करते हैं── ऑटोजेन v0.2 के ग्रुपचैट 语义 में AG2 कांटा में बरकरार रखा गया; ऑटोजेन v0.4 इसे इवेंट-ड्राइव अभिनेता मॉडल के रूप में फिर से लिखेंगे। माइक्रोसॉफ्ट 2026 के 2 महीने में ऑटोजेन को रखरखाव मोड में रख देगा, इसका समांतर सेमेटिक कर्नेल के साथ होगा Microsoft एजेंट फ्रेमवर्क में शामिल होगा।

**类型：**学习 + 构建
**语言：**पायथन (stdlib)
**前置条件：**चरण 16 · 04 (प्राथमिक मॉडल)
**时间：**~ 60 मिनट

## 问题

जब कार्यप्रवाह 已知时,静态图表(LangGraph) अच्छा उपयोग है。 वास्तविक बातचीत静态 का नहीं हैः कभी-कभी कोडर रिव्यूजर्स से पूछता है, कभी-कभी शोधकर्ता से पूछता है, कभी-कभी लेखक से पूछता है。硬编码 प्रत्येक संभावित हस्तान्तरण का बढ़त उत्पन्न होती है 爆── आप क्या चाहते हैं *एजेंट्स साझा池 पर प्रतिक्रिया करते हैं*,并由某函数决定下一个谁说话──

यही ऑटोजेन ग्रुपचैट करता है।

## 概念

### 形状

```
              ┌─── shared pool ────┐
              │   m1  m2  m3  ...  │
              └─────────┬──────────┘
                        │ (everyone reads all)
      ┌───────┬─────────┼─────────┬───────┐
      ▼       ▼         ▼         ▼       ▼
    Agent A  Agent B  Agent C  Agent D  Selector
                                           │
                                           ▼
                                  "next speaker = C"
```

प्रत्येक एजेंट प्रत्येक संदेश को देख सकता है। प्रत्येक दौर में एक चयनकर्ता फ़ंक्शन का उपयोग करके अगले वक्ता का चयन किया जाता है।

### 三种 चयनकर्ता 风格

**Round-robin。**固定循环──确定性──按N 线性扩展,但会忽略上下文: भले ही विषय कानूनी审查 हो, कोडर भी轮次获得──

**LLM-selected。**调用一个LLM,它读取最近的池内容并返回最合适的下一个发言人──具有上下文感知能力,但速度慢:每轮都会增加一次LLM 调用──AutoGen的默认方式──

**Custom。**एक पायथन  फ़ंक्शन, जिसमें आप चाहते हैं किसी भी तर्क को शामिल किया गया है।

### वार्तालाप करने योग्यएजेंट एपीआई

```
agent = ConversableAgent(
    name="coder",
    system_message="You write Python.",
    llm_config={...},
)
chat = GroupChat(agents=[coder, reviewer, tester], messages=[])
manager = GroupChatManager(groupchat=chat, llm_config={...})
```

`GroupChatManager`持有选择者──当一个代理 完成一轮后,经理会调用选择者,选择者 返回下一个代理──循环持续到满足终止条件──

### 终止

三种常见模式:

- **Max rounds。**कुल चक्र संख्या की सीमा निर्धारित करना
- **"TERMINATE" token。**एजेंट एक sentinel संदेश भेज सकते हैं; प्रबंधक यह होने पर रोक.
- **Goal-reached check。**एक हल्के मात्रा सत्यापनकर्ता प्रत्येक दौर एक बार चलाने, और चैट करने के लिए 完成时停止──

### ऑटोजेन → एजी 2 分裂, तथा माइक्रोसॉफ्ट एजेंट फ्रेमवर्क 合并

2025 की शुरुआत में, माइक्रोसॉफ्ट ने ऑटोजन (AutoGen) के लिए घटना-चालित अभिनेता मॉडल के आसपास एक बड़ा पुनर्लेख शुरू किया।

2026 में, माइक्रोसॉफ्ट ने घोषणा की कि ऑटोजेन एक घटना-चालित अभिनेता मॉडल में प्रवेश करेगा।**Microsoft Agent Framework**(RC 2026 साल 2 月,现在已与语义核心合并) ――GroupChat 概念在两条路线中都保留下来;实现细节不同──对于兼容 v0.2 的代码,AG2 是首选上游──

### 什么时候适合 ग्रुपचैट

- **Emergent conversations。**आप नहीं चाहते कि आप अगले स्पीकर से पहले कनेक्ट हो जाओ।
- **角色混合任务。**कोडर 问研究员,研究员 问档案家,档案家 再问回编码者──流程不是DAG──
- **探索式问题解决。** कल्पना मस्तिष्क तूफान सम्मेलन, बजाय流水线──

### 什么时候会失败

- **严格确定性。**LLM चयनकर्ता हो सकता है असहमत हो.
- **Sycophancy cascades。**एजेंटों को सबसे अधिक आत्मविश्वास वाले व्यक्ति का पालन करना होगा।
- **Context bloat。**प्रत्येक एजेंट हर संदेश को पढ़ता है; 10 राउंड के बाद संदर्भ बड़ा होगा।
- **Hot speakers。**某个代理因为选择者 偏好它的专长而主导对话――将扬声器平衡作为选择者特征 引入――

### समूह चैट बनाम पर्यवेक्षक

समान आदिम, भिन्न मानः

- पर्यवेक्षक: एक एजेंट 规划,其他代理 执行── चयनकर्ता 问规划者 接下来做什么──
- समूह चैटः सभी एजेंट सहकर्मी हैं; चयनकर्ता साझा करने के लिए एक भूमिका है।

两者都使用课 04 中的四个原始语── ग्रुप चैट 默认使用 LLM-selected orchestration 和 full-pool shared state──


```figure
swarm-speaker
```

##  इसे निर्माण

`code/main.py`प्रयोग करने के लिए एक समूह चैट को शून्य से लागू करें। इसमें तीन एजेंट शामिल हैं।`TERMINATE`टोकन का समापन

इस डेमो में दो चरों के वार्तालाप का प्रतिलिपि और चयनकर्ता के निर्णय का पता लगाया जाएगा।

运行:

```
python3 code/main.py
```

## इसका उपयोग करें

`outputs/skill-groupchat-selector.md`会为给定任务配置 ग्रुपचैट चयनकर्ता:राउंड-रोबिन बनाम एलएलएम-सेलेक्ट बनाम कस्टम, तथा चयनकर्ता इनपुट का उपयोग करने के लिए (अभी हाल के संदेश, एजेंट विशेषताएं, टर्न काउंट)

##  इसे जारी करें

चेकलिस्टः

- **Max rounds cap。**始终需要──典型任务为10-20──
- **Speaker-balance metric。**प्रत्येक एजेंट के दौरे की संख्या; जब असंतुलन से अधिक है
- **Termination token。** `TERMINATE`या विशेष सत्यापन एजेंट
- **Projection 或 scoped memory。** 条 后, विचार केवल प्रत्येक एजेंट को एक परिधि दृश्य देने के लिए, संदर्भ फुलाव को रोकने के लिए 
- **Selector logging。** LLM- चयनित 变体 के लिए, साथ ही रिकॉर्ड चयनकर्ता के इनपुट तथा विकल्प 否则无法调试

## 关键术语

| Term | 人们的说法 | 它实际的含义 |
|------|----------------|------------------------|
| GroupChat | "Agents in one chat room" | Shared message pool + selector function。AutoGen / AG2 primitive。 |
| Speaker selection | "Who talks next" | 选择下一个 agent 的函数。Round-robin、LLM-selected 或 custom。 |
| GroupChatManager | "The meeting host" | 拥有 selector 并循环处理轮次的 AutoGen component。 |
| ConversableAgent | "The base agent" | AutoGen base class；一个可以发送和接收 messages 的 agent。 |
| Termination token | "The 'stop' word" | 结束 chat 的 sentinel string（通常是 `TERMINATE`）。 |
| Hot speaker | "One agent dominates" | selector 不断选择同一个 agent 的 failure mode。 |
| Context bloat | "Pool grows unbounded" | 每个 agent 都读取所有先前 message；context 随轮次增长。 |
| Projection | "Scoped view" | 面向角色的共享池视图，用于防止 context bloat。 |
