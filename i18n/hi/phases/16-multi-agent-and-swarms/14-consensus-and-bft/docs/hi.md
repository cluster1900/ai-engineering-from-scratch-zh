# 面向 एजेंट्स का सहमति तथा बीजान्टिन दोष सहिष्णुता

> 经典分布式系统 BFT 遇上随机性 LLM──2025-2026 वर्षों में तीन अध्ययन दिशाएं दिखाई दीं:**CP-WBFT**(arXiv:2511.10400)  प्रति बार मतदान के अधिकार के लिए विश्वास जांच के माध्यम से;**DecentLLMs**(arXiv:2507.14928) 采用无领导方式,并行工人提案与几何中介集;**WBFT**(arXiv:2505.05103) वेटेड वोटिंग के साथ पदानुक्रमिक संरचना क्लस्टरिंग 结结,把节点分分为核心和边缘──来自 क्या एआई एजेंट्स सहमत हो सकते हैं? ## 问题

आप के पास N LLM एजेंट हैं, प्रत्येक एक उत्तर से निकलते हैं। वे मतभेद करते हैं। बहुमत ने गलत उत्तर का चयन किया है, क्योंकि दो एजेंटों के पास एक ही आधार मॉडल है।

现在加入一个欺骗的代理:它故意撒谎――或加入一个伪善的代理:它同意最后发言的人―― क्लासिक बीएफटी में,假设是拜占庭节点占比为`f < n/3`,और व्यवहार करना चाहे 2026 की वास्तविकता यह है कि:LLM नोड्स, यहां तक कि ईमानदारी से भी, आकस्मिक हैं, मॉडल के बीच होंगे संबंधित, और एक दूसरे के आउटपुट  प्रभावित होंगे

经典 BFT(PBFT, 1999)并没有错,但它不完整──它处理任意的点翻──它处理不三个诚实代理 因共享训练数据而共享同一个幻觉──本课从PBFT的基础开始,并叠加三种2025-2026年的适配──

## 概念
### 经典 BFT 给你什么

व्यावहारिक बीजान्टिन दोष सहिष्णुता (कास्त्रो और लिस्कोव, ओएसडीआई 1999)`f < n/3`个 बीजान्टिन नोड्स──该协议有三个阶段(pre-prepare、prepare、commit) 和两个原始的(签名的消息、共数证书)──它在`n >= 3f + 1`个诚意或恶意节点之间单一价值达成协议 हेतु सहमति

ये गारंटी  बहुत मजबूत हैं, लेकिन निम्नलिखित धारणाएं हैंः

1. **Independent faults。**बीजान्टिनियों ने नहीं किया
2. **Honest nodes 确实诚实。**ईमानदार आउटपुट की सहीता कोई समस्या नहीं है; प्रोटोकॉल केवल असहमति है।
3. **问题存在 ground-truth answer。**गलतियों के बारे में सहमति बनी हुई है।

LLM एजेंटों ने इस तीनों बिंदुओं के विपरीत किया है। दो एजेंटों ने एक ही आधार मॉडल का संचालन किया है। वे एक ही त्रुटि साझा करते हैं।

### तीन प्रकार के एलएलएम-विशिष्ट हमले

**Byzantine lie。**एक एजेंट 输出故意错误的答案──如果`f < n/3`, क्लासिक BFT 能处理它──

**Sycophantic conformity。**एक एजेंट मतदान से पहले दूसरों के उत्तरों को पढ़ता है, और अंतिम बोलने वाले व्यक्ति के साथ सहमत रहता है। यह बुरा इरादा नहीं है, लेकिन सबसे बड़ी आवाज से संबंधित होगा।

**Correlated-error monoculture。**तीन एजेंट एक आधार मॉडल साझा करते हैं। वे एक ही गलत उत्तर से पगलाते हैं।

### 2025-2026 वर्ष का प्रतिसाद

**CP-WBFT**(arXiv:2511.10400)  आत्मविश्वास-प्रोबेड वज़न वाले बीएफटी── प्रत्येक मतदाता  अपने उत्तर को एक आत्मविश्वास जांच जोड़ें(स्व-सूचना संभावना, या एक अलग माप मॉडल का अनुमान)── मतदान वजन विश्वास के साथ  संकुचन── रिपोर्ट称在完整图上 BFT सुधार 为 +85.71%── मिटाने 目标: साइकोफैंटिक अनुरूपता(अनुरूप एजेंट 往往对其主动给出的位置信心 较低)──

**DecentLLMs**(arXiv:2507.14928)    नेता नहीं है                                                                                                                                                                                                                                                      `f < n/2`时具备强性── मिटाई 目标:विजांटाइन झूठ 和 संबद्ध त्रुटियां(आकृतिहीनों के लिए ज्यामितीय मध्यस्थ मजबूत,并拉向密集集集群,而不是模型偏见平均) 

**WBFT**(arXiv:2505.05103)  पदानुक्रम संरचना के साथ वजन BFT Clustering。 मतदान वजन प्रतिक्रिया गुणवत्ता से 加上从历史学习到的信任分分配──将代理 聚类为核心和边缘;कोर एजेंट 必须先达成共识,边缘代理 跟随── मिटियाज 目标:可扩展性(कोर सहमति 小而快)以及部分应对单文化(कोर可按多样性 选择)。

### 实证:क्या एआई एजेंट सहमत हो सकते हैं? (arXiv:2603.01213)

इस लेख में  मापने के लिए कई सीमा मॉडल                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  

- यहां तक कि बिना प्रतिद्वंद्वियों के, एलएलएम एजेंटों के बीच कई बेंचमार्क पर स्केल प्रश्नों पर असहमति दरें भी 30% से अधिक हैं।
- 单个采用欺骗性的人的代理 可将 混合-of-एजेंट सहमति 拉离诚实基线 40+ प्रतिशत अंक
- असहमति दरें 相关;समूहों की तुलना में विषम समूहों 分歧更多(好处:अनसंदर्भित त्रुटियां), लेकिन बहाव 也更慢(坏处:समझ-से-समझ 更长) ◊

结论:BFT 给你对齐输出的机制, लेकिन यह आपको对齐后的输出的机制, यह नहीं बताता कि क्या यह सही है, सत्यापन के साथ संयोजन करना है (Phase 16 · 08 भूमिका विशेषज्ञता)  विविधता (Phase 16 · 15 बहस के प्रकार)  और मूल्यांकनकर्ता एजेंट (Phase 16 · 24 बेंचमार्क) 

### 剥离到核心协议

एक ओर LLM एजेंटों का न्यूनतम BFT राउंडः

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

अर्थिक क्लस्टरिंग 步骤是LLM-विशेष की महत्वपूर्ण परिवर्तनों── दो उत्तर अध्ययन रिपोर्ट 4.2% 和 4.2% सुधार                                                                                                                                                                                                                                             

### सीमा समायोजन

`threshold`पैरामीटर तय करता है कि कब स्वीकार करें, कब पुनः प्रयास करें, क्या करें, कम से कम स्वीकार करें।`n=5-7`个代理为0.5-0.67;更小的 `n`需要更高值──低于值时, escalate 给人类或另一个代理团队──

### सहमति 无法提供帮助的地方

- **Ambiguous questions。**यदि समस्या में कोई आधारभूत सत्य नहीं है, तो सहमति एक राय है।
- **Compound questions。**कोड लिखें और समझाएं  是两个答案──分别对每个答案投票──
- **Adversarial multi-round。**यदि एजेंट पहले के दौर को देख सकते हैं और उनकी नकल कर सकते हैं, तो वे एक-दूसरे से सहमत होने लगेंगे, सच्चाई के बावजूद।

## 关键术语
| Term | 人们常说 | 实际含义 |
|------|----------------|------------------------|
| BFT | “Byzantine fault tolerance” | Castro-Liskov 1999 protocol，用于在 `f < n/3` arbitrary faults 下达成 consensus。 |
| Byzantine | “任何坏行为” | 一个可以撒谎、丢弃 messages、静默失败的节点，除了安全 crash 外什么都可能做。 |
| Confidence probe | “你有多确定？” | 附加到 vote 上的自报或 calibrator-predicted probability。 |
| Semantic clustering | “同一答案，不同表述” | 在 counting votes 之前对等价 answers 分组。 |
| Geometric median | “Robust center” | 最小化到 sample points 距离之和的点。与 mean 不同，它对 outliers robust。 |
| Monoculture | “相同 model，相同 failures” | agents 共享 training data 或 base model 时产生的 correlated errors。 |
| Sycophantic conformity | “同意最大声的声音” | agent 的 vote 偏向最先/最大声发言的人。 |
| Core/Edge | “Hierarchical BFT” | WBFT 拆分：小规模 Core 先 consensus，Edge nodes 跟随。限制 latency。 |
