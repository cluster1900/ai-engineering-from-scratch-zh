# हस्तान्तरण और दिनचर्या  无状态编排

> OpenAI का Swarm (OpenAI का Swarm) (२०२४ साल 10 月) बहु-एजेंट 编排提炼为两个原语:**routines**(क्योंकि सिस्टम शीघ्र का निर्देश + उपकरण) और **handoffs**(返回另一个代理的工具) 没有状态机,没有分支的 DSLLLM 通过调用正确的手机工具 来路由──OpenAI Agents SDK(2025年3月) इसका उत्पादन श्रेणी के बाद वाला उत्तराधिकारी है──Swarm 本身仍然是最清的概念参考它的全部源码只有几百行── यह पैटर्न 传播很快,因为API 表面大致就是agent = शीघ्र + उपकरण; handoff = फ़ंक्शन रिटर्निंग एजेंट──限制:无状态,因此记忆是调用方的问题──

## 问题

प्रत्येक मल्टी-एजेंट फ्रेमवर्क चाहता है कि आप इसके डीएसएल को सीखेंः लांगग्राफ के नोड्स और किनारे, क्रूएआई के चालक दल और कार्य, ऑटोजेन के ग्रुपचैट और प्रबंधक। ये डीएसएल वास्तविक सार हैं, लेकिन वे चीजों को आवश्यक से अधिक भारी बनाते हैं।

Swarm 走向相反方向: उपयोग模型已经具备的工具调用能力──Handoffs 变成工具调用──Orchestrator 就是当前掌握对话的那个代理──状态机隐含在代理的系统提示中──

## 概念

### 两个原语

**Routine。**定义 Agent 角色和可用工具的系统提示── इसे एक समूह के रूप में देखा जा सकता है जिसका कार्यक्षेत्र हैः你是分类代理; यदि उपयोगकर्ता धनवापसी का प्रश्न पूछता है, तो 给退款代理──

**Handoff。**एजेंट एक उपकरण को समायोजित कर सकते हैं, यह एक नए एजेंट ऑब्जेक्ट को लौटा देता है।

```
def transfer_to_refunds():
    return refund_agent  # Swarm sees Agent return → switch active agent

triage_agent = Agent(
    name="triage",
    instructions="Route the user to the right specialist.",
    functions=[transfer_to_refunds, transfer_to_sales, transfer_to_support],
)
```

ट्राईज एजेंट की सिस्टम प्रॉम्प्ट  इसे उपयोगकर्ता के संदेश के अनुसार सही हाथों का चयन करें LLM के उपकरण-कॉल  जिम्मेदार मार्ग द्वारा 

### क्यों यह तेजी से फैलता है

- **API 小。**केवल दो अवधारणाओं को सीखने की जरूरत है।
- **使用模型已经会做的事。**उपकरण कॉल  विभिन्न प्रदाताओं के बीच उत्पादन स्तर पर पहुंच चुका है
- **没有状态机负担。**आप ग्राफ का वर्णन करने की आवश्यकता नहीं है; एजेंट के संकेतों का वर्णन करें वे किसी को भी दे देंगे

### 无状态取舍

Swarm 间运行 间明确无状态的. फ्रेमवर्क 间运行 期间保存消息历史,但不会持久化任何东西.

में उत्पादन वातावरण में (OpenAI Agents SDK, 2025 साल 3 月), यह मुख्य परिवर्तनों में से एक हैःSDK ने अंतर्निहित सत्र प्रबंधन, गार्ड्रेल और ट्रैकिंग को जोड़ा, जबकि हस्तांतरण को बरकरार रखा।

### सवार/हैंडोफ़ 适合的场景

- **Triage patterns。**एक लाइन एजेंट उपयोगकर्ता को विशेषज्ञ को मार्ग देगा।
- **基于技能的 handoffs。**यदि कार्य को कोड की आवश्यकता है, तो कोडर को कॉल करें; यदि अनुसंधान की आवश्यकता है, तो शोधकर्ता को कॉल करें。
- **短而有边界的对话。**ग्राहक सहायता प्रश्न-से-टिकट सरल कार्यप्रवाह

### स्वाम 吃力的场景

- **带共享 memory 的长 sessions。**हाथों को बातचीत की स्थिति को पुनर्स्थापित करने के लिए नए एजेंट के लिए त्वरित और इतिहास के साथ।
- **并行执行。**हाथ एक बार एक active एजेंट होगा चेंज;. समानांतरता  जरूरत है को调用方编排多个Swarm रन。
- **Audit 和 replay。**无状态 runs 很难精确重播;LLM का हस्तांतरण 选择不是确定性的──

### OpenAI एजेंट्स SDK(2025 साल 3 月)

उत्पादन श्रेणी के बाद के उत्तराधिकारी ने जोड़ाः

- **Session state。**跨 runs के स्थायी धागे
- **Guardrails。**输入/输出 सत्यापन हुक
- **Tracing。**हर उपकरण कॉल और हस्तांतरण दर्ज किया जाएगा।
- **Handoff filters。**控制 हस्तान्तरण 时转移哪些上下文──

मूल भाषा को छोड़ना; इसके चारों ओर उत्पादन की उपलब्धता को पूरा करना

### समूह चैट बनाम समूह चैट

两者都使用LLM-चालित मार्ग, लेकिन अंतर में है**谁选择下一个**:

- ग्रुपचैट:由外部的选择者 (外部的选择者) से बाहरी चयनकर्ता (外部的选择者) से बाहरी चयनकर्ता (外部的选择者) से निम्न वक्ता (外部的选择者)
- Swarm:当前 एजेंट 通过调用 हस्तान्तरण उपकरण 选择它的继任者──

Swarm एजेंट तय करता है कि अगला कदम क्या है ;GroupChat  प्रबंधक तय करता है कि अगला कदम क्या है ;;Swarm का निर्णय सक्रिय एजेंट के उपकरण कॉल में होता है ;GroupChat का निर्णय होता है `GroupChatManager`मध्य में

## 关键术语

| Term | 人们的说法 | 它实际意味着什么 |
|------|----------------|------------------------|
| Routine | “Agent prompt” | System prompt + tool list。定义角色和可用 handoffs。 |
| Handoff | “转交给另一个 Agent” | active agent 可以调用的一个 tool，它返回新的 Agent。runtime 会切换 active agent。 |
| Stateless | “runs 之间没有 memory” | Swarm 不持久化任何东西；memory 是调用方的责任。 |
| Active agent | “现在谁在说话” | 当前掌握对话的 Agent。Handoff 会改变它。 |
| Context transfer | “handoff 时移动什么” | incoming agent 能看到哪些 history 的策略：full、last N 或 summarized。 |
| Handoff loop | “Agents 来回 ping-pong” | 两个 Agents 不断 hand back 给对方的失败模式。 |
| OpenAI Agents SDK | “生产级 Swarm” | 2025 年 3 月的后继者；在 handoff 原语之上添加 sessions、guardrails、tracing。 |
| Handoff filter | “转移时的 gate” | SDK feature，用于在 handoff 边界检查和修改上下文。 |
