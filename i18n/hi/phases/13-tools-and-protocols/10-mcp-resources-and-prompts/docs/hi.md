## उपयोगकर्ता का इन्तजार

滥用MCP सबसे आसान तरीका सीधे कोड को लागू करने से शुरू करना है। डेटाबेस क्वेरी क्योंकि फ़ंक्शन जैसे उपकरण बन जाता है; दोहराया जा सकता है कार्यप्रवाह क्योंकि फ़ाइल में संग्रहीत संसाधन बन जाता है; त्वरित क्योंकि होस्ट में डाला जा सकता है, इसलिए छिपे हुए रणनीति बन जाता है।

कृपया सबसे पहले यह चुनें कि कौन आकर चुनता है और वे क्या उम्मीद करते हैं।

| Primitive | 主要意图 | 选择主体 | 典型结果 |
|---|---|---|---|
| Tool | 执行某项操作 | Model 或应用程序 | 结构化动作结果 |
| Resource | 读取特定 URI 的内容 | Host、应用程序或用户 | 文本或二进制内容 |
| Prompt | 启动可复用的消息工作流 | 用户（通过 Host UI） | 一条或多条 prompt 消息 |

位于 `notes://note-1`नोट एक संसाधन है क्योंकि यह पता लगाने योग्य सामग्री है।`delete_note`यह एक उपकरण है, क्योंकि यह बदल जाएगा।`review_note`यह एक त्वरित है, क्योंकि उपयोगकर्ता द्वारा मुख्य रूप से चयनित किया गया है।

 न केवल कार्य पूर्ण दिखने के लिए बल्कि एक ही ऑपरेशन को एक ही समय में इन तीनों के लिए उजागर करने के लिए। प्रत्येक अतिरिक्त सतह के लिए अतिरिक्त खोज, प्राधिकरण, कैशिंग, त्रुटि प्रसंस्करण, परीक्षण और दस्तावेज रखरखाव लागतों की आवश्यकता होती है।

## 2026-07-28 无状态信封

इस कोर्स के लिए एमसीपी 协议 संस्करण `2026-07-28` इस विनियमन विन्यास के तहत, कोई प्रारम्भिकता हाथ मिलाव (Handshake)  या प्रोटोकॉल सत्र (Protocol session)  नहीं है।`_meta`键中携带其协议版本和客户端功能──

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "resources/list",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      },
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
```

सर्वर ज़रूर कार्यान्वित `server/discover` इसके परिणामों को बाहरी घोषणाओं में समर्थित संस्करणों में  संसाधनों और शीघ्र क्षमताओं में  पहचान और कैशिंग सुझावों को प्राप्त करना  कैशिंग सुझावों में  ग्राहक सीधे अन्य तरीकों का उपयोग कर सकता है, लेकिन खोज  ग्राहक  उपयोगकर्ता इंटरफ़ेस के निर्माण में सक्षम होने से पहले एक स्थिर त्वरित छवि प्राप्त कर सकता है 

```json
{
  "resultType": "complete",
  "supportedVersions": ["2026-07-28"],
  "capabilities": {
    "resources": {"listChanged": true, "subscribe": true},
    "prompts": {"listChanged": true}
  },
  "ttlMs": 3600000,
  "cacheScope": "public"
}
```

常规结果会声明 `"resultType": "complete"`                                                                                                                                                                                                                                                              `_meta` 会通过 `io.modelcontextprotocol/serverInfo`标识服务端的实现信息── यह जानकारी निदान के लिए है, पहचान प्रमाण पत्र नहीं है── साथ में असमर्थित अनुबंध संस्करण के अनुरोध पर प्रतिक्रिया होगी `-32022`错误,同时带上所请求的版本以及服务器 支持的版本列表──

无状态契约会重塑你的设计直觉――列表查询不能依赖单条连接上前调用历史―― पहचान अधिकार प्रमाण पत्र अनुरोध के रूप में प्रवेश किया जा सकता है, लेकिन कनेक्शन इतिहास परिणामों को प्रभावित नहीं कर सकता है――

## संसाधन 契约 यानि स्थिर URI

संसाधन URI द्वारा पहचान की गई सामग्री से है।

良好的 URI 应具备的属性:

-  पर्याप्त स्थिर, इसे एक पत्र में शामिल किया जा सकता है या कई बार अनुरोधों के बीच भेजा जा सकता है।
- 划分在服务器的专有命名空间 (नामस्थान) 下。
- 独立于具体进程 ID或连接──
-                                                                                                                                                                                                                                                               
- प्रत्येक पाठ में अधिकार प्राप्त होता है।

`notes://note-1`优于 `note-1`, क्योंकि इसका नामकरण अंतरिक्ष स्पष्ट है. फ़ाइल सर्वर इस्तेमाल किया जा सकता है.`file://`यूआरआई, लेकिन पटल कोड लिंक और सापेक्ष पथ के बाद, अच्छी तरह से विनियोजित सूची सीमाओं का सख्ती से निरीक्षण करना आवश्यक है।

`resources/list`返回调用方当前可见的资源──必需按照稳定键 (उदाहरण के लिए URI) क्रमशः──确定性的 क्रमशः缓存震荡击穿 (Cache misses) 、快照漂移以及主机UI在刷新时发生跳动──

```json
{
  "resultType": "complete",
  "resources": [
    {
      "uri": "notes://note-1",
      "name": "Architecture decision",
      "description": "Why the service uses a stateless boundary",
      "mimeType": "text/markdown"
    }
  ],
  "ttlMs": 300000,
  "cacheScope": "public",
  "_meta": {
    "io.modelcontextprotocol/serverInfo": {
      "name": "notes-server",
      "version": "2.0.0"
    }
  }
}
```

`resources/read`返回一个或多个内容项──未知的URI 不代表读取成功但内容为空──当前资源规范将无效或未知的资源URI 归类为 JSON-RPC 无效参数,错码为`-32602`

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "error": {
    "code": -32602,
    "message": "Unknown or invalid resource URI",
    "data": {
      "uri": "notes://missing"
    }
  }
}
```

इस प्रकार का भेदभाव ग्राहक को स्पष्ट रूप से संसाधनों को पहचानने में सक्षम बनाता है जो कि वैध रिक्त दस्तावेजों के साथ मौजूद नहीं हैं, साथ ही यह भी व्यापक खोजों में अप्रत्याशित वापसी को रोकता है।

## त्वरित है उपयोगकर्ता नियंत्रण का模板

MCP prompt 专为用户显式选择而设计──Host इन्हें染为斜命令 (slash commands) 、菜单项或工作流按──协议本身不限于某种特定 UI 表现形式──

 समान अनुरोध पहचान अधिकार पर निम्नलिखित,`prompts/list`प्रत्येक प्रम्प्ट को एक स्थिर नाम, उपयोगी विवरण, तथा मेजबान को तैनात करने की आवश्यकता होती है।`prompts/get`之前收集输入的参数声明。

```json
{
  "resultType": "complete",
  "prompts": [
    {
      "name": "review_note",
      "title": "Review a note",
      "description": "Review one note for a named concern",
      "arguments": [
        {
          "name": "uri",
          "description": "The note resource URI",
          "required": true
        }
      ]
    }
  ],
  "ttlMs": 600000,
  "cacheScope": "public"
}
```

`prompts/get`एक सूत्र को एक समूह संदेश में हल किया जाएगा। यह होस्ट के सिस्टम निर्देशों को प्रतिस्थापित नहीं करेगा। होस्ट के पास यह निर्णय लेने का अधिकार है कि कैसे लौटने वाला संदेश मॉडल पर नीचे दिए गए अंतिम निर्णय का अधिकार है, और हमेशा अपनी विश्वसनीयता रणनीति को उच्च प्राथमिकता के साथ बनाए रखता है।

सर्वर पर 边界处严格校验提示 参数。Prompt 中引用的 URI 必须通过与直接读取资源 相同的识别权检查──切勿让提示 成为绕过资源 访问控制的侧信道──

## 缓存提示是正确性 का हिस्सा

`ttlMs`告知客户 结果可以多久再用──`cacheScope` किसके द्वारा यह संग्रहण मूल्य साझा किया जा सकता है 

| 范围 | 含义 | 典型用途 |
|---|---|---|
| `public` | 在鉴权许可的前提下可在多用户间复用 | 公共 prompt 目录 |
| `private` | 绑定到请求发起用户或凭证上下文 | 用户名下的私有笔记内容 |

डेटा के परिवर्तन की आवृत्ति और समय के साथ-साथ पुराने नुकसान के आधार पर TTL का चयन करें। सार्वजनिक संकेत के अनुसार, कैलेंडर 5 मिनट के लिए उपयुक्त हो सकता है, जबकि निजी नोट्स पढ़ने के लिए 1 मिनट के लिए उपयुक्त हो सकता है।

एमसीपी 规范中 `cacheScope`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             `public`和 `private` संवेदनशील रहस्य या अत्यधिक बारम्बार परिवर्तन के परिणामों के लिए, लौटाया जाना चाहिए `cacheScope: "private"`配合 `ttlMs: 0`इसके बाद मेजबान के पास भंडारण के लिए अधिक सख्त नियम लागू किए गए।`no-store`本身并非MCP 规范中 `cacheScope`取值──

缓存提示永远不能代替鉴权――缓存键必须包含所有影响可见性的请求维度,包括租户(租户) 、用户、权限范围(范围) 、语言区域(局部) 以及分页游标标(पृष्ठ पृष्ठ के कर्सर) ⋅ यदि साझा缓存 इन आयामों को सुरक्षित रूप से व्यक्त नहीं कर सकता है, तो कृपया उपयोग करें `private`配合 0 TTL, और होस्ट 层 实施 店 策略──

## 订阅 ग्राहक प्रक्षेपण का उपयोग

आधुनिक सदस्यता मोड ने पूर्ववर्ती को बदल दिया है।`resources/subscribe`आरपीसी तथा पुराने संस्करण HTTP GET के घटना端点 पर आधारित हैं।

ग्राहक के लिए सामान्य JSON-RPC अनुरोध के रूप में भेजने `subscriptions/listen`在 Streamable HTTP 传输层上, यह एक POST अनुरोध है, इसकी HTTP 响应 को ओपन स्टेट में रखने के लिए SSE(सर्वर-सेंड इवेंट्स)流`notifications`वस्तु एक श्वेतसूची है। सर्वर 绝绝不能发送未经请求的通知类型──

```json
{
  "jsonrpc": "2.0",
  "id": 17,
  "method": "subscriptions/listen",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {},
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      }
    },
    "notifications": {
      "resourcesListChanged": true,
      "promptsListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

अनुरोध आईडी 即为订阅 आईडी(सब्स्क्राइबशन आईडी) 👇`notifications/subscriptions/acknowledged`通知── इनमें से केवल सर्वर 实际接受的子集── शामिल हैं।

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/subscriptions/acknowledged",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "notifications": {
      "resourcesListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

 बाद में इस धारा पर प्रत्येक घटना एक ही डेटा के साथ है:

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/resources/updated",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "uri": "notes://note-1"
  }
}
```

 सूचना सूचित संसाधन  परिवर्तन हुआ है  ग्राहक वर्तमान में पहचान अधिकार के बंधन के तहत पारित `resources/read`重新读取该资源──客户不应假设通知事件本身就包含最新文档内容──

कई ग्राहक एक ही स्टूडियो को साझा कर सकते हैं।`resultType: "complete"`响应──

切勿将订阅流当作协议会话 (प्रोटोकॉल सत्र) उपयोग──后续的读取操作仍然是完整的独立请求,能够路由至任何健康的服务器 实例──

## 关键术语

- **Resource：**MCP सर्वर 暴露的、通过 URI 寻址的内容──
- **Prompt：**MCP सर्वर 暴露的、由用户控制的消息模板──
- **确定性列表（Deterministic list）：** समान अनुरोध प्रविष्टि के लिए, इसके सदस्य और क्रम स्थिर खोज परिणाम 
- **`ttlMs`：**缓存新鲜度持续时间(毫秒) 
- **`cacheScope`：**缓存结果的共享边界(`public`या `private`)。
- **`subscriptions/listen`：**एक दीर्घ जीवन चक्र अनुरोध, जिसका स्पष्ट रूप से पारगमन के लिए प्रतिक्रिया प्रवाह सूचना प्रदान करना
- **Subscription ID（订阅 ID）：**मूल सुनो अनुरोध की पहचान, सूचना में जानकारी प्राप्त करें
- **无效参数（Invalid parameters）：**JSON-RPC 错误 `-32602`, अप्रभावी या अज्ञात संसाधन यूआरआई हेतु प्रयोग किया जाता है
- **不支持的协议版本（Unsupported protocol version）：**JSON-RPC 错误 `-32022`, समाहित `supported``requested`版本列表──
- **`server/discover`：**强制要求的服务器 方法, वापसी समर्थित संस्करण, क्षमताएँ, सेवा पहचान और चयन योग्य कैशिंग सुझाव
