## 概念

![Bahdanau attention: decoder queries all encoder states](../assets/attention.svg)

प्रत्येक डिकोडर कदम में `t`:

1. उपयोग पिछला एक डिकोडर छिपे हुए राज्य `s_{t-1}`作为 **query**
2. इसे हर एन्कोडर के साथ छिपे राज्य में होगा `h_1, ..., h_T`打分── प्रत्येक एन्कोडर 位置一个 skalar──
3. स्कोर के लिए नरम अधिकतम, ध्यान वजन प्राप्त`α_{t,1}, ..., α_{t,T}`, वे कुल मिलाकर 1 हैं
4. संदर्भ वेक्टर `c_t = Σ α_{t,i} * h_i`संकेतक राज्यों का 加权平均
5. डिसीडर 接收 `c_t`पहले एक आउटपुट टोकन के साथ, अगला टोकन उत्पन्न करें

加权平均才是重点── जब डिकोडर 需要把 "Je" 翻译成 "I" 时,它会让 "Je" 上面的编码状态 权重大,其他位置权重小── जब इसे "not" 时,它会让 "pass" 权重大── संदर्भ वेक्टर 在每一步都重塑──

## आकारों( सबसे आसानी से काटने के लिए लोगों के स्थान)

यह हर ध्यान को लागू करने की पहली बार है जहाँ आप गलत हो जाते हैं।

| Thing | Shape | Notes |
|-------|-------|-------|
| Encoder hidden states `H` | `(T_enc, d_h)` | 如果是 BiLSTM，`d_h = 2 * d_hidden` |
| Decoder hidden state `s_{t-1}` | `(d_s,)` | 一个 vector |
| Attention score `e_{t,i}` | scalar | 每个 encoder 位置一个 |
| Attention weight `α_{t,i}` | scalar | 对所有 `i` 做 softmax 之后 |
| Context vector `c_t` | `(d_h,)` | 与一个 encoder state 的 shape 相同 |

**Bahdanau（additive）score。** `e_{t,i} = v_α^T * tanh(W_a * s_{t-1} + U_a * h_i)`

- `s_{t-1}`का आकार है `(d_s,)`,`h_i`का आकार है `(d_h,)`
- `W_a`का आकार है `(d_attn, d_s)``U_a`का आकार है `(d_attn, d_h)`
-  इनका आकार                                                                                                                                                                                                                                                             `(d_attn,)`
- `v_α`का आकार है `(d_attn,)`与 `v_α`आंतरिक उत्पाद को एक पैमाने में संकुचित करना**这就是 `v_α` 的作用。**यह जादू नहीं है. यह ध्यान-अवकाश वेक्टर को स्कार्चर स्कोर का अनुमान है.

##  इसे निर्माण

### 步骤 1: अतिरिक्त

```python
import numpy as np


def additive_attention(decoder_state, encoder_states, W_a, U_a, v_a):
    projected_dec = W_a @ decoder_state
    projected_enc = encoder_states @ U_a.T
    combined = np.tanh(projected_enc + projected_dec)
    scores = combined @ v_a
    weights = softmax(scores)
    context = weights @ encoder_states
    return context, weights


def softmax(x):
    x = x - np.max(x)
    e = np.exp(x)
    return e / e.sum()
```

 ऊपर दिखाएँ आपके आकारों की जाँच करें`encoder_states`का आकार है `(T_enc, d_h)``projected_enc`का आकार है `(T_enc, d_attn)``projected_dec`का आकार है `(d_attn,)`, और प्रसारित किया जाएगा.`combined`का आकार है `(T_enc, d_attn)``scores`का आकार है `(T_enc,)``weights`का आकार है `(T_enc,)``context`का आकार है `(d_h,)`🏻 इसे प्रकाशित कर सकता हूँ

### 步骤 2: लोंग डॉट 和 जनरल

```python
def dot_attention(decoder_state, encoder_states):
    scores = encoder_states @ decoder_state
    weights = softmax(scores)
    return weights @ encoder_states, weights


def general_attention(decoder_state, encoder_states, W):
    projected = W.T @ decoder_state
    scores = encoder_states @ projected
    weights = softmax(scores)
    return weights @ encoder_states, weights
```

प्रत्येक तीन पंक्ति है। यही कारण है कि लूंग का पेपर  बना सकता है। अधिकांश कार्यों में सटीकता समान है, कोड बहुत कम है।

### 步骤 3: एक पूर्ण संख्यात्मक मान उदाहरण

给定三个编码状态(大致对应 "cat"、"sat"、"mat") तथा एक सबसे निकटतम प्रथम राज्य के विकoder राज्य, ध्यान वितरण 会集中在位置 0。 यदि विकoder राज्य 移动到更接近最后一个编码状态,attention 就会移动到位置 2。 संदर्भ वेक्टर会随之跟踪。

```python
H = np.array([
    [1.0, 0.0, 0.2],
    [0.5, 0.5, 0.1],
    [0.1, 0.9, 0.3],
])

s_close_to_cat = np.array([0.9, 0.1, 0.2])
ctx, w = dot_attention(s_close_to_cat, H)
print("weights:", w.round(3))
```

```
weights: [0.464 0.305 0.231]
```

प्रथम पंक्ति जीत── फिर  डिकोडर स्टेट 移至更接近第三码码状态,观察重量 如何移动──就是如此── ध्यान स्पष्ट संरेखण──

### चरण 4: यह ट्रांसफार्मर के लिए एक पुल क्यों है

इसे ऊपर की भाषा में अनुवादित करें

- **Query**= डिकोडर स्थिति `s_{t-1}`
- **Key**= एन्कोडर राज्यों(हमनेआ来打分的对象)
- **Value**= एन्कोडर राज्यों (((आम्ज़ा加权求和的对象)

क्लासिकल ध्यान में, कुंजी और मान एक ही चीज हैं। स्व-ध्यान उन्हें अलग करेगाः आप एक अनुक्रम क्वेरी  खुद को, के लिए और वी का उपयोग अलग सीखे गए अनुमानों का उपयोग कर सकते हैं।

गणित एक ही है। आकार एक ही है। बहनाऊ ध्यान से लेकर स्केल डॉट-प्रोडक्ट ध्यान तक, मुख्य रूप से केवल संकेतन है।

| Attention | 看东西 | 对 value sequence 做加权平均，weights 由 query-key similarity 计算。 |
| Query, Key, Value | QKV | 三个 projections：Q 发问，K 是要匹配的内容，V 是要返回的内容。 |
| Additive attention | Bahdanau | Feed-forward score: `v^T tanh(W q + U k)`。 |
| Multiplicative attention | Luong dot / general | Score 是 `q^T k` 或 `q^T W k`。更便宜，在大多数任务上 accuracy 相同。 |
| Alignment matrix | 好看的图 | Attention weights 作为 `(T_dec, T_enc)` 网格。读取它可以看到 model attend 到了什么。 |
