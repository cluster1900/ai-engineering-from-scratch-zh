# बोल बोलने वाले पहचान और सत्यापन

> एएसआर प्रश्न है कि वे क्या कहते हैं? स्पीकर मान्यता प्रश्न है कि कौन कहता है? गणित का रूप एक जैसा दिखता है, अर्थात् एम्बेडिंग प्लस कॉसीन, लेकिन प्रत्येक उत्पादन निर्णय एक एकल ईईआर संख्या पर निर्भर करता है।

## 问题

यूजर ने एक वाक्य पासवर्ड कहा है. आप यह जानना चाहते हैंः क्या यह वह व्यक्ति है जिसे वे दावा करते हैं कि वह है? या क्या यह आपके नामांकन बैंक में पहला व्यक्ति है? या क्या यह एक अज्ञात बोल बोलने वाला व्यक्ति है?

2018 साल पहलेःGMM-UBM + i-वेक्टरों。EER 尚可,但对频道转移(फोन बनाम लैपटॉप)和情绪很脆弱──20182022:x-वेक्टरों◆ कोणीय मार्जिन 训练的TDNN脊柱)──2022+:ECAPA-TDNN 和 WavLM-large Embedding──2026 साल तक, इस क्षेत्र में तीन मॉडल और एक सूचक मुख्य हैं──

यह संकेत है**EER**, अर्थात् समान त्रुटि दर── अपने निर्णय मूल्य सेट करें, जिससे गलत स्वीकार दर = गलत अस्वीकार दर──交叉点就是 EER── प्रत्येक लेख、 प्रत्येक लीडरबोर्ड、 प्रत्येक采购评审都会使用它──

##  इसे निर्माण
### 步骤 1: एमएफसीसी के आंकड़ों से 构建玩具 एम्बेडिंग

```python
def embed_mfcc_stats(signal, sr):
    frames = featurize_mfcc(signal, sr, n_mfcc=13)
    mean = [sum(f[i] for f in frames) / len(frames) for i in range(13)]
    std = [
        math.sqrt(sum((f[i] - mean[i]) ** 2 for f in frames) / len(frames))
        for i in range(13)
    ]
    return mean + std  # 26-d
```

离 SOTA 很远, केवल शिक्षण हेतु`code/main.py`इसे सिंथेटिक स्पीकर डेटा के रूप में उपयोग करना

### 步骤 2:कोसिन समानता + सीमा

```python
def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(x * x for x in b))
    return dot / (na * nb) if na and nb else 0.0

def verify(enroll, test, threshold=0.75):
    return cosine(enroll, test) >= threshold
```

### 步骤 3: समानता जोड़े से  गणना ईईआर

```python
def eer(same_scores, diff_scores):
    thresholds = sorted(set(same_scores + diff_scores))
    best = (1.0, 1.0, 0.0)  # (fa, fr, threshold)
    for t in thresholds:
        fr = sum(1 for s in same_scores if s < t) / len(same_scores)
        fa = sum(1 for s in diff_scores if s >= t) / len(diff_scores)
        if abs(fa - fr) < abs(best[0] - best[1]):
            best = (fa, fr, t)
    return (best[0] + best[1]) / 2, best[2]
```

返回 (eer, threshold_at_eer) ⋅ दो रिपोर्ट करना चाहिए

### 步骤 4: स्पीचब्रेन का उपयोग करके उत्पादन को प्राप्त करें

## 陷
- **Channel mismatch。**≠ फोन कॉल ऑडियो──始终在目标频道上评估──
- **短 utterance。**测试音频低于3秒时,EER 会急剧变差──
- **带噪声的 enrollment。**एक शोर भरा नामांकन 会污染 एंकर。 उपयोग ≥3 个干净样本并取平均──
- **跨条件固定阈值。**始终在来自目标域的持久开发集 上调值──
- **对未归一化 Embedding 使用 Cosine。**पहले L2 को सामान्य बनाना; अन्यथा परिमाण 会主导结果──

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| EER | 标题指标 | False Accept = False Reject 时的阈值。 |
| Verification | 1:1 | “这是 Alice 吗？” |
| Identification | 1:N | “是谁在说话？” |
| Open-set | 可能未知 | Test set 可以包含未 enrollment 的说话人。 |
| Enrollment | 注册 | 计算说话人的 reference Embedding。 |
| AAM-softmax | Loss | 带 additive angular margin 的 softmax；强制 cluster separation。 |
| PLDA | 经典 scoring | Probabilistic LDA；在 Embedding 之上做 likelihood-ratio scoring。 |
| DER | Diarization metric | Diarization Error Rate，即 miss + false alarm + confusion。 |
