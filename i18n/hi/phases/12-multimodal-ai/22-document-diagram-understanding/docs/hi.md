# 文档与图表理解

> 文档不是照片──PDF、科学论文、发票或手写表单单包含布局、表格、图表、脚注、页眉和语义结构,这些是普通图像理解无法捕获的──VLM 之前的堆积是一个管道:Tesseract OCR + LayoutLMv3 + 表格抽取演理学──VLM 浪潮使用 OCR-free मॉडल 取代它──Donut (2022) Nougat (2023) DocLLM (2023) 模型 能直接输出结构化标记──到2026年,前沿已经只是把页面图像以2576课程为本地输入 Claude Opus 4.7,结构化标记输输出这些都得到自然本文──三代的 AI 图文.

**Type:** Build
**Languages:** Python (stdlib, layout-aware document parser skeleton)
**Prerequisites:** Phase 12 · 05 (LLaVA), Phase 5 (NLP)

## 学习目标

- 解释文件 AI 的三个时代:ओसीआर पाइपलाइन、ओसीआर मुक्त、वीएलएम-नेटिव。
- 描述 LayoutLMv3 के तीन प्रकार के输入流:文本、布局(bbox)、图像补丁,以及统一掩饰──
- तुलना करें Donut(OCR मुक्त,छवि → मार्कअप)、Nougat(科学论文 → LaTeX)、DocLLM(लेआउट-जाहिर जनरेटिव)、PaliGemma 2(VLM-नेटिव)。
- 新任务选择文件模型 (), 发票,科学论文,手写表单,中文票据)

## 问题

 इस PDF को समझने में कठिनाई है

- 文本内容(90% 的信号)
- लेआउट (पृष्ठ眉,脚注,侧,双格式)
- 表格(行、列、合并单元格)
- 图形和图表──
- हाथ से लिखा हुआ
- 字体与排版(标题 vs 正文) ⋅

मूल ओसीआर पाठ से बाहर निकल जाएगा, लेकिन शेष जानकारी खो देगा।

## 概念

### युग 1  ओसीआर पाइपलाइन(2021年前)

经典 स्टैक:

1. पीडीएफ → प्रति पृष्ठ छवि。
2. टेसरेक्ट (Tesseract) (या व्यावसायिक OCR)
3. लेआउट विश्लेषक 识别 ब्लॉक्स(शीर्षक, तालिका, पैराग्राफ)
4. तालिका संरचना पहचानकर्ता 解析表格──
5. डोमेन नियम + रेगएक्स 抽取字段。

干净的印刷文本 हेतु उपयुक्त 遇到手写、倾斜扫描、复杂表格、非英语文字会崩── प्रत्येक विफलता मोड को अपवाद पथ की आवश्यकता होती है──

### ट्रोकर (2021)

TrOCR(Li et al., arXiv:2109.10282) ने टेसरेक्ट  क्लासिक के सीएनएन-सीटीसी को बदलकर, सिंथेट + वास्तविक ग्रंथ छवि पर प्रशिक्षित किए गए ट्रांसफार्मर एन्कोडर-डेकोडर का उपयोग किया।

### युग 2  ओसीआर मुक्त(2022-2023)

ओसीआर मुक्त मॉडल का पहला विचार यह हैः पूरी तरह से पता लगाने से बाहर निकलना, छवि पिक्सल को सीधे बाहर निकालना 映射为结构化输出──

डोनट ((किम एट अल., arXiv:2111.15664):
- एन्कोडर-डेकोडर ट्रांसफार्मर, एन्कोडर है स्विन-बी
-  आउटपुट एकल समझ में JSON प्रदर्शित करने के लिए उपयोग किया जा सकता है  संचयी मार्कडाउन के लिए, या किसी भी विशिष्ट कार्य योजना 
-  बिना ओसीआर  बिना लेआउट  बिना पता लगाने 

Nougat(Blecher et al., arXiv:2308.13418):
- 专门在科学论文上训练──
- 输出是 拉特克斯 / मार्कडाउन
- 处理 समीकरणों、多 लेआउट、आंकड़े──
- प्रत्येक अभिलेखागार पार्सर को एक मॉडल का उपयोग करना होगा।

ये सामान्यवादी नहीं बल्कि विशेषज्ञ हैं।

### लेआउटLMv3 (2022)

另一条路线──LayoutLMv3(Huang et al., arXiv:2204.08387) OCR को बरकरार रखें, लेकिन लेआउट समझ में शामिल होंः

- 三类输入流:ओसीआर पाठ टोकन, प्रत्येक टोकन के 2D बॉन्डिंग बॉक्स, छवि पैच,
- 跨三种modality 的 मास्क प्रशिक्षण उद्देश्य(मास्क पाठ、मास्क पैच、मास्क लेआउट)
- 下游任务: वर्गीकरण, इकाई निकासी, तालिका QA

LayoutLMv3 OCR पर आधारित दस्तावेज समझ शिखर है। यह प्रदर्शन और发票 पर बहुत मजबूत है।

### डॉकॉलम (2023)

डॉक्यूएलएम ((वांग एट अल., arXiv:2401.00908) LayoutLM का उत्पन्न करने वाला भाई है। यह लेआउट टोकन पर आधारित है।

### गणितीय समीकरणों 和 लैटेक्स 输出

वैज्ञानिक लेख को सटीक लैटेक्स समीकरण की आवश्यकता है 输出──Nougat 就是为此训练的──带 लैटेक्स लक्ष्य 训练的VLMs(Qwen2.5-VL-Math、Nougat व्युत्पन्न) उपलब्ध लैटेक्स उत्पन्न कर सकते हैं──没有明显的拉टेक्स 训练时,VLMs 会产生可读但不精确的转写──

2026 के वैज्ञानिक शोध पत्र पाइपलाइन: पहले PDF 上跑 Nougat, फिर से VLM का उपयोग करें 处理棘手页面──

## 关键术语

| Term | 人们的说法 | 实际含义 |
|------|-----------------|------------------------|
| OCR pipeline | "Tesseract-style" | 分阶段 stack：detect -> OCR -> layout -> rules；确定性、脆弱 |
| OCR-free | "Donut-style" | 跳过显式 OCR 的 image-to-output transformer；单一 model |
| Layout-aware | "LayoutLM" | 输入包含逐 token bbox coordinates；跨 modalities 的统一 masking |
| VLM-native | "Frontier VLM" | 直接把 page image 以高分辨率输入 Claude/GPT/Qwen VLM；无 pipeline |
| DocVQA | "Doc benchmark" | Document VQA 标准；最常被引用的分数 |
| Markup output | "LaTeX / MD" | 结构化输出格式，而不是 free-form text；支持下游自动化 |
