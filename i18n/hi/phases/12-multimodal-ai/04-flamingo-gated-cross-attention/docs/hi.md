## 问题
BLIP-2 32 दृश्य टोकन होगा 输入结 LLM के इनपुट परत── प्रत्येक प्रॉम्प्ट एक छवि जब काम कर सकते हैं── लेकिन यदि आप छवि A को इनपुट करना चाहते हैं, तो इसके लिए कैप्शन उत्पन्न करें; यहाँ छवि B है, इसके लिए कैप्शन उत्पन्न करें; अब छवि C है, इसके लिए कैप्शन उत्पन्न करें यह?LLM का स्व-विवेक  एक स्ट्रिम में छवि टोकन और पाठ टोकन को संसाधित करने की आवश्यकता है, और यह समस्या जटिल हो जाएगी कि कौन से चित्रों में भाग ले सकते हैं।

फ्लेमिंगो का जवाब हैः LLM के इनपुट स्ट्रीम को पूरी तरह से न बदलें। मौजूदा LLM ब्लॉकों के बीच अतिरिक्त क्रॉस-अटेंशन परतों को सम्मिलित करें। पाठ टोकन  अभी भी हमेशा की तरह LLM के कारण से गुजरते हैं।

Flamingo  उत्तर का दूसरा प्रश्न है: प्रत्येक प्रॉम्प्ट में परिवर्तनीय संख्या के चित्रों को कैसे संसाधित किया जाए? 0、1 या多张?

### रिसेप्टर रिसेम्पलर

对于快速中的每张图像,ViT 会生成 N 个补丁代币──感知器复制器有 K 个固定的可学习的潜伏(Flamingo 使用 K=64)──每个复制器块有两个步骤:

1. क्रॉस-अटेंशन: K 个 लटेंट्स तक N 个 पैच टोकन तक उपस्थित होते हैं
2. लातेंट 内部的 स्व-ध्यान + FFN。

经过6 个复制模块 后,输出是K=64 个 dim 1024 के दृश्य टोकन,无论 ViT 生成多少补丁──224x224 图像(196补丁) और 480x480 图像(900补丁)都会输出为64 个复制模块的 टोकन──

对于视频,resampler 会按时间应用: प्रत्येक  के पैच उत्पन्न 64 个潜伏, जबकि temporal positional encoding 让模型区分 t=0 和 t=N── पूर्ण वीडियो 变成 T * 64 个视觉代币──

### ग्लिटेड क्रॉस-अटेंशन

में结 LLM के प्रत्येक M 层 के बीच(Flamingo उपयोग M=4) एक नए गेट पार ध्यान ब्लॉक में插插插入:

```
x_after_llm_block = llm_block(x_before)
cross = cross_attn(x_after, resampler_output)
gated = tanh(alpha) * cross + x_after
x_before_next_block = gated
```

- `alpha`यह एक प्रारंभिक शून्य के लिए सीखने योग्य स्केल है।
- `tanh(0) = 0`, इसलिए प्रारंभ में जब बंद शाखा  योगदान 零──
-  के साथ `alpha`远离零,跨关注 贡献会平滑增长──
- शेष कनेक्शन का अर्थ है कि गेट पूरी तरह से खुला है, और LLM के ग्रंथों को कवर नहीं करेगा; यह केवल इसके ऊपर दृश्य जानकारी जोड़ता है।

### BLIP-2 की तुलना

| | BLIP-2 | Flamingo |
|---|---|---|
| Visual bridge | 输入处一次性使用 Q-Former | 每 M 层使用 gated cross-attention |
| Visual tokens | 每张图像 32 个 | 每张图像每个 cross-attn layer 64 个 |
| Frozen LLM | Yes | Yes |
| Few-shot in-context | 弱 | 强 — 论文的核心 |
| Interleaved inputs | 无原生支持 | Yes，设计目标 |
| Training data | 130M pairs | 1.3B pairs + 43M interleaved pages |
| Parameter count | 188M trained | ~10B trained (cross-attn layers) |
| Compute | 8 个 A100 上数天 | 数千个 TPUv4 上数周 |

## 关键术语
| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Perceiver resampler | "Fixed-latent cross-attention" | 从可变数量的 input patches 中生成 K 个固定 tokens 的 module |
| Gated cross-attention | "Tanh-gated bridge" | residual layer `y = tanh(alpha)*cross + x`，learnable alpha，初始化为 0 |
| Interleaved input | "Mixed sequence" | 图像和文本按阅读顺序自由混合的 prompt format |
| Frozen LLM | "No LLM gradients" | 文本 LLM 的 weights 不更新；只训练 resampler + cross-attn layers |
| Few-shot | "In-context examples" | 在 prompt 中给出少量（image, answer）对；模型无需 finetuning 即可泛化 |
| OBELICS | "Interleaved web corpus" | 包含 141M 个网页的开放数据集，图像和文本按阅读顺序排列 |
| Chinchilla | "70B frozen base" | Flamingo 的冻结文本 LLM，来自 DeepMind 的 Chinchilla paper |
| Gate schedule | "How alpha moves" | 训练期间 cross-attention gate 打开的速率 |
| Cross-attn frequency | "Every M layers" | 插入 gated cross-attention block 的频率；Flamingo 使用 M=4 |
| OpenFlamingo | "Open reproduction" | MosaicML/LAION 的 3-9B 开放 checkpoint；architecture 与 Flamingo 相同 |
