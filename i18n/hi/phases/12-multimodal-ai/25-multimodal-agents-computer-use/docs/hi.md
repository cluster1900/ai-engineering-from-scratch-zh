# मल्टीमोडल एजेंट्स और कंप्यूटर-उपयोग (Capstone)

> 2026 के सीमा उत्पाद एक बहुआयामी एजेंट हैः यह स्क्रीनशॉट पढ़ सकता है, बटन क्लिक कर सकता है, वेब यूआई ब्राउज़ कर सकता है, फॉर्म भर सकता है, और वर्कफ़्लो को समाप्त कर सकता है।SeeClick और CogAgent(2024) ने GUI-ग्राउंडिंग आदिम को साबित किया।

**Type:** Capstone
**语言：**पायथन(stdlib、action schema + एजेंट लूप कंकाल)
**Prerequisites:** Phase 12 · 05（LLaVA）、Phase 12 · 09（Qwen-VL JSON）、Phase 14（Agent Engineering）
**Time:** 约 240 分钟

## 学习目标
- 设计一个多型代理循环:perceive → reason → act → observe → repeat──
- 构建一个GUI ग्राउंडिंग आउटपुट स्कीम(क्लिक करें निर्देशांक, टाइप पाठ, स्क्रोल, ड्रैग),让VLM 能以JSON发发出──
- तुलना करें केवल स्क्रीनशॉट एजेंटों, पहुंच-वृक्ष एजेंटों और हाइब्रिड एजेंटों
- एक छोटे से VisualWebArena स्लाइस में मल्टीमोडल एजेंट बेंचमार्क मूल्यांकन को ऊपर सेट करें

## 问题
एक बुकिंग साइट वर्कफ़्लोः "मुझे 15 अप्रैल के लिए टोक्यो की उड़ान ढूंढो, 800 डॉलर से कम के गलियारे की सीट, बुक करो। "

बहुआयामी एजेंट 需要:

1. 获取浏览क का स्क्रीनशॉट──
2. 将 स्क्रीनशॉट + URL + लक्ष्य 解析为计划──
3. 发出 संरचित क्रिया:क्लिक करें(在 x,y) 、प्रकार "टोक्यो"(在元素 E) 、 नीचे स्क्रॉल करें、select करें(रेडियो बटन) 👇
4.                                                                                                                                                                                                                                                               
5. 观察新状态(下一个截图)。
6. 重复 जब तक कार्य पूरा नहीं हो जाता

प्रत्येक चरण एक मल्टीमोडल VLM कॉल है। VLM आउटपुट को JSON को हल करने योग्य होना चाहिए। त्रुटियां चरणों के पार होती हैं।

## 概念
### जीयूआई ग्राउंडिंग  आदिम

GUI ग्राउंडिंग है: given determining a screenshot 和一条 प्राकृतिक भाषा निर्देश,输出要点击的 (x, y) समन्वय (( या अन्य कार्रवाई)

SeeClick(arXiv:2401.10935) पहला बड़े पैमाने पर खुला परिणाम हैः में सिंथेटिक + असली GUI डेटा ऊपर बारीक-ट्यूनिंग एक VLM, सादा पाठ टोकन 输出坐标──有效──

CogAgent(arXiv:2312.08914) ने घनिष्ठ यूआई के लिए 1120x1120 उच्च-रिज़ॉल्यूशन एन्कोडिंग बढ़ा दी है।

Ferret-UI(arXiv:2404.05719) मोबाइल UI पर केंद्रित है,并与iOS पहुंच डेटा 集成──

आउटपुट प्रारूप आमतौर पर JSON हैः

```json
{"action": "click", "x": 384, "y": 220, "element_desc": "Search button"}
```

`element_desc`पुनर्प्राप्ति में सहायताः यदि निर्देशांक स्क्रीनशॉट के बीच भटकते हैं, तो अर्थिक संकेत सिस्टम को पुनर्स्थापित कर सकते हैं।

### कार्य योजनाएं

एक विशिष्ट कार्य योजना में 6-10 प्रकार की कार्यप्रणाली होती हैः

- `click`: (x, y)
- `type`: (टेक्स्ट, x? y?)
- `scroll`: (दिशा, राशि)
- `drag`(x0, y0, x1, y1)
- `select`: (option_index)
- `hover`: (x, y)
- `navigate`: (url)
- `wait`(ms)
- `done`: (सफलता, स्पष्टीकरण)

एजेंट प्रत्येक चरण में एक कार्रवाई जारी करते हैं. ब्राउज़र के रैपर को निष्पादित करते हुए, नई स्थिति में लौटते हुए.

### 仅截图 vs 可访问性树

两种输入方式:

- केवल स्क्रीनशॉटः पूर्ण छवि, कोई संरचनात्मक जानकारी नहीं।
- पहुँचने योग्य वृक्षःसंरचित DOM/iOS पहुंच जानकारी── भूमि पर स्थापित करने के लिए विश्वसनीय; वृक्ष के लिए उपयुक्त; उपलब्ध स्थानों हेतु हेतु उपयुक्त──
- हाइब्रिडः दो में से सभी, पेड़ के साथ परमाणु क्रियाओं के विश्वसनीय आधार के रूप में, स्क्रीनशॉट के साथ अर्थपूर्ण संदर्भ प्रदान करते हैं।

उत्पादन एजेंटों में हो सकता है हाइब्रिड उपयोग करें। ब्राउज़र स्वचालन।

### दीर्घकालिक स्मृति

एक 20 चरण कार्यप्रवाह 20 张 स्क्रीनशॉट उत्पन्न करेगा──VLM का संदर्भ 很快就会被填满──三种压缩策略:

- सारांश-श्रृंखला: प्रत्येक 5 चरणों के बाद, कुल मिलाकर जो हुआ है, पुराने स्क्रीनशॉट को छोड़ दिया गया है।
- स्किप-फ्रेमः पहला 张、 आखिरी 张, तथा प्रत्येक 3 张 स्क्रीनशॉट को बरकरार रखें
- उपकरण-रिकॉर्ड लॉगः कार्य निष्पादित करें, पूर्ण सामग्री का पाठ लॉग बनाए रखें; पुरानी स्क्रीनशॉट को फिर से न देखें。

क्लाउड का कंप्यूटर उपयोग एपीआई लॉग पैटर्न का उपयोग करें।

### दृश्य उपकरण का उपयोग

ChartAgent(arXiv:2510.04514) के लिए चार्ट समझ  ने दृश्य उपकरण उपयोग शुरू कियाः फसल、 ज़ूम、 ओसीआर、 बाहरी पता लगाने को调用──एजेंट "क्षेत्र (100, 200, 300, 400) में फसल डाल सकते हैं फिर ओसीआर को कॉल करें" 作为工具 कॉल 输出──工具 返回文字;VLM 继续推理──

यह पैटर्न को व्यापक रूप से परिभाषित किया जा सकता हैः सेट-ऑफ-मार्क प्रॉम्प्टिंग, क्षेत्र एनोटेशन और बाहरी पता लगाने के उपकरण एक ही अनुरूप हैं आउटपुट उपकरण कॉल, प्राप्त संरचनात्मक प्रतिक्रिया योजना।

### 2026 के बेंचमार्क

- स्क्रीनस्पॉट-प्रो── लगभग 1k वेब स्क्रीनशॉट ऊपर की GUI ग्राउंडिंग──ओपन SOTA Qwen2.5-VL-72B  लगभग 85%──फ्रंटियर  लगभग 90%──
- VisualWebArena──अंत-से-अंत वेब कार्य(शॉप、फोरम、वर्गीकृत विज्ञापन)──ओपन SOTA 约20%──जेमिनी 3 प्रो 约27%──
- एजेंटविस्टा ((arXiv:2602.23166)。 सबसे कठिन 2026 बेंचमार्क── 12 डोमेन के पार यथार्थवादी कार्यप्रवाह── सीमा मॉडल 得分 27-40%; खुली मॉडल 10-20%──
- वेबएरेना / वेबशॉप── पहले से बेंचमार्क; पहले से ही सीमा पर हैं 和──

### क्यों यह अभी भी कठिन है

एजेंट 性能瓶:

1. 细粒度 दृश्य ग्राउंडिंग──"छोटे एक्स पर क्लिक करें" 经常在移动解析度下失败──
2. दीर्घकालिक नियोजन―10                                                                                                                                                                                                                                                            
3. त्रुटि वसूली── एक बार क्लिक करें 失败(错误 बटन)
4. क्रॉस-पेज संदर्भ──在 टैब या长 फॉर्म 之间跳转会丢失状态──

अनुसंधान दिशाएँःस्मृति वास्तुकलाएँ, स्पष्ट पुनर्विचार, बहुआयामी सत्यापन, कार्रवाई सफलता के स्क्रीनशॉट मैच के लिए उपयोग की जाती हैं)

### कपास्टोन इसे बनाने के लिए

कैपस्टोन कार्यः एक कंप्यूटर-उपयोग एजेंट का निर्माण, यह सक्षम हैः

1. 读取 बुकिंग साइट नकली पृष्ठ का HTML + स्क्रीनशॉट。
2. 规划 बहु-चरण अनुक्रम:खोज → चयन → भरें फॉर्म → सबमिट करें。
3. 发发出与行动方案 匹配的JSON क्रियाएँ──
4.  निश्चित 10-कार्य स्लाइस ऊपर मूल्यांकन

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| GUI grounding | "Click coordinates" | Model 在 screenshot 上针对 instruction 的 target 输出 (x,y) |
| Action schema | "Tool definitions" | 有效 actions（click、type、scroll、drag）的 JSON description |
| Accessibility tree | "Structured DOM" | 来自 browser/iOS APIs 的 machine-readable UI hierarchy |
| Hybrid agent | "Screenshot + tree" | 同时使用 image 和 structured info；比单独使用任一者更可靠 |
| Visual tool use | "Zoom/crop/detect" | Agent 在 plan 中途调用 external vision tools（OCR、detection） |
| Summary-chain | "Memory compression" | 周期性 text summaries 替代很长的 screenshot history |
| VisualWebArena | "E2E web bench" | 2024 benchmark，用于 end-to-end web tasks |
| AgentVista | "2026 hard bench" | 12-domain realistic workflows；即使 Gemini 3 Pro 也只有约 30% |
