## 问题
Qwen-VL  अगस्त 2023 में जारी किया गया था, LLaVA-1.5 और BLIP-2 के लिए प्रत्यक्ष प्रतिक्रिया है।

फ़ैसलाःLLaVA-1.5 运行在 336x336──对照片也可以,但对中文发票或密集电子表格截图没有用──क्यूवेन-वीएल का पहला नवाचार 448x448 和地面边界框 输出,让模型能够指向对象──

视频:Video-LLaMA 堆叠逐编码并把它们给LLM── यह लघु片 के लिए प्रभावी है, लेकिन अधिकांश घंटे के लिए उपयुक्त नहीं है, क्योंकि इस प्रकार के वीडियो का समय轴 केवल संकेत है──Qwen 团队 चाहता है कि समय का एक एकल एन्कोडर समझें──

प्रत्येक पीढ़ी के क्वेन-वीएल में विस्तार हुआ है।

### Qwen2.5-VL(2025 年 2 月)  गतिशील FPS + पूर्ण समय

Qwen2.5VL का प्रमुख परिवर्तन वीडियो है।

- 绝对时间 टोकन──不使用位置索引( फ्रेम 0, 1, 2...),而使用实际时间──"0:04, बिल्ली कूदती है।" 模型会看到与框架 टोकन 交错的`<time>0.04</time>`टोकन
- गतिशील एफपीएस──慢速素材以1 एफपीएस 采样,动作场景以4+ एफपीएस 采样──由用户或训练器选择;M-RoPE 会适应──
- ViT 中的窗口注意──空间注意── खिड़की में प्रवेश करने के लिए खिड़की में प्रवेश करने का उपयोग करना; प्रत्येक隔几层加入全球注意──
- 显式 JSON 输出格式──使用工具-call 数据训练:"{\"工具\": \"क्लिक\", \"कोर्ड्स\": [380, 220]}"──开箱即代理-ready──
- MRoPE-v2 स्केलिंग── स्थान अधिकतम इनपुट के साथ होगा, इसलिए 10 मिनट का वीडियो आवृत्ति सीमा का पूरा उपयोग नहीं करेगा──

### मैथमेटिकल रूप से एम-रोपी

经典 RoPE 使用成对坐标,按位置 `m`旋转维度为 `d``q`:

```
q_rot[2i]   = q[2i]   * cos(m * theta_i) - q[2i+1] * sin(m * theta_i)
q_rot[2i+1] = q[2i]   * sin(m * theta_i) + q[2i+1] * cos(m * theta_i)
theta_i     = 10000^(-2i/d)
```

M-RoPE छिपा हुआ होगा dim 切分为三条带――假设 `d = 96` 32 डिम्स का वितरण 给 temporal、32 给 height、32 给 width── प्रत्येक बैंड 根据自己的轴位置旋转──位于 (t=5, h=10, w=20) के पैच 会在其三条 बैंड 上分别应用旋转`R_t(5)``R_h(10)``R_w(20)`

पाठ टोकन 使用 `t = text_index, h = 0, w = 0`(या एक प्रकार से इसे एकीकरण चयन) के लिए, इसे बनाए रखने के लिए`t = frame_time, h = row, w = col`△ एकल छवि उपयोग `t = 0`

लाभः एक स्थान कोड वह है जिसे पाठ, चित्र और वीडियो को संसाधित करने की आवश्यकता नहीं है, अलग-अलग स्थान कोड या अलग-अलग स्थानों पर।

### गतिशील-एफपीएस 采样逻辑

给定一个时长为 `T`秒的视频和目标 टोकन  बजट `B`:

1. 计算你能承担的最大FPS:`fps_max = B / (T * tokens_per_frame)`
2. से `{1, 2, 4, 8}`中选择满足 `fps <= fps_max`लक्ष्य एफपीएस:
3. यदि गति बल, तो चयन करें FPS से कम FPS
4. 按选定FPS 均采样;中之间插入 `<time>t</time>`टोकन

Qwen2.5VL 会隐式训练这种逻辑;推理时用户通过 `fps`参数控制── एक 60 सेकंड गति क्रम, 4 FPS  81 टोकन 计算, बराबर 19440 टोकन, 32k संदर्भ में 中可管理──

### संरचित एजेंट आउटपुट

Qwen2.5-VL के एजेंट  प्रशिक्षण स्पष्ट रूप से चेहरे की ओर संरचनात्मक उपकरण कॉलः

```
{
  "tool": "mouse_click",
  "coords": [1024, 512],
  "button": "left",
  "modifier": null
}
```

解析是确定性的: मॉडल के लिए JSON.parse. से निष्पादन आउटपुट। तुलना में, फ्रीडम प्रारूप के "क्लिक करें (1024, 512) " को regex और भेदभाव की आवश्यकता है। यह परिवर्तन बताता है कि क्यूवेन2.5 वीएल का स्क्रीनस्पॉट का अनुपात क्यूवेन2-वीएल के 55% से 84% तक बढ़ गया है।

## 关键术语
| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| M-RoPE | "Multimodal RoPE" | hidden dim 中带 temporal、height 和 width bands 的 3D rotary position embedding |
| Dynamic FPS | "Smart sampling" | 根据运动、时长和 Token 预算为每个视频选择的帧采样率 |
| Absolute time token | "Timestamp token" | 在序列中交错插入的 `<time>t</time>`，让模型看到实际秒数而不是帧索引 |
| Window attention | "Local attention" | 为提速而限制在小窗口内的 spatial self-attention；周期性加入 global attention |
| Structured agent output | "JSON mode" | 通过训练数据监督教 VLM 输出可解析 JSON，其中包含 coords 和 tool names |
| min_pixels / max_pixels | "Resolution bounds" | Qwen2.5-VL 的每请求控制项，用来约束总像素数，从而约束 Token 数 |
| Grounding | "Point-at-it" | 将 bounding-box 坐标作为文本 Token 输出；自 Qwen-VL v1 起使用 |
