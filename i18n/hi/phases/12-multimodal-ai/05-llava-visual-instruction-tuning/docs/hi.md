# दृश्य निर्देशों के साथ LLaVA ट्यूनिंग

> LLaVA(2023 साल 4 月) पृथ्वी पर सबसे अधिक कॉपी की गई बहुआयामी वास्तुकला है। यह 2-परत MLP का उपयोग करके BLIP-2 के Q-Former को बदल गया, सरल टोकन संकेतन के साथ फ्लेमिंगो के गेट किए गए क्रॉस-अटेंशन को बदल दिया, और 158k 条 दृश्य-निर्देश प्रशिक्षण में बदल गया। यह डेटा GPT-4 से शुद्ध ग्रंथ से उत्पन्न हुआ। VLM के किसी भी प्रैक्टिशनर ने 2023 से 2026 वर्ष के बीच निर्माण किया। किसी भी LLaVA 变体.

**类型：**构建
**语言：**Python(stdlib、प्रोजेक्टर + निर्देश-टेम्पलेट बिल्डर)
**先修：**चरण 12 · 02(CLIP),चरण 11(LLM इंजीनियरिंग  निर्देशों को समायोजित करना)
**时间：**~ 180 मिनट

## 学习目标

- 构建一个2层 MLP प्रोजेक्टर,将ViT patch Embedding(dim 1024)映射到LLM的 Embedding dim(dim 4096)。
- 走通 LLaVA दो चरणों की नुस्खा:(1) 558k कैप्शन जोड़े में ऊपर प्रदर्शन प्रोजेक्टर संरेखण,(2) 158k GPT-4-जनित मोड़ों में ऊपर प्रदर्शन दृश्य निर्देश ट्यूनिंग
- 构建一个LLaVA-format प्रॉम्प्ट,包含图像 टोकन प्लेसहोल्डर、系统 प्रॉम्प्ट 和 उपयोगकर्ता/सहायक टर्न──
- 解释为什么社区从Q-Former 转向MLP,尽管Q-Former 在 टोकन बजट上有优势──

## 问题

BLIP-2 का Q-Former(Lection 12.03) एक张图像 को 32 个 टोकन में संकुचित करें।

प्रथम, क्यू-पूर्व प्रशिक्षित है, लेकिन इसका नुकसान अंतिम कार्य नहीं है। पहला चरण ITC+ITM+ITG को प्रशिक्षित करता है। दूसरा चरण LM को प्रशिक्षित करता है।

दूसरा, क्यू-फॉर्म में 188 मिलियन पैरामीटर हैं, जबकि एलएलएवीए के 2023 के पैमाने पर, आपको इसे लक्ष्य एलएलएम के साथ रखना होगा।

LLaVA का जवाब सरल से शर्मनाक हैः प्राप्त ViT के 576  पैच टोकन, प्रत्येक टोकन दो परत MLP के माध्यम से अनुमति दें`1024 → 4096 → 4096`), फिर सभी 576 个都塞入 LLM के प्रवेश क्रम में डाल दिया गया है।

डेटा से कहां से आया?LLaVA का दूसरा गुफा见: GPT-4 का उपयोग करें (केवल पाठ) निर्देश डेटा उत्पन्न करें।

结果: एक 8张A100上运行一天、在MMMU上击败弗拉明戈、并发布社区可扩展的开放检查点的VLM──到2023年底,它已经产生了50+叉──

## 概念

### 架构

13B पर LLaVA-1.5:
- दृष्टि एन्कोडरःCLIP ViT-L/14 @ 336(चरण 1 结,चरण 2 可选解)
- प्रोजेक्टरः 2 परत MLP के साथ GELU सक्रियण,`1024 → 4096 → 4096`
- LLM: विंका-13B (बाद में लामा-3.1-8B)

图像 + 文本 शीघ्र का आगे का पासः

```
img -> ViT -> 576 patches of dim 1024
patches -> MLP -> 576 tokens of dim 4096
prompt: system + "<image>" placeholder + user question
replace <image> token with the 576 projected tokens
feed the full sequence to the LLM
decode response
```

图像占用 LLM संदर्भ 中的 576 个 टोकन──在 2048 संदर्भ में 下,文本剩余1472 个 टोकन──在 32k संदर्भ में 下,这只是一个舍进错误──

### चरण 1:प्रोजेक्टर संरेखण

结 ViT──结 LLM──只训练 2-layer MLP──Dataset:558k छवि-शीर्षक जोड़े(LAION-CC-SBU)──Loss:在投影图像 टोकन 条件下,对标题做语言建模──

इस बैच 128 में प्रशिक्षण एक ही युग, कुछ घंटे में पूरा हो सकता है।

### चरण 2: दृश्य निर्देशों को समायोजित करना

解 प्रोजेक्टर ((仍然可训练) ――解 LLM (通常全量,有时使用LoRA)──在158k दृश्य-उपदेश मोड़上训练──

निर्देश डेटा                                                                                                                                                                                                                                                              
1. 取一张 COCO 图像──
2. 提取文本描述(5 条 मानव उपशीर्षक + सीमा-बॉक्स सूची)
3. तीन प्रकार के शीघ्र टेम्पलेट्स का उपयोग करें GPT-4 को भेजेंः
   - वार्तालापः एक उपयोगकर्ता और सहायक का सृजन  इस चित्र के आसपास बातचीत का आदान-प्रदान करना
   - 详细描述:छवि का समृद्ध, विस्तृत विवरण दें।
   - 复杂推理:  एक प्रश्न प्रस्तुत करना जो छवि के आधार पर विचार करने की आवश्यकता है, फिर इसका उत्तर देना
4. 将 GPT-4 का输出解析为(उपदेश, प्रतिक्रिया) जोड़े

 पूरी प्रक्रिया सीधे चित्र से संपर्क नहीं करती केवल पाठ से संपर्क करती  GPT-4 में कुछ ध्वनि होती                                                                                                                                                                                                                                                  

### क्यों समुदाय इस योजना को दोहराया

-  कोई समायोजन की आवश्यकता नहीं है- चरण-1 विशिष्ट हानि── पूर्ण प्रयोग LM हानि──
- प्रोजेक्टर को दिन के समय के बजाय समय के साथ प्रशिक्षित किया जाता है।
-  केवल पुनः प्रशिक्षण प्रोजेक्टर के माध्यम से, LLM को बदल सकते हैं  LLaVA-Llama2、 LLaVA-Mistral、 LLaVA-Llama3) 
- दृश्य-निर्देश डेटा पाइपलाइन GPT-4 का उपयोग करते हुए, और नए क्षेत्र के लिए पुनः उत्पन्न की लागत बहुत कम है।

### LLaVA-1.5 और LLaVA- NEXT

LLaVA-1.5(2023 年 10 月)加入:
- शैक्षणिक कार्य डेटा को संयोजित करना
- बेहतर प्रणाली शीघ्रता.
- 2048 → 32k संदर्भ

LLaVA-NEXT(2024 साल 1 月)加入:
- AnyRes:把高分辨率图像切成2x2或1x3 网格的336x336 फसल,再加一个全球低分辨率 लघु图片──每种 फसल 变成576 个标签;每张图像总计约2880 个视觉标签──OCR和图表 任务大幅提升──
- उपयोग ShareGPT4V(高质量 GPT-4V कैप्शन) के बेहतर निर्देश डेटा मिश्रण
- अधिक强的基础LLMs(मिस्ट्रल-7बी、Yi-34B)

### LLaVA-OneVision

पाठ 12.08 会深入讲 OneVision──简短版: एक ही प्रोजेक्टर के साथ, लेकिन एक पाठ्यक्रम के साथ 训练, एक मॉडल में एकल-छवि, बहु-छवि और वीडियो को कवर,并共享视觉标志预算──

### Q-Former के साथ तुलना

| | Q-Former（BLIP-2） | MLP（LLaVA） |
|---|---|---|
| 每张图像的 visual Token | 32 | 576（base）或 2880（AnyRes） |
| 可训练参数 | 188M + LM | 40M + LM |
| Stage 1 loss | ITC+ITM+ITG | 仅 LM |
| LLM drop-in | 需要重新训练 | 最小重新训练即可替换 |
| Multi-image | 别扭 | 自然（concat） |
| Video | 别扭 | 自然（per-frame concat） |
| Token budget | 小 | 大 |

एमएलपी 赢在简单性和 टोकन 灵活性──Q-पूर्व 赢在 टोकन बजट──2023 साल के अंत तक, टोकन बजट 已经不再是约束瓶(एलएलएम संदर्भ 增长到32k-128k+),简单性占上风──

## इसका उपयोग करें

`code/main.py`实现:

1. 纯 Python 中的 2 लेयर एमएलपी प्रोजेक्टर(खेल के पैमाने 下dim 16 → 32 → 32)。
2. त्वरित निर्माण पाइपलाइनः सिस्टम प्रॉम्प्ट + 用 N 个 प्रोजेक्टेड टोकन 替换 `<image>`+ उपयोगकर्ता बारी + सहायक पीढ़ी प्लेसहोल्डर。
3. एक विज़ुअलाइज़र, जिसका उपयोग 576-टोकन विज़ुअल ब्लॉक को LLM संदर्भ में दिखाए जाने के लिए किया जाता है।

## 关键术语

| 术语 | 人们的说法 | 它实际上的含义 |
|------|----------------|------------------------|
| Projector | “MLP bridge” | 带 GELU 的 2-layer MLP，将 ViT dim 映射到 LLM dim |
| Image Token | “<image> placeholder” | Prompt marker，在 inference 前被 N 个 projected visual Token 替换 |
| Visual instruction tuning | “LLaVA stage 2” | 在 GPT-4-generated（image, instruction, response）triplets 上训练 |
| Stage 1 alignment | “Projector pretraining” | 冻结 ViT 和 LLM，用 captions 上的 LM loss 训练 projector |
| AnyRes | “Multi-crop tiling” | 将高分辨率图像切分为 tile grid，并拼接每个 tile 的 visual Token |
| LLaVA-Instruct | “GPT-4-generated” | 从 COCO captions + GPT-4 合成的 158k instruction-response pairs |
| Vision encoder freeze | “Backbone locked” | CLIP weights 在 stage 1 不更新，有时在 stage 2 也不更新 |
| ShareGPT4V | “Better captions” | 由 GPT-4V 生成的 1M dense captions，用于更高质量 alignment |
| VQA | “Visual question answering” | 回答关于图像的自由形式问题的任务 |
| Prismatic VLMs | “Design-space paper” | Karamcheti 2024 ablation，系统测试 projector 和 data choices |
