AI Engineering from Scratch

开发者资源

这是 AI Engineering from Scratch 的机器可读入口。该项目是一套静态的开源课程，而不是托管式应用 API。Agent 和开发者 Tool 应从 llms.txt 开始，该文件将课程映射到其规范页面和原始 Markdown 源文件。

稳定资源

  • /llms.txt 是面向 Agent 的课程地图。
  • /sitemap.xml 列出了规范公开 URL。
  • /openapi.json 描述了只读资源接口。
  • /catalog.html 是可搜索的人工阅读课程目录。
  • GitHub 是课程、代码、测验和可复用产物的权威来源。

Markdown 内容协商

使用 Accept: text/markdown 请求首页或主要导航路由时，会收到 Agent 地图，且 Content-Type: text/markdown。响应会根据 Accept 而变化，因此缓存不会混用 HTML 和 Markdown 表示。

MCP 状态

该网站目前不提供托管式 MCP server 或需要身份验证的产品 API。本课程确实会教授如何构建和运行 MCP server，相关课程产物位于 repository 中。远程 Streamable HTTP MCP endpoint 需要单独的产品决策、身份验证策略和运维负责人。
