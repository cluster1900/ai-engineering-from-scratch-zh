关于这个项目

AI Engineering from Scratch 是一套免费、open-source 的课程体系，手写构建每一个核心 AI 算法。覆盖 20 个 phase 的 503 节课，从 linear algebra 到 autonomous agents，使用 Python、TypeScript、Rust 和 Julia。

它为什么存在

大多数 AI 材料都是碎片化教学：这里一篇论文，那里一篇 fine-tuning 文章，别处又有一个 framework demo。你可以交付一个 chatbot，却无法解释它的 loss curve；也可以把一个工具接到 agent 上，却不知道调用它的模型内部的 attention 到底做了什么。

这套课程体系就是主干。每个算法都会先从原始数学手写出来，然后再用 production library 运行一遍，让你看清 library 背后做了什么。等 PyTorch 出现时，你已经知道它在计算什么。每节课都以一个可复用 artifact 结束，你可以留下它：一个 prompt、一个 skill、一个 agent，或一个 MCP server。

它是如何制作的

课程在 AI 辅助下编写，并由人工对照一手来源审阅。凡是课程陈述事实的地方，都会引用原始来源：RFC、spec 或 research paper，而不是二手总结。欢迎修正，所有修正都会在 GitHub 上公开追踪。

网站本身刻意保持简洁：手写 HTML、CSS 和 vanilla JavaScript，没有 framework。单个构建脚本（site/build.js）会在每次部署时读取 repository 中的课程 Markdown，并生成 catalog、search index、sitemap 和 llms.txt，因此发布出来的数字永远不会偏离源内容。它托管在 Vercel 上。

由谁构建

中文版由 cluster1900 和贡献者维护，源自 Rohit Ghumare 的原始课程。它采用 MIT license，并且永久免费。没有 token，没有课程加售，也没有 gated content。
