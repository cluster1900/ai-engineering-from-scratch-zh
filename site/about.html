关于本项目

AI Engineering from Scratch 是一套免费、开源的课程体系，带你亲手构建每一种核心 AI 算法。课程体系涵盖 20 个阶段中的每一节已发布课程，从 Linear Algebra 到自主 Agent，并使用 Python、TypeScript、Rust 和 Julia。

它为何存在

大多数 AI 资料都以零散片段的方式教学。这里一篇论文，那里一篇 Fine-tuning 文章，别处又有一个框架演示。你可以在无法解释 Loss 曲线的情况下发布聊天机器人，也可以在不知道调用 Tool 的 Model 内部 Attention 如何工作的情况下，将 Tool 接入 Agent。

这套课程体系就是学习主干。每种算法都会先从基础数学开始编写，再使用生产级库运行相同内容，让你看清库实际完成了什么。等学到 PyTorch 时，你已经知道它计算的是什么。每节课程最后都会交付一个供你保留的可复用产物：Prompt、Skill、Agent 或 MCP server。

它如何制作

课程在 AI 辅助下编写，并由人工依据一手来源进行审核。课程中陈述事实时，会引用原始资料：RFC、规范或研究论文，而不是二手摘要。我们欢迎纠错，所有修正都会在 GitHub 上公开跟踪。

网站本身刻意保持简洁：使用手写 HTML、CSS 和原生 JavaScript，不使用框架。每次部署时，单个构建脚本（site/build.js）都会读取 repository 中的课程 Markdown，并生成课程目录、搜索索引、站点地图和 llms.txt。公开的课程数量从这些生成的数据中读取。网站托管在 Vercel 上。

由谁构建
