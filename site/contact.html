联系我们

AI Engineering from Scratch 以公开方式维护。联系维护者和贡献者最快的方式是通过项目 repository。问题会与其描述的课程或行为保持关联，从而能够结合上下文获得解答。

项目支持

  • 报告 bug 或提议新增课程。
  • 发起讨论，交流学习问题、想法并寻求社区帮助。
  • 联系维护者的个人资料页面，沟通公开项目事务。

负责任地报告问题

请勿在 issue 中发布 secret、学习者隐私数据或 credential。对于涉及漏洞且与安全相关的报告，请为该 repository 创建私有 GitHub security advisory。对于一般的内容、可访问性、课程或站点问题，请提供 URL、预期行为、实际行为和最小复现步骤。
